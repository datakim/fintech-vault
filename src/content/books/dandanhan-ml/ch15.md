이 장의 실습 문제는 모두 Python(numpy, pandas)으로 직접 구현해 실행한 결과를 실었습니다. 수박 데이터 세트 2.0은 표 4.1, 2.0α는 표 4.4를 그대로 옮겼고, 수박 데이터 세트 5.0은 표 4.2의 훈련 세트와 417쪽의 '정도' 순서로 만들었습니다. 15.1에서 만든 `rules.py`, 15.3의 `ripper.py`, 15.5의 `wm50.py`, 15.6의 `lgg.py`는 뒤의 문제에서 다시 씁니다.

양성 클래스는 '잘 익은 수박'(5.0에서는 '더 좋음')이고, 별도로 적지 않으면 학습한 규칙은 모두 양성 클래스에 대한 규칙입니다. 규칙 집합이 커버하지 못하는 샘플은 디폴트 규칙(409쪽)으로 음성이라고 판정합니다.

## 문제 15.1

> 수박 데이터 세트 2.0에 대해 부정 형식의 문자를 포함해 하향식 전략으로 명제 규칙 집합을 학습하라.

**풀이**

**설정.** 후보 문자는 긍정 문자 $(a = v)$와 부정 문자 $\neg(a = v)$입니다. 하향식 단일 규칙 생성은 412~413쪽의 방법을 그대로 따릅니다.

1. 빈 규칙 '잘 익은 수박 ←'에서 시작합니다.
2. 후보 문자를 하나씩 붙여 보고, 새 규칙이 현재 훈련 세트에서 커버하는 양성 수 $n$과 전체 수 $m$으로 정확도 $n/m$을 계산합니다.
3. 정확도가 가장 높은 문자를 고르고, 정확도가 같으면 커버하는 샘플 수가 많은 쪽, 그것도 같으면 속성 순서가 앞인 쪽을 고릅니다(413쪽의 기준). 같은 속성 안에서는 긍정 문자를 부정 문자보다 먼저 봅니다.
4. 규칙이 음성을 하나도 커버하지 않을 때까지 2~3을 반복합니다.

순차적 커버링(410쪽)은 이렇게 만든 규칙이 커버한 양성 샘플을 훈련 세트에서 지우고, 양성이 남지 않을 때까지 다음 규칙을 학습합니다. 한 속성에 긍정 문자가 들어가면 그 속성의 다른 문자는 더 붙이지 않고, 부정 문자는 같은 속성에 여러 개 붙을 수 있게 했습니다(3값 속성에서 $\neg(a=v_1) \wedge \neg(a=v_2)$는 $(a=v_3)$와 같습니다).

**구현이 책과 같은지 먼저 확인합니다.** 책은 표 4.2의 훈련 세트(샘플 1, 2, 3, 6, 7, 10, 14, 15, 16, 17)로 두 가지 예를 보여 줍니다. 아래 코드의 `exhaustive`(411쪽처럼 길이 1, 2, ... 순으로 사전식 탐색해 처음 찾은 일관된 규칙을 채택)는 411쪽의 규칙 1~4를 그대로 냅니다.

```
잘 익은 수박 ← (색깔 = 청록색) ∧ (꼭지 = 약간 말림)
잘 익은 수박 ← (색깔 = 청록색) ∧ (소리 = 혼탁)
잘 익은 수박 ← (색깔 = 진녹색) ∧ (꼭지 = 말림)
잘 익은 수박 ← (색깔 = 진녹색) ∧ (줄무늬 = 약간 흐림)
```

`grow`(부정 문자 없이)는 그림 15.1의 숫자를 모두 재현합니다. 첫 라운드는 색깔 = 청록색(2/4), 색깔 = 진녹색(3/4), 꼭지 = 말림(3/5), 소리 = 혼탁(4/6), 줄무늬 = 선명함(4/6), 배꼽 = 움푹 패임(3/4), 감촉 = 단단함(3/6)으로 '색깔 = 진녹색'이 뽑히고, 두 번째 라운드에서 100%가 되는 문자 5개(꼭지 = 말림 2/2, 소리 = 둔탁 1/1, 줄무늬 = 약간 흐림 1/1, 배꼽 = 움푹 패임 2/2, 감촉 = 단단함 2/2) 가운데 '꼭지 = 말림'이 뽑혀 그림의 규칙 '잘 익은 수박 ← (색깔 = 진녹색) ∧ (꼭지 = 말림)'이 나옵니다.

공통 코드입니다. 표 4.1을 옮기면서 15장의 규칙 표기에 맞춰 '꼭지 모양', '배꼽 모양'을 '꼭지', '배꼽'으로 줄였습니다.

```python
# rules.py
import io
import numpy as np
import pandas as pd

# 표 4.1 수박 데이터 세트 2.0 (15장 규칙 표기에 맞춰 '꼭지 모양'→꼭지, '배꼽 모양'→배꼽)
CSV = """번호,색깔,꼭지,소리,줄무늬,배꼽,감촉,잘 익은 수박
1,청록색,말림,혼탁,선명함,움푹 패임,단단함,예
2,진녹색,말림,둔탁,선명함,움푹 패임,단단함,예
3,진녹색,말림,혼탁,선명함,움푹 패임,단단함,예
4,청록색,말림,둔탁,선명함,움푹 패임,단단함,예
5,연녹색,말림,혼탁,선명함,움푹 패임,단단함,예
6,청록색,약간 말림,혼탁,선명함,약간 패임,물렁함,예
7,진녹색,약간 말림,혼탁,약간 흐림,약간 패임,물렁함,예
8,진녹색,약간 말림,혼탁,선명함,약간 패임,단단함,예
9,진녹색,약간 말림,둔탁,약간 흐림,약간 패임,단단함,아니오
10,청록색,곧음,맑음,선명함,평평함,물렁함,아니오
11,연녹색,곧음,맑음,흐림,평평함,단단함,아니오
12,연녹색,말림,혼탁,흐림,평평함,단단함,아니오
13,청록색,약간 말림,혼탁,약간 흐림,움푹 패임,단단함,아니오
14,연녹색,약간 말림,둔탁,약간 흐림,움푹 패임,단단함,아니오
15,진녹색,약간 말림,혼탁,선명함,약간 패임,물렁함,아니오
16,연녹색,말림,혼탁,흐림,평평함,단단함,아니오
17,청록색,말림,둔탁,약간 흐림,약간 패임,단단함,아니오"""
LABEL = "잘 익은 수박"
df = pd.read_csv(io.StringIO(CSV), index_col="번호")
Y = (df[LABEL] == "예").to_numpy()
TRAIN = [1, 2, 3, 6, 7, 10, 14, 15, 16, 17]                # 표 4.2 상반부(훈련 세트)
ATTRS = [c for c in df.columns if c != LABEL]
VALUES = {a: list(dict.fromkeys(df[a])) for a in ATTRS}    # 표에 처음 나온 순서

def lit_mask(d, lit):                       # 문자 lit = (속성, 값, 부정 여부)
    a, v, neg = lit
    m = (d[a] == v).to_numpy()
    return ~m if neg else m

def body_mask(d, body):                     # 규칙 본체(논리곱)가 커버하는 샘플
    m = np.ones(len(d), bool)
    for lit in body: m &= lit_mask(d, lit)
    return m

def candidates(neg=True):                   # 순서: 속성 순서 → 긍정 문자 → 부정 문자
    for a in ATTRS:
        for v in VALUES[a]: yield (a, v, False)
        if neg:
            for v in VALUES[a]: yield (a, v, True)

def show_lit(l):
    return f"¬({l[0]} = {l[1]})" if l[2] else f"({l[0]} = {l[1]})"

def show(body, head="잘 익은 수박"):
    return f"{head} ← " + " ∧ ".join(map(show_lit, body))
```

하향식 생성과 순차적 커버링입니다. `general=True`는 아래에서 설명할 동점 처리 변형입니다.

```python
# p151.py
import itertools
import numpy as np
from rules import df, Y, TRAIN, candidates, lit_mask, body_mask, show, show_lit

def grow(d, y, neg, verbose=False, general=False):
    """하향식: 빈 규칙에서 시작해 (정확도, 커버 수, 순서)로 문자를 하나씩 추가"""
    body, cov = [], np.ones(len(d), bool)
    while (cov & ~y).any():
        best = None
        for lit in candidates(neg):
            if any(l[0] == lit[0] and not l[2] for l in body):  # 이미 값이 고정된 속성
                continue
            new = cov & lit_mask(d, lit)
            p, n = (new & y).sum(), (new & ~y).sum()
            if p == 0 or (new == cov).all():
                continue
            if verbose: print(f"   {show_lit(lit)} ({p}/{p+n})")
            key = (p / (p + n), p, lit_mask(df, lit).sum() if general else 0)
            if best is None or key > best[0]:            # 동점이면 먼저 나온 문자
                best = (key, lit, new)
        body.append(best[1]); cov = best[2]
        if verbose: print(" →", show(body))
    return body

def sequential_covering(d, y, neg, general=False):
    keep, R = np.ones(len(d), bool), []
    while (keep & y).any():
        body = grow(d[keep], y[keep], neg, general=general)
        cov = body_mask(d, body)
        R.append((body, list(d.index[cov & y]), list(d.index[cov & ~y])))
        keep &= ~(cov & y)                                # 커버된 양성 샘플 제거
    return R

def exhaustive(d, y):
    """책 411쪽: 길이 1, 2, ... 순으로 사전식 탐색해 처음 찾은 일관된 규칙 채택"""
    keep, R, lits = np.ones(len(d), bool), [], list(candidates(False))
    while (keep & y).any():
        for L in itertools.count(1):
            found = None
            for body in itertools.combinations(lits, L):
                if len({l[0] for l in body}) < L: continue
                m = body_mask(d, body) & keep
                if (m & y).any() and not (m & ~y).any(): found = body; break
            if found: break
        R.append(found); keep &= ~body_mask(d, found)
    return R

if __name__ == "__main__":
    tr = df.loc[TRAIN]; ytr = Y[[i - 1 for i in TRAIN]]
    for b in exhaustive(tr, ytr): print(" ", show(b))      # 411쪽 규칙 1~4
    grow(tr, ytr, neg=False, verbose=True)                  # 그림 15.1
    for neg, gen in [(False, False), (True, False), (True, True)]:
        print(f"[부정 문자 {neg}, 일반성 동점 처리 {gen}]")
        for body, P, N in sequential_covering(df, Y, neg, gen):
            print(f"  {show(body)}   양성 {P} 음성 {N}")
```

**실행 결과 (수박 데이터 세트 2.0의 17개 샘플 전체)**

부정 문자를 후보에 넣고 책의 기준으로 학습한 규칙 집합은 다음과 같습니다.

| 순서 | 규칙 | 커버하는 양성 |
|------|------|--------------|
| 1 | 잘 익은 수박 ← (줄무늬 = 선명함) ∧ (감촉 = 단단함) | 1, 2, 3, 4, 5, 8 |
| 2 | 잘 익은 수박 ← (감촉 = 물렁함) ∧ (줄무늬 = 약간 흐림) | 7 |
| 3 | 잘 익은 수박 ← (줄무늬 = 선명함) ∧ (색깔 = 청록색) ∧ (꼭지 = 약간 말림) | 6 |

세 규칙 모두 음성을 하나도 커버하지 않으므로 훈련 정확도는 100%입니다. 그런데 이 결과는 부정 문자를 후보에서 뺐을 때와 완전히 같습니다. 부정 문자가 뽑히지 않은 이유는 매 라운드에서 부정 문자가 긍정 문자를 이기지 못했기 때문입니다. 실제로 동점이 된 경우를 보면 다음과 같습니다.

- 규칙 1의 두 번째 문자: (감촉 = 단단함)과 ¬(감촉 = 물렁함)이 6/6으로 동점입니다. 감촉은 값이 두 개뿐이라 두 문자는 같은 조건입니다.
- 규칙 2의 두 번째 문자: (줄무늬 = 약간 흐림)과 ¬(줄무늬 = 선명함)이 1/1로 동점입니다.
- 규칙 3의 세 번째 문자: (꼭지 = 약간 말림), ¬(꼭지 = 곧음), (소리 = 혼탁), ¬(소리 = 맑음), (배꼽 = 약간 패임), ¬(배꼽 = 평평함)이 모두 1/1입니다.

동점에서는 순서상 먼저인 긍정 문자가 뽑힙니다. 그런데 동점인 두 문자의 차이는 남은 훈련 세트 밖에 있습니다. 예를 들어 ¬(꼭지 = 곧음)은 '말림 또는 약간 말림'이라서 (꼭지 = 약간 말림)보다 일반적인 조건입니다. 순차적 커버링은 이미 커버한 양성을 지워 버리므로, 이 일반성의 차이가 남은 데이터에서는 보이지 않는 것입니다.

그래서 동점일 때 **전체 데이터에서 더 많은 샘플을 만족하는 문자**(더 일반적인 문자)를 고르도록 기준을 하나 더 붙여 보면(`general=True`), 부정 문자가 실제로 쓰입니다.

| 순서 | 규칙 | 커버하는 양성 |
|------|------|--------------|
| 1 | 잘 익은 수박 ← (줄무늬 = 선명함) ∧ (감촉 = 단단함) | 1, 2, 3, 4, 5, 8 |
| 2 | 잘 익은 수박 ← (감촉 = 물렁함) ∧ ¬(줄무늬 = 선명함) | 7 |
| 3 | 잘 익은 수박 ← (줄무늬 = 선명함) ∧ ¬(꼭지 = 곧음) ∧ ¬(색깔 = 진녹색) | 1, 4, 5, 6 |

규칙 2는 '줄무늬가 선명하지 않고 물렁한 수박'이고, 규칙 3은 '줄무늬가 선명하고, 꼭지가 곧지 않으며, 진녹색이 아닌 수박'입니다. 훈련 세트에서의 성능은 앞의 규칙 집합과 같지만(정확도 100%), 규칙 3은 양성 4개를 커버하는 더 일반적인 규칙이 되었습니다. 정리하면 부정 문자는 '두 값 중 하나'를 문자 하나로 표현하게 해 주므로 규칙을 더 짧고 일반적으로 만들 수 있지만, 정확도 기준의 탐욕적 탐색에서는 그 이점이 동점 처리 방식에 따라 드러나기도 하고 숨기도 합니다.

**참고 (표 4.1의 12번 감촉 값).** 4장 해답에서 확인했듯 12번 샘플의 감촉은 원서에서 '물렁함'일 가능성이 큽니다. 12번을 '물렁함'으로 바꾸면 규칙 1은 그대로이고, 규칙 2와 3이 다음처럼 바뀝니다. 규칙 2 '(감촉 = 물렁함) ∧ (줄무늬 = 약간 흐림)'이 12번을 커버하지는 않지만, 첫 문자 선택 단계의 정확도가 달라지기 때문입니다.

- 부정 문자 없음(또는 책의 기준): (배꼽 = 약간 패임) ∧ (소리 = 혼탁) ∧ (색깔 = 청록색) → 6, (색깔 = 진녹색) ∧ (소리 = 혼탁) ∧ (줄무늬 = 약간 흐림) → 7
- 일반성 동점 처리: (배꼽 = 약간 패임) ∧ ¬(소리 = 둔탁) ∧ ¬(색깔 = 진녹색) → 6, (색깔 = 진녹색) ∧ ¬(소리 = 둔탁) ∧ ¬(줄무늬 = 선명함) → 7

## 문제 15.2

> 수박 데이터 세트 2.0에 대해 학습 과정에서 문자 제거, 규칙 일반화 등을 통해 상향식 전략으로 명제 규칙 집합을 학습하라.

**풀이**

상향식 전략(412쪽)은 가장 특수한 규칙에서 출발해 문자를 지우거나 조건을 넓혀 가며 일반화합니다. 다음처럼 구현했습니다.

1. **씨앗.** 아직 커버되지 않은 양성 샘플 중 번호가 가장 작은 것을 고르고, 그 샘플의 속성값 6개를 모두 본체에 넣은 규칙(그 샘플만 커버하는 가장 특수한 규칙)에서 시작합니다.
2. **일반화 연산.** 한 단계 일반화로 두 가지를 씁니다.
   - 문자 제거: 본체에서 문자 하나를 지웁니다.
   - 규칙 일반화(완화): 긍정 문자 $(a = v)$를 부정 문자 $\neg(a = w)$ ($w \ne v$)로 바꿉니다. 3값 속성에서 $\neg(a = w)$는 $v$와 세 번째 값을 모두 허용하므로 $(a = v)$보다 일반적입니다.
3. **선택.** 음성을 하나도 커버하지 않는 일반화만 허용하고, 그중 아직 커버되지 않은 양성을 가장 많이 커버하는 것, 같으면 전체 양성을 더 많이 커버하는 것, 그래도 같으면 문자 수가 적은 것을 고릅니다.
4. 허용되는 일반화가 없으면 멈추고 규칙을 확정합니다. 커버한 양성을 지우고 1로 돌아갑니다.

```python
# p152.py
import numpy as np
from rules import df, Y, ATTRS, VALUES, body_mask, show

def generalizations(body):
    """한 단계 일반화: 문자 하나 삭제, 또는 (a = v)를 ¬(a = w)로 완화"""
    for i, (a, v, neg) in enumerate(body):
        rest = body[:i] + body[i + 1:]
        yield "삭제", rest
        if not neg and len(VALUES[a]) > 2:
            for w in VALUES[a]:
                if w != v: yield "완화", rest[:i] + [(a, w, True)] + rest[i:]

def bottom_up(d, y, keep, seed, verbose=False):
    body = [(a, d.loc[seed, a], False) for a in ATTRS]       # 가장 특수한 규칙
    while True:
        best = None
        for op, g in generalizations(body):
            m = body_mask(d, g)
            if (m & ~y).any(): continue                           # 음성을 덮으면 탈락
            key = ((m & y & keep).sum(), (m & y).sum(), -len(g))
            if best is None or key > best[0]: best = (key, op, g)
        if best is None: return body
        body = best[2]
        if verbose: print(f"    {best[1]}: {show(body)}  새 양성 {best[0][0]}")

def learn(d, y, verbose=False):
    keep, R = y.copy(), []
    while keep.any():
        seed = d.index[keep][0]
        if verbose: print(f"  씨앗 샘플 {seed}")
        body = bottom_up(d, y, keep, seed, verbose)
        m = body_mask(d, body)
        R.append((body, list(d.index[m & y])))
        keep &= ~m
    return R

if __name__ == "__main__":
    for body, P in learn(df, Y, verbose=True):
        print(f"  {show(body)}   양성 {P}")
```

**실행 결과**

일반화 과정은 다음과 같습니다(괄호 안은 그 단계에서 새로 커버하는 양성 수).

- 씨앗 1 (청록색, 말림, 혼탁, 선명함, 움푹 패임, 단단함): 색깔 삭제(3) → 소리 삭제(5) → 꼭지 삭제(5) → 배꼽 삭제(6). 결과 '(줄무늬 = 선명함) ∧ (감촉 = 단단함)'.
- 씨앗 6 (청록색, 약간 말림, 혼탁, 선명함, 약간 패임, 물렁함): 꼭지 삭제 → 소리 삭제 → 줄무늬 삭제로 '(색깔 = 청록색) ∧ (배꼽 = 약간 패임) ∧ (감촉 = 물렁함)'이 된 뒤, (색깔 = 청록색)을 ¬(색깔 = 진녹색)으로, (배꼽 = 약간 패임)을 ¬(배꼽 = 평평함)으로 완화합니다.
- 씨앗 7 (진녹색, 약간 말림, 혼탁, 약간 흐림, 약간 패임, 물렁함): 색깔, 꼭지, 소리, 배꼽을 차례로 삭제한 뒤 (줄무늬 = 약간 흐림)을 ¬(줄무늬 = 선명함)으로 완화합니다.

- 반대로 상향식은 씨앗 샘플에 크게 의존합니다. 씨앗과 일반화 순서가 바뀌면 결과도 쉽게 달라지고, 노이즈가 있는 샘플을 씨앗으로 잡으면 그 샘플만 외우는 규칙이 생깁니다. 책(412쪽)이 하향식이 노이즈에 더 견고하다고 설명하는 이유입니다.

## 문제 15.3

> RIPPER 알고리즘에 대한 코드를 작성하고, 수박 데이터 세트 2.0을 사용해 규칙 데이터 세트를 학습하라.

**풀이**

그림 15.2의 RIPPER를 구현합니다. 구성 요소는 다음과 같습니다.

| 단계 | 구현 내용 |
|------|----------|
| 분할 | 규칙을 하나 만들 때마다 남은 양성·음성을 각각 2:1로 나눠 생성 세트(grow)와 가지치기 세트(prune)로 씁니다. |
| 규칙 생성 | 빈 규칙에서 시작해 FOIL 이득(식 15.3)이 가장 큰 문자를 붙이고, 생성 세트의 음성을 모두 배제할 때까지 반복합니다. |
| 가지치기 (IREP\*) | 규칙 말미의 문자열을 지운 후보 중 가지치기 세트에서 $v^* = (p - n)/(p + n)$이 가장 큰 것을 남깁니다. 동점이면 더 짧은 규칙을 고릅니다. |
| 중단 조건 | 가지치기한 규칙의 가지치기 세트 오류율이 50%를 넘으면($n > p$) 규칙 생성을 멈춥니다. 규칙을 채택하면 커버된 샘플(양성·음성 모두)을 지웁니다. |
| 후처리 (PostOpt) | 각 규칙 $r_i$마다 새로 분할한 뒤, 빈 규칙에서 다시 키운 치환 규칙 $r_i'$와 $r_i$에 문자를 더 붙인 수정 규칙 $r_i''$를 만들고, 둘 다 '규칙 집합 전체의 가지치기 세트 오류'가 최소가 되도록 가지치기합니다. 셋 중 전체 훈련 세트 오류가 가장 작은 것을 남기고, 같으면 문자 수가 적은 것을 남깁니다. |
| 반복 | 그림 15.2의 4~7행처럼 후처리한 규칙 집합이 커버하지 못한 샘플로 IREP\*를 다시 돌려 규칙을 보탭니다. $k = 2$(RIPPER2)로 실행했습니다. |

Cohen(1995)의 원래 RIPPER는 IREP\*의 중단 조건과 후처리 단계의 선택에 최소 기술 길이(MDL)를 씁니다. 여기서는 코드를 짧게 하려고 중단 조건을 IREP의 '오류율 50%' 규칙으로, 후처리의 선택을 '전체 오류 → 문자 수'로 바꿨습니다. 마지막에 기술 길이를 늘리는 규칙을 지우는 단계도 생략했습니다.

가지치기 지표에 대해 한 가지 짚어 둡니다. 416쪽은 IREP\*가 $\frac{\hat m_+ + (m_- - \hat m_-)}{m_+ + m_-}$를 써서 IREP의 정확도를 대체했다고 설명합니다. Cohen(1995)을 보면 이 식은 원래 IREP의 가지치기 지표이고, IREP\*는 이를 $(p - n)/(p + n)$으로 바꿨습니다. 앞의 식은 분모와 $m_-$가 상수이므로 사실상 $p - n$을 비교하는 셈이라, 커버 범위가 큰 규칙을 지나치게 선호한다는 것이 Cohen의 지적입니다. 여기서는 Cohen의 정의를 따랐습니다.

문자를 '이름 → 불리언 배열' 사전으로 넘기도록 만들어서, 15.5의 일차 규칙 학습에도 그대로 쓸 수 있게 했습니다.

```python
# ripper.py
import numpy as np
# 문자 = 이름, M[이름] = 각 샘플(예제)에서 그 문자가 참인지 나타내는 불리언 배열
# 규칙 = 문자 이름의 리스트(논리곱), 규칙 집합 = 규칙 리스트(논리합)

def cov(rule, M, n):
    m = np.ones(n, bool)
    for l in rule: m &= M[l]
    return m

def cov_set(R, M, n):
    m = np.zeros(n, bool)
    for r in R: m |= cov(r, M, n)
    return m

def grow(rule, y, idx, M):
    """FOIL 이득(식 15.3)으로 문자를 붙여 grow 세트의 음성을 모두 배제할 때까지 특화"""
    rule = list(rule)
    while True:
        c = cov(rule, M, len(y)) & idx
        p0, n0 = (c & y).sum(), (c & ~y).sum()
        if n0 == 0 or p0 == 0: return rule
        best, bg = None, 0.0
        for l in M:
            c1 = c & M[l]; p1, n1 = (c1 & y).sum(), (c1 & ~y).sum()
            if p1 == 0: continue
            g = p1 * (np.log2(p1 / (p1 + n1)) - np.log2(p0 / (p0 + n0)))
            if g > bg + 1e-12: best, bg = l, g
        if best is None: return rule
        rule.append(best)

def v_star(rule, y, idx, M):                              # Cohen의 (p - n)/(p + n)
    c = cov(rule, M, len(y)) & idx; p, n = (c & y).sum(), (c & ~y).sum()
    return (p - n) / (p + n) if p + n else 0.0

def prune(rule, score):
    """규칙 말미의 문자열을 지워 가며 score가 가장 큰 접두부를 고른다(동점이면 짧은 것)"""
    cands = [rule[:k] for k in range(1, len(rule) + 1)]
    return max(cands, key=lambda r: (score(r), -len(r)))

def split(idx, y, rng):                                   # 양성·음성 각각 2:1로 grow/prune 분할
    g = np.zeros(len(y), bool)
    for cls in (y, ~y):
        ids = rng.permutation(np.flatnonzero(idx & cls))
        g[ids[: int(np.ceil(len(ids) * 2 / 3))]] = True
    return idx & g, idx & ~g

def irep_star(y, idx, M, rng):
    R, idx = [], idx.copy()
    while (idx & y).any():
        gi, pi = split(idx, y, rng)
        r = grow([], y, gi, M)
        r = prune(r, lambda q: v_star(q, y, pi, M))
        c = cov(r, M, len(y))
        p, n = (c & pi & y).sum(), (c & pi & ~y).sum()
        if n > p or not (c & idx & y).any(): break         # prune 세트 오류율 50% 초과면 중단
        R.append(r); idx &= ~c                             # 커버된 샘플(양성·음성) 제거
    return R

def errors(R, y, M):
    return (cov_set(R, M, len(y)) != y).sum()

def optimize(R, y, M, rng):
    """그림 15.2의 PostOpt: 각 규칙을 치환 규칙·수정 규칙과 비교"""
    R = list(R); allidx = np.ones(len(y), bool)
    for i in range(len(R)):
        gi, pi = split(allidx, y, rng)
        others = R[:i] + R[i + 1:]
        def set_err(q):                                    # q로 바꾼 전체 규칙 집합의 prune 세트 오류
            m = cov_set(others + [q], M, len(y))
            return -((m != y) & pi).sum()
        rep = prune(grow([], y, gi, M), set_err)           # 치환 규칙 r'
        rev = prune(grow(R[i], y, gi, M), set_err)         # 수정 규칙 r''
        R[i] = min([R[i], rep, rev],                       # (간략화) 전체 오류 → 문자 수
                   key=lambda q: (errors(others + [q], y, M), len(q)))
    return R

def ripper(y, M, k=2, seed=0):
    rng = np.random.default_rng(seed)
    R = irep_star(y, np.ones(len(y), bool), M, rng)
    for _ in range(k):
        R1 = optimize(R, y, M, rng)
        rest = ~cov_set(R1, M, len(y))                     # NotCovered(R', D)
        R = R1 + irep_star(y, rest, M, rng)
    return [r for j, r in enumerate(R) if r not in R[:j]]
```

```python
import collections

M = {show_lit(l): lit_mask(df, l) for l in candidates(neg=False)}
```


훈련 오류는 2/17(10번과 15번을 양성으로 잘못 판정)입니다. 과정을 따라가 보면 다음과 같습니다.

1. 첫 IREP\*: 생성 세트 {1, 3, 4, 5, 6, 7, 9, 11, 12, 13, 14, 16}에서는 '(줄무늬 = 선명함)'만으로 음성이 모두 배제되어(음성 10, 15는 가지치기 세트에 들어감) 규칙이 그대로 채택됩니다. 이어서 '(색깔 = 진녹색)'이 만들어지지만 가지치기 세트 오류율이 50%를 넘어 IREP\*가 멈춥니다.
2. 후처리: 치환 규칙과 수정 규칙은 둘 다 '(줄무늬 = 선명함) ∧ (감촉 = 단단함)'까지 자랐다가, 가지치기 세트에서 규칙 집합 오류가 더 작은 '(줄무늬 = 선명함)'으로 다시 잘립니다.
3. 커버되지 않은 샘플 {7, 9, 11, 12, 13, 14, 16, 17}에 IREP\*를 돌려 '(감촉 = 물렁함)'을 보탭니다. 두 번째 반복에서는 바뀌는 것이 없습니다.

분할이 무작위이므로 seed마다 결과가 다릅니다. seed = 1, 2에서는 '잘 익은 수박 ← (줄무늬 = 선명함) ∧ (감촉 = 단단함)' 하나만 남습니다(훈련 오류 2/17, 6번과 7번을 놓침). seed 0~99의 100회 실행에서 훈련 오류는 2개가 86회, 3개 6회, 1개 5회, 0개·4개·8개가 각 1회였고, 가장 자주 나온 규칙은 '(줄무늬 = 선명함)'(56회), '(감촉 = 물렁함)'(52회), '(줄무늬 = 선명함) ∧ (감촉 = 단단함)'(34회)였습니다.

## 문제 15.4

> 규칙 학습은 결측 데이터에 대해서도 학습이 가능하다. 의사결정 트리의 결측값 처리 방식을 모방해, 순차적 커버링에 기반한 명제 규칙 집합을 수박 데이터 세트 2.0α를 통해 학습하라.

**풀이**

4.4.2절은 결측값 문제를 두 질문으로 나눕니다. 속성값이 빠졌을 때 어떻게 분할 속성을 고를지, 그리고 분할 속성의 값이 빠진 샘플을 어떻게 나눌지입니다. 규칙 학습에서 '문자를 하나 붙이는 것'은 트리에서 '한 가지(branch)로 내려가는 것'과 같으므로, 두 답을 그대로 옮길 수 있습니다.

| 의사결정 트리(4.4.2절) | 규칙 학습으로 옮긴 방법 |
|------------------------|------------------------|
| 각 샘플에 가중치 $w_x$(처음에는 1) | 같음. 여기에 현재 규칙이 샘플을 커버하는 정도 $c_x \in [0, 1]$을 둡니다(처음에는 1). |
| 속성 $a$의 평가는 $a$가 결측이 아닌 부분집합 $\tilde D$에서 하고, $\rho$를 곱함(식 4.12) | 문자 $(a = v)$의 정확도를 $\tilde D$에서 가중치 $w_x c_x$로 계산합니다. 정확도가 같으면 $\rho \times$(커버하는 양성 가중치)가 큰 문자를 고릅니다. |
| 결측 샘플은 모든 가지로 들어가되 가중치를 $\tilde r_v w_x$로 조정 | 문자 $(a = v)$를 붙일 때 $a$가 결측인 샘플은 $c_x \leftarrow \tilde r_v c_x$로 일부만 통과합니다. $\tilde r_v$는 현재 커버된 무결측 샘플 중 $a = v$인 비율(식 4.11)입니다. |
| (해당 없음) | 규칙을 채택하면 양성 샘플의 가중치를 $w_x \leftarrow w_x(1 - c_x)$로 줄입니다. 순차적 커버링의 '커버된 샘플 제거'를 부분적으로 하는 것입니다. |

규칙은 커버하는 음성 가중치 $\sum_{x \in D^-} w_x c_x$가 0이 될 때까지 키우고, 남은 가중치가 0.5 이상인 양성이 없으면 학습을 마칩니다. 새 샘플을 판정할 때는 규칙마다 저장해 둔 $\tilde r_v$로 커버 정도를 계산하고(값이 있으면 일치 여부 0/1, 결측이면 $\tilde r_v$를 곱함), 규칙들을 합쳐 $P(\text{양성}) = 1 - \prod_r (1 - c_r)$로 계산해 0.5 이상이면 양성으로 판정합니다.

```python
# p154.py
import io
import numpy as np
import pandas as pd
from rules import LABEL, ATTRS, VALUES

# 표 4.4 수박 데이터 세트 2.0α (빈칸 = 결측)
CSV = """번호,색깔,꼭지,소리,줄무늬,배꼽,감촉,잘 익은 수박
1,,말림,혼탁,선명함,움푹 패임,단단함,예
2,진녹색,말림,둔탁,선명함,움푹 패임,,예
3,진녹색,말림,,선명함,움푹 패임,단단함,예
4,청록색,말림,둔탁,선명함,움푹 패임,단단함,예
5,,말림,혼탁,선명함,움푹 패임,단단함,예
6,청록색,약간 말림,혼탁,선명함,,물렁함,예
7,진녹색,약간 말림,혼탁,약간 흐림,약간 패임,물렁함,예
8,진녹색,약간 말림,혼탁,,약간 패임,단단함,예
9,진녹색,,둔탁,약간 흐림,약간 패임,단단함,아니오
10,청록색,곧음,맑음,,평평함,물렁함,아니오
11,연녹색,곧음,맑음,흐림,평평함,,아니오
12,연녹색,말림,,흐림,평평함,단단함,아니오
13,,약간 말림,혼탁,약간 흐림,움푹 패임,단단함,아니오
14,연녹색,약간 말림,둔탁,약간 흐림,움푹 패임,단단함,아니오
15,진녹색,약간 말림,혼탁,선명함,,물렁함,아니오
16,연녹색,말림,혼탁,흐림,평평함,단단함,아니오
17,청록색,,둔탁,약간 흐림,약간 패임,단단함,아니오"""
d = pd.read_csv(io.StringIO(CSV), index_col="번호")
y = (d[LABEL] == "예").to_numpy()
X = {a: d[a].to_numpy() for a in ATTRS}
known = {a: d[a].notna().to_numpy() for a in ATTRS}

def apply_lit(c, w, a, v, r=None):
    """문자 (a = v) 적용 후 커버 정도. 결측 샘플은 r̃_v 비율만큼 통과(식 4.11)"""
    k = known[a]
    if r is None:
        tot = (w * c)[k].sum()
        r = (w * c)[k & (X[a] == v)].sum() / tot if tot > 0 else 0.0
    return np.where(k, c * (X[a] == v), c * r), r

def grow(w):
    body, c = [], np.ones(len(y))
    while (w * c)[~y].sum() > 1e-9:
        best = None
        for a in ATTRS:
            if a in [l[0] for l in body]: continue
            k = known[a]; wc = w * c
            rho = wc[k].sum() / wc.sum()                      # 식 4.9
            for v in VALUES[a]:
                m = k & (X[a] == v)
                p, n = wc[m & y].sum(), wc[m & ~y].sum()      # D̃ 위에서만 평가
                if p == 0: continue
                key = (p / (p + n), rho * p)                  # 정확도 → ρ로 보정한 커버 양성 가중치
                if best is None or key > best[0]: best = (key, a, v)
        if best is None: break
        c, r = apply_lit(c, w, best[1], best[2])
        body.append((best[1], best[2], r))
    return body, c

def learn():
    w, R = np.ones(len(y)), []
    while (w * y).max() >= 0.5:                               # 아직 절반 이상 남은 양성이 있으면 계속
        body, c = grow(w)
        if (c * w * y).sum() == 0: break
        R.append(body)
        w = np.where(y, w * (1 - c), w)                       # 커버된 만큼 양성 가중치를 덜어냄
    return R

def degree(body):
    c = np.ones(len(y))
    for a, v, r in body: c, _ = apply_lit(c, None, a, v, r)
    return c

if __name__ == "__main__":
    R = learn(); P = np.zeros(len(y))
    for body in R:
        c = degree(body); P = 1 - (1 - P) * (1 - c)
        txt = " ∧ ".join(f"({a} = {v})[r̃={r:.2f}]" for a, v, r in body)
        hit = {i: round(float(x), 2) for i, x in zip(d.index, c) if x > 0}
        print(f"잘 익은 수박 ← {txt}\n   커버 정도 {hit}")
    print("P(잘 익은 수박):", {i: round(float(p), 2) for i, p in zip(d.index, P) if p > 0})
    print("훈련 정확도:", ((P >= 0.5) == y).mean())
```

모든 양성의 $P(\text{양성})$이 1, 모든 음성이 0이 되어 훈련 정확도는 100%입니다.

규칙 1의 계산을 따라가 보겠습니다. 첫 문자 후보 중 (줄무늬 = 선명함)은 줄무늬가 결측이 아닌 15개 샘플($\tilde D$, 8번과 10번 제외)에서 {1, 2, 3, 4, 5, 6, 15}를 커버해 정확도 6/7 = 0.857로 가장 높습니다. 이 문자를 붙이면 줄무늬가 결측인 8번과 10번은 $\tilde r_{\text{선명함}} = 7/15 = 0.467$만큼만 남습니다. 두 번째 문자 (꼭지 = 말림)의 $\tilde r$는 이 부분 커버를 반영해 $5 / (5 + 1 + 1 + 0.467 + 0.467) = 0.630$이 됩니다(분모는 말림 1~5번, 약간 말림 6·15번, 그리고 부분적으로 남은 8번(약간 말림)과 10번(곧음)). 이렇게 결측 샘플도 일부 가중치로 평가에 참여합니다.

결측값이 있는 샘플을 모두 버리면 남는 샘플은 {4, 7, 14, 16} 네 개뿐이고(106쪽), 같은 방법으로 학습하면 '(색깔 = 청록색)', '(색깔 = 진녹색)'이라는 의미 없는 규칙 두 개가 나옵니다. 결측 샘플을 부분적으로라도 쓰는 것이 훨씬 낫다는 점을 볼 수 있습니다.

이 데이터에서는 최종 규칙이 훈련 샘플을 '부분적으로' 커버하는 경우가 생기지 않았습니다. 결측값을 가진 샘플이 다른 문자에서 걸러지기 때문입니다. 부분 커버는 새 샘플을 판정할 때 드러납니다. 예를 들어 (색깔 = ?, 꼭지 = 말림, 소리 = 혼탁, 줄무늬 = ?, 배꼽 = 움푹 패임, 감촉 = 단단함)인 수박은 규칙 1을 $0.467 \times 1 = 0.467$만큼 만족하고 다른 규칙은 만족하지 않으므로 $P(\text{양성}) = 0.467$이 되어, 근소하게 '잘 익지 않음'으로 판정됩니다.

규칙을 평가하는 기준(정확도 다음에 $\rho$로 보정한 커버 가중치)과 종료 조건(남은 가중치 0.5)은 제가 정한 설계입니다. 트리에서 $\rho$를 이득에 곱했듯 정확도에 직접 $\rho$를 곱하는 등 다른 선택도 가능합니다. 표 4.4의 12번 감촉을 '물렁함'으로 바꿔도 규칙 집합의 내용은 같고, 규칙 3과 4의 순서와 $\tilde r_v$ 값만 조금 달라집니다.

## 문제 15.5

> RIPPER 알고리즘에 대한 코드를 작성하고, 부정 형식의 문자를 사용해 수박 데이터 세트 5.0상에서 일차 규칙 집합을 학습하라.

**풀이**

**데이터 만들기.** 수박 데이터 세트 5.0(표 15.1)은 표 4.2의 훈련 세트 10개 샘플과 417쪽의 '정도' 순서로 만듭니다.

- 배경지식: 술어 6개(색이 더 진함, 꼭지가 더 말림, 소리가 더 탁함, 줄무늬가 더 선명함, 배꼽이 더 패임, 촉감이 더 단단함). 10개 샘플의 모든 순서쌍 $(i, j)$에 대해 $i$의 값이 $j$보다 순서상 앞이면 사실로 넣습니다.
- 예제: 좋은 수박 $\{1, 2, 3, 6, 7\}$과 나쁜 수박 $\{10, 14, 15, 16, 17\}$에 대해 양성 예제 '더 좋음(좋은 수박, 나쁜 수박)' 25개, 음성 예제 '¬더 좋음(나쁜 수박, 좋은 수박)' 25개입니다.

```python
# wm50.py
from rules import df, Y, TRAIN
ORDER = {  # 술어 이름: (속성, 값 순서(큰 것부터)), 417쪽
    "색이 더 진함":     ("색깔", ["진녹색", "청록색", "연녹색"]),
    "꼭지가 더 말림":   ("꼭지", ["말림", "약간 말림", "곧음"]),
    "소리가 더 탁함":   ("소리", ["둔탁", "혼탁", "맑음"]),
    "줄무늬가 더 선명함": ("줄무늬", ["선명함", "약간 흐림", "흐림"]),
    "배꼽이 더 패임":   ("배꼽", ["움푹 패임", "약간 패임", "평평함"]),
    "촉감이 더 단단함": ("감촉", ["단단함", "물렁함"]),
}
OBJ = TRAIN                                            # [1, 2, 3, 6, 7, 10, 14, 15, 16, 17]
GOOD = [i for i in OBJ if Y[i - 1]]; BAD = [i for i in OBJ if not Y[i - 1]]
rank = lambda p, i: -ORDER[p][1].index(df.loc[i, ORDER[p][0]])
BK = {p: {(i, j) for i in OBJ for j in OBJ if rank(p, i) > rank(p, j)} for p in ORDER}
POS = [(i, j) for i in GOOD for j in BAD]              # 더 좋음(i, j)
NEG = [(i, j) for i in BAD for j in GOOD]              # ¬더 좋음(i, j)
```

표 15.1에 인쇄된 항목(술어마다 앞과 뒤의 일부)과 대조하면 꼭지, 줄무늬, 촉감은 인쇄된 앞부분과 뒷부분이 정의대로 만든 목록과 정확히 같습니다. 다음 세 가지는 어긋납니다.

- '소리가 더 탁함(17, 14)': 17번과 14번은 소리가 둘 다 '둔탁'이므로 정의상 거짓입니다. 정의대로라면 마지막 항목은 (17, 16)입니다.
- '배꼽이 더 패임(15, 17)': 둘 다 '약간 패임'이므로 거짓입니다. 정의대로라면 (17, 10)이 빠져 있습니다.
- 색과 소리의 첫 줄은 1번 샘플이 관련된 사실 '색이 더 진함(1, 14)', '색이 더 진함(1, 16)', '소리가 더 탁함(1, 10)'을 건너뛰고 2번부터 시작합니다.

또 표 아래쪽(분할선 아래)의 '더 좋음(10, 1)'부터 '더 좋음(17, 7)'까지는 나쁜 수박이 앞에 오는 음성 예제이므로 '¬더 좋음(10, 1)'처럼 부정 기호가 있어야 합니다. 어긋난 두 사실은 모두 나쁜 수박끼리의 쌍이라 예제(좋은 수박과 나쁜 수박의 쌍)를 판정하는 데는 영향이 없습니다. 아래 계산은 정의대로 만든 데이터를 씁니다.

**후보 문자.** 예제가 두 수박의 쌍이므로 규칙 머리는 더 좋음$(X, Y)$입니다. 후보 문자는 술어마다 $p(X, Y)$, $p(Y, X)$, $\neg p(X, Y)$, $\neg p(Y, X)$의 네 가지, 모두 24개입니다. 부정 문자는 닫힌 세계 가정에 따라 '그 사실이 배경지식에 없으면 참'으로 해석합니다. 419쪽처럼 새 변수 $Z$를 쓰는 문자도 후보가 될 수 있지만, 여기서는 규칙을 단순하게 유지하려고 $X$, $Y$만 쓰는 문자로 제한했습니다($p(X, X)$는 순서가 엄격하므로 항상 거짓이라 뺐습니다). 이렇게 하면 각 문자를 '예제 50개 위의 불리언 배열'로 미리 계산할 수 있어서, 15.3의 `ripper.py`를 그대로 쓸 수 있습니다. RIPPER는 원래 명제 규칙 학습기이지만, 규칙 생성 단계가 FOIL 이득을 쓰는 하향식 탐색이라 후보 문자만 일차 문자로 바꾸면 FOIL처럼 일차 규칙을 학습합니다.

```python
# p155.py
import collections
import numpy as np
from wm50 import BK, POS, NEG
from ripper import ripper, grow, cov, cov_set, errors

E = POS + NEG                                           # 예제: 더 좋음(x, y) / ¬더 좋음(x, y)
y = np.array([True] * len(POS) + [False] * len(NEG))
M = {}
for p, facts in BK.items():                             # 변수 X, Y만 쓰는 후보 문자 4가지
    xy = np.array([(a, b) in facts for a, b in E]); yx = np.array([(b, a) in facts for a, b in E])
    M[f"{p}(X,Y)"], M[f"{p}(Y,X)"], M[f"¬{p}(X,Y)"], M[f"¬{p}(Y,X)"] = xy, yx, ~xy, ~yx

def stats(rule):
    c = cov(rule, M, len(y))
    return int((c & y).sum()), int((c & ~y).sum()), [E[i] for i in np.flatnonzero(c & ~y)]

if __name__ == "__main__":
    for l in M:                                         # 첫 문자의 FOIL 이득
        p, n, neg = stats([l])
        g = p * (np.log2(p / (p + n)) - np.log2(25 / 50)) if p else float("nan")
        if g > 5: print(f"  {l}: {p}/{n}  FOIL 이득 {g:.2f}  음성 {neg if n <= 3 else '...'}")
    R, left = [], np.ones(len(y), bool)
    while (left & y).any():                             # 가지치기 없는 순차적 커버링(FOIL 방식)
        r = grow([], y, left, M); R.append(r); left &= ~(cov(r, M, len(y)) & y)
    print("[가지치기 없음]", R, "오류", errors(R, y, M))
    cnt = collections.Counter()
    for seed in range(100):
        R = ripper(y, M, k=2, seed=seed)
        cnt[(tuple(map(tuple, R)), int(errors(R, y, M)))] += 1
        if seed == 0:
            for r in R: print("  더 좋음(X,Y) ←", " ∧ ".join(r), stats(r)[:2])
    for (R, e), k in cnt.most_common(4): print(k, "회:", [" ∧ ".join(r) for r in R], "오류", e)
```

## 문제 15.6

> 수박 데이터 세트 5.0에 대해, 귀납 논리 프로그래밍 학습 개념 '더 나쁨(X, Y)'을 사용해 보아라.

**풀이**

문제를 '수박 데이터 세트 5.0에서 귀납 논리 프로그래밍(ILP)으로 개념 더 나쁨(X, Y)를 학습해 보아라'로 해석했습니다. 15.5.1절의 상향식 방법, 즉 구체적인 사실을 초기 규칙으로 두고 LGG로 일반화하는 방법을 씁니다.

**예제.** 더 나쁨은 더 좋음의 반대이므로 양성 예제는 '더 나쁨(나쁜 수박, 좋은 수박)' 25개, 음성 예제는 '¬더 나쁨(좋은 수박, 나쁜 수박)' 25개입니다.

**초기 규칙.** 책의 예(421쪽)는 논의를 간단히 하려고 $(X, Y)$ 방향의 관계만 초기 규칙에 넣었습니다. 그런데 '더 나쁨(X, Y)'를 설명하는 관계는 대부분 'Y가 X보다 꼭지가 더 말림'처럼 $(Y, X)$ 방향이므로, 여기서는 두 샘플 사이의 배경지식 원자를 양방향 모두 넣었습니다. 예를 들어 양성 예제 더 나쁨(10, 1)의 초기 규칙은 다음과 같습니다.

$$\text{더 나쁨}(10, 1) \leftarrow \text{꼭지가 더 말림}(1, 10) \wedge \text{소리가 더 탁함}(1, 10) \wedge \text{배꼽이 더 패임}(1, 10) \wedge \text{촉감이 더 단단함}(1, 10)$$

**학습 방법 (GOLEM 방식의 순차적 커버링).**

1. 아직 커버되지 않은 첫 양성 예제의 초기 규칙을 $r$로 둡니다.
2. 커버되지 않은 다른 양성 예제 $e$마다 $\mathrm{LGG}(r, r_e)$를 계산하고, 음성을 커버하지 않는 것 중 남은 양성을 가장 많이 커버하는 것으로 $r$을 바꿉니다. 더 이상 바꿀 수 없을 때까지 반복합니다.
3. 음성을 커버하지 않는 한 본체의 문자를 하나씩 지워 더 일반화합니다(규칙 축소).
4. $r$을 규칙 집합에 넣고, 커버된 양성을 지운 뒤 1로 돌아갑니다.

LGG는 422쪽의 방법 그대로 구현했습니다. 같은 술어의 문자끼리 짝짓고, 서로 다른 항의 쌍 $(s, t)$는 하나의 표를 통해 항상 같은 새 변수로 바꿉니다. 양방향 관계를 넣었기 때문에 방향이 엇갈린 문자끼리 짝지어지는 경우가 생깁니다. 예를 들어 더 나쁨(10, 1)의 '꼭지가 더 말림(1, 10)'과 더 나쁨(17, 6)의 '꼭지가 더 말림(17, 6)'을 짝지으면 머리의 변수 $X = V_{10,17}$, $Y = V_{1,6}$과 무관한 '꼭지가 더 말림$(V_{1,17}, V_{10,6})$'이 나옵니다. 이런 문자는 거의 항상 참이 되어 정보가 없으므로, 머리의 변수와 연결되지 않는 문자는 버렸습니다.

```python
# lgg.py  함수 기호가 없는 일차 절(규칙)의 LGG. 원자 = (술어, (항, ...)), 정수 = 상수, 문자열 = 변수
from wm50 import BK
PRED = list(BK)

def lgg_rules(r1, r2):
    """r = (머리 원자, 본체 원자 frozenset). 같은 술어 문자끼리 짝지어 LGG를 구한다."""
    table = {}                                         # (s, t) → 새 변수: 같은 쌍은 같은 변수로
    def term(s, t):
        if s == t: return s                            # LGG(t, t) = t
        if (s, t) not in table: table[(s, t)] = f"V{len(table)}"
        return table[(s, t)]
    atom = lambda a, b: (a[0], tuple(term(s, t) for s, t in zip(a[1], b[1])))
    head = atom(r1[0], r2[0])
    body = {atom(a, b) for a in r1[1] for b in r2[1] if a[0] == b[0]}
    hv = set(head[1])                                  # 머리와 연결되지 않은 문자는 버린다
    body = {a for a in body if all(isinstance(t, int) or t in hv for t in a[1])}
    return normalize((head, frozenset(body)))

def normalize(r):
    """변수 이름을 머리 자리에 따라 X, Y로 바꿔 같은 규칙을 같게 만든다"""
    names = {t: "XY"[i] for i, t in enumerate(r[0][1]) if isinstance(t, str)}
    f = lambda a: (a[0], tuple(names.get(t, t) for t in a[1]))
    return (f(r[0]), frozenset(f(a) for a in r[1]))

def bottom(head_pred, a, b, both=False):
    """예제 head_pred(a, b)의 초기 규칙: (a, b) 사이의 배경지식 원자를 모두 본체에"""
    body = {(p, (a, b)) for p in BK if (a, b) in BK[p]}
    if both: body |= {(p, (b, a)) for p in BK if (b, a) in BK[p]}
    return (head_pred, (a, b)), frozenset(body)

def covers(r, a, b):
    (_, args), body = r
    th = {}
    for t, c in zip(args, (a, b)):
        if isinstance(t, int):
            if t != c: return False
        elif th.setdefault(t, c) != c: return False
    sub = lambda t: th.get(t, t)
    return all((sub(s), sub(t)) in BK[p] for p, (s, t) in body)

def show(r):
    fa = lambda a: f"{a[0]}({', '.join(map(str, a[1]))})"
    key = lambda a: (PRED.index(a[0]), str(a[1]))
    return f"{fa(r[0])} ← " + " ∧ ".join(fa(a) for a in sorted(r[1], key=key))
```

```python
# p156.py
from wm50 import POS as BETTER
from lgg import lgg_rules, bottom, covers, show

POS = [(b, a) for a, b in BETTER]          # 더 나쁨(나쁜 수박, 좋은 수박): 25개
NEG = [(a, b) for a, b in BETTER]          # ¬더 나쁨(좋은 수박, 나쁜 수박): 25개
B = {e: bottom("더 나쁨", *e, both=True) for e in POS}
cov = lambda r, E: [e for e in E if covers(r, *e)]

def golem(verbose=True):
    left, R = list(POS), []
    while left:
        r = B[left[0]]                                         # 씨앗 예제의 초기 규칙
        while True:                                            # 음성을 덮지 않는 한 LGG로 계속 일반화
            cands = [lgg_rules(r, B[e]) for e in left if not covers(r, *e)]
            cands = [c for c in cands if not cov(c, NEG)]
            if not cands: break
            r = max(cands, key=lambda c: len(cov(c, left)))
        while True:                                            # 문자 삭제(음성을 덮지 않을 때만)
            outs = [(r[0], r[1] - {a}) for a in r[1]]
            outs = [o for o in outs if not cov(o, NEG) and len(cov(o, left)) >= len(cov(r, left))]
            if not outs: break
            r = max(outs, key=lambda o: len(cov(o, POS)))
        got = cov(r, left); R.append(r); left = [e for e in left if e not in got]
        if verbose: print(f"  {show(r)}\n     양성 {len(cov(r, POS))}/25, 음성 {len(cov(r, NEG))}")
    return R

if __name__ == "__main__":
    golem()
    print("[배경지식에 더 좋음(·,·) 사실 25개를 추가]")
    import lgg; from wm50 import BK
    BK["더 좋음"] = set(BETTER); lgg.PRED.append("더 좋음")
    B.update({e: bottom("더 나쁨", *e, both=True) for e in POS})
    golem()
```

| 2 | 더 나쁨(X, Y) ← 색이 더 진함(Y, X) ∧ 줄무늬가 더 선명함(Y, X) | 11/0 |
| 3 | 더 나쁨(17, Y) ← | 5/0 |
| 4 | 더 나쁨(15, Y) ← | 5/0 |
| 5 | 더 나쁨(14, 7) ← | 1/0 |

규칙 1, 2는 '좋은 수박 Y가 X보다 꼭지가 더 말리고 배꼽이 더 패였으면 X가 더 나쁘다', 'Y가 X보다 색이 진하고 줄무늬가 선명하면 X가 더 나쁘다'는 뜻으로, 15.8에서 구한 더 좋음의 LGG(색이 더 진함 ∧ 줄무늬가 더 선명함, 꼭지가 더 말림 ∧ 배꼽이 더 패임)를 뒤집은 것과 정확히 대응합니다.

남은 양성 6개((17, 1), (17, 6), (17, 7), (15, 6), (15, 7), (14, 7))는 변수만으로는 일반화하지 못하고, 상수를 포함한 규칙(사실상 암기)으로 커버됩니다. 예를 들어 15번(나쁜 수박)과 6번(좋은 수박)은 색깔만 다르고 그마저 15번이 더 진하므로, 더 나쁨(15, 6)의 초기 규칙은 '색이 더 진함(15, 6)' 하나뿐입니다. 이 사실은 '나쁜 수박이 오히려 색이 진한' 예외라서 다른 양성과 LGG를 취하면 본체가 비어 음성까지 커버합니다. 머리에 상수가 있는 규칙 3~5는 X 자리에 나쁜 수박만 오므로 음성을 커버할 수 없고, 그래서 3단계의 문자 삭제가 본체를 모두 지웠습니다. LGG 기반 학습은 이렇게 예외적인 예제를 일반화하지 못하고 그대로 외우는 경향이 있습니다.

**배경지식을 바꾸면.** 일차 규칙 학습의 장점은 도메인 지식을 쉽게 넣을 수 있다는 것입니다(418쪽). 더 좋음의 양성 사실 25개를 배경지식에 추가하면 모든 양성 예제의 초기 규칙에 '더 좋음(좋은 수박, 나쁜 수박)'이 들어가고, 같은 알고리즘이 규칙 하나를 냅니다.

$$\text{더 나쁨}(X, Y) \leftarrow \text{더 좋음}(Y, X)$$

양성 25개를 모두 커버하고 음성은 하나도 커버하지 않습니다. 명제 규칙으로는 '두 대상의 관계를 뒤집는다'는 지식을 이렇게 간단히 표현할 수 없습니다.

## 문제 15.7

> 다음을 증명하라. 일차 공식 $\mathbf{r}_1$과 $\mathbf{r}_2$에 대해, $\mathbf{r}_1$과 $\mathbf{r}_2$로 특화하거나 이들의 LGG를 일반화할 일차 공식 $\mathbf{r}'$이 존재하지 않는다.

**풀이**

423쪽 본문의 문장('$\mathbf{r}_1$와 $\mathbf{r}_2$로 특화되고 LGG로 일반화되는 일차 공식 $\mathbf{r}'$는 존재하지 않기 때문에')에 맞춰, 문제를 다음처럼 읽습니다. "$\mathbf{r}_1$과 $\mathbf{r}_2$로 특화될 수 있으면서 동시에 LGG로 일반화될 수 있는 $\mathbf{r}'$, 즉 LGG보다 엄격히 더 특수하면서 여전히 $\mathbf{r}_1$, $\mathbf{r}_2$의 공통 일반화인 $\mathbf{r}'$은 존재하지 않는다." LGG 자신은 당연히 두 조건을 만족하므로, '존재하지 않는다'는 'LGG와 동치가 아닌 것은 존재하지 않는다'는 뜻입니다.

**Step 1. 용어를 정합니다.**

규칙(일차 공식) $\mathbf{r}$을 머리 원자 $h(\mathbf{r})$와 본체 문자의 집합 $b(\mathbf{r})$로 봅니다. 어떤 치환 $\theta$가 있어

$$h(\mathbf{r})\theta = h(\mathbf{s}), \qquad b(\mathbf{r})\theta \subseteq b(\mathbf{s})$$

이면 $\mathbf{r}$을 $\mathbf{s}$의 일반화(또는 $\mathbf{s}$를 $\mathbf{r}$의 특화)라고 하고 $\mathbf{r} \succeq \mathbf{s}$로 씁니다. 책이 말하는 일반화 연산 두 가지(상수를 변수로 바꾸기, 본체의 문자 지우기)를 거꾸로 하면 각각 치환 적용과 문자 추가가 되므로, 이 정의는 책의 '일반화/특화'와 같습니다. 치환을 합성하면 되므로 $\succeq$는 반사적이고 추이적입니다.

LGG는 422쪽의 방법대로 만듭니다. 서로 다른 항의 쌍 $(s, t)$마다 새 변수 $V_{s,t}$를 하나씩 정하는 표를 공식 전체에서 하나만 씁니다.

$$\mathrm{lgg}(t, t) = t, \qquad \mathrm{lgg}(s, t) = V_{s,t} \ (s \ne t)$$

$$\mathrm{lgg}(P(s_1, \dots, s_n), P(t_1, \dots, t_n)) = P(\mathrm{lgg}(s_1, t_1), \dots, \mathrm{lgg}(s_n, t_n))$$

$$h(\mathrm{LGG}) = \mathrm{lgg}(h(\mathbf{r}_1), h(\mathbf{r}_2)), \qquad b(\mathrm{LGG}) = \{\mathrm{lgg}(L_1, L_2) : L_1 \in b(\mathbf{r}_1),\ L_2 \in b(\mathbf{r}_2),\ \text{같은 술어(같은 부호)}\}$$

공통 술어가 없는 문자는 짝이 없으므로 저절로 빠집니다(422쪽 '공통의 술어를 포함하지 않는 문자를 무시'). 새 변수 $V_{s,t}$는 $\mathbf{r}_1$, $\mathbf{r}_2$에 없는 이름으로 잡습니다.

**Step 2. LGG는 $\mathbf{r}_1$, $\mathbf{r}_2$의 공통 일반화입니다.**

$\sigma_1 = \{s / V_{s,t}\}$(표의 모든 $V_{s,t}$를 $s$로)라 두면 모든 항 쌍에 대해 $\mathrm{lgg}(s, t)\sigma_1 = s$입니다. 따라서 $\mathrm{lgg}(L_1, L_2)\sigma_1 = L_1 \in b(\mathbf{r}_1)$이고 머리도 $h(\mathbf{r}_1)$로 갑니다. 즉 $\mathrm{LGG} \succeq \mathbf{r}_1$입니다. $\sigma_2 = \{t / V_{s,t}\}$로 같은 논증을 하면 $\mathrm{LGG} \succeq \mathbf{r}_2$입니다.

**Step 3 (핵심). $\mathbf{r}_1$, $\mathbf{r}_2$의 공통 일반화는 모두 LGG의 일반화입니다.**

$\mathbf{r}' \succeq \mathbf{r}_1$ (치환 $\theta_1$), $\mathbf{r}' \succeq \mathbf{r}_2$ (치환 $\theta_2$)라고 합시다. $\mathbf{r}'$의 변수 $x$마다

$$x\theta = \mathrm{lgg}(x\theta_1,\ x\theta_2)$$

로 치환 $\theta$를 정의합니다. 이때 $\mathbf{r}'$에 나오는 모든 항 $u$에 대해 $u\theta = \mathrm{lgg}(u\theta_1, u\theta_2)$가 성립합니다. $u$가 변수면 정의 그대로이고, 상수 $c$면 $c\theta_1 = c\theta_2 = c$이므로 $\mathrm{lgg}(c, c) = c = c\theta$입니다.

이제 본체 문자 $L = P(u_1, \dots, u_n) \in b(\mathbf{r}')$을 봅시다. $L\theta_1 \in b(\mathbf{r}_1)$, $L\theta_2 \in b(\mathbf{r}_2)$이고 둘은 같은 술어 $P$(같은 부호)를 가지므로 LGG를 만들 때 짝지어지는 쌍입니다. 따라서

$$\mathrm{lgg}(L\theta_1, L\theta_2) = P(\mathrm{lgg}(u_1\theta_1, u_1\theta_2), \dots) = P(u_1\theta, \dots, u_n\theta) = L\theta \in b(\mathrm{LGG})$$

입니다. 머리도 같은 계산으로 $h(\mathbf{r}')\theta = \mathrm{lgg}(h(\mathbf{r}_1), h(\mathbf{r}_2)) = h(\mathrm{LGG})$입니다. 그러므로 $\mathbf{r}' \succeq \mathrm{LGG}$입니다.

이 단계에서 '같은 쌍 $(s, t)$는 공식 전체에서 항상 같은 변수로 바꾼다'는 규칙(422쪽 '이후에 출현하는 LGG(s, t)의 위치는 V로 대체')이 결정적입니다. $\mathbf{r}'$의 한 변수 $x$가 여러 문자에 나와도 $\mathrm{lgg}(x\theta_1, x\theta_2)$는 어디서나 같은 변수이므로 $\theta$가 잘 정의됩니다.

**Step 4. 결론.**

$\mathbf{r}'$이 문제의 조건, 즉 $\mathbf{r}' \succeq \mathbf{r}_1$, $\mathbf{r}' \succeq \mathbf{r}_2$이고 $\mathrm{LGG} \succeq \mathbf{r}'$을 만족한다고 합시다. Step 3에 의해 $\mathbf{r}' \succeq \mathrm{LGG}$이기도 하므로, $\mathbf{r}'$과 LGG는 서로가 서로의 일반화입니다. 두 공식은 같은 특화 집합을 가지며(변수 이름이나 중복 문자만 다를 뿐) 동치입니다. 따라서 LGG보다 엄격히 더 특수하면서 $\mathbf{r}_1$, $\mathbf{r}_2$를 모두 일반화하는 공식은 존재하지 않고, LGG는 $\mathbf{r}_1$, $\mathbf{r}_2$의 공통 일반화 중 가장 특수한(최소 일반) 공식입니다. ∎

**참고.** 항에 함수 기호가 있으면 $\mathrm{lgg}(f(s_1, \dots, s_k), f(t_1, \dots, t_k)) = f(\mathrm{lgg}(s_1, t_1), \dots)$로 재귀적으로 정의하고, 함수 기호가 다르면 새 변수로 둡니다. Step 3의 '$u\theta = \mathrm{lgg}(u\theta_1, u\theta_2)$'는 항의 구조에 대한 귀납법으로 그대로 성립합니다($u = f(u_1, \dots, u_k)$이면 $u\theta_1$, $u\theta_2$가 같은 함수 기호 $f$를 가지므로 $\mathrm{lgg}(u\theta_1, u\theta_2) = f(u_1\theta, \dots, u_k\theta) = u\theta$). 이 결과는 Plotkin(1970)의 정리입니다.

## 문제 15.8

> 수박 데이터 세트 5.0의 LGG 집합을 만들어 보아라.

**풀이**

문제를 '수박 데이터 세트 5.0의 양성 예제들에서 LGG를 구해 모아 보아라'로 해석하고, 책의 예(421~423쪽)와 같은 가정, 즉 초기 규칙에 $(X, Y)$ 방향의 관계만 넣는 가정을 따랐습니다. 다음 세 가지를 계산합니다.

1. 책의 예제를 재현합니다.
2. 양성 예제 25개의 초기 규칙에서 가능한 모든 쌍($\binom{25}{2} = 300$개)의 LGG를 구하고, 서로 다른 것만 모은 'LGG 집합'을 만듭니다.
3. 그중 음성을 커버하지 않는 LGG로 양성을 모두 덮는 규칙 집합을 고릅니다.

```python
# p158.py
from collections import defaultdict
from itertools import combinations
from wm50 import POS, NEG
from lgg import lgg_rules, bottom, covers, show

B = {e: bottom("더 좋음", *e) for e in POS}                                  # (X, Y) 방향만
r = lgg_rules(B[(1, 10)], B[(1, 15)]); print(" ", show(r))                 # 식 15.4
print(" ", show(lgg_rules(r, B[(2, 10)])))                                    # 15.4 + 15.5
groups = defaultdict(list)                                                   # 모든 양성 쌍의 LGG
for e1, e2 in combinations(POS, 2):
    groups[lgg_rules(B[e1], B[e2])].append((e1, e2))
print(f"양성 쌍 300개 → 서로 다른 LGG {len(groups)}개")
for r, pairs in groups.items():
    p = sum(covers(r, *e) for e in POS); n = sum(covers(r, *e) for e in NEG)
    print(f"  {show(r)}   양성 {p} 음성 {n}  (쌍 {len(pairs)}개)")
allr = B[POS[0]]
for e in POS[1:]: allr = lgg_rules(allr, B[e])
print("25개 전체의 LGG:", show(allr))
cons = [r for r in groups if not any(covers(r, *e) for e in NEG)]          # 음성을 덮지 않는 LGG
left = set(POS)
while left:
    r = max(cons, key=lambda r: (sum(covers(r, *e) for e in left), r[0][1] == ("X", "Y"), -len(r[1])))
    got = {e for e in left if covers(r, *e)}
    left -= got; print("  커버 규칙:", show(r), "새로 커버", sorted(got))
```

**1. 책의 예제.** 더 좋음(1, 10)과 더 좋음(1, 15)의 LGG는 식 15.4

$$\text{더 좋음}(1, Y) \leftarrow \text{꼭지가 더 말림}(1, Y) \wedge \text{배꼽이 더 패임}(1, Y) \wedge \text{촉감이 더 단단함}(1, Y)$$

이고, 여기에 더 좋음(2, 10)의 초기 규칙을 합치면 423쪽의 규칙 '더 좋음(X, Y) ← 꼭지가 더 말림(X, Y) ∧ 배꼽이 더 패임(X, Y) ∧ 촉감이 더 단단함(X, Y)'가 나옵니다. 책과 같습니다. (식 15.5의 초기 규칙에는 '색이 더 진함(2, 10)'도 들어가야 하지만(2번은 진녹색, 10번은 청록색), 식 15.4에 이 술어가 없으므로 LGG 결과는 같습니다.)

**2. LGG 집합.** 300개 쌍에서 서로 다른 LGG가 60개 나옵니다.

변수만으로 된 규칙 두 개가 양성 19개를 설명하고, 나머지 6개는 상수 규칙으로만 덮입니다. 특히 더 좋음(6, 15)와 더 좋음(7, 15)는 $(X, Y)$ 방향 관계가 하나도 없어 초기 규칙의 본체부터 비어 있습니다. 6번과 7번은 15번(나쁜 수박)보다 어느 속성에서도 '더' 낫지 않기 때문입니다. 책의 간단화 가정, 즉 $(X, Y)$ 방향 관계만 쓰는 가정의 한계를 보여 주는 예이고, 15.6처럼 양방향 관계를 넣거나 15.5처럼 부정 문자를 써야 이런 예제를 일반적인 규칙으로 설명할 수 있습니다.

## 문제 15.9\* (심화)

> 일차 원자 공식은 일종의 재귀 정의의 공식이다. $P(t_1, t_2, \dots, t_n)$과 같이 생겼고, 여기서 $P$는 술어 혹은 함수 부호다. $t_i$는 '항'이라 불리고, 논리상수, 변수 혹은 기타 원자 공식이 될 수 있다. 일차 원자 공식 $E_i$의 집합 $S = \{E_1, E_2, \dots, E_n\}$에 대해, 알고리즘을 만들어 MGU를 구하라.

**풀이**

Robinson(1965)의 결합 알고리즘을 '등식 집합' 형태로 정리합니다. 표기는 책(425쪽)을 따릅니다. 치환 $\{t/x\}$는 변수 $x$를 항 $t$로 바꾸고, 합성 $\theta \circ \lambda$는 $\theta$를 먼저, $\lambda$를 나중에 적용한 것입니다. $\delta$가 MGU라는 것은 $\delta$가 결합자이고, 임의의 결합자 $\theta$에 대해 $\theta = \delta \circ \lambda$인 $\lambda$가 존재한다는 뜻입니다(426쪽).

**알고리즘**

입력: $S = \{E_1, \dots, E_n\}$

1. 등식 집합 $\mathcal{E} = \{E_1 \doteq E_2, E_1 \doteq E_3, \dots, E_1 \doteq E_n\}$, $\sigma = \varnothing$(항등 치환)으로 시작합니다.
2. $\mathcal{E}$가 빌 때까지 등식 하나 $s_0 \doteq t_0$를 꺼내 $s = s_0\sigma$, $t = t_0\sigma$로 두고 다음을 적용합니다.
   - (삭제) $s = t$이면 버립니다.
   - (교환) $t$가 변수이고 $s$가 변수가 아니면 $s$와 $t$를 바꿉니다.
   - (대입) $s$가 변수 $x$일 때, $x$가 $t$ 안에 나타나면 실패합니다(출현 검사). 아니면 $\sigma \leftarrow \sigma \circ \{t/x\}$로 갱신합니다.
   - (분해) $s = f(s_1, \dots, s_k)$, $t = f(t_1, \dots, t_k)$처럼 기호와 인자 수가 같으면 $s_i \doteq t_i$ ($i = 1, \dots, k$)를 $\mathcal{E}$에 넣습니다.
   - (충돌) 그 밖의 경우(서로 다른 상수, 상수와 복합 항, 기호나 인자 수가 다른 복합 항)에는 실패합니다.
3. $\sigma$를 MGU로 반환합니다.

술어 기호와 함수 기호, 그리고 항으로 들어간 원자 공식을 모두 '기호와 인자 목록'으로 똑같이 다루므로, 문제의 재귀적 정의를 그대로 처리합니다.

**정당성 증명**

치환 $\theta$에 대해 '$\theta = \sigma \circ \theta$'를 '모든 변수 $y$에 대해 $y\sigma\theta = y\theta$'라는 뜻으로 씁니다. 다음 불변식을 보입니다.

> (I) $\sigma$는 멱등이고(정의역의 변수가 치환 결과에 나타나지 않음), 임의의 $\theta$에 대해 "$\theta$가 $S$의 결합자" ⇔ "$\theta = \sigma \circ \theta$이고 $\theta$가 $\mathcal{E}$의 모든 등식을 만족".

처음에는 $\sigma$가 항등 치환이고 $\mathcal{E}$가 $E_1 \doteq E_i$들이므로 (I)이 성립합니다. 꺼낸 등식에 대해, $\theta = \sigma \circ \theta$이면 $s_0\theta = s_0\sigma\theta = s\theta$이고 $t_0\theta = t\theta$이므로 '$\theta$가 $s_0 \doteq t_0$를 만족' ⇔ '$\theta$가 $s \doteq t$를 만족'입니다. 이제 각 경우가 (I)을 유지함을 봅니다.

- 삭제: $s = t$는 모든 $\theta$가 만족합니다.
- 분해: $f(s_1, \dots, s_k)\theta = f(t_1, \dots, t_k)\theta$ ⇔ 모든 $i$에 대해 $s_i\theta = t_i\theta$입니다.
- 충돌: 맨 바깥 기호가 다르면 어떤 치환으로도 같아지지 않으므로 결합자가 없고, 실패가 옳은 답입니다.
- 출현 검사 실패: $x \ne t$이고 $x$가 $t$에 나타나면 $t$는 복합 항이고, $x\theta$는 $t\theta$의 진부분항이 되어 $t\theta$보다 기호 수가 적습니다. 두 항이 같을 수 없으므로 결합자가 없습니다.
- 대입: $x$가 $t$에 나타나지 않을 때 $\sigma' = \sigma \circ \{t/x\}$라 하면, "$\theta = \sigma \circ \theta$이고 $x\theta = t\theta$" ⇔ "$\theta = \sigma' \circ \theta$"임을 보이면 됩니다. 핵심은 $x\theta = t\theta$이면 임의의 항 $u$에 대해 $u\{t/x\}\theta = u\theta$라는 사실입니다.
  - (⇒) $\sigma$의 정의역에 있는 $y$에 대해 $y\sigma'\theta = (y\sigma)\{t/x\}\theta = y\sigma\theta = y\theta$입니다. $x$는 $s = s_0\sigma$로 나온 변수이고 $\sigma$가 멱등이므로 $\sigma$의 정의역에 없고, $x\sigma'\theta = t\theta = x\theta$입니다. 나머지 변수는 둘 다 건드리지 않습니다.
  - (⇐) $x\theta = x\sigma'\theta = t\theta$이고, 이를 이용하면 $y\theta = y\sigma'\theta = y\sigma\{t/x\}\theta = y\sigma\theta$입니다.
  - 멱등성: $t = t_0\sigma$에는 $\sigma$의 정의역 변수가 없고(멱등) $x$도 없으므로, $\sigma'$의 치환 결과에는 $x$도 $\sigma$의 정의역 변수도 나타나지 않습니다.

**종료.** (아직 $\sigma$의 정의역에 들어가지 않은 $S$의 변수 수, $\mathcal{E}\sigma$의 전체 기호 수, $\mathcal{E}$의 등식 수)를 사전식으로 비교하면, 대입은 첫째 값을, 분해는 둘째 값을(바깥 기호 두 개가 사라짐), 삭제는 둘째나 셋째 값을 줄이고 앞의 값을 늘리지 않습니다. 따라서 알고리즘은 반드시 끝납니다.

**결론.** 실패는 결합자가 없을 때만 일어납니다. 성공해서 $\mathcal{E} = \varnothing$이 되면 (I)에 의해 "$\theta$가 $S$의 결합자" ⇔ "$\theta = \sigma \circ \theta$"입니다. $\sigma$는 멱등이라 $\sigma = \sigma \circ \sigma$이므로 $\sigma$ 자신이 결합자이고, 임의의 결합자 $\theta$는 $\theta = \sigma \circ \theta$, 즉 $\lambda = \theta$로 두면 $\theta = \sigma \circ \lambda$입니다. 따라서 $\sigma$는 MGU입니다. ∎

```python
# p159.py  항: 대문자로 시작하는 문자열 = 변수, 그 밖의 문자열·숫자 = 상수,
#          튜플 (기호, 인자, ...) = 원자 공식 또는 함수 항
is_var = lambda t: isinstance(t, str) and t[:1].isupper()

def apply(t, s):
    if is_var(t): return s.get(t, t)
    if isinstance(t, tuple): return (t[0],) + tuple(apply(a, s) for a in t[1:])
    return t

def occurs(x, t):
    return t == x or (isinstance(t, tuple) and any(occurs(x, a) for a in t[1:]))

def mgu(S):
    """S = [E1, ..., En]의 MGU를 {변수: 항} 사전으로 반환, 결합 불가능하면 None"""
    eqs = [(S[0], E) for E in S[1:]]          # E1 = E2, E1 = E3, ..., E1 = En
    sigma = {}
    while eqs:
        s, t = eqs.pop()
        s, t = apply(s, sigma), apply(t, sigma)   # 지금까지의 치환을 먼저 적용
        if s == t: continue                         # 삭제
        if is_var(t) and not is_var(s): s, t = t, s
        if is_var(s):
            if occurs(s, t): return None            # 출현 검사 실패
            sigma = {x: apply(v, {s: t}) for x, v in sigma.items()}
            sigma[s] = t                            # σ ← σ ◦ {t/s}
        elif (isinstance(s, tuple) and isinstance(t, tuple)
              and s[0] == t[0] and len(s) == len(t)):
            eqs.extend(zip(s[1:], t[1:]))           # 분해
        else:
            return None                             # 기호 충돌

    return sigma

def fmt(t):
    return f"{t[0]}({', '.join(fmt(a) for a in t[1:])})" if isinstance(t, tuple) else str(t)

if __name__ == "__main__":
    tests = [
        [("색깔이 더 짙음", 1, "Y"), ("색깔이 더 짙음", "X", "Y")],
        [("색깔이 더 짙음", 1, "X"), ("색깔이 더 짙음", "Y", 2)],
        [("P", "X", ("f", "Y"), "Z"), ("P", ("g", "W"), ("f", "a"), "W"), ("P", ("g", "b"), "V", "U")],
        [("P", ("Q", "X", "a"), "Y"), ("P", "Z", ("f", "Z"))],
        [("P", "X", "X"), ("P", "Y", ("f", "Y"))],
        [("P", "a", "X"), ("P", "b", "Y")],
    ]
    for S in tests:
        s = mgu(S)
        txt = "결합 불가" if s is None else "{" + ", ".join(f"{fmt(v)}/{x}" for x, v in sorted(s.items())) + "}"
        print(" , ".join(map(fmt, S)), "→", txt, "" if s is None else "→ " + fmt(apply(S[0], s)))
```

## 문제 15.10\* (심화)

> 순차적 커버링 규칙 학습 알고리즘을 기반으로 다음 규칙을 학습하기 전에, 이미 현재 규칙 집합에 커버된 샘플은 훈련 집합에서 제거될 수 있다. 이러한 그리디 전략은 이후 학습 과정에서 커버되지 않았던 샘플에만 포커스를 맞추게 만들고, 규칙 커버 비율을 판정할 때 전후 규칙의 상관성을 무시하게 만든다. 그렇지만 이 전략은 이후 학습 과정에서 참고해야 하는 샘플의 수를 계속해서 줄이는 효과가 있다. 그렇다면 샘플을 제거하지 않는 규칙 학습 알고리즘을 하나 만들어 보아라.

**풀이**

샘플을 지우는 대신 **가중치를 줄이는** 가중 커버링(weighted covering) 알고리즘을 설계합니다. CN2-SD [Lavrač et al., 2004]가 쓴 아이디어를 15.1의 하향식 생성에 맞게 단순화한 것입니다.

**알고리즘**

입력: 훈련 세트 $D$, 감쇠율 $\gamma \in [0, 1)$

1. 모든 샘플의 커버 횟수 $k_x = 0$으로 둡니다. 샘플은 끝까지 하나도 지우지 않습니다.
2. 아직 한 번도 커버되지 않은 양성이 남아 있는 동안 반복합니다.
   1. 가중치를 양성은 $w_x = \gamma^{k_x}$, 음성은 $w_x = 1$로 둡니다.
   2. 15.1처럼 빈 규칙에서 시작해 문자를 붙이되, 정확도와 커버 수를 가중치로 계산합니다(가중 정확도 $\sum_{x \in D^+_r} w_x / \sum_{x \in D_r} w_x$, 같으면 가중 양성 커버). 단, 규칙은 아직 커버되지 않은 양성을 적어도 하나 커버해야 합니다. 음성을 하나도 커버하지 않을 때까지 키웁니다.
   3. 규칙을 넣고, 이 규칙이 커버하는 양성의 $k_x$를 1씩 늘립니다.
3. (사후 정리) 다른 규칙들이 이미 커버하는 양성만 커버하는 규칙은 지웁니다.

**성질**

- $\gamma = 0$이면 커버된 양성의 가중치가 0이 되어 '지운 것'과 같으므로, 15.1의 순차적 커버링과 정확히 같아집니다. $\gamma$가 클수록 이미 커버된 양성도 다음 규칙의 평가에 더 많이 반영됩니다.
- 모든 샘플이 남아 있으므로 새 규칙은 전체 데이터 위에서 평가되고, 앞의 규칙과 겹치는 정도($k_x$)를 직접 볼 수 있습니다. 이 정보를 이용하면 3단계처럼 규칙 집합 전체를 보고 중복 규칙을 정리할 수 있습니다. 문제에서 지적한 '전후 규칙의 상관성'을 반영하는 부분입니다.
- 매 규칙이 새 양성을 적어도 하나 커버하므로 규칙 수는 양성 수를 넘지 않고, 알고리즘은 반드시 끝납니다.
- 대가는 계산량입니다. 매 라운드 전체 샘플을 다시 평가하므로, 샘플을 지우는 방식보다 뒤쪽 라운드가 느립니다.

```python
# p1510.py
import numpy as np
from rules import df, Y, candidates, lit_mask, body_mask, show

def grow(w, fresh):
    """모든 샘플을 그대로 두고, 가중치 w로 (가중 정확도, 가중 양성 커버) 기준 하향식 생성"""
    body, cov = [], np.ones(len(Y), bool)
    while (cov & ~Y).any():
        best = None
        for lit in candidates(neg=False):
            if lit[0] in [l[0] for l in body]: continue
            new = cov & lit_mask(df, lit)
            p, n = w[new & Y].sum(), w[new & ~Y].sum()
            if not (new & fresh).any() or (new == cov).all(): continue   # 새 양성을 하나는 덮어야 함
            key = (p / (p + n), p)
            if best is None or key > best[0]: best = (key, lit, new)
        body.append(best[1]); cov = best[2]
    return body, cov

def weighted_covering(gamma=0.5, max_rules=10):
    k = np.zeros(len(Y))                       # 각 샘플이 지금까지 커버된 횟수
    R = []
    while len(R) < max_rules and (Y & (k == 0)).any():
        w = np.where(Y, gamma ** k, 1.0)       # 커버된 양성은 지우지 않고 가중치만 γ^k로 낮춘다
        body, cov = grow(w, Y & (k == 0))
        R.append(body); k += cov & Y
    # 사후 정리: 다른 규칙들이 이미 덮는 양성만 덮는 규칙은 삭제(전역적으로 중복 판정)
    for r in sorted(R, key=lambda r: body_mask(df, r).sum()):
        others = [q for q in R if q is not r]
        cov_o = np.zeros(len(Y), bool)
        for q in others: cov_o |= body_mask(df, q)
        if others and not (body_mask(df, r) & Y & ~cov_o).any(): R = others
    return R

if __name__ == "__main__":
    for g in [0.0, 0.5, 0.9]:
        print(f"[γ = {g}]")
        for r in weighted_covering(g):
            m = body_mask(df, r); print(f"  {show(r)}   양성 {list(df.index[m & Y])}")
```

**실행 결과 (수박 데이터 세트 2.0)**

$\gamma = 0$에서는 예상대로 15.1과 같은 규칙 집합이 나옵니다. $\gamma = 0.5$와 $\gamma = 0.9$에서는 같은 규칙 집합이 나오며, 15.1과 다음처럼 달라집니다.

| 순서 | $\gamma = 0$ (= 순차적 커버링) | $\gamma = 0.5$, $0.9$ (가중 커버링) |
|------|------|------|
| 1 | (줄무늬 = 선명함) ∧ (감촉 = 단단함) → 1, 2, 3, 4, 5, 8 | (줄무늬 = 선명함) ∧ (감촉 = 단단함) → 1, 2, 3, 4, 5, 8 |
| 2 | (감촉 = 물렁함) ∧ (줄무늬 = 약간 흐림) → 7 | (줄무늬 = 선명함) ∧ (소리 = 혼탁) ∧ (색깔 = 청록색) → 1, 6 |
| 3 | (줄무늬 = 선명함) ∧ (색깔 = 청록색) ∧ (꼭지 = 약간 말림) → 6 | (색깔 = 진녹색) ∧ (소리 = 혼탁) ∧ (줄무늬 = 약간 흐림) → 7 |

두 번째 규칙이 정해지는 과정을 보면 차이가 분명합니다. 첫 규칙 뒤에 샘플을 지우면 남은 양성은 6, 7번뿐이라, 첫 문자로 둘을 함께 잡는 (감촉 = 물렁함)(양성 2, 음성 10·15)이 유리합니다. 샘플을 남겨 두고 커버된 양성을 0.5로 계산하면 (줄무늬 = 선명함)의 가중 정확도가 $(6 \times 0.5 + 1)/(6 \times 0.5 + 1 + 2) = 0.667$로, (감촉 = 물렁함)의 $2/4 = 0.5$보다 높습니다. 즉 이미 커버된 양성들이 '줄무늬가 선명한 수박은 대체로 잘 익었다'는 근거로 계속 쓰이고, 그 결과 6번을 위한 규칙이 1번까지 함께 커버하는(근거가 하나 더 있는) 규칙이 됩니다. 세 번째 규칙도 같은 이유로 2, 3, 8번이 함께 있는 '진녹색' 쪽에서 출발합니다.

이 데이터는 너무 작아서 두 방식의 일반화 성능을 비교하기는 어렵습니다. 하지만 가중 커버링이 규칙 간의 겹침을 허용하고 그 겹침을 평가에 반영한다는 점, 그리고 $\gamma$ 하나로 순차적 커버링과 연속적으로 이어진다는 점은 확인할 수 있습니다.

같은 문제의식에서 나온 다른 설계도 있습니다. 부스팅으로 가중치를 갱신하며 규칙을 하나씩 더하는 SLIPPER [Cohen and Singer, 1999], 그리고 이미 만든 규칙 집합 전체를 다시 최적화하는 RIPPER의 후처리(그림 15.2의 4행, 15.3 참조)도 '앞뒤 규칙의 상관성'을 고려하는 방법입니다.
