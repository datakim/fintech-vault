## 문제 9.1

> 다음을 증명하라. $p \geqslant 1$일 때 민코프스키 거리는 거리척도의 네 가지 기본 성질을 만족한다. $0 \leqslant p < 1$일 때 민코프스키 거리는 삼각부등식을 만족하지 못하지만, 비음수성(non-negativity), 동일성, 대칭성은 만족시킨다. $P$가 무한대로 커질 때 민코프스키 거리는 대응하는 컴포넌트의 최대 절대 거리와 같아진다. 즉, 다음 수식과 같다.
>
> $$\lim_{p \to +\infty}\left(\sum_{u=1}^{n}|x_{iu}-x_{ju}|^p\right)^{\frac{1}{p}} = \max_u |x_{iu}-x_{ju}| .$$

**풀이**

민코프스키 거리(식 9.18)는 다음과 같습니다.

$$\operatorname{dist}_{\mathrm{mk}}(\boldsymbol{x}_i, \boldsymbol{x}_j) = \left(\sum_{u=1}^{n}|x_{iu}-x_{ju}|^p\right)^{\frac{1}{p}}$$

$p = 0$이면 지수 $1/p$가 정의되지 않으므로, 아래에서는 $0 < p < 1$을 다룹니다. 편의상 $a_u = |x_{iu} - x_{ju}| \geqslant 0$이라 두겠습니다.

**(1) 비음수성, 동일성, 대칭성 ($p > 0$이면 모두 성립)**

- 비음수성(식 9.14): 각 항 $a_u^p \geqslant 0$이므로 합도 0 이상이고, 0 이상인 수의 $1/p$ 제곱도 0 이상입니다.
- 동일성(식 9.15): $\boldsymbol{x}_i = \boldsymbol{x}_j$이면 모든 $a_u = 0$이므로 거리는 0입니다. 반대로 거리가 0이면 $\sum_u a_u^p = 0$이고, 0 이상인 항들의 합이 0이므로 모든 $a_u^p = 0$입니다. $p > 0$이면 $t^p = 0 \Leftrightarrow t = 0$이므로 모든 $a_u = 0$, 즉 $\boldsymbol{x}_i = \boldsymbol{x}_j$입니다.
- 대칭성(식 9.16): $|x_{iu} - x_{ju}| = |x_{ju} - x_{iu}|$이므로 식이 그대로 같습니다.

이 세 성질은 $p$의 크기와 관계없이 $p > 0$이기만 하면 성립합니다.

**(2) $p \geqslant 1$일 때 삼각부등식(식 9.17)**

세 샘플 $\boldsymbol{x}_i, \boldsymbol{x}_k, \boldsymbol{x}_j$에 대해 $a_u = |x_{iu} - x_{ku}|$, $b_u = |x_{ku} - x_{ju}|$로 두고, $\|\boldsymbol{a}\|_p = (\sum_u a_u^p)^{1/p}$라 쓰겠습니다. 보일 것은 $\operatorname{dist}_{\mathrm{mk}}(\boldsymbol{x}_i, \boldsymbol{x}_j) \leqslant \|\boldsymbol{a}\|_p + \|\boldsymbol{b}\|_p$입니다.

Step 1. 성분별 삼각부등식에서 $|x_{iu} - x_{ju}| \leqslant a_u + b_u$이고, $t \mapsto t^p$는 $t \geqslant 0$에서 증가함수이므로

$$\operatorname{dist}_{\mathrm{mk}}(\boldsymbol{x}_i, \boldsymbol{x}_j) \leqslant \left(\sum_u (a_u + b_u)^p\right)^{\frac{1}{p}} = \|\boldsymbol{a} + \boldsymbol{b}\|_p .$$

Step 2. 이제 $\|\boldsymbol{a} + \boldsymbol{b}\|_p \leqslant \|\boldsymbol{a}\|_p + \|\boldsymbol{b}\|_p$(민코프스키 부등식)를 보입니다. $A = \|\boldsymbol{a}\|_p$, $B = \|\boldsymbol{b}\|_p$라 하겠습니다. $A = 0$이면 $\boldsymbol{a} = \boldsymbol{0}$이라 양변이 모두 $B$로 같고, $B = 0$일 때도 마찬가지입니다. 따라서 $A, B > 0$이라 가정합니다. $\lambda = A/(A+B) \in (0, 1)$로 두면 각 성분에 대해

$$\frac{a_u + b_u}{A + B} = \lambda \cdot \frac{a_u}{A} + (1 - \lambda) \cdot \frac{b_u}{B}$$

입니다. $p \geqslant 1$이면 $\varphi(t) = t^p$는 $t \geqslant 0$에서 볼록함수이므로

$$\left(\frac{a_u + b_u}{A + B}\right)^p \leqslant \lambda \left(\frac{a_u}{A}\right)^p + (1 - \lambda)\left(\frac{b_u}{B}\right)^p .$$

Step 3. 양변을 $u = 1, \dots, n$에 대해 더하면, $\sum_u (a_u/A)^p = 1$, $\sum_u (b_u/B)^p = 1$이므로

$$\frac{\sum_u (a_u + b_u)^p}{(A + B)^p} \leqslant \lambda + (1 - \lambda) = 1 .$$

양변에 $(A+B)^p$를 곱하고 $1/p$ 제곱을 하면 $\|\boldsymbol{a} + \boldsymbol{b}\|_p \leqslant A + B$입니다.

Step 1과 Step 3을 합치면

$$\operatorname{dist}_{\mathrm{mk}}(\boldsymbol{x}_i, \boldsymbol{x}_j) \leqslant \operatorname{dist}_{\mathrm{mk}}(\boldsymbol{x}_i, \boldsymbol{x}_k) + \operatorname{dist}_{\mathrm{mk}}(\boldsymbol{x}_k, \boldsymbol{x}_j)$$

이 됩니다. (1)과 함께 $p \geqslant 1$이면 네 가지 성질을 모두 만족합니다. 증명에서 볼록성을 쓴 곳이 Step 2 하나뿐이라는 점을 기억해 두면, 다음 (3)에서 왜 $p < 1$일 때 깨지는지가 자연스럽게 보입니다.

**(3) $0 < p < 1$이면 삼각부등식이 성립하지 않는 경우가 있다**

반례 하나로 충분합니다. 2차원에서 $\boldsymbol{x}_i = (0, 0)$, $\boldsymbol{x}_k = (1, 0)$, $\boldsymbol{x}_j = (1, 1)$로 두면

$$\operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_k) = 1,\quad \operatorname{dist}(\boldsymbol{x}_k, \boldsymbol{x}_j) = 1,\quad \operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_j) = (1^p + 1^p)^{\frac{1}{p}} = 2^{\frac{1}{p}}$$

입니다. $0 < p < 1$이면 $1/p > 1$이므로 $2^{1/p} > 2 = 1 + 1$이 되어 삼각부등식이 깨집니다. 예를 들어 $p = 1/2$이면 $\operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_j) = 4 > 2$입니다. 이때는 $t^p$가 오목함수라서 (2)의 Step 2가 반대 방향 부등식이 됩니다.

참고로 $0 < p < 1$일 때 $1/p$ 제곱을 하지 않은 $\sum_u |x_{iu} - x_{ju}|^p$는 거리척도입니다. $t \geqslant 0$에서 $(s + t)^p \leqslant s^p + t^p$가 성립하기 때문입니다. 또 흔히 $p = 0$의 극한처럼 부르는 "서로 다른 성분의 개수"는 해밍 거리이고, 이것도 삼각부등식을 만족합니다. 즉 문제에서 말하는 실패는 식 9.18의 형태를 그대로 쓸 때의 이야기입니다.

**(4) $p \to \infty$의 극한**

$M = \max_u a_u$라 두겠습니다. $M = 0$이면 모든 $a_u = 0$이라 양변이 0으로 같습니다. $M > 0$이면, 합 안에는 $M^p$인 항이 적어도 하나 있고 각 항은 $M^p$ 이하이므로

$$M^p \leqslant \sum_{u=1}^{n} a_u^p \leqslant n M^p .$$

$1/p$ 제곱을 하면

$$M \leqslant \left(\sum_{u=1}^{n} a_u^p\right)^{\frac{1}{p}} \leqslant n^{\frac{1}{p}} M .$$

$p \to \infty$이면 $n^{1/p} = e^{(\ln n)/p} \to 1$이므로, 샌드위치 정리에 의해 가운데 식은 $M = \max_u |x_{iu} - x_{ju}|$로 수렴합니다. 이것이 체비셰프 거리입니다.

## 문제 9.2

> 같은 샘플 공간에서 집합 $X$와 $Z$ 사이의 거리는 하우스도르프 거리(Hausdorff distance)를 통해 계산된다.
>
> $$\operatorname{dist}_{\mathrm{H}}(X, Z) = \max\left(\operatorname{dist}_{\mathrm{h}}(X, Z), \operatorname{dist}_{\mathrm{h}}(Z, X)\right) ,$$
>
> 식 9.44에서 $\operatorname{dist}_{\mathrm{h}}(X, Z)$는 다음과 같다.
>
> $$\operatorname{dist}_{\mathrm{h}}(X, Z) = \max_{\boldsymbol{x} \in X}\min_{\boldsymbol{z} \in Z}\|\boldsymbol{x} - \boldsymbol{z}\|_2 .$$
>
> 하우스도르프 거리가 거리척도의 네 가지 기본 성질을 만족한다는 사실을 증명하라.

**풀이**

클러스터링에서 다루는 집합은 샘플의 유한집합이므로, $X, Z$를 공집합이 아닌 유한집합으로 둡니다. 유한집합이면 식 9.45의 max와 min이 항상 어떤 원소에서 실제로 달성된다는 점을 증명에서 씁니다.

먼저 $\operatorname{dist}_{\mathrm{h}}(X, Z)$의 뜻을 정리해 두면 증명이 쉬워집니다. "$X$의 각 점에서 $Z$의 가장 가까운 점까지의 거리" 중 최댓값이므로, $\operatorname{dist}_{\mathrm{h}}(X, Z) \leqslant r$이라는 것은 "$X$의 모든 점이 $Z$의 어떤 점과 $r$ 이내에 있다"는 뜻입니다. $\operatorname{dist}_{\mathrm{h}}$ 자체는 대칭이 아닙니다. 예를 들어 $X = \{0\}$, $Z = \{0, 10\}$(1차원)이면 $\operatorname{dist}_{\mathrm{h}}(X, Z) = 0$이지만 $\operatorname{dist}_{\mathrm{h}}(Z, X) = 10$입니다. 그래서 식 9.44처럼 두 방향의 최댓값을 취합니다.

**(1) 비음수성.** $\|\boldsymbol{x} - \boldsymbol{z}\|_2 \geqslant 0$이고, 0 이상인 값들의 min과 max도 0 이상입니다. 따라서 $\operatorname{dist}_{\mathrm{h}} \geqslant 0$이고 $\operatorname{dist}_{\mathrm{H}} \geqslant 0$입니다.

**(2) 동일성.** $X = Z$이면 각 $\boldsymbol{x} \in X$에 대해 $\boldsymbol{z} = \boldsymbol{x}$를 고를 수 있으므로 $\min_{\boldsymbol{z}}\|\boldsymbol{x} - \boldsymbol{z}\|_2 = 0$입니다. 따라서 두 방향 모두 0이고 $\operatorname{dist}_{\mathrm{H}}(X, Z) = 0$입니다.

반대로 $\operatorname{dist}_{\mathrm{H}}(X, Z) = 0$이라 합시다. 그러면 $\operatorname{dist}_{\mathrm{h}}(X, Z) = 0$이고, 모든 $\boldsymbol{x} \in X$에 대해 $\min_{\boldsymbol{z} \in Z}\|\boldsymbol{x} - \boldsymbol{z}\|_2 = 0$입니다. $Z$가 유한집합이라 이 최솟값을 주는 $\boldsymbol{z}^* \in Z$가 존재하고 $\|\boldsymbol{x} - \boldsymbol{z}^*\|_2 = 0$, 즉 $\boldsymbol{x} = \boldsymbol{z}^* \in Z$입니다. 따라서 $X \subseteq Z$입니다. 같은 논리를 $\operatorname{dist}_{\mathrm{h}}(Z, X) = 0$에 적용하면 $Z \subseteq X$이므로 $X = Z$입니다.

**(3) 대칭성.** $\max(s, t) = \max(t, s)$이므로 정의에서 바로 $\operatorname{dist}_{\mathrm{H}}(X, Z) = \operatorname{dist}_{\mathrm{H}}(Z, X)$입니다.

**(4) 삼각부등식.** 세 집합 $X, Y, Z$에 대해 $\operatorname{dist}_{\mathrm{H}}(X, Z) \leqslant \operatorname{dist}_{\mathrm{H}}(X, Y) + \operatorname{dist}_{\mathrm{H}}(Y, Z)$를 보입니다.

Step 1. 한 방향 거리부터 보입니다. 임의의 $\boldsymbol{x} \in X$를 고정합니다.

- $Y$에서 $\boldsymbol{x}$와 가장 가까운 점을 $\boldsymbol{y}^*$라 하면 $\|\boldsymbol{x} - \boldsymbol{y}^*\|_2 = \min_{\boldsymbol{y} \in Y}\|\boldsymbol{x} - \boldsymbol{y}\|_2 \leqslant \operatorname{dist}_{\mathrm{h}}(X, Y)$입니다.
- $Z$에서 $\boldsymbol{y}^*$와 가장 가까운 점을 $\boldsymbol{z}^*$라 하면 $\|\boldsymbol{y}^* - \boldsymbol{z}^*\|_2 \leqslant \operatorname{dist}_{\mathrm{h}}(Y, Z)$입니다($\boldsymbol{y}^* \in Y$이므로).
- 유클리드 거리의 삼각부등식에 의해

$$\min_{\boldsymbol{z} \in Z}\|\boldsymbol{x} - \boldsymbol{z}\|_2 \leqslant \|\boldsymbol{x} - \boldsymbol{z}^*\|_2 \leqslant \|\boldsymbol{x} - \boldsymbol{y}^*\|_2 + \|\boldsymbol{y}^* - \boldsymbol{z}^*\|_2 \leqslant \operatorname{dist}_{\mathrm{h}}(X, Y) + \operatorname{dist}_{\mathrm{h}}(Y, Z) .$$

우변은 $\boldsymbol{x}$와 무관하므로 좌변의 $\boldsymbol{x} \in X$에 대한 최댓값도 우변 이하입니다.

$$\operatorname{dist}_{\mathrm{h}}(X, Z) \leqslant \operatorname{dist}_{\mathrm{h}}(X, Y) + \operatorname{dist}_{\mathrm{h}}(Y, Z) \leqslant \operatorname{dist}_{\mathrm{H}}(X, Y) + \operatorname{dist}_{\mathrm{H}}(Y, Z) .$$

Step 2. Step 1은 임의의 세 집합에 대해 성립하므로, $X$와 $Z$의 역할을 바꿔 $Z \to Y \to X$ 순서에 적용하면

$$\operatorname{dist}_{\mathrm{h}}(Z, X) \leqslant \operatorname{dist}_{\mathrm{h}}(Z, Y) + \operatorname{dist}_{\mathrm{h}}(Y, X) \leqslant \operatorname{dist}_{\mathrm{H}}(Y, Z) + \operatorname{dist}_{\mathrm{H}}(X, Y) .$$

Step 3. 두 방향이 모두 같은 상한을 가지므로 그 최댓값도 같은 상한을 가집니다.

$$\operatorname{dist}_{\mathrm{H}}(X, Z) = \max\left(\operatorname{dist}_{\mathrm{h}}(X, Z), \operatorname{dist}_{\mathrm{h}}(Z, X)\right) \leqslant \operatorname{dist}_{\mathrm{H}}(X, Y) + \operatorname{dist}_{\mathrm{H}}(Y, Z) .$$

따라서 하우스도르프 거리는 네 가지 성질을 모두 만족합니다.

참고로 무한집합으로 넓힐 때는 max/min을 sup/inf로 바꾸고 집합을 유계인 닫힌집합(콤팩트 집합)으로 제한해야 합니다. 예를 들어 $X = [0, 1)$, $Z = [0, 1]$이면 $\operatorname{dist}_{\mathrm{H}}(X, Z) = 0$이지만 $X \neq Z$라서 동일성이 깨집니다. (2)에서 "최솟값을 주는 점이 존재한다"는 사실을 쓴 이유가 여기에 있습니다.

## 문제 9.3

> $k$평균 알고리즘이 식 9.24를 최소화하는 최적해를 찾을 수 있을지 분석해 보아라.

**풀이**

결론부터 말하면, $k$평균은 유한 번의 반복 안에 반드시 멈추지만 멈춘 지점은 국소 최적해일 뿐이고 식 9.24의 전역 최적해라는 보장은 없습니다. 초기 평균 벡터에 따라 결과가 달라집니다.

식 9.24를 클러스터 분할 $\mathcal{C}$와 평균 벡터 $\boldsymbol{\mu} = (\boldsymbol{\mu}_1, \dots, \boldsymbol{\mu}_k)$ 두 변수의 함수로 보겠습니다.

$$E(\mathcal{C}, \boldsymbol{\mu}) = \sum_{i=1}^{k}\sum_{\boldsymbol{x} \in C_i}\|\boldsymbol{x} - \boldsymbol{\mu}_i\|_2^2$$

**(1) 매 단계에서 $E$는 증가하지 않는다.** 그림 9.2의 한 번의 반복은 두 단계입니다.

- 4~8행(할당): $\boldsymbol{\mu}$를 고정하고 각 샘플을 가장 가까운 평균 벡터에 보냅니다. 샘플마다 자기 항 $\|\boldsymbol{x} - \boldsymbol{\mu}_{\lambda}\|^2$을 가장 작게 만드는 선택이므로, 고정된 $\boldsymbol{\mu}$에서 $E$를 최소화하는 분할입니다.
- 9~16행(갱신): $\mathcal{C}$를 고정하고 $\boldsymbol{\mu}_i$를 바꿉니다. $f(\boldsymbol{\mu}_i) = \sum_{\boldsymbol{x} \in C_i}\|\boldsymbol{x} - \boldsymbol{\mu}_i\|^2$는 $\boldsymbol{\mu}_i$에 대해 강볼록이고, 기울기 $-2\sum_{\boldsymbol{x} \in C_i}(\boldsymbol{x} - \boldsymbol{\mu}_i) = \boldsymbol{0}$을 풀면 유일한 최소점이 $\boldsymbol{\mu}_i = \frac{1}{|C_i|}\sum_{\boldsymbol{x} \in C_i}\boldsymbol{x}$, 즉 평균입니다.

즉 $k$평균은 $\mathcal{C}$와 $\boldsymbol{\mu}$를 번갈아 최소화하는 좌표 하강법이고, 각 단계가 $E$를 늘리지 않습니다.

**(2) 유한 번 안에 멈춘다.** 동점일 때는 현재 클러스터를 유지한다는 규칙을 두겠습니다. 그러면 할당 단계에서 분할이 바뀌었다는 것은 어떤 샘플이 엄격하게 더 가까운 평균 벡터로 옮겼다는 뜻이므로 $E$가 엄격하게 줄어듭니다. 이어지는 갱신 단계는 $E$를 늘리지 않으므로, 분할이 바뀐 반복마다 $E$가 엄격하게 감소합니다. 그런데 가능한 분할은 많아야 $k^m$개로 유한하고, 평균 벡터가 분할로 결정되므로 같은 분할이 두 번 나올 수 없습니다. 따라서 유한 번 안에 분할이 더 이상 바뀌지 않고, 그때 평균 벡터도 바뀌지 않아 17행에서 멈춥니다.

**(3) 멈춘 지점은 전역 최적이 아닐 수 있다.** 멈춘 지점에서는 "평균 벡터를 고정하면 어떤 샘플도 옮길 이유가 없고, 분할을 고정하면 평균 벡터가 최적"입니다. 이것은 국소 최적 조건일 뿐입니다. 간단한 반례로 2차원의 네 점 $(0,0), (0,1), (L,0), (L,1)$ ($L > 1$)을 $k = 2$로 나누는 경우를 보겠습니다.

- 초기 평균 벡터를 $(0,0), (L,0)$으로 잡으면 왼쪽 두 점과 오른쪽 두 점으로 나뉘고 $E = 4 \times 0.25 = 1$입니다. 이것이 전역 최적입니다.
- 초기 평균 벡터를 $(0,0), (0,1)$로 잡으면 아래 두 점과 위 두 점으로 나뉘고, 평균 벡터는 $(L/2, 0), (L/2, 1)$이 됩니다. 점 $(0,0)$에서 자기 평균까지는 $L/2$, 다른 평균까지는 $\sqrt{L^2/4 + 1}$이라 옮기지 않으므로 그대로 멈춥니다. 이때 $E = 4 \times L^2/4 = L^2$입니다.

$L = 4$이면 $E = 16$으로 최적값 1의 16배이고, $L$을 키우면 이 비율은 얼마든지 커집니다. 직접 실행해도 같은 결과가 나왔습니다.

**(4) 수박 데이터 세트 4.0에서의 확인.** $k = 2$이면 전역 최적해를 정확히 구할 수 있습니다. 최적 분할에서는 모든 샘플이 자기 평균에 더 가까워야 하므로(그렇지 않으면 그 샘플을 옮기고 평균을 다시 구해 $E$를 더 줄일 수 있습니다), 두 클러스터는 두 평균의 수직이등분선으로 나뉘는 직선 분리 분할입니다. 30개 점을 직선으로 나누는 방법은 투영 방향을 돌려 가며 모두 나열할 수 있고, 실제로 서로 다른 분할 435개를 모두 검사한 결과 전역 최솟값은 $E^* = 0.6932$였습니다.

그런데 가능한 초기 평균 벡터 쌍 $\binom{30}{2} = 435$가지로 $k$평균을 모두 돌려 보면, $E^*$에 도달하는 경우는 35가지(8.0%)뿐이었고 최종 결과는 9가지로 갈렸으며 가장 나쁜 결과는 $E = 0.9599$였습니다. $k = 3$에서도 $\binom{30}{3} = 4060$가지 초기값의 최종 결과가 37가지로 갈렸습니다(자세한 결과는 문제 9.4).

**(5) 정리.** 식 9.24의 최솟값 자체는 분할이 유한하므로 반드시 존재하지만, 책에서 언급한 대로 이를 찾는 문제는 NP-hard입니다. $k$평균은 이 문제를 탐욕적으로 근사하는 방법이므로 전역 최적해를 보장하지 못하며, 실무에서는 초기값을 여러 번 바꿔 실행한 뒤 $E$가 가장 작은 결과를 고르거나 $k$-means++처럼 초기 평균 벡터를 퍼뜨려 고르는 방법으로 그 위험을 줄입니다.

## 문제 9.4

> $k$평균 알고리즘의 코드를 작성해 보고, 3개의 서로 다른 $k$값, 초기 중심점을 설정해 수박 데이터 세트 4.0상에서 비교 실험해 보아라. 그리고 어떤 초기 중심값이 결과를 좋게 만드는지 논해 보아라.

**풀이**

그림 9.2를 그대로 옮긴 구현입니다. 반복 횟수는 "평균 벡터가 바뀌지 않음을 확인한 마지막 반복"까지 셉니다(책의 예에서 5회).

```python
def kmeans(X, init_idx, max_iter=100):
    """그림 9.2. init_idx: 초기 평균 벡터로 쓸 샘플 번호(0부터)."""
    mu = X[list(init_idx)].copy()
    for it in range(1, max_iter + 1):
        d = np.linalg.norm(X[:, None, :] - mu[None, :, :], axis=2)  # d_ji
        lab = d.argmin(axis=1)                                       # lambda_j
        new_mu = np.array([X[lab == i].mean(axis=0) if np.any(lab == i) else mu[i]
                           for i in range(len(mu))])
        if np.allclose(new_mu, mu):        # 평균 벡터가 갱신되지 않으면 종료
            break
        mu = new_mu
    E = ((X - mu[lab]) ** 2).sum()         # 식 9.24
    return lab, mu, it, E
```

**구현 확인.** 책의 예(초기값 $\boldsymbol{x}_6, \boldsymbol{x}_{12}, \boldsymbol{x}_{24}$)를 넣으면 $\boldsymbol{x}_1$과 세 평균 벡터의 거리가 0.369, 0.506, 0.220, 첫 갱신 평균 벡터가 $(0.493; 0.207), (0.394; 0.066), (0.602; 0.396)$으로 책과 같고, 5회째 반복에서 멈춥니다. 최종 결과는 $E = 0.4126$, $C_1 = \{3, 5, 7, 9, 13, 14, 16, 17, 21\}$, $C_2 = \{6, 8, 10, 11, 12, 15, 18, 19, 20\}$, $C_3 = \{1, 2, 4, 22, \dots, 30\}$입니다.

**실험 설계.** $k = 2, 3, 4$ 각각에 대해, 초기 평균 벡터로 쓸 수 있는 샘플 조합을 무작위로 몇 개 뽑는 대신 **전부** 돌렸습니다($\binom{30}{2} = 435$, $\binom{30}{3} = 4060$, $\binom{30}{4} = 27405$가지). 데이터가 30개뿐이라 가능하고, 무작위 시드에 따라 결론이 바뀌는 문제가 없습니다.

```python
import itertools, collections
for k in [2, 3, 4]:
    runs = [kmeans(X, init) + (init,) for init in itertools.combinations(range(30), k)]
    E = np.array([r[3] for r in runs]); it = np.array([r[2] for r in runs])
    best = E.min()
    print(k, len(runs), len(set(E.round(6))), best, np.mean(E <= best + 1e-9),
          E.max(), it.mean(), it.max())
```

|---|---|---|---|---|---|---|---|
| 2 | 435 | 9 | 0.6932 | 8.0% | 0.9599 | 4.05 / 9 | 1.448 / 0.111 |
| 3 | 4060 | 37 | 0.4097 | 8.5% | 0.6992 | 4.55 / 14 | 1.181 / 0.177 |
| 4 | 27405 | 290 | 0.2477 | 10.3% | 0.5204 | 4.63 / 13 | 1.012 / 0.226 |

$k = 2$의 최소 $E$ 0.6932는 문제 9.3에서 구한 전역 최적값과 같습니다. $k = 3, 4$의 최소 $E$는 "샘플을 초기값으로 쓰는 모든 경우 중 최선"이며 전역 최적이라고 증명한 것은 아닙니다. 각 $k$의 최소 $E$ 해는 다음과 같습니다.

- $k = 2$(초기값 예: $\{1, 19\}$, 6회): $\{1, 2, 3, 4, 5, 9, 13, 14, 16, 17, 21, 22, 25, 26, 27, 29\}$, $\{6, 7, 8, 10, 11, 12, 15, 18, 19, 20, 23, 24, 28, 30\}$. 밀도가 높은 쪽과 낮은 쪽으로 나뉩니다.
- $k = 3$(초기값 예: $\{1, 2, 10\}$, 4회): $\{1, 2, 4, 22, 23, 24, 25, 26, 27, 28, 29, 30\}$, $\{3, 5, 9, 13, 14, 16, 17, 21\}$, $\{6, 7, 8, 10, 11, 12, 15, 18, 19, 20\}$. 평균 벡터는 $(0.600; 0.405)$, $(0.652; 0.163)$, $(0.349; 0.208)$입니다.
- $k = 4$(초기값 예: $\{1, 2, 3, 17\}$, 6회): $\{15, 23, 24, 25, 27, 28, 30\}$, $\{1, 2, 4, 22, 26, 29\}$, $\{6, 7, 8, 10, 11, 12, 18, 19, 20\}$, $\{3, 5, 9, 13, 14, 16, 17, 21\}$. $k = 3$의 첫 클러스터에 $\boldsymbol{x}_{15}$가 더해진 뒤 둘로 나뉜 모양이고, 나머지 두 클러스터는 $\boldsymbol{x}_{15}$가 빠진 것 외에 $k = 3$과 같습니다.

$E$는 $k$가 커질수록 당연히 작아지므로 서로 다른 $k$를 $E$로 비교하면 안 됩니다. 내부 지표로 보면 이 세 경우 중에서는 DBI(작을수록 좋음)와 DI(클수록 좋음)가 모두 $k = 4$를 가장 좋게 평가했습니다. 클러스터 수를 고르는 문제는 문제 9.10에서 다시 다룹니다.

**나쁜 초기값의 예.** $k = 3$에서 가장 나쁜 결과($E = 0.6992$)는 초기값 $\{6, 12, 27\}$에서 나왔습니다. $\boldsymbol{x}_{12}$가 아래쪽 가장자리에 있어서 첫 할당에서 $\{11, 12, 16\}$ 세 점만 가져가고, 2회 만에 그대로 굳어 버립니다. 나머지 27개 점은 두 클러스터가 나눠 가지므로 $E$가 큽니다. 책의 예에서 쓴 $\{6, 12, 24\}$도 첫 할당에서는 $C_2 = \{11, 12, 16\}$이었지만, 이때는 $\boldsymbol{x}_{24}$가 위쪽에 있어 나머지 점들이 다시 정리될 여유가 있었고 최종 $E = 0.4126$으로 최소값 0.4097에 가까운 결과가 나왔습니다.

**어떤 초기값이 좋은가.** 최소 $E$ 해의 클러스터를 기준으로, 초기 평균 벡터가 "서로 다른 최종 클러스터에 하나씩" 들어가 있는지(아래 표의 "고르게 분포")에 따라 결과를 나눠 보았습니다. "최적 근처"는 최소 $E$의 1% 이내로 끝난 경우입니다.

|---|---|---|---|
| 2 | 51.5% | 51.3% / 18.0% | 12.9% / 2.8% |
| 3 | 23.6% | 54.6% / 32.1% | 18.1% / 5.5% |

초기 평균 벡터가 실제 클러스터 영역마다 하나씩 놓이면 좋은 결과가 나올 확률이 2~4배 높아집니다. 반대로 초기값 사이의 최소 거리만 크게 하는 것은 별 도움이 되지 않았습니다. $k = 3$에서 초기값 간 최소 거리를 사분위로 나눠 보면 최소 $E$ 도달 비율이 8.3%, 6.6%, 10.6%, 8.4%로 뚜렷한 경향이 없었습니다. 실제로 거리만 기준으로 가장 먼 점을 차례로 고르는 방법(max-min, 30개 시작점)은 가장자리의 외딴 점을 고르기 쉬워서, 최적 근처 비율이 $k = 2, 3, 4$에서 20.0%, 50.0%, 23.3%로 들쭉날쭉했습니다. 거리에 비례한 확률로 고르는 $k$-means++(시드 0, 2000회)는 37.4%, 40.5%, 34.2%로 균등 무작위(35.2%, 37.4%, 33.6%)보다 조금 나은 정도였습니다.

이 데이터에서 초기화 방법의 차이가 작은 이유는 수박 데이터 세트 4.0에 뚜렷하게 분리된 클러스터가 없기 때문입니다($k = 3$에서 상위 세 결과의 $E$가 0.4097, 0.4114, 0.4126으로 거의 같습니다). 정리하면 좋은 초기값은 (1) 클러스터가 있을 법한 밀집 영역마다 하나씩 놓이고, (2) 데이터 가장자리의 외딴 점은 피하는 것입니다. 이런 초기값을 미리 알기는 어려우므로, 실무적으로는 초기값을 여러 번 바꿔 돌리고 $E$가 가장 작은 결과를 고르는 것이 가장 확실합니다. $k = 3$의 균등 무작위 초기화로 계산하면 10번 돌렸을 때 한 번이라도 최소 $E$에 도달할 확률은 $1 - (1 - 0.085)^{10} \approx 58.7\%$, 30번이면 약 93.0%입니다.

## 문제 9.5

> DBSCAN의 기본 정의에 기반해, $\boldsymbol{x}$가 핵심 대상이라면 $\boldsymbol{x}$ 밀도에 의해 커버되는 모든 샘플로 구성된 집합을 $X$라 한다. $X$는 연속성(식 9.39)와 최대성(식 9.40)을 만족한다는 사실을 증명하라.

**풀이**

9.5절의 정의를 다시 적습니다. $N_\epsilon(\boldsymbol{x}_j) = \{\boldsymbol{x}_i \in D \mid \operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_j) \leqslant \epsilon\}$이고, $|N_\epsilon(\boldsymbol{x}_j)| \geqslant MinPts$이면 $\boldsymbol{x}_j$는 핵심 대상입니다.

- 직접 밀도 접근 가능: $\boldsymbol{x}_i$가 핵심 대상이고 $\boldsymbol{x}_j \in N_\epsilon(\boldsymbol{x}_i)$이면, $\boldsymbol{x}_j$는 $\boldsymbol{x}_i$에서 직접 밀도 접근 가능합니다.
- 밀도 접근 가능: 수열 $\boldsymbol{p}_1 = \boldsymbol{x}_i, \boldsymbol{p}_2, \dots, \boldsymbol{p}_n = \boldsymbol{x}_j$가 있어 각 $\boldsymbol{p}_{t+1}$이 $\boldsymbol{p}_t$에서 직접 밀도 접근 가능하면, $\boldsymbol{x}_j$는 $\boldsymbol{x}_i$에서 밀도 접근 가능합니다.
- 밀도 연결: $\boldsymbol{x}_i$와 $\boldsymbol{x}_j$가 모두 어떤 $\boldsymbol{x}_k$에서 밀도 접근 가능하면 둘은 밀도 연결되어 있습니다.

문제의 집합은 253쪽의 $X = \{\boldsymbol{x}' \in D \mid \boldsymbol{x}' \text{은 } \boldsymbol{x} \text{에서 밀도 접근 가능}\}$입니다.

**준비: $X$는 공집합이 아닌 $D$의 부분집합이다.** 정의상 $X \subseteq D$입니다. 또 $\operatorname{dist}(\boldsymbol{x}, \boldsymbol{x}) = 0 \leqslant \epsilon$이므로 $\boldsymbol{x} \in N_\epsilon(\boldsymbol{x})$이고, $\boldsymbol{x}$는 핵심 대상이므로 $\boldsymbol{x}$는 자기 자신에서 직접 밀도 접근 가능합니다. 길이 2의 수열 $\boldsymbol{p}_1 = \boldsymbol{p}_2 = \boldsymbol{x}$를 쓰면 $\boldsymbol{x} \in X$이므로 $X \neq \varnothing$입니다. 클러스터의 정의가 "공집합이 아닌 부분집합"을 요구하므로 이 확인이 필요합니다.

**연결성(식 9.39).** $\boldsymbol{x}_i, \boldsymbol{x}_j \in X$를 임의로 고르면, $X$의 정의에 의해 $\boldsymbol{x}_i$도 $\boldsymbol{x}_j$도 $\boldsymbol{x}$에서 밀도 접근 가능합니다. 따라서 $\boldsymbol{x}_k = \boldsymbol{x}$로 두면 밀도 연결의 정의를 그대로 만족하므로, $\boldsymbol{x}_i$와 $\boldsymbol{x}_j$는 밀도 연결되어 있습니다.

**최대성(식 9.40).** $\boldsymbol{x}_i \in X$이고 $\boldsymbol{x}_j$가 $\boldsymbol{x}_i$에서 밀도 접근 가능하다고 합시다. 보일 것은 $\boldsymbol{x}_j \in X$입니다.

Step 1. $\boldsymbol{x}_i \in X$이므로 수열 $\boldsymbol{p}_1 = \boldsymbol{x}, \boldsymbol{p}_2, \dots, \boldsymbol{p}_n = \boldsymbol{x}_i$가 있어 각 $\boldsymbol{p}_{t+1}$은 $\boldsymbol{p}_t$에서 직접 밀도 접근 가능합니다.

Step 2. $\boldsymbol{x}_j$가 $\boldsymbol{x}_i$에서 밀도 접근 가능하므로 수열 $\boldsymbol{q}_1 = \boldsymbol{x}_i, \boldsymbol{q}_2, \dots, \boldsymbol{q}_l = \boldsymbol{x}_j$가 있어 각 $\boldsymbol{q}_{t+1}$은 $\boldsymbol{q}_t$에서 직접 밀도 접근 가능합니다.

Step 3. $\boldsymbol{p}_n = \boldsymbol{q}_1 = \boldsymbol{x}_i$이므로 두 수열을 이어 붙인

$$\boldsymbol{x} = \boldsymbol{p}_1, \dots, \boldsymbol{p}_n = \boldsymbol{q}_1, \boldsymbol{q}_2, \dots, \boldsymbol{q}_l = \boldsymbol{x}_j$$

에서도 이웃한 두 원소는 모두 "뒤가 앞에서 직접 밀도 접근 가능"한 관계입니다. 따라서 $\boldsymbol{x}_j$는 $\boldsymbol{x}$에서 밀도 접근 가능하고, $\boldsymbol{x}_j \in D$이므로 $\boldsymbol{x}_j \in X$입니다.

두 성질을 모두 만족하므로 $X$는 DBSCAN이 정의하는 클러스터입니다. 참고로 이 증명은 밀도 접근 가능 관계가 추이적(transitive)이라는 사실(Step 3)과, 연결성의 "공통 출발점"으로 핵심 대상 $\boldsymbol{x}$를 쓸 수 있다는 사실이 핵심입니다. 그림 9.9의 10~24행은 시드 $\boldsymbol{o}$에서 출발해 정확히 이 집합 $X$를 찾아내는 너비 우선 탐색입니다. 수박 데이터 세트 4.0에 $\epsilon = 0.11$, $MinPts = 5$로 직접 구현해 돌려 보면, 핵심 대상 13개와 $\boldsymbol{x}_8$을 시드로 한 첫 클러스터 $\{6, 7, 8, 10, 12, 18, 19, 20, 23\}$, 이후의 $\{3, 4, 5, 9, 13, 14, 16, 17, 21\}$, $\{1, 2, 22, 26, 29\}$, $\{24, 25, 27, 28, 30\}$이 책과 같게 나오고, 노이즈는 $\boldsymbol{x}_{11}$과 $\boldsymbol{x}_{15}$입니다.

## 문제 9.6

> AGNES 알고리즘에서 최소 거리와 최대 거리를 사용하는 차이점을 분석하라.

**풀이**

최소 거리 $d_{\min}$(식 9.41, 단일 연결)은 두 클러스터에서 **가장 가까운 한 쌍**만 보고, 최대 거리 $d_{\max}$(식 9.42, 완전 연결)는 **가장 먼 한 쌍**을 봅니다. 이 차이에서 다음 성질들이 나옵니다.

| 관점 | 최소 거리(단일 연결) | 최대 거리(완전 연결) |
|---|---|---|
| 병합 기준의 뜻 | 두 클러스터 사이에 가까운 점이 하나라도 있으면 합침 | 합친 뒤 클러스터의 모든 점 쌍이 가까워야 합침 |
| 높이 $h$에서 끊은 클러스터 | 거리 $h$ 이하인 점끼리 간선을 이은 그래프의 연결 성분과 같음(최소 신장 트리의 긴 간선부터 끊는 것과 같음) | 각 클러스터의 지름(식 9.9의 diam)이 $h$ 이하 |
| 만들어지는 모양 | 길쭉하거나 휘어진 모양, 비컨벡스 모양도 가능 | 지름이 비슷한 둥글고 조밀한 모양 |
| 대표적 약점 | 연쇄 효과(chaining): 중간에 점 몇 개만 이어져 있어도 두 덩어리가 합쳐지고, 큰 클러스터 하나와 외톨이 점들로 나뉘기 쉬움 | 크기가 큰 자연스러운 클러스터를 쪼개기 쉽고, 먼 점 하나가 클러스터 간 거리를 크게 부풀림 |
| 이상점에 대한 반응 | 이상점은 맨 마지막까지 외톨이로 남음 | 이상점이 들어간 클러스터는 다른 클러스터와 잘 합쳐지지 않음 |

수박 데이터 세트 4.0에서 그림 9.11을 직접 구현해 비교했습니다.

```python
def agnes(X, k, link="max"):
    agg = {"min": np.min, "max": np.max, "avg": np.mean}[link]
    D = np.linalg.norm(X[:, None] - X[None], axis=2)
    C, heights = [[j] for j in range(len(X))], []
    while len(C) > k:
        best = (np.inf, None, None)
        for a in range(len(C)):
            for b in range(a + 1, len(C)):
                d = agg(D[np.ix_(C[a], C[b])])        # 식 9.41~9.43
                if d < best[0]: best = (d, a, b)
        d, a, b = best
        C[a] = C[a] + C[b]; del C[b]; heights.append(d)
    return C, heights
```

$d_{\max}$로 7개 클러스터까지 병합하면 $\{1, 26, 29\}$, $\{2, 3, 4, 21, 22\}$, $\{23, 24, 25, 27, 28, 30\}$, $\{5, 7\}$, $\{9, 13, 14, 16, 17\}$, $\{6, 8, 10, 15, 18, 19, 20\}$, $\{11, 12\}$로 257쪽의 결과와 정확히 같습니다. 같은 데이터에 $d_{\min}$을 쓰면 결과가 크게 달라집니다.

| 클러스터 수 | 최소 거리(단일 연결) | 최대 거리(완전 연결) |
|---|---|---|
| $k = 7$ 클러스터 크기 | 8, 8, 6, 5, 1, 1, 1 (외톨이: $\boldsymbol{x}_{11}, \boldsymbol{x}_{15}, \boldsymbol{x}_{21}$) | 7, 6, 5, 5, 3, 2, 2 |
| $k = 4$ 클러스터 크기 | 23, 5, 1, 1 (외톨이: $\boldsymbol{x}_{11}, \boldsymbol{x}_{15}$) | 9, 8, 7, 6 |
| $k = 2$ 클러스터 크기 | 29, 1 (외톨이: $\boldsymbol{x}_{15}$) | 21, 9 |
| 마지막 병합 높이 | 0.113 | 0.665 |

단일 연결은 점들이 사슬처럼 이어지는 대로 합쳐서 $k = 4$에서 이미 23개짜리 큰 클러스터가 생기고, 주변에서 조금 떨어진 $\boldsymbol{x}_{11}$, $\boldsymbol{x}_{15}$ 같은 점만 따로 남습니다. 완전 연결은 클러스터 크기가 고르고 공간적으로 조밀한 덩어리를 만듭니다. 마지막 병합 높이가 0.113과 0.665로 크게 다른 것도 같은 이유입니다. 단일 연결에서는 사슬의 가장 긴 고리만 넘으면 되지만, 완전 연결에서는 데이터 전체의 지름에 해당하는 거리가 되어야 마지막 병합이 일어납니다.

정리하면, 클러스터가 길쭉하거나 휘어져 있고 잡음이 적을 때는 최소 거리가, 클러스터가 둥글고 크기가 비슷하며 사이에 잡음 점이 끼어 있을 때는 최대 거리가 더 적합합니다. 평균 거리(식 9.43)는 둘의 절충으로, 이 데이터에서 $k = 4$일 때 크기 10, 8, 7, 5의 클러스터를 만들었습니다.

## 문제 9.7

> 클러스터링 결과에서 만약 모든 클러스터가 모두 컨벡스 헐(convex hull)이 있고 컨벡스 헐들이 서로 교차하지 않으면, 컨벡스 클러스터라고 부른다. 이번 장에서 소개한 어떤 알고리즘이 컨벡스 클러스터만을 생성하고 어떤 알고리즘이 비컨벡스 클러스터를 생성하는지 분석해 보아라.

**풀이**

유한 점 집합은 언제나 컨벡스 헐을 가지므로, 실제 조건은 "서로 다른 클러스터의 컨벡스 헐이 겹치지 않는다"입니다. 결론은 다음과 같습니다.

| 알고리즘 | 컨벡스 클러스터만 생성하는가 | 이유 |
|---|---|---|
| $k$평균 | 예 | 최종 분할이 평균 벡터의 Voronoi 분할 |
| 학습 벡터 양자화(LVQ) | 예(원형 벡터 하나를 클러스터 하나로 볼 때) | 식 9.27의 Voronoi 분할 |
| 가우시안 혼합 클러스터링 | 아니요(공분산이 모두 같을 때만 예) | 경계가 이차곡선 |
| DBSCAN | 아니요 | 밀도 연결로 임의의 모양을 만듦 |
| AGNES | 아니요(단일 연결에서 특히 자주) | 병합 기준이 공간을 볼록 영역으로 나누지 않음 |

**$k$평균과 LVQ가 컨벡스 클러스터만 만드는 이유.** $k$평균이 멈췄을 때 각 샘플은 가장 가까운 평균 벡터의 클러스터에 속합니다. 동점인 샘플이 없다고 하면 $C_i$의 모든 샘플은

$$R_i = \{\boldsymbol{x} \mid \|\boldsymbol{x} - \boldsymbol{\mu}_i\|_2 < \|\boldsymbol{x} - \boldsymbol{\mu}_l\|_2,\ \forall l \neq i\}$$

에 들어갑니다. $\|\boldsymbol{x} - \boldsymbol{\mu}_i\|^2 < \|\boldsymbol{x} - \boldsymbol{\mu}_l\|^2$을 전개하면 $2(\boldsymbol{\mu}_l - \boldsymbol{\mu}_i)^\top\boldsymbol{x} < \|\boldsymbol{\mu}_l\|^2 - \|\boldsymbol{\mu}_i\|^2$이라는 $\boldsymbol{x}$에 대한 일차 부등식, 즉 열린 반공간이 됩니다. $R_i$는 반공간들의 교집합이므로 볼록 집합이고, 볼록 집합에 들어 있는 점들의 컨벡스 헐은 그 볼록 집합 안에 있습니다. 서로 다른 $R_i$는 겹치지 않으므로 컨벡스 헐도 겹치지 않습니다. LVQ도 학습이 끝나면 식 9.27처럼 가장 가까운 원형 벡터로 영역을 나누므로 같은 논리가 적용됩니다. 다만 책의 예처럼 원형 벡터 여러 개가 같은 클래스 레이블을 가질 때 같은 레이블의 영역을 합쳐 하나의 클러스터로 본다면, 볼록 영역의 합집합은 볼록이 아닐 수 있으므로 비컨벡스 클러스터가 생길 수 있습니다.

**가우시안 혼합.** 샘플은 $\alpha_i \, p(\boldsymbol{x} \mid \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)$가 가장 큰 성분에 배정됩니다(식 9.31). 두 성분의 로그 비를 쓰면

$$\ln\frac{\alpha_i \, p(\boldsymbol{x} \mid \boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i)}{\alpha_l \, p(\boldsymbol{x} \mid \boldsymbol{\mu}_l, \boldsymbol{\Sigma}_l)} = -\frac{1}{2}\boldsymbol{x}^\top(\boldsymbol{\Sigma}_i^{-1} - \boldsymbol{\Sigma}_l^{-1})\boldsymbol{x} + (\text{일차항}) + (\text{상수})$$

입니다. $\boldsymbol{\Sigma}_i = \boldsymbol{\Sigma}_l$이면 이차항이 사라져 경계가 초평면이고, 위의 $k$평균과 같은 이유로 컨벡스 클러스터가 됩니다. 그렇지 않으면 경계가 이차곡선입니다. 예를 들어 분산이 작은 성분이 분산이 큰 성분 안쪽에 있으면, 분산이 큰 성분의 영역은 타원의 바깥쪽이라 볼록이 아니고, 그 클러스터의 컨벡스 헐이 안쪽 클러스터를 감쌀 수 있습니다.

**DBSCAN과 AGNES.** DBSCAN의 클러스터는 밀도 접근 가능한 점들의 사슬로 정의되므로 고리 모양, 초승달 모양처럼 볼록하지 않은 모양을 그대로 따라갑니다. AGNES의 단일 연결도 같은 이유(문제 9.6의 연쇄 효과)로 비컨벡스 클러스터를 만듭니다. 완전 연결과 평균 연결은 조밀한 클러스터를 선호해서 대부분 컨벡스지만, 병합 기준이 공간을 볼록 영역으로 나누는 구조가 아니므로 보장은 없습니다.

**실험으로 확인.** 두 점 집합의 컨벡스 헐이 겹치는지는 "$\sum_a \lambda_a \boldsymbol{a} = \sum_b \mu_b \boldsymbol{b}$, $\lambda, \mu \geqslant 0$, $\sum \lambda = \sum \mu = 1$을 만족하는 해가 있는가"라는 선형계획 문제로 정확히 판정할 수 있습니다.

```python
from scipy.optimize import linprog
def hulls_intersect(A, B):
    na, nb = len(A), len(B)
    Aeq = np.vstack([np.hstack([A.T, -B.T]),
                     np.r_[np.ones(na), np.zeros(nb)], np.r_[np.zeros(na), np.ones(nb)]])
    beq = np.r_[np.zeros(A.shape[1]), 1, 1]
    return linprog(np.zeros(na + nb), A_eq=Aeq, b_eq=beq, bounds=(0, None),
                   method="highs").status == 0   # 실현 가능하면 겹침
```

수박 데이터 세트 4.0의 결과에 적용하면 다음과 같습니다.

- $k$평균: $k = 3$(최소 $E$ 해, 책의 초기값 해), $k = 4$ 모두 컨벡스였습니다.
- 가우시안 혼합(책의 초기값, $k = 3$): 5회, 10회, 50회 반복 결과는 컨벡스였지만 **20회 반복 결과는 비컨벡스**였습니다. 이때 클러스터는 $\{6, 7, 8, 10, 11, 12, 18, 19, 20, 23\}$, $\{1, 2, 3, 9, 13, 14, 16, 17, 21, 22, 26, 29\}$, $\{4, 5, 15, 24, 25, 27, 28, 30\}$이고, 첫째 클러스터의 $\boldsymbol{x}_{23}$이 셋째 클러스터의 컨벡스 헐 안에 들어 있어서 두 헐이 겹칩니다. $k$평균이었다면 일어날 수 없는 배치입니다.
- DBSCAN($\epsilon = 0.11$, $MinPts = 5$): 이 데이터에서는 우연히 컨벡스였습니다.
- AGNES: $d_{\max}$와 $d_{\text{avg}}$는 $k = 7, 4$ 모두 컨벡스였고, **$d_{\min}$은 $k = 4$에서 비컨벡스**였습니다. 외톨이 $\{\boldsymbol{x}_{15}\}$가 23개짜리 큰 클러스터의 컨벡스 헐 안에 들어 있기 때문입니다.

수박 데이터만으로는 DBSCAN과 완전·평균 연결의 비컨벡스 사례가 나오지 않아 인공 데이터로 확인했습니다. 반지름 1의 고리(100점, 잡음 표준편차 0.03)와 그 가운데 덩어리(30점, 표준편차 0.1)를 만들면(시드 0), DBSCAN($\epsilon = 0.2$, $MinPts = 4$)과 단일 연결($k = 2$)은 고리 100점과 가운데 30점으로 정확히 나누는데, 고리의 컨벡스 헐이 가운데 덩어리를 감싸므로 비컨벡스입니다. 같은 데이터에서 완전 연결은 고리를 잘라 컨벡스한 두 덩어리(94, 36점)를 만들었습니다. 또 $[0,1]^2$에 균등하게 뿌린 30개 점으로 $k = 4$ 클러스터링을 3000번(시드 0~2999, scipy의 `linkage` 사용) 해 보면, 완전 연결은 0.8%, 평균 연결은 0.2%의 경우에서 컨벡스 헐이 겹치는 결과가 나왔습니다. 드물지만 일어나므로 "컨벡스 클러스터만 생성한다"고 말할 수 없습니다.

## 문제 9.8

> 클러스터링 성능척도 지표를 만들고 9.2절에서의 지표와 비교해 보아라.

**풀이**

답이 하나로 정해진 문제가 아니므로, 9.2절 지표의 약점 하나를 정하고 그것을 보완하는 지표를 설계해 보겠습니다.

**동기.** 9.2절의 내부 지표 중 DBI(식 9.12)는 클러스터 내 평균 거리 avg와 중심점 간 거리 $d_{\text{cen}}$을, DI(식 9.13)는 클러스터 간 최단 거리 $d_{\min}$과 클러스터 지름 diam을 씁니다. avg, diam, $d_{\text{cen}}$은 모두 클러스터가 둥글고 조밀하다는 가정에 맞춰져 있어서, 초승달처럼 길쭉하지만 잘 분리된 클러스터는 "지름이 크다", "중심이 가깝다"는 이유로 나쁘게 평가됩니다. 그래서 클러스터의 "지름" 대신 "클러스터가 끊기지 않고 이어져 있는 정도"를 재는 지표를 만들었습니다.

**제안 지표: 연결-분리 비율(CSR).** 클러스터 $C$ 안의 점들로 최소 신장 트리(MST)를 만들고, 그 가장 긴 간선 길이를 $\operatorname{gap}(C)$라 합니다. $\operatorname{gap}(C)$는 "클러스터 안에서 가장 크게 벌어진 틈"이고, 클러스터가 길쭉해도 점들이 촘촘히 이어져 있으면 작습니다.

$$\operatorname{CSR} = \frac{\min_{i \neq j} d_{\min}(C_i, C_j)}{\max_{1 \leqslant l \leqslant k}\operatorname{gap}(C_l)}$$

분자는 클러스터 사이의 가장 좁은 간격(식 9.10), 분모는 클러스터 안의 가장 넓은 틈이므로, 값이 클수록 "안은 촘촘히 이어져 있고 밖과는 뚜렷이 떨어져 있다"는 뜻입니다. DI의 diam을 gap으로 바꾼 형태이고, 비슷한 MST 기반 DI 변형이 문헌에도 제안된 바 있습니다(Pal and Biswas, 1997).

```python
from scipy.sparse.csgraph import minimum_spanning_tree
def csr(X, lab):
    C = [X[lab == k] for k in np.unique(lab)]
    D = lambda A, B: np.linalg.norm(A[:, None] - B[None], axis=2)
    sep = min(D(A, B).min() for A, B in itertools.combinations(C, 2))
    gap = max(minimum_spanning_tree(D(A, A)).toarray().max() if len(A) > 1 else 0 for A in C)
    return sep / gap
```

- 반면 수박 데이터에서 CSR은 외톨이 $\boldsymbol{x}_{15}$ 하나만 떼어 낸 단일 연결 결과($\{\boldsymbol{x}_{15}\}$와 나머지 29개)를 가장 좋게 평가했습니다. 외톨이 클러스터는 gap이 0이고, 그 점이 다른 점들에서 조금만 떨어져 있어도 분자가 분모보다 커지기 때문입니다. 이것이 CSR의 약점입니다. 실제로 쓰려면 최소 클러스터 크기를 두거나 외톨이를 노이즈로 따로 처리해야 합니다. 분자와 분모가 모두 최솟값·최댓값 하나로 정해지므로 잡음 점 하나에 민감하다는 점도 DI와 같습니다.
- 외부 지표도 비교해 볼 만합니다. 수박 데이터의 단일 연결 결과는 거의 모든 점을 한 클러스터에 넣었을 뿐인데 JC, FMI가 가장 높게 나왔습니다. 같은 클러스터에 넣은 쌍만 세는 JC, FMI는 큰 클러스터 하나로 몰아넣는 결과를 과대평가할 수 있고, 다른 클러스터에 넣은 쌍($d$)도 세는 RI는 0.503으로 이를 잡아냈습니다.

## 문제 9.9\* (심화)

> 혼합 속성에 사용 가능한 비척도 거리를 만들어 보아라.

**풀이**

비척도 거리는 식 9.14~9.17 중 하나 이상(주로 삼각부등식)을 만족하지 않는 거리입니다. 가장 간단한 답은 식 9.22의 MinkovDM$_p$에서 $p < 1$을 쓰거나(문제 9.1의 반례), 제곱근을 씌우지 않은 제곱 거리를 쓰는 것입니다. 하지만 그림 9.1의 "사람, 말, 인마(켄타우로스)" 예처럼 비척도성이 의미를 갖는 거리를 만들어 보겠습니다. 아이디어는 "**일부 속성만 비슷해도 비슷하다**"고 보는 부분 일치 거리입니다.

**정의.** 샘플 $\boldsymbol{x}_i, \boldsymbol{x}_j$의 속성 $u$마다 $[0, 1]$ 범위의 비유사도 $\delta_u$를 정합니다.

- 연속 속성: $\delta_u = \dfrac{|x_{iu} - x_{ju}|}{\max_u - \min_u}$ (데이터에서의 값 범위로 정규화)
- 순서형 이산 속성: 값을 순위 $1, \dots, V_u$로 바꾼 뒤 $\delta_u = \dfrac{|\text{순위 차}|}{V_u - 1}$
- 무순서형 이산 속성: $\delta_u = \dfrac{1}{2}\operatorname{VDM}_1(x_{iu}, x_{ju})$ (식 9.21에서 $p = 1$이면 최댓값이 2이므로 2로 나눔)

이 $n$개의 값을 작은 것부터 $\delta_{(1)} \leqslant \delta_{(2)} \leqslant \dots \leqslant \delta_{(n)}$로 정렬하고, $r < n$을 정해 가장 작은 $r$개만 더합니다.

$$\operatorname{dist}_r(\boldsymbol{x}_i, \boldsymbol{x}_j) = \sum_{t=1}^{r}\delta_{(t)}(\boldsymbol{x}_i, \boldsymbol{x}_j)$$

즉 두 샘플이 가장 많이 다른 $n - r$개 속성은 무시합니다. $r = n$이면 정규화된 MinkovDM$_1$(식 9.22)이고, 이것은 거리척도입니다.

**성질.**

- 비음수성: $\delta_u \geqslant 0$이므로 성립합니다.
- 대칭성: 각 $\delta_u$가 대칭이고(VDM 정의도 $a, b$에 대해 대칭), 정렬 후 합도 대칭이므로 성립합니다.
- 동일성: $\boldsymbol{x}_i = \boldsymbol{x}_j$이면 모든 $\delta_u = 0$이라 거리는 0입니다. 그러나 역은 성립하지 않습니다. 두 샘플이 $r$개 속성에서 같으면 다른 속성이 아무리 달라도 거리가 0입니다.
- 삼각부등식: 성립하지 않습니다. 속성 두 개($n = 2$), $r = 1$인 경우를 보겠습니다. $\boldsymbol{x} = (a, c)$, $\boldsymbol{z} = (a, d)$, $\boldsymbol{y} = (b, d)$이고 $\delta(a, b) > 0$, $\delta(c, d) > 0$이면

$$\operatorname{dist}_1(\boldsymbol{x}, \boldsymbol{z}) = \min(0, \delta(c,d)) = 0,\quad \operatorname{dist}_1(\boldsymbol{z}, \boldsymbol{y}) = \min(\delta(a,b), 0) = 0,$$

$$\operatorname{dist}_1(\boldsymbol{x}, \boldsymbol{y}) = \min(\delta(a,b), \delta(c,d)) > 0 = \operatorname{dist}_1(\boldsymbol{x}, \boldsymbol{z}) + \operatorname{dist}_1(\boldsymbol{z}, \boldsymbol{y}) .$$

$\boldsymbol{z}$가 바로 "인마"입니다. 앞 속성은 $\boldsymbol{x}$("사람")와, 뒤 속성은 $\boldsymbol{y}$("말")와 같아서 양쪽 모두와 가깝지만, $\boldsymbol{x}$와 $\boldsymbol{y}$는 서로 멉니다.

**수박 데이터 세트 3.0에서 확인.** 표 4.3의 수박 데이터 세트 3.0(17개 샘플, 무순서형 이산 속성 6개와 연속 속성 2개)에 $r = 6$을 적용했습니다. VDM의 클러스터로는 "잘 익은 수박" 클래스(2개)를 썼습니다.

```python
def vdm1(u, a, b):             # 식 9.21, p=1, 클래스를 클러스터로 사용
    col = df[u].values
    return sum(abs(np.mean(lab[col == a] == c) - np.mean(lab[col == b] == c)) for c in classes)

def deltas(i, j):              # 속성별 비유사도, 모두 [0, 1]
    xi, xj = df.loc[i], df.loc[j]
    return np.array([abs(xi[u] - xj[u]) / rng_[u] for u in num] +
                    [vdm1(u, xi[u], xj[u]) / 2 for u in cat])

def dist_r(i, j, r=6):         # 가장 작은 r개 속성 비유사도의 합
    return np.sort(deltas(i, j))[:r].sum()
```

샘플 쌍 $\{i, j\}$ 136개와 나머지 샘플 $k$ 15개로 만든 2040개의 조합 중 318개(15.6%)에서 $\operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_j) > \operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_k) + \operatorname{dist}(\boldsymbol{x}_k, \boldsymbol{x}_j)$가 되었습니다. 같은 코드에서 $r = 8$(모든 속성 사용)이면 위반이 0개였습니다. 위반 폭이 가장 큰 조합은 $\boldsymbol{x}_5$, $\boldsymbol{x}_{12}$, $\boldsymbol{x}_{11}$입니다.

| 쌍 | 밀도 | 당도 | 색깔 | 꼭지 | 소리 | 줄무늬 | 배꼽 | 감촉 | $\operatorname{dist}_6$ |
|---|---|---|---|---|---|---|---|---|---|
| $\boldsymbol{x}_5$, $\boldsymbol{x}_{11}$ | 0.586 | 0.378 | 0 | 0.625 | 0.6 | 0.778 | 0.714 | 0 | 2.189 |
| $\boldsymbol{x}_5$, $\boldsymbol{x}_{12}$ | 0.401 | 0.278 | 0 | 0 | 0 | 0.778 | 0.714 | 0 | 0.679 |
| $\boldsymbol{x}_{12}$, $\boldsymbol{x}_{11}$ | 0.185 | 0.100 | 0 | 0.625 | 0.6 | 0 | 0 | 0 | 0.285 |

$\boldsymbol{x}_{12}$(연녹색, 말림, 혼탁, 흐림, 평평함, 단단함)는 꼭지·소리가 $\boldsymbol{x}_5$와 같고 줄무늬·배꼽이 $\boldsymbol{x}_{11}$과 같은 "인마" 역할을 합니다. 그래서 $2.189 > 0.679 + 0.285 = 0.964$가 됩니다. 또 $\boldsymbol{x}_{12}$와 $\boldsymbol{x}_{16}$은 이산 속성 6개가 모두 같고 밀도·당도만 다른데, $r = 6$이면 그 두 속성이 버려져 거리가 0이 됩니다(동일성 위반).

**쓰임과 주의점.** 이 거리는 속성 몇 개가 측정 오류나 무관한 정보로 크게 어긋나 있어도 나머지 속성이 비슷하면 비슷하다고 판단하므로, 일부 속성이 오염된 데이터나 부분 일치가 중요한 검색 문제에 맞습니다. 대신 삼각부등식이 없으므로 이를 이용하는 가속 기법(거리 상한을 이용한 가지치기 등)을 쓸 수 없고, 평균 벡터를 계산하는 $k$평균에는 바로 쓸 수 없습니다. 거리 행렬만 있으면 되는 AGNES, DBSCAN, 또는 중심을 샘플 중에서 고르는 $k$-medoids와 함께 씁니다. 또 VDM은 클러스터(또는 클래스) 정보가 있어야 계산되므로, 레이블이 없는 데이터에서는 직전 클러스터링 결과를 클러스터 정보로 쓰고 번갈아 갱신하는 방식이 필요합니다.

## 문제 9.10\* (심화)

> 자동으로 클러스터링 수를 결정하는 개선된 $k$평균 알고리즘을 만들고, 수박 데이터 세트 4.0상에서 실험해 보아라.

**풀이**

책의 더 읽을거리에서 소개한 X-means(Pelleg and Moore, 2000)의 아이디어를 따라 구현했습니다. 하나의 클러스터에서 시작해, 각 클러스터를 2평균으로 둘로 나눠 보고 **나눈 쪽의 BIC가 더 높을 때만** 실제로 나눕니다. 더 이상 나눌 클러스터가 없으면 멈추므로 $k$가 자동으로 정해집니다.

**BIC.** 각 클러스터를 같은 분산 $\hat\sigma^2$(차원마다 같음)의 구형 가우시안으로 보고, 샘플이 자기 클러스터에 확정적으로 배정되었다고 보는 로그 우도를 씁니다. 샘플 수 $R$, 차원 $M$, 클러스터 수 $K$, 클러스터 내 제곱합을 SSE(식 9.24의 $E$)라 하면

$$\ell = \sum_{i=1}^{K}|C_i|\ln\frac{|C_i|}{R} - \frac{RM}{2}\ln(2\pi\hat\sigma^2) - \frac{\text{SSE}}{2\hat\sigma^2},\qquad \hat\sigma^2 = \frac{\text{SSE}}{M(R - K)}$$

$$\text{BIC} = \ell - \frac{p}{2}\ln R,\qquad p = (K - 1) + KM + 1$$

입니다. $p$는 혼합 비율, 중심, 분산의 자유 파라미터 수입니다. $K$를 늘리면 SSE가 줄어 $\ell$이 커지지만 $p$가 늘어 벌점도 커지므로, 그 균형으로 $K$가 정해집니다.

```python
def bic(X, lab):
    R, M = X.shape; ks = np.unique(lab); K = len(ks)
    sse = sum(((X[lab == k] - X[lab == k].mean(0))**2).sum() for k in ks)
    var = sse / (M * (R - K))
    ll = sum(n * np.log(n / R) for n in (np.sum(lab == k) for k in ks)) \
         - R * M / 2 * np.log(2 * np.pi * var) - sse / (2 * var)
    return ll - ((K - 1) + K * M + 1) / 2 * np.log(R)

def best_2means(P):            # 가능한 초기 쌍 중 E가 가장 작은 2평균 결과
    runs = [kmeans(P, init) for init in itertools.combinations(range(len(P)), 2)]
    return min(runs, key=lambda r: r[3])[0]

def xmeans(X, k_max=10):
    clusters = [np.arange(len(X))]
    while len(clusters) < k_max:
        new, changed = [], False
        for c in clusters:
            if len(c) < 6: new.append(c); continue        # 너무 작으면 쪼개지 않음
            sub = best_2means(X[c])
            if min(np.bincount(sub)) >= 2 and bic(X[c], sub) > bic(X[c], np.zeros(len(c), int)):
                new += [c[sub == 0], c[sub == 1]]; changed = True
            else:
                new.append(c)
        if not changed: break
        mu = np.array([X[c].mean(0) for c in new])     # 전체에서 k평균으로 경계 다듬기
        lab = kmeans_from(X, mu)                       # 주어진 중심에서 시작하는 k평균
        clusters = [np.where(lab == i)[0] for i in range(len(mu)) if np.any(lab == i)]
    return clusters
```

(클러스터가 클 때는 `best_2means`에서 초기 쌍을 시드 0으로 200쌍만 뽑아 쓰도록 했습니다. 수박 데이터에서는 모든 쌍을 씁니다.)

**알고리즘 확인.** 수박 데이터에 쓰기 전에 클러스터가 분명한 인공 데이터로 동작을 확인했습니다. `make_blobs`(200점, 중심 4개, cluster_std=0.6, random_state=0)에서 X-means는 $k = 4$를 찾았고 정답과 완전히 일치했습니다(ARI 1.000). 다만 cluster_std=1.0으로 클러스터가 겹치게 하면 $k = 2$에서 멈췄습니다. 위에서부터 둘씩 나누는 방식이라 겹친 클러스터를 한 번에 가르지 못하는 한계입니다.

**수박 데이터 세트 4.0 결과.** X-means는 첫 단계에서 전체를 둘로 나누지 않고 $k = 1$로 끝났습니다. 확인을 위해 $k = 1, \dots, 8$마다 $E$가 가장 작은 $k$평균 해($k \leqslant 4$는 모든 초기값, 그 이상은 시드 0으로 무작위 2000회)의 전체 BIC를 계산하고, 다른 두 기준도 함께 계산했습니다. 갭 통계량(Tibshirani et al., 2001)은 데이터의 범위 안에서 균등분포로 뽑은 참조 데이터 50개(시드 0)와 $\ln E$를 비교하며, "$\text{Gap}(k) \geqslant \text{Gap}(k+1) - s_{k+1}$을 만족하는 가장 작은 $k$"를 고릅니다. 실루엣 계수는 클수록 좋고 $k \geqslant 2$에서만 정의됩니다.

|---|---|---|---|---|---|
| 1 | 1.2622 | **25.591** | -0.092 | 0.128 | - |
| 2 | 0.6932 | 17.685 | -0.149 | 0.139 | 0.367 |
| 3 | 0.4097 | 16.445 | -0.139 | 0.137 | 0.404 |
| 4 | 0.2477 | 17.601 | -0.059 | 0.137 | **0.453** |
| 5 | 0.2008 | 12.885 | -0.178 | 0.166 | 0.421 |
| 6 | 0.1613 | 9.364 | -0.243 | 0.151 | 0.397 |
| 7 | 0.1239 | 6.489 | -0.231 | 0.158 | 0.394 |
| 8 | 0.1070 | 1.495 | -0.302 | 0.146 | 0.366 |

(갭 통계량을 계산할 때는 $k \geqslant 4$에서 무작위 초기값 300회(시드 0) 중 최솟값을 썼고, 그 값은 $k = 8$에서만 0.1075로 표의 $E$와 조금 달랐습니다.)

BIC가 $k = 1$에서 가장 크고, 갭 통계량도 $\text{Gap}(1) = -0.092 \geqslant \text{Gap}(2) - s_2 = -0.288$이라 $k = 1$을 고릅니다. 서로 다른 두 기준이 모두 "이 데이터에는 균등하게 퍼진 점들과 구별되는 클러스터 구조가 뚜렷하지 않다"고 판단한 것입니다. 30개 점이 밀도 0.24~0.77, 당도 0.04~0.49 범위에 고르게 퍼져 있다는 점을 생각하면 납득할 만한 결과이고, 문제 9.4에서 거의 같은 $E$의 국소 최적해가 많이 나온 것과도 맞아떨어집니다.

반면 "클러스터가 반드시 두 개 이상 있다"고 전제하고 평균 실루엣 계수가 가장 큰 $k$를 고르는 방식은 $k = 4$를 고릅니다. 이때의 분할은 문제 9.4의 $k = 4$ 최소 $E$ 해, 즉 $\{15, 23, 24, 25, 27, 28, 30\}$, $\{1, 2, 4, 22, 26, 29\}$, $\{6, 7, 8, 10, 11, 12, 18, 19, 20\}$, $\{3, 5, 9, 13, 14, 16, 17, 21\}$입니다. 문제 9.4에서 DBI, DI가 $k = 2, 3, 4$ 중 $k = 4$를 고른 것과도 일치합니다.

정리하면, 클러스터 수를 자동으로 정하는 방법은 "클러스터를 하나 더 두는 것이 정당한가"를 판단하는 기준에 따라 답이 달라집니다. BIC와 갭 통계량처럼 $k = 1$도 후보로 보는 기준은 수박 데이터 세트 4.0에 뚜렷한 클러스터가 없다고 답하고, 실루엣처럼 $k \geqslant 2$ 안에서 고르는 기준은 $k = 4$를 고릅니다. 실제로 쓸 때는 두 종류의 기준을 함께 보고, 자동으로 정한 $k$를 데이터에 대한 이해와 대조해 보는 것이 안전합니다.
