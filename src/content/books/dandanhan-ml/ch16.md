### 실험에 쓰는 수박 물 주기 MDP(그림 16.2)

16.2, 16.3, 16.4, 16.6에서는 436쪽 그림 16.2의 MDP를 그대로 씁니다. 상태는 4개(건강함, 물 부족, 물이 넘침, 시듦), 액션은 2개(물을 줌, 물을 주지 않음)이고, 그림을 표로 옮기면 다음과 같습니다. 괄호 안은 (전이 확률, 보상)입니다.

| 현재 상태 | 액션 | 다음 상태 (전이 확률, 보상) |
|---|---|---|
| 건강함 | 물을 줌 | 건강함 (0.6, $+1$), 물이 넘침 (0.4†, $-1$) |
| 건강함 | 물을 주지 않음 | 건강함 (0.4, $+1$), 물 부족 (0.6, $-1$) |
| 물 부족 | 물을 줌 | 물 부족 (0.5, $-1$), 건강함 (0.5, $+1$‡) |
| 물 부족 | 물을 주지 않음 | 물 부족 (0.4, $-1$), 시듦 (0.6, $-100$) |
| 물이 넘침 | 물을 줌 | 물이 넘침 (0.6, $-1$), 시듦 (0.4, $-100$) |
| 물이 넘침 | 물을 주지 않음 | 물이 넘침 (0.4, $-1$), 건강함 (0.6, $+1$‡) |
| 시듦 | 두 액션 모두 | 시듦 (1, $-100$) |

그림을 옮기면서 두 군데는 손을 봤습니다.

- (†) 그림에는 건강함에서 물을 줄 때 "건강함 0.6, 물이 넘침 0.5"로 인쇄되어 있어 확률의 합이 1.1입니다. 합이 1이 되도록 물이 넘침 쪽을 0.4로 두었습니다.
- (‡) 그림에는 물 부족→건강함, 물이 넘침→건강함의 보상이 $-1$로 되어 있지만, 436쪽 본문은 "전이 후 건강하면 1점, 물이 부족하거나 넘치면 $-1$점"이라고 설명합니다. 본문 설명에 맞춰 $+1$로 두었습니다. 그림대로 $-1$을 써도 최적 정책은 같다는 것을 문제 16.3에서 함께 확인합니다.

시듦은 빠져나올 수 없는 상태라서 들어간 뒤로는 매 단계 $-100$을 받습니다. 따라서 γ할인 누적 보상에서는 어떤 정책이든 $V(\text{시듦})=-100/(1-\gamma)$이고, $\gamma=0.9$이면 $-1000$입니다.

```python
# mdp.py: 그림 16.2 수박 물 주기 MDP
import numpy as np
S = ["건강함", "물 부족", "물이 넘침", "시듦"]   # H, D, O, W
A = ["물을 줌", "물을 주지 않음"]
H, D, O, W = range(4)
WATER, NO = range(2)

def build(printed_rewards=False):
    """(s, a) -> [(s', p, r)]. 건강함->물이 넘침(물을 줌)은 그림의 0.5 대신 0.4로 둔다."""
    rH = -1 if printed_rewards else 1          # 물 부족/물이 넘침 -> 건강함 보상
    T = {(H, WATER): [(H, .6, 1), (O, .4, -1)],
         (H, NO):    [(H, .4, 1), (D, .6, -1)],
         (D, WATER): [(D, .5, -1), (H, .5, rH)],
         (D, NO):    [(D, .4, -1), (W, .6, -100)],
         (O, WATER): [(O, .6, -1), (W, .4, -100)],
         (O, NO):    [(O, .4, -1), (H, .6, rH)],
         (W, WATER): [(W, 1., -100)],
         (W, NO):    [(W, 1., -100)]}
    P = np.zeros((4, 2, 4)); R = np.zeros((4, 2, 4))
    for (s, a), lst in T.items():
        for s2, p, r in lst:
            P[s, a, s2] += p; R[s, a, s2] = r
    assert np.allclose(P.sum(2), 1)
    return P, R
```

## 문제 16.1

> K-암드 밴딧 머신에 사용하는 UCB(Upper Confidence Bound) 방법은 매번 $Q(k) + UC(k)$값이 가장 큰 손잡이를 선택하고, 여기서 $Q(k)$는 손잡이 $k$의 평균 보상이며 $UC(k)$는 신뢰 구간이다. 예를 들어,
>
> $$Q(k)+\sqrt{\frac{2\ln n}{n_k}},$$
>
> 여기서 $n$은 이미 실행한 모든 손잡이의 총 횟수이며, $n_k$는 실행한 손잡이 $k$의 횟수다. UCB 방법과 $\epsilon$-그리디 방법, 그리고 소프트맥스 방법의 차이점과 공통점에 대해 비교해 보아라.

**풀이**

**UCB의 보너스 항이 어디서 나오는지부터 보겠습니다.** 보상이 $[0,1]$ 안의 값이고 손잡이 $k$를 $n_k$번 당겨 평균 $Q(k)$를 얻었다면, 호에프딩 부등식에 따라 진짜 기대 보상 $\mu_k$에 대해

$$
P\big(\mu_k \ge Q(k)+c\big)\le e^{-2n_k c^2}
$$

입니다. 여기에 $c=\sqrt{2\ln n/n_k}$를 넣으면 우변이 $e^{-4\ln n}=n^{-4}$가 됩니다. 즉 $Q(k)+\sqrt{2\ln n/n_k}$는 확률 $1-n^{-4}$ 이상으로 $\mu_k$보다 큰 "신뢰 상한"입니다. UCB는 각 손잡이를 이 상한으로 평가해서, 아직 잘 모르는 손잡이는 좋을 수도 있다고 낙관적으로 보고 시도합니다. 많이 당긴 손잡이는 $n_k$가 커져 보너스가 줄고, 적게 당긴 손잡이는 $\ln n$이 천천히 커지면서 보너스가 다시 커지므로 어떤 손잡이도 영원히 버려지지 않습니다. 이렇게 하면 기대 보상이 최적보다 $\Delta_k$만큼 낮은 손잡이는 대략 $O(\ln n/\Delta_k^2)$번만 당겨지고, 누적 손실(후회)이 $O\big(\sum_k \ln n/\Delta_k\big)$로 로그 속도로만 늘어난다는 것이 알려져 있습니다(Auer, Cesa-Bianchi, Fischer, 2002). 한 번도 당기지 않은 손잡이는 $n_k=0$이라 보너스가 무한대이므로, 처음에는 모든 손잡이를 한 번씩 당기고 시작합니다.

**공통점**

1. 셋 다 단일 단계 강화 학습, 곧 K-암드 밴딧의 탐색-이용 딜레마를 푸는 방법입니다. 손잡이별 평균 보상 $Q(k)$를 식 16.2(또는 식 16.3)로 점진적으로 갱신하는 부분은 똑같고, 다른 것은 "다음에 어느 손잡이를 당길지"를 고르는 규칙뿐입니다.
2. 셋 다 평균 보상이 높은 손잡이를 주로 고르면서(이용) 다른 손잡이에도 기회를 줍니다(탐색).
3. 파라미터를 극단으로 보내면 탐색만 하거나 이용만 하는 방법으로 돌아갑니다. $\epsilon=0$이나 $\tau\to0$은 이용만, $\epsilon=1$이나 $\tau\to\infty$는 탐색만에 해당하고, UCB도 보너스 항에 계수 $c$를 붙여 $Q(k)+c\sqrt{\ln n/n_k}$로 쓰면 $c=0$일 때 이용만이 됩니다.

**차이점**

| 구분 | $\epsilon$-그리디 | 소프트맥스 | UCB |
|---|---|---|---|
| 선택 방식 | 확률적: $\epsilon$ 확률로 균등 무작위 | 확률적: 볼츠만 분포(식 16.4) | 결정론적: $Q(k)+UC(k)$ 최대 |
| 쓰는 정보 | $Q$의 순위(최댓값이 누구인지)만 | $Q$의 크기 차이 | $Q$와 시도 횟수 $n_k$, $n$ |
| 탐색이 어디로 가는가 | 모든 손잡이에 똑같이, 명백히 나쁜 손잡이에도 | 평균 보상이 높은 손잡이일수록 자주 | 덜 시도해서 불확실한 손잡이로 |
| 시간에 따른 탐색량 | $\epsilon$이 상수면 끝까지 그대로라서 $\epsilon=1/\sqrt{t}$ 같은 감소 일정을 따로 정해야 함 | $\tau$가 상수면 $Q$의 차이로 정해지는 비율이 그대로 유지됨 | $n_k$가 늘면서 저절로 줄어듦 |
| 조절할 값 | $\epsilon$ | $\tau$ (보상의 스케일에 민감) | 위 형태에서는 없음 (대신 보상이 $[0,1]$이라는 가정) |
| 장기 성능 | $\epsilon$ 고정이면 후회가 선형으로 증가 | $\tau$ 고정이면 후회가 선형으로 증가 | 후회가 로그로 증가 |

정리하면 $\epsilon$-그리디와 소프트맥스는 무작위성으로 탐색을 만들고, UCB는 불확실성(시도 횟수)을 점수에 직접 넣어 탐색을 만듭니다. 소프트맥스는 "얼마나 좋은가"를 반영한다는 점에서 $\epsilon$-그리디보다 낫지만 "얼마나 확실한가"는 반영하지 못하고, UCB는 둘 다 반영합니다.

**실험.** 그림 16.6과 같은 2-암드 밴딧(손잡이1은 0.4 확률로 보상 1, 손잡이2는 0.2 확률로 보상 1)에서 3,000번 시도를 1,000번 반복해 평균 누적 보상(누적 보상 ÷ 시도 횟수의 평균)을 쟀습니다. 시드는 0입니다.

```python
import numpy as np
p = np.array([0.4, 0.2])            # 그림 16.6의 2-암드 밴딧
K, T, RUNS = 2, 3000, 1000

def run(select, seed=0):
    rng = np.random.default_rng(seed)
    Q = np.zeros((RUNS, K)); cnt = np.zeros((RUNS, K)); total = np.zeros(RUNS)
    avg = np.zeros(T); best = np.zeros(T)
    for t in range(1, T + 1):
        k = select(Q, cnt, t, rng)
        v = (rng.random(RUNS) < p[k]).astype(float)       # v = R(k)
        idx = np.arange(RUNS)
        Q[idx, k] += (v - Q[idx, k]) / (cnt[idx, k] + 1)   # 식 16.3
        cnt[idx, k] += 1; total += v
        avg[t - 1] = (total / t).mean(); best[t - 1] = (k == 0).mean()
    return avg, best

def argmax_rand(M, rng):             # 동률이면 임의로 하나
    return (M + 1e-9 * rng.random(M.shape) * (M == M.max(1, keepdims=True))).argmax(1)

def eps_greedy(eps):
    def f(Q, cnt, t, rng):
        k = argmax_rand(Q, rng)
        explore = rng.random(len(Q)) < eps
        return np.where(explore, rng.integers(0, K, len(Q)), k)
    return f

def softmax(tau):
    def f(Q, cnt, t, rng):
        z = np.exp((Q - Q.max(1, keepdims=True)) / tau)   # 식 16.4
        P = z / z.sum(1, keepdims=True)
        return (rng.random((len(Q), 1)) > P.cumsum(1)).sum(1)
    return f

def ucb(Q, cnt, t, rng):
    n = cnt.sum(1, keepdims=True)
    with np.errstate(divide='ignore', invalid='ignore'):
        U = Q + np.sqrt(2 * np.log(np.maximum(n, 1)) / cnt)
    U[cnt == 0] = np.inf               # 아직 안 당긴 손잡이를 먼저 당긴다
    return argmax_rand(U, rng)

algos = {"탐색만": lambda Q, c, t, r: r.integers(0, K, len(Q)),
         "이용만": eps_greedy(0.0), "e-greedy 0.1": eps_greedy(0.1),
         "e-greedy 0.01": eps_greedy(0.01), "softmax 0.1": softmax(0.1),
         "softmax 0.01": softmax(0.01), "UCB": ucb}
for name, f in algos.items():
    avg, best = run(f, seed=0)
    print(f"{name:14s} avg@100 {avg[99]:.4f} @500 {avg[499]:.4f} @3000 {avg[-1]:.4f}  best-arm@3000 {best[-1]:.3f}")
```

| 방법 | 100번째 | 500번째 | 3,000번째 | 3,000번째 시도에서 손잡이1을 고른 비율 |
|---|---|---|---|---|
| 탐색만 | 0.2992 | 0.3000 | 0.3001 | 0.493 |
| 이용만 | 0.3341 | 0.3334 | 0.3339 | 0.669 |
| $\epsilon$-그리디 ($\epsilon=0.1$) | 0.3537 | 0.3775 | 0.3879 | 0.953 |
| $\epsilon$-그리디 ($\epsilon=0.01$) | 0.3376 | 0.3509 | 0.3816 | 0.979 |
| 소프트맥스 ($\tau=0.1$) | 0.3609 | 0.3747 | 0.3771 | 0.881 |
| 소프트맥스 ($\tau=0.01$) | 0.3280 | 0.3275 | 0.3279 | 0.639 |
| UCB | 0.3395 | 0.3628 | 0.3861 | 0.978 |

책의 방법들 사이 순서는 그림 16.6과 같고, 소프트맥스($\tau=0.01$)가 이용만과 거의 겹치는 것도 재현됩니다. 표에서 세 가지를 읽을 수 있습니다.

- UCB는 초반(100번째)에 오히려 낮습니다. $n$이 작을 때 보너스가 커서 손잡이2도 꽤 당겨 보기 때문입니다. 이후 손잡이2의 보너스가 줄면서 3,000번째에는 손잡이1을 97.8% 고릅니다.
- $\epsilon=0.1$은 이 짧은 실험에서는 가장 높지만 천장이 있습니다. 시간이 아무리 지나도 $\epsilon/2=5\%$는 손잡이2를 고르므로 기대 보상이 $0.95\times0.4+0.05\times0.2=0.39$를 넘지 못합니다. 손잡이1을 고른 비율이 0.953에 머무는 것이 그 흔적입니다. UCB는 손잡이2를 고르는 비율이 계속 줄어 0.4에 다가갑니다.
- 소프트맥스($\tau=0.1$)에서 두 손잡이의 평균 보상 차이가 0.2이면 손잡이1을 고를 확률이 $1/(1+e^{-0.2/0.1})=0.881$로 고정됩니다. 표의 0.881이 정확히 이 값입니다. $\tau$를 고정하면 탐색 비율이 줄지 않는다는 점을 보여 줍니다.

## 문제 16.2

> 그림 16.7을 참조해 $\gamma$할인 보상 함수의 정책 평가 알고리즘을 작성하라.

**풀이**

그림 16.7은 T단계 누적 보상용입니다. γ할인 누적 보상으로 바꾸려면 445쪽 설명대로 두 곳을 고칩니다. 3행의 갱신식을 식 16.8로 바꾸고, 반복이 끝나지 않으므로 4행의 종료 조건 $t=T+1$을 식 16.9의 수렴 역치 조건으로 바꿉니다.

**입력**: MDP 쿼드러플 $E=\langle X,A,P,R\rangle$, 평가받는 정책 $\pi$, 보상 할인 $\gamma$, 수렴 역치 $\theta$

**과정**:

1. $\forall x\in X:\ V(x)=0$
2. **for** $t=1,2,\dots$ **do**
3. &emsp; $\forall x\in X:\ V'(x)=\sum_{a\in A}\pi(x,a)\sum_{x'\in X}P^a_{x\to x'}\big(R^a_{x\to x'}+\gamma V(x')\big)$ (식 16.8)
4. &emsp; **if** $\max_{x\in X}|V(x)-V'(x)|<\theta$ **then** (식 16.9)
5. &emsp;&emsp; **break**
6. &emsp; **else**
7. &emsp;&emsp; $V=V'$
8. &emsp; **end if**
9. **end for**

**출력**: 상태 가치 함수 $V'$

**왜 수렴하는지.** 3행을 연산자 $V'=\mathcal{T}_\pi V$로 쓰면, 두 함수 $V_1,V_2$에 대해

$$
\big|(\mathcal{T}_\pi V_1)(x)-(\mathcal{T}_\pi V_2)(x)\big|
=\gamma\Big|\sum_{a}\pi(x,a)\sum_{x'}P^a_{x\to x'}\big(V_1(x')-V_2(x')\big)\Big|
\le\gamma\max_{x'}|V_1(x')-V_2(x')|
$$

입니다. 마지막 부등식은 $\sum_a\sum_{x'}\pi(x,a)P^a_{x\to x'}=1$이라 가중 평균이 최댓값을 넘지 못하기 때문입니다. 따라서 $\mathcal{T}_\pi$는 최대 노름에서 계수 $\gamma<1$인 축소 사상이고, 바나흐 고정점 정리에 따라 어디서 시작하든 유일한 고정점으로 수렴합니다. 식 16.8에 따라 그 고정점이 $V^\pi_\gamma$입니다. T단계 버전과 달리 정확한 값에 유한 번에 도달하지는 않으므로 종료 조건이 필요한 것입니다.

**멈췄을 때의 오차.** $\max_x|V(x)-V'(x)|<\theta$에서 멈추면, $V'=\mathcal{T}_\pi V$, $V^\pi=\mathcal{T}_\pi V^\pi$이므로

$$
\|V'-V^\pi\|_\infty\le\gamma\|V-V^\pi\|_\infty\le\gamma\big(\|V-V'\|_\infty+\|V'-V^\pi\|_\infty\big)
\;\Longrightarrow\;
\|V'-V^\pi\|_\infty\le\frac{\gamma\theta}{1-\gamma}
$$

입니다. $\gamma$가 1에 가까우면 같은 $\theta$라도 오차 한계가 커지므로 $\theta$를 더 작게 잡아야 합니다.

**실험.** 위 알고리즘을 수박 MDP에 적용했습니다. $\gamma=0.9$, $\theta=10^{-6}$이고, 검산을 위해 선형 방정식 $(\mathbf{I}-\gamma\mathbf{P}_\pi)V=\boldsymbol{r}_\pi$의 해(정확한 $V^\pi$)도 함께 구했습니다. 함수 `policy_eval`이 위의 알고리즘이고, 같은 파일의 나머지 함수는 문제 16.3에서 씁니다.

```python
import numpy as np
from mdp import build, S, A
np.set_printoptions(precision=3, suppress=True)

def policy_eval(P, R, pi, gamma=0.9, theta=1e-6):
    """pi[x, a] = π(x, a). 그림 16.7의 3행을 식 16.8로, 4행을 식 16.9로 바꾼 것."""
    V = np.zeros(P.shape[0])
    for t in range(1, 100000):
        # V'(x) = Σ_a π(x,a) Σ_x' P(x,a,x') (R(x,a,x') + γ V(x'))
        V_new = np.einsum('xa,xay,xay->x', pi, P, R + gamma * V[None, None, :])
        if np.max(np.abs(V - V_new)) < theta:
            return V_new, t
        V = V_new

def q_from_v(P, R, V, gamma):          # 식 16.10
    return np.einsum('xay,xay->xa', P, R + gamma * V[None, None, :])

def policy_iteration(P, R, gamma=0.9, theta=1e-6):
    nS, nA = P.shape[:2]
    pi = np.full((nS, nA), 1 / nA)       # 1행: 균등 랜덤 정책
    log = []
    while True:
        V, sweeps = policy_eval(P, R, pi, gamma, theta)
        Q = q_from_v(P, R, V, gamma)
        new = np.eye(nA)[Q.argmax(1)]    # 식 16.17 (동률이면 앞쪽 액션)
        log.append((sweeps, V.copy(), Q.argmax(1)))
        if np.array_equal(new, pi):
            return pi, V, log
        pi = new

def value_iteration(P, R, gamma=0.9, theta=1e-6):
    V = np.zeros(P.shape[0])
    for t in range(1, 100000):
        V_new = q_from_v(P, R, V, gamma).max(1)          # 식 16.19
        if np.max(np.abs(V - V_new)) < theta:
            return V_new, q_from_v(P, R, V_new, gamma).argmax(1), t
        V = V_new

if __name__ == "__main__":
    for printed in [False, True]:
        P, R = build(printed)
        print("==== printed_rewards =", printed)
        uni = np.full((4, 2), .5)
        book = np.eye(2)[[0, 0, 1, 0]]   # 건강함:줌, 물부족:줌, 넘침:안줌, 시듦:임의(줌)
        for name, pi in [("uniform", uni), ("book", book)]:
            V, t = policy_eval(P, R, pi, 0.9)
            Ppi = np.einsum('xa,xay->xy', pi, P)            # 검산: (I - γP_π)^{-1} r_π
            rpi = np.einsum('xa,xay,xay->x', pi, P, R)
            print(name, "sweeps", t, V, "exact", np.linalg.solve(np.eye(4) - 0.9 * Ppi, rpi))
        pi, V, log = policy_iteration(P, R)
        for k, (sw, v, a) in enumerate(log):
            print("PI round", k + 1, "sweeps", sw, v, [A[i] for i in a])
        print("Q*", q_from_v(P, R, V, .9))
        Vv, av, t = value_iteration(P, R)
        print("VI sweeps", t, Vv, [A[i] for i in av])
        for g in [0.5, 0.7, 0.95, 0.99]:
            Vv, av, t = value_iteration(P, R, g)
            print(" VI gamma", g, t, Vv, [A[i] for i in av])
```

두 정책을 평가한 결과입니다. "책의 정책"은 437쪽에서 최적이라고 한 정책(건강함: 물을 줌, 물 부족: 물을 줌, 물이 넘침: 물을 주지 않음, 시듦: 아무거나)입니다.

| 정책 | 반복 횟수 | $V(\text{건강함})$ | $V(\text{물 부족})$ | $V(\text{물이 넘침})$ | $V(\text{시듦})$ |
|---|---|---|---|---|---|
| 균등 랜덤 ($\pi(x,a)=1/2$) | 176 | $-561.127$ | $-716.729$ | $-639.463$ | $-1000$ |
| 책의 정책 | 176 | $2.000$ | $1.636$ | $2.000$ | $-1000$ |

두 경우 모두 선형 방정식의 해와 소수 셋째 자리까지 같았습니다. 반복 횟수가 둘 다 176인 것은 우연이 아닙니다. 시듦 상태의 값은 $V_t(\text{시듦})=-100(1+0.9+\dots+0.9^{t-1})$로 가장 느리게 수렴하고, 변화량 $100\times0.9^{t-1}$이 $10^{-6}$보다 작아지는 첫 $t$가 176입니다($0.9^{175}\approx9.8\times10^{-9}$). 정책과 상관없이 이 상태가 반복 횟수를 정합니다.

책의 정책 값도 손으로 확인할 수 있습니다. 이 정책에서 건강함과 물이 넘침은 둘 다 한 단계 기대 보상이 $0.6\times1+0.4\times(-1)=0.2$이고, 다음 상태도 건강함과 물이 넘침 사이에서만 오갑니다. 그래서 $V(\text{건강함})=V(\text{물이 넘침})=0.2/(1-\gamma)=2$입니다. 물 부족은 한 단계 기대 보상이 0이고 $V(\text{물 부족})=\gamma\big(0.5V(\text{물 부족})+0.5\times2\big)$를 풀면 $0.9/0.55=1.636$입니다.

## 문제 16.3

> 그림 16.8을 참조해 $\gamma$할인 보상 함수의 정책 반복 알고리즘을 작성하라.

**풀이**

그림 16.8의 정책 평가 부분(3~10행)을 문제 16.2의 γ할인 정책 평가로 바꾸고, 11행에서 $Q$를 계산할 때 식 16.10의 γ할인 식을 쓰면 됩니다.

**입력**: MDP 쿼드러플 $E=\langle X,A,P,R\rangle$, 보상 할인 $\gamma$, 수렴 역치 $\theta$

**과정**:

1. $\forall x\in X:\ V(x)=0,\ \pi(x,a)=\frac{1}{|A(x)|}$
2. **loop**
3. &emsp; **for** $t=1,2,\dots$ **do**
4. &emsp;&emsp; $\forall x\in X:\ V'(x)=\sum_{a\in A}\pi(x,a)\sum_{x'\in X}P^a_{x\to x'}\big(R^a_{x\to x'}+\gamma V(x')\big)$
5. &emsp;&emsp; **if** $\max_{x\in X}|V(x)-V'(x)|<\theta$ **then break else** $V=V'$
6. &emsp; **end for**
7. &emsp; $\forall x\in X,\,a\in A:\ Q(x,a)=\sum_{x'\in X}P^a_{x\to x'}\big(R^a_{x\to x'}+\gamma V'(x')\big)$ (식 16.10)
8. &emsp; $\forall x\in X:\ \pi'(x)=\arg\max_{a\in A}Q(x,a)$ (식 16.17, 현재 액션이 최댓값 중 하나면 그대로 둠)
9. &emsp; **if** $\forall x:\ \pi'(x)=\pi(x)$ **then break else** $\pi=\pi'$
10. **end loop**

**출력**: 최적 정책 $\pi$

몇 가지를 덧붙입니다.

- **유한 번에 끝납니다.** 8행의 개선은 식 16.16에 따라 모든 상태에서 $V^{\pi'}(x)\ge V^{\pi}(x)$를 보장하고, 실제로 액션이 바뀐 상태가 있으면(그 상태에서 $Q^\pi(x,\pi'(x))>V^\pi(x)$) 값이 엄격히 커집니다. 따라서 한 번 거친 정책으로 되돌아가는 일이 없고, 결정론적 정책은 $|A|^{|X|}$개뿐이므로 반복은 유한 번에 끝납니다. 끝났을 때는 $V^\pi(x)=\max_aQ^\pi(x,a)$가 성립하므로 최적 벨만 방정식(식 16.13)을 만족하고, $\pi$가 최적 정책입니다.
- **동률 처리가 필요합니다.** 최댓값을 내는 액션이 여럿일 때 매번 임의로 고르면, 가치는 같은데 액션만 다른 정책 사이를 오가며 9행의 종료 조건이 영원히 만족되지 않을 수 있습니다. 그래서 8행에 "현재 액션이 최댓값 중 하나면 바꾸지 않는다"는 규칙을 붙였습니다(아래 코드는 동률이면 항상 앞쪽 액션을 고르는 방식이라 같은 효과가 납니다).
- **평가를 이어서 합니다.** 그림 16.8처럼 $V$를 매 바퀴 0으로 되돌리지 않고 직전 정책의 값에서 출발하면, 정책이 조금만 바뀌었을 때 평가가 빨리 끝납니다. 축소 사상이라 시작점과 상관없이 같은 값으로 수렴하므로 결과는 같습니다. (아래 코드는 단순하게 매번 0에서 시작했습니다.)
- 정책 평가를 끝까지 하지 않고 한 번만 갱신한 뒤 바로 개선하면 그림 16.9의 가치 반복(3행을 식 16.19로 바꾼 것)이 됩니다.

**실험.** 문제 16.2의 코드에서 `policy_iteration`과 `value_iteration`을 수박 MDP에 돌린 결과입니다($\gamma=0.9$, $\theta=10^{-6}$).

| 바퀴 | 평가한 정책 | 평가 반복 횟수 | 평가 결과 $V$ (건강함, 물 부족, 물이 넘침, 시듦) | 개선된 정책 (건강함, 물 부족, 물이 넘침) |

정책 반복은 두 바퀴 만에 끝났고, 첫 개선에서 이미 책 437쪽의 최적 정책(건강함: 물을 줌, 물이 넘침: 물을 주지 않음, 물 부족: 물을 줌)이 나왔습니다. 시듦에서는 두 액션의 $Q$가 같아 앞쪽 액션(물을 줌)이 골라졌는데, 책 말대로 아무 액션이나 상관없습니다. 최적 상태-액션 가치 함수는 다음과 같습니다.

## 문제 16.4

> MDP 모델이 없을 때 먼저 MDP 모델을 학습한 후, 모델 기반 강화 학습법을 사용한다. 이 방법과 비모델 강화 학습법(model-free)의 장단점을 기술하라.

**풀이**

먼저 학습하는 방법은 환경과 상호작용하며 모은 전이 $(x,a,r,x')$로 $\hat P^a_{x\to x'}=\dfrac{\text{count}(x,a,x')}{\text{count}(x,a)}$, $\hat R^a_{x\to x'}=$ (관측된 보상의 평균)을 추정하고, 이 추정 모델에 16.3절의 정책 반복이나 가치 반복을 적용하는 것입니다. 모델-프리 방법은 16.4절의 몬테카를로, Sarsa, Q-학습처럼 $P$, $R$을 추정하지 않고 가치 함수나 정책을 바로 갱신합니다.

| 구분 | 모델을 학습한 뒤 모델 기반으로 풀기 | 모델-프리 |
|---|---|---|
| 샘플 효율 | 높음. 한 번 관측한 전이가 모델에 남아, 계획(동적 프로그래밍) 과정에서 모든 상태의 가치 계산에 반복해서 쓰임 | 낮음. 샘플 하나가 한 번의 갱신에만 쓰이고, 보상 정보가 한 단계씩 천천히 퍼짐 |
| 편향 | 모델 오차가 그대로 정책에 들어감(모델 편향). 추정 모델에서 최적인 정책이 실제 환경에서는 나쁠 수 있고, 여러 단계를 내다볼수록 오차가 쌓임 | 모델을 거치지 않으므로 모델 편향이 없음 |
| 저장과 계산 | $P$에 $|X|^2|A|$개의 값이 필요하고, 모델이 바뀔 때마다 계획을 다시 풀어야 함 | $Q$에 $|X||A|$개, 갱신은 샘플당 $O(|A|)$ |
| 큰 상태 공간 | 연속·고차원 상태에서 전이 분포 자체를 학습하기가 매우 어려움 | 가치 함수 근사(16.5절)와 결합하기 쉬움 |
| 재사용 | 학습한 전이 모델을 다른 보상이나 목표에 다시 쓸 수 있고, 모델로 가상의 경험을 만들어 시뮬레이션·계획에 활용 가능 | 학습한 $Q$는 그 보상 함수에만 유효 |
| 탐색 | 모델이 정확하려면 모든 $(x,a)$를 충분히 시도해야 함. 대신 "어디가 불확실한지"를 모델로 판단해 탐색을 설계할 수 있음 | $\epsilon$-그리디 등으로 탐색. 정책과 관련 없는 부분은 정확히 몰라도 됨 |
| 해석 | 학습한 전이와 보상을 사람이 들여다보고 검증할 수 있음 | 가치 함수만 남아 환경에 대한 설명력이 약함 |

한마디로 모델 기반은 "적은 데이터로 빨리 좋아지지만 모델이 틀리면 틀린 쪽으로 확신하고", 모델-프리는 "느리지만 데이터가 충분하면 모델 오차 없이 수렴"합니다. 상태가 적고 전이 구조가 단순하면 모델 기반이, 상태 공간이 크거나 전이가 복잡하면 모델-프리가 유리한 경우가 많습니다.

**실험.** 수박 MDP에서 같은 데이터를 두 방법에 주고 비교했습니다. 데이터는 균등 랜덤 정책으로 모은 전이 $N$개입니다(10단계마다 건강함에서 다시 시작). 모델 기반은 빈도로 $\hat P$, 평균으로 $\hat R$을 추정한 뒤 가치 반복을 했고, 한 번도 시도하지 않은 $(x,a)$는 균등 전이로 두었습니다. 모델-프리는 같은 전이를 순서대로 한 번 훑는 Q-학습이고, 갱신 길이로 상수 $\alpha=0.1$과 줄어드는 $\alpha_n=n(x,a)^{-0.6}$ 두 가지를 썼습니다. 시드 0~199로 200번 반복해, 건강함·물 부족·물이 넘침 세 상태의 정책이 모두 최적과 같은 비율을 쟀습니다($\gamma=0.9$).

```python
import numpy as np
from mdp import build, H
from p16_2_3 import value_iteration
P, R = build(); g = 0.9
opt = value_iteration(P, R, g)[1][:3]            # 건강함/물 부족/물이 넘침의 최적 액션

def collect(N, rng, ep_len=10):                  # 균등 랜덤 정책으로 전이 N개 수집(10단계마다 건강함에서 재시작)
    data, x = [], H
    for i in range(N):
        if i % ep_len == 0: x = H
        a = rng.integers(2); x2 = rng.choice(4, p=P[x, a])
        data.append((x, a, R[x, a, x2], x2)); x = x2
    return data

def model_based(data):                           # 빈도로 P, 평균으로 R을 추정한 뒤 가치 반복
    C = np.zeros((4, 2, 4)); Rs = np.zeros((4, 2, 4))
    for x, a, r, x2 in data: C[x, a, x2] += 1; Rs[x, a, x2] += r
    n = C.sum(2, keepdims=True)
    Ph = np.where(n > 0, C / np.maximum(n, 1), 0.25)  # 한 번도 안 해 본 (x,a)는 균등 전이로 둔다
    Rh = Rs / np.maximum(C, 1)
    return value_iteration(Ph, Rh, g)[1][:3]

def q_learning(data, alpha=None):                # 같은 데이터를 한 번 훑는 Q-학습
    Q = np.zeros((4, 2)); n = np.zeros((4, 2))
    for x, a, r, x2 in data:
        n[x, a] += 1
        lr = alpha if alpha else n[x, a] ** -0.6
        Q[x, a] += lr * (r + g * Q[x2].max() - Q[x, a])
    return Q.argmax(1)[:3]

if __name__ == "__main__":
    for N in [50, 100, 200, 500, 1000, 5000]:
        hit = np.zeros(3)
        for seed in range(200):
            d = collect(N, np.random.default_rng(seed))
            hit += [np.array_equal(f(d), opt) for f in
                    (model_based, lambda d: q_learning(d, 0.1), q_learning)]
        print(N, hit / 200)
```

|---|---|---|---|---|---|---|
| 모델 학습 후 가치 반복 | 0.655 | 0.790 | 0.930 | 0.985 | 1.000 | 1.000 |
| Q-학습 ($\alpha=0.1$) | 0.700 | 0.860 | 0.875 | 0.910 | 0.910 | 0.905 |
| Q-학습 ($\alpha_n=n^{-0.6}$) | 0.585 | 0.785 | 0.845 | 0.935 | 0.985 | 1.000 |

전이가 200개 이상이면 모델 기반이 같은 데이터로 더 자주 최적 정책을 찾고, 1,000개에서 200번 모두 맞혔습니다. Q-학습은 상수 갱신 길이에서는 90% 근처에서 더 오르지 않았고, 갱신 길이를 줄여 가면 5,000개에서야 모두 맞혔습니다. 상수 갱신 길이에서는 $Q$값이 최근 샘플 쪽으로 계속 흔들리기 때문입니다. $N=5000$에서 건강함의 두 $Q$값 차이 $Q(\text{건강함},\text{줌})-Q(\text{건강함},\text{주지 않음})$은 200번 평균 0.57, 표준편차 0.44였고(참값 0.596), 틀린 19번은 모두 이 차이의 부호가 뒤집힌 경우였습니다. 반대로 50~100개처럼 데이터가 아주 적을 때는 모델 기반이 근소하게 뒤졌는데, 시도하지 않은 $(x,a)$를 균등 전이로 채운 가정이 틀린 모델을 만들었기 때문입니다. 표의 양 끝이 위 표의 "샘플 효율"과 "모델 편향"을 각각 보여 줍니다. 이 MDP는 상태가 4개뿐이라 모델 학습이 쉬운 경우라는 점도 감안해야 합니다.

## 문제 16.5

> Sarsa 알고리즘의 갱신 공식 16.31을 유도하라.

**풀이**

목표는 식 16.31

$$
Q^\pi_{t+1}(x,a)=Q^\pi_t(x,a)+\alpha\big(R^a_{x\to x'}+\gamma Q^\pi_t(x',a')-Q^\pi_t(x,a)\big)
$$

입니다. 출발점은 식 16.29(평균의 증분식)와 식 16.30(γ할인 벨만 등식)입니다.

**1단계: 식 16.30을 기댓값 하나로 묶습니다.** 식 16.30은

$$
Q^\pi(x,a)=\sum_{x'\in X}P^a_{x\to x'}\Big(R^a_{x\to x'}+\gamma\sum_{a'\in A}\pi(x',a')\,Q^\pi(x',a')\Big)
$$

입니다. $\sum_{a'}\pi(x',a')=1$이므로 $R^a_{x\to x'}=\sum_{a'}\pi(x',a')R^a_{x\to x'}$로 쓸 수 있고, 그러면

$$
Q^\pi(x,a)=\sum_{x'\in X}\sum_{a'\in A}P^a_{x\to x'}\,\pi(x',a')\big(R^a_{x\to x'}+\gamma Q^\pi(x',a')\big)
=\mathbb{E}_{x'\sim P^a_{x\to\cdot},\;a'\sim\pi(x',\cdot)}\big[R^a_{x\to x'}+\gamma Q^\pi(x',a')\big]
$$

입니다. 곧 $Q^\pi(x,a)$는 확률 변수 $Y=R^a_{x\to x'}+\gamma Q^\pi(x',a')$의 기댓값이고, 이 기댓값은 "$x$에서 $a$를 실행해 $x'$로 가고, $x'$에서 정책 $\pi$로 $a'$를 고르는" 결합 분포에 대한 것입니다.

**2단계: 모델 없이 $Y$의 샘플을 얻습니다.** $P$와 $R$을 몰라도, 환경에서 상태 $x$일 때 액션 $a$를 실행하면 보상 $r=R^a_{x\to x'}$와 다음 상태 $x'\sim P^a_{x\to\cdot}$을 관찰할 수 있고, 이어서 정책 $\pi$로 $a'$를 고르면 $a'\sim\pi(x',\cdot)$입니다. 이 $(r,x',a')$는 1단계의 결합 분포에서 뽑은 샘플 하나이므로, $y=r+\gamma Q^\pi(x',a')$는 $Q^\pi(x,a)$의 불편 추정값입니다. 몬테카를로 방법이 경로 끝까지의 누적 보상을 샘플로 썼다면, 여기서는 한 단계 보상과 다음 상태-액션의 가치를 샘플로 쓰는 것입니다.

**3단계: 샘플의 평균을 증분식으로 계산합니다.** $(x,a)$에 대해 이런 샘플 $y_1,y_2,\dots$를 얻을 때마다 평균을 갱신하면 식 16.29와 같은 꼴이 됩니다.

$$
Q_{t+1}(x,a)=Q_t(x,a)+\frac{1}{t+1}\big(y_{t+1}-Q_t(x,a)\big).
$$

455쪽 설명대로 $\frac{1}{t+1}$을 계수 $\alpha_{t+1}$로, 실전에서는 작은 양수 상수 $\alpha$로 바꿉니다. 상수 $\alpha$를 써도 여전히 샘플들의 가중 평균이라는 점은 전개해 보면 확인됩니다.

$$
Q_t=(1-\alpha)^tQ_0+\sum_{i=1}^{t}\alpha(1-\alpha)^{t-i}y_i,\qquad
(1-\alpha)^t+\sum_{i=1}^{t}\alpha(1-\alpha)^{t-i}=(1-\alpha)^t+\big(1-(1-\alpha)^t\big)=1.
$$

계수의 합이 1이고, 최근 샘플일수록 가중치 $\alpha(1-\alpha)^{t-i}$가 크므로 $\alpha$가 클수록 최근 샘플이 더 중요해집니다. 정책이 계속 바뀌는 상황에서는 이 성질이 오히려 유리합니다.

**4단계: 모르는 $Q^\pi(x',a')$를 현재 추정값으로 바꿉니다.** 샘플 $y=r+\gamma Q^\pi(x',a')$ 안에는 구하려는 함수 $Q^\pi$가 들어 있어 그대로 계산할 수 없습니다. 식 16.36에서 $V^\pi(x')$를 현재 추정값 $V_{\boldsymbol\theta}(x')$로 바꾼 것과 같은 방식으로, 현재 추정값 $Q^\pi_t(x',a')$를 대신 씁니다(이를 부트스트래핑이라고 합니다). 그러면 $y_{t+1}\approx R^a_{x\to x'}+\gamma Q^\pi_t(x',a')$이고, 3단계 식에 넣으면

$$
Q^\pi_{t+1}(x,a)=Q^\pi_t(x,a)+\alpha\big(R^a_{x\to x'}+\gamma Q^\pi_t(x',a')-Q^\pi_t(x,a)\big)
$$

로 식 16.31이 얻어집니다. 괄호 안의 $\delta=r+\gamma Q(x',a')-Q(x,a)$를 시간차(TD) 오차라고 부릅니다.

**덧붙임.** 갱신에 $(x,a,r,x',a')$ 다섯 개가 필요해서 Sarsa라는 이름이 붙었습니다. 4단계의 대체 때문에 목표값이 편향되어 있어 평균의 수렴 논리를 바로 쓸 수는 없지만, 표 형태 Sarsa는 모든 $(x,a)$를 무한히 자주 방문하고 갱신 길이가 $\sum_t\alpha_t=\infty$, $\sum_t\alpha_t^2<\infty$를 만족하며 정책이 점점 탐욕적으로 바뀌면($\epsilon\to0$) 확률 1로 $Q^*$에 수렴한다는 결과가 있습니다(Singh et al., 2000). 또 2단계에서 $a'$를 정책 $\pi$로 뽑는 대신 $\max_{a'}$를 쓰면, 식 16.30 대신 최적 벨만 방정식(식 16.15)의 기댓값을 추정하게 되어 Q-학습의 갱신식이 됩니다.

## 문제 16.6

> 그림 16.14를 참조해 선형 가치 함수 근사 Q-학습 알고리즘에 대해 기술하라.

**풀이**

Q-학습(그림 16.13)이 Sarsa(그림 16.12)와 다른 점은, 실행은 $\epsilon$-그리디 정책으로 하되 평가(갱신 목표)는 원시 정책, 곧 탐욕 정책으로 한다는 것입니다. 그림 16.14의 선형 Sarsa에 이 차이를 그대로 옮기면 됩니다.

상태-액션 가치 함수를 $Q_{\boldsymbol\theta}(\boldsymbol x,a)=\boldsymbol\theta^{\mathrm T}(\boldsymbol x;a)$로 근사합니다. 최적 벨만 방정식(식 16.15)에서 $Q^*(\boldsymbol x,a)=\mathbb{E}\big[R+\gamma\max_{a'}Q^*(\boldsymbol x',a')\big]$이므로, 한 번의 전이 $(\boldsymbol x,a,r,\boldsymbol x')$에서 얻는 목표값은 $r+\gamma\max_{a''}\boldsymbol\theta^{\mathrm T}(\boldsymbol x';a'')$입니다. 식 16.35에서 $V^\pi(\boldsymbol x)$ 자리에 이 목표값을 넣고, $\nabla_{\boldsymbol\theta}\,\boldsymbol\theta^{\mathrm T}(\boldsymbol x;a)=(\boldsymbol x;a)$를 쓰면 갱신식이 나옵니다.

**입력**: 환경 $E$, 액션 공간 $A$, 초기 상태 $\boldsymbol x_0$, 보상 할인 $\gamma$, 갱신 길이 $\alpha$

**과정**:

1. $\boldsymbol\theta=\boldsymbol 0$
2. $\boldsymbol x=\boldsymbol x_0$
3. **for** $t=1,2,\dots$ **do**
4. &emsp; $r,\boldsymbol x'=$ $E$에서 액션 $a=\pi^\epsilon(\boldsymbol x)$를 실행하여 얻은 보상과 전이된 상태 (원시 정책의 $\epsilon$-그리디 정책으로 실행)
5. &emsp; $a'=\pi(\boldsymbol x')=\arg\max_{a''}\boldsymbol\theta^{\mathrm T}(\boldsymbol x';a'')$ (원시 정책으로 평가)
6. &emsp; $\boldsymbol\theta=\boldsymbol\theta+\alpha\big(r+\gamma\boldsymbol\theta^{\mathrm T}(\boldsymbol x';a')-\boldsymbol\theta^{\mathrm T}(\boldsymbol x;a)\big)(\boldsymbol x;a)$
7. &emsp; $\pi(\boldsymbol x)=\arg\max_{a''}\boldsymbol\theta^{\mathrm T}(\boldsymbol x;a'')$
8. &emsp; $\boldsymbol x=\boldsymbol x'$
9. **end for**

**출력**: 정책 $\pi$

그림 16.14와 비교한 차이는 세 군데입니다.

- 4행: 실행할 액션을 이번 단계에서 $\epsilon$-그리디로 새로 고릅니다. Sarsa는 직전 단계에서 고른 $a'$를 그대로 실행합니다.
- 5~6행: 목표값에 쓰는 $a'$는 실제로 다음에 실행할 액션이 아니라 탐욕 액션입니다. 그래서 6행은 $\boldsymbol\theta^{\mathrm T}(\boldsymbol x';a')=\max_{a''}\boldsymbol\theta^{\mathrm T}(\boldsymbol x';a'')$이고, 상이 정책(off-policy) 알고리즘이 됩니다.
- 8행: 다음 액션은 4행에서 다시 고르므로 $a=a'$를 넘기지 않습니다.

종료 상태가 있는 과업이라면 $\boldsymbol x'$가 종료 상태일 때 목표값을 $r$로 둡니다. 7행은 $\boldsymbol\theta$로부터 바로 계산되므로 실제 구현에서는 정책을 따로 저장하지 않아도 됩니다.

주의할 점이 두 가지 있습니다.

1. **반쪽짜리 경사입니다.** 목표값 $r+\gamma\max\boldsymbol\theta^{\mathrm T}(\boldsymbol x';a'')$도 $\boldsymbol\theta$에 의존하지만 미분하지 않고 상수처럼 둡니다(식 16.36과 같음). 그래서 어떤 목적 함수의 진짜 경사하강법이 아니고, 표 형태와 달리 수렴이 보장되지 않습니다. 상이 정책 학습, 함수 근사, 부트스트래핑이 함께 쓰이면 선형 근사로도 파라미터가 발산하는 예가 알려져 있습니다(Baird, 1995). 실전에서는 갱신 길이를 작게 잡고 특성을 정규화하는 것이 좋습니다.
2. **$(\boldsymbol x;a)$를 이어 붙이는 방식에는 한계가 있습니다.** 459쪽처럼 상태 벡터에 액션 원-핫 벡터를 이어 붙이면 $\boldsymbol\theta^{\mathrm T}(\boldsymbol x;a)=\boldsymbol\theta_x^{\mathrm T}\boldsymbol x+\boldsymbol\theta_a^{\mathrm T}\boldsymbol a$로 상태 부분과 액션 부분이 더해지기만 합니다. 그러면 $\arg\max_a$는 $\boldsymbol\theta_a^{\mathrm T}\boldsymbol a$만으로 정해져서 **모든 상태에서 같은 액션**이 골라집니다. 상태에 따라 액션이 달라야 하는 과업이라면 상태와 액션의 곱 특성 $\boldsymbol x\otimes\boldsymbol a$(액션마다 따로 둔 가중치 $\boldsymbol\theta_a$로 $Q=\boldsymbol\theta_a^{\mathrm T}\boldsymbol x$)를 써야 합니다.

**실험.** 수박 MDP의 상태를 4차원 원-핫 벡터로 두고 두 특성 방식으로 선형 Q-학습을 돌렸습니다. 건강함에서 시작하는 10단계 에피소드 3,000개, $\alpha=0.01$, $\epsilon=0.1$, $\gamma=0.9$, 시드 0입니다. 학습된 탐욕 정책의 가치는 문제 16.2의 정책 평가로 정확히 계산했습니다.

```python
import numpy as np
from mdp import build, H, A
from p16_2_3 import policy_eval
P, R = build(); g = 0.9
I4, I2 = np.eye(4), np.eye(2)
feat = {"concat": lambda x, a: np.r_[I4[x], I2[a]],             # (x; a)
        "outer":  lambda x, a: np.outer(I4[x], I2[a]).ravel()}  # x ⊗ a

def linear_q_learning(phi, episodes=3000, ep_len=10, alpha=0.01, eps=0.1, seed=0):
    rng = np.random.default_rng(seed)
    theta = np.zeros(len(phi(0, 0)))
    q = lambda x: np.array([theta @ phi(x, b) for b in range(2)])
    for _ in range(episodes):
        x = H
        for _ in range(ep_len):
            a = rng.integers(2) if rng.random() < eps else q(x).argmax()   # a = π^ε(x)
            x2 = rng.choice(4, p=P[x, a]); r = R[x, a, x2]
            delta = r + g * q(x2).max() - theta @ phi(x, a)               # max_a'' θ^T(x'; a'')
            theta += alpha * delta * phi(x, a)
            x = x2
    return theta, np.array([q(x).argmax() for x in range(4)])

for name, phi in feat.items():
    theta, pol = linear_q_learning(phi)
    V, _ = policy_eval(P, R, np.eye(2)[pol], g)
    print(name, "theta", np.round(theta, 2), "policy", [A[i] for i in pol[:3]], "V(H)", round(V[H], 3))
```

| 특성 | 학습된 정책 (건강함, 물 부족, 물이 넘침) | 그 정책의 $V(\text{건강함})$ |
|---|---|---|
| $(\boldsymbol x;a)$ 이어 붙이기 (6차원) | 줌, 줌, 줌 | $-681.115$ |
| $\boldsymbol x\otimes\boldsymbol a$ 곱 특성 (8차원) | 줌, 줌, 주지 않음 | $2.000$ (최적) |

이어 붙인 특성에서는 액션 부분의 가중치가 물을 줌 $-546.32$, 물을 주지 않음 $-550.50$으로 학습되어, 예상대로 모든 상태에서 물을 주는 정책이 나왔습니다. 물이 넘친 상태에서도 물을 주니 시듦으로 빠지기 쉽고 가치가 $-681$로 떨어집니다. 시드 0~9로 반복해도 이어 붙인 특성은 10번 모두 "모든 상태에서 같은 액션"(8번은 모두 줌, 2번은 모두 주지 않음)이었고, 곱 특성은 10번 모두 최적 정책을 찾았습니다. 상태가 원-핫 벡터이면 곱 특성은 표 형태 Q-학습과 똑같으므로, 선형 Q-학습은 표 형태 Q-학습을 일반화한 것이라고도 볼 수 있습니다.

## 문제 16.7

> 선형 가치 함수 근사는 실전에서 큰 오차를 발생시킨다. BP 신경망과 결합해 선형 가치 함수 근사 Sarsa 알고리즘을 신경망을 사용하여 근사시키는 Sarsa 알고리즘으로 확장해 보아라.

**풀이**

**갱신 규칙.** 선형 함수 $\boldsymbol\theta^{\mathrm T}(\boldsymbol x;a)$ 대신 파라미터 $\boldsymbol\theta$(신경망의 모든 가중치와 임곗값)를 가진 신경망 $Q_{\boldsymbol\theta}(\boldsymbol x,a)$를 씁니다. 식 16.33~16.36과 같은 논리로, 샘플 하나에 대한 오차를

$$
E_{\boldsymbol\theta}=\frac12\big(y-Q_{\boldsymbol\theta}(\boldsymbol x,a)\big)^2,\qquad y=r+\gamma Q_{\boldsymbol\theta}(\boldsymbol x',a')
$$

로 두고 목표값 $y$는 상수로 취급합니다. 그러면

$$
-\frac{\partial E_{\boldsymbol\theta}}{\partial\boldsymbol\theta}=\big(y-Q_{\boldsymbol\theta}(\boldsymbol x,a)\big)\nabla_{\boldsymbol\theta}Q_{\boldsymbol\theta}(\boldsymbol x,a)
=\delta\,\nabla_{\boldsymbol\theta}Q_{\boldsymbol\theta}(\boldsymbol x,a)
$$

이므로 갱신은 $\boldsymbol\theta\leftarrow\boldsymbol\theta+\alpha\,\delta\,\nabla_{\boldsymbol\theta}Q_{\boldsymbol\theta}(\boldsymbol x,a)$입니다. 선형이면 $\nabla_{\boldsymbol\theta}Q=(\boldsymbol x;a)$라서 그림 16.14의 6행과 같고, 신경망이면 $\nabla_{\boldsymbol\theta}Q$를 5장의 오차 역전파로 계산하면 됩니다.

**경사 계산.** 입력을 $\boldsymbol z=(\boldsymbol x;a)$(액션은 원-핫), 은닉층 뉴런 $q$개, 활성화 함수를 $\tanh$, 출력은 선형 뉴런 하나로 둡니다. 할인율 $\gamma$와 겹치지 않도록 임곗값은 $c_h$, $c_0$로 쓰겠습니다.

$$
u_h=\tanh\Big(\sum_i v_{ih}z_i-c_h\Big),\qquad Q_{\boldsymbol\theta}(\boldsymbol x,a)=\sum_{h=1}^{q}w_hu_h-c_0.
$$

각 파라미터에 대한 편미분은 다음과 같습니다($\tanh'(s)=1-\tanh^2(s)$).

$$
\frac{\partial Q}{\partial w_h}=u_h,\quad
\frac{\partial Q}{\partial c_0}=-1,\quad
\frac{\partial Q}{\partial v_{ih}}=w_h(1-u_h^2)\,z_i,\quad
\frac{\partial Q}{\partial c_h}=-w_h(1-u_h^2).
$$

5장의 BP와 비교하면, 출력층의 오차 항 자리에 TD 오차 $\delta$가 들어간 것만 다릅니다. 액션이 이산적이면 입력에 액션을 넣지 않고 출력 뉴런을 $|A|$개 두어 $Q(\boldsymbol x,\cdot)$를 한 번에 내는 구조도 많이 씁니다. 이때는 실행한 액션의 출력 뉴런에만 $\delta$를 흘려보냅니다.

**알고리즘.**

**입력**: 환경 $E$, 액션 공간 $A$, 초기 상태 $\boldsymbol x_0$, 보상 할인 $\gamma$, 갱신 길이 $\alpha$, 은닉 뉴런 수 $q$

**과정**:

1. 신경망 파라미터 $\boldsymbol\theta$를 작은 난수로 초기화 (모두 0이면 은닉 뉴런이 대칭이 되어 똑같이 학습됨)
2. $\boldsymbol x=\boldsymbol x_0$, $a=\pi^\epsilon(\boldsymbol x)$, 여기서 $\pi(\boldsymbol x)=\arg\max_{a''}Q_{\boldsymbol\theta}(\boldsymbol x,a'')$
3. **for** $t=1,2,\dots$ **do**
4. &emsp; $r,\boldsymbol x'=$ $E$에서 액션 $a$를 실행하여 얻은 보상과 전이된 상태
5. &emsp; $a'=\pi^\epsilon(\boldsymbol x')$
6. &emsp; $\delta=r+\gamma Q_{\boldsymbol\theta}(\boldsymbol x',a')-Q_{\boldsymbol\theta}(\boldsymbol x,a)$ (종료 상태면 $\delta=r-Q_{\boldsymbol\theta}(\boldsymbol x,a)$)
7. &emsp; 역전파로 $\nabla_{\boldsymbol\theta}Q_{\boldsymbol\theta}(\boldsymbol x,a)$를 계산하고 $\boldsymbol\theta=\boldsymbol\theta+\alpha\,\delta\,\nabla_{\boldsymbol\theta}Q_{\boldsymbol\theta}(\boldsymbol x,a)$
8. &emsp; $\boldsymbol x=\boldsymbol x'$, $a=a'$
9. **end for**

**출력**: 정책 $\pi(\boldsymbol x)=\arg\max_aQ_{\boldsymbol\theta}(\boldsymbol x,a)$

신경망은 표현력이 큰 대신 불안정해지기 쉽습니다. 연속된 샘플끼리 상관이 크고, 갱신할 때마다 목표값 $y$도 같은 신경망으로 계산되어 함께 움직이기 때문입니다. 갱신 길이를 작게 두는 것이 기본이고, Q-학습 쪽에서는 지난 전이를 저장해 두고 무작위로 뽑아 미니배치로 학습하는 경험 재생과, 목표값 계산용 신경망을 따로 두고 가끔만 복사하는 목표 신경망이 널리 쓰입니다(DQN, Mnih et al., 2015). Sarsa는 동일 정책 알고리즘이라 오래된 경험을 재사용하는 데 제약이 있다는 점은 기억해 두면 좋습니다.

**실험.** 선형 근사의 한계가 드러나도록 연속 상태 과업을 하나 만들었습니다. 위치 $x\in[0,1]$인 1차원 도로에서 목표 구간 $|x-0.5|\le0.05$에 도착하는 과업입니다. 액션은 왼쪽($-0.05$)과 오른쪽($+0.05$) 두 개, 목표에 닿을 때까지 매 단계 보상 $-1$, $\gamma=0.95$, 에피소드 최대 50단계이고 시작 위치는 목표 밖에서 균등하게 뽑습니다. 결정론적 과업이라 최적 가치가 닫힌 꼴 $V^*(x)=-\frac{1-\gamma^{k(x)}}{1-\gamma}$($k(x)$는 목표까지 필요한 최소 단계 수)로 나옵니다. 목표가 가운데에 있으니 $V^*$는 0.5에서 가장 높은 삼각형 모양이고, 최적 정책은 "0.5보다 왼쪽이면 오른쪽, 오른쪽이면 왼쪽"입니다. 공통 Sarsa 루프와 평가 코드는 다음과 같습니다.

```python
# road.py: 1차원 도로 과업. 위치 x∈[0,1], 목표 구간 |x-0.5|<=0.05, 액션 0=왼쪽(-0.05) 1=오른쪽(+0.05)
import numpy as np
STEP, G, MAXT = 0.05, 0.95, 50
def step(x, a):
    x2 = float(np.clip(x + (STEP if a == 1 else -STEP), 0, 1))
    done = abs(x2 - 0.5) <= 0.05 + 1e-9
    return -1.0, x2, done                    # 목표에 닿을 때까지 매 단계 -1
def v_star(x):                               # 최적 가치(결정론적이라 닫힌 꼴)
    k = np.ceil((np.abs(x - 0.5) - 0.05) / STEP - 1e-9)
    return -(1 - G ** k) / (1 - G)
def sarsa(agent, episodes=3000, eps=0.1, seed=0):
    rng = np.random.default_rng(seed)
    pol = lambda x: rng.integers(2) if rng.random() < eps else int(np.argmax(agent.q(x)))
    for _ in range(episodes):
        x = rng.uniform(0, 1)
        while abs(x - 0.5) <= 0.05: x = rng.uniform(0, 1)
        a = pol(x)
        for t in range(MAXT):
            r, x2, done = step(x, a)
            a2 = pol(x2)
            target = r if done else r + G * agent.q(x2)[a2]
            agent.update(x, a, target - agent.q(x)[a])     # δ = r + γQ(x',a') - Q(x,a)
            if done: break
            x, a = x2, a2
    return agent
def evaluate(agent):
    xs = np.linspace(0, 1, 201); xs = xs[np.abs(xs - 0.5) > 0.05 + 1e-9]
    succ, steps = 0, []
    for x0 in xs:
        x = x0
        for t in range(MAXT):
            _, x, done = step(x, int(np.argmax(agent.q(x))))
            if done: succ += 1; steps.append(t + 1); break
    V = np.array([agent.q(x).max() for x in xs])
    rmse = np.sqrt(np.mean((V - v_star(xs)) ** 2))
    opt = np.mean([np.ceil((abs(x - .5) - .05) / STEP - 1e-9) for x in xs])
    return succ / len(xs), np.mean(steps) if steps else np.nan, opt, rmse
```

선형 Sarsa(그림 16.14 그대로, 특성 $(x;a)$)와 은닉층 하나짜리 BP 신경망 Sarsa입니다.

```python
import numpy as np
from road import sarsa, evaluate

class Linear:                       # 그림 16.14: θ^T(x; a), a는 원-핫
    def __init__(s, alpha=0.05): s.th = np.zeros(3); s.al = alpha
    def phi(s, x, a): return np.r_[x, np.eye(2)[a]]
    def q(s, x): return np.array([s.th @ s.phi(x, a) for a in (0, 1)])
    def update(s, x, a, d): s.th += s.al * d * s.phi(x, a)

class MLP:                          # 문제 16.7: 은닉층 하나(tanh)의 BP 신경망
    def __init__(s, h=20, alpha=0.01, seed=0):
        r = np.random.default_rng(seed)
        s.V = r.normal(0, 1, (3, h)); s.c = np.zeros(h)       # 입력->은닉 가중치, 은닉 임곗값
        s.w = r.normal(0, .1, h); s.c0 = 0.0; s.al = alpha     # 은닉->출력 가중치, 출력 임곗값
    def fwd(s, x, a):
        z = np.r_[x, np.eye(2)[a]]; u = np.tanh(z @ s.V - s.c)
        return z, u, u @ s.w - s.c0
    def q(s, x): return np.array([s.fwd(x, a)[2] for a in (0, 1)])
    def update(s, x, a, d):         # θ ← θ + α δ ∇_θ Q(x,a)
        z, u, _ = s.fwd(x, a)
        e = s.w * (1 - u ** 2)                       # 역전파: ∂Q/∂(은닉층 입력)
        s.w += s.al * d * u; s.c0 -= s.al * d
        s.V += s.al * d * np.outer(z, e); s.c -= s.al * d * e

for name, ag in [("linear", Linear()), ("MLP", MLP())]:
    sarsa(ag, seed=0)
    print(name, evaluate(ag))       # (성공률, 평균 단계 수, 최적 평균 단계 수, V의 RMSE)
```

## 문제 16.8

> 커널 기법을 결합하여 선형 가치 함수 근사 Sarsa 알고리즘을 커널 함수를 사용하는 비선형 가치 함수 근사 Sarsa 알고리즘으로 확장해 보아라.

**풀이**

**커널화.** 상태-액션 쌍 $\boldsymbol z=(\boldsymbol x,a)$를 특성 공간으로 보내는 사상 $\phi(\boldsymbol z)$를 두고 $Q(\boldsymbol z)=\langle\boldsymbol\theta,\phi(\boldsymbol z)\rangle$로 근사합니다. 그림 16.14의 6행은 특성 공간에서

$$
\boldsymbol\theta\leftarrow\boldsymbol\theta+\alpha\,\delta_t\,\phi(\boldsymbol z_t),\qquad
\delta_t=r_t+\gamma Q(\boldsymbol z_t')-Q(\boldsymbol z_t)
$$

입니다($\boldsymbol z_t'=(\boldsymbol x',a')$). $\boldsymbol\theta=\boldsymbol 0$에서 시작하면 귀납적으로

$$
\boldsymbol\theta_t=\sum_{i=1}^{t}\beta_i\,\phi(\boldsymbol z_i),\qquad \beta_i=\alpha\,\delta_i
$$

꼴이 유지됩니다. 매 갱신이 $\phi(\boldsymbol z_t)$ 방향으로만 더해지기 때문입니다. 따라서

$$
Q_t(\boldsymbol z)=\sum_{i=1}^{t}\beta_i\,\langle\phi(\boldsymbol z_i),\phi(\boldsymbol z)\rangle=\sum_{i=1}^{t}\beta_i\,\kappa(\boldsymbol z_i,\boldsymbol z)
$$

이고, $\delta_t$ 계산과 정책 선택 모두 커널 함수 $\kappa$만으로 할 수 있습니다. 6장의 커널 기법과 같은 구조로, $\phi$를 명시적으로 계산하지 않고 가우스 커널처럼 무한 차원 특성 공간에 대응하는 비선형 근사를 쓸 수 있습니다.

**커널 선택.** 액션이 이산적이면 $\kappa\big((\boldsymbol x,a),(\boldsymbol x',a')\big)=\exp\big(-\|\boldsymbol x-\boldsymbol x'\|^2/2\sigma^2\big)\cdot\mathbb{I}(a=a')$처럼 상태 커널에 액션 일치 여부를 곱하면 편합니다. 이러면 $Q(\boldsymbol x,a)=\sum_{i:\,a_i=a}\beta_i\,k(\boldsymbol x_i,\boldsymbol x)$로 액션별 함수가 따로 학습됩니다. 액션끼리 정보를 나누고 싶으면 $(\boldsymbol x;\boldsymbol a)$를 이어 붙인 벡터에 가우스 커널을 써도 됩니다. 이 경우는 문제 16.6에서 본 이어 붙이기의 한계가 없습니다. 가우스 커널은 상태와 액션의 곱 형태 상호작용까지 표현하기 때문입니다.

**사전(dictionary) 희소화.** 위 식대로라면 매 단계 항이 하나씩 늘어 계산량이 $O(t)$로 커집니다. 그래서 중심점 집합(사전) $\mathcal D$를 유지하고, 새 샘플이 사전으로 충분히 표현되면 새 항을 추가하지 않습니다. 근사 선형 종속(ALD) 기준(Engel, Mannor, Meir, 2004)을 쓰면 다음과 같습니다. 사전의 커널 행렬을 $\mathbf K_{\mathcal D}$, 새 샘플과 사전 원소들 사이의 커널 값을 $\boldsymbol k_{\mathcal D}(\boldsymbol z)$라 할 때

$$
\boldsymbol c=\mathbf K_{\mathcal D}^{-1}\boldsymbol k_{\mathcal D}(\boldsymbol z),\qquad
\Delta=\kappa(\boldsymbol z,\boldsymbol z)-\boldsymbol k_{\mathcal D}(\boldsymbol z)^{\mathrm T}\boldsymbol c
$$

를 계산합니다. $\Delta$는 $\phi(\boldsymbol z)$를 사전 원소들의 선형 결합으로 근사했을 때 남는 오차의 제곱입니다. $\Delta>\nu$면 $\boldsymbol z$를 사전에 추가하고 계수 $\alpha\delta$를 붙입니다. 아니면 $\phi(\boldsymbol z)\approx\sum_j c_j\phi(\boldsymbol z_j)$이므로 $\boldsymbol\theta\leftarrow\boldsymbol\theta+\alpha\delta\sum_jc_j\phi(\boldsymbol z_j)$, 곧 $\boldsymbol\beta\leftarrow\boldsymbol\beta+\alpha\delta\,\boldsymbol c$로 기존 계수만 고칩니다.

**알고리즘.**

**입력**: 환경 $E$, 액션 공간 $A$, 초기 상태 $\boldsymbol x_0$, 보상 할인 $\gamma$, 갱신 길이 $\alpha$, 커널 $\kappa$, 희소화 역치 $\nu$

**과정**:

1. 사전 $\mathcal D=\varnothing$, 계수 $\boldsymbol\beta=\varnothing$, $Q(\boldsymbol z)=\sum_{\boldsymbol z_j\in\mathcal D}\beta_j\kappa(\boldsymbol z_j,\boldsymbol z)$
2. $\boldsymbol x=\boldsymbol x_0$, $a=\pi^\epsilon(\boldsymbol x)$, 여기서 $\pi(\boldsymbol x)=\arg\max_{a''}Q(\boldsymbol x,a'')$
3. **for** $t=1,2,\dots$ **do**
4. &emsp; $r,\boldsymbol x'=$ $E$에서 액션 $a$를 실행하여 얻은 보상과 전이된 상태
5. &emsp; $a'=\pi^\epsilon(\boldsymbol x')$
6. &emsp; $\delta=r+\gamma Q(\boldsymbol x',a')-Q(\boldsymbol x,a)$
7. &emsp; $\boldsymbol z=(\boldsymbol x,a)$에 대해 $\boldsymbol c$, $\Delta$ 계산
8. &emsp; **if** $\Delta>\nu$ **then** $\mathcal D=\mathcal D\cup\{\boldsymbol z\}$, $\boldsymbol\beta=(\boldsymbol\beta;\alpha\delta)$, $\mathbf K_{\mathcal D}^{-1}$ 갱신
9. &emsp; **else** $\boldsymbol\beta=\boldsymbol\beta+\alpha\delta\,\boldsymbol c$
10. &emsp; $\boldsymbol x=\boldsymbol x'$, $a=a'$
11. **end for**

**출력**: 정책 $\pi(\boldsymbol x)=\arg\max_aQ(\boldsymbol x,a)$

$\nu=0$이면 모든 샘플을 추가하는 정확한 커널 Sarsa가 되고, $\nu$가 클수록 사전이 작아져 빠르지만 거칠어집니다. 커널 폭 $\sigma$는 너무 크면 선형에 가까워져 과소적합하고, 너무 작으면 방문하지 않은 상태로 일반화가 안 됩니다. $\mathbf K_{\mathcal D}^{-1}$는 원소를 추가할 때 블록 역행렬 공식으로 $O(|\mathcal D|^2)$에 갱신할 수 있습니다(아래 코드는 짧게 쓰려고 매번 역행렬을 새로 계산했습니다).

**실험.** 문제 16.7의 1차원 도로 과업에서 위 알고리즘을 돌렸습니다. 커널은 상태 가우스 커널과 액션 일치 여부의 곱이므로, 코드에서는 액션별로 사전을 따로 둡니다($\sigma=0.05$, $\alpha=0.2$, $\nu=0.01$, 시드 0).

```python
import numpy as np
from road import sarsa, evaluate

class KernelSarsa:                  # κ((x,a),(x',a')) = exp(-(x-x')²/2σ²)·1[a=a']
    def __init__(s, sigma=0.05, alpha=0.2, nu=0.01):
        s.C = [[], []]; s.B = [np.zeros(0), np.zeros(0)]; s.Kinv = [None, None]
        s.k = lambda u, v: np.exp(-(np.asarray(u)[:, None] - np.asarray(v)[None, :]) ** 2 / (2 * sigma ** 2))
        s.al, s.nu = alpha, nu
    def q(s, x):
        return np.array([s.k([x], s.C[a])[0] @ s.B[a] if s.C[a] else 0.0 for a in (0, 1)])
    def update(s, x, a, d):
        C = s.C[a]
        if C:
            kv = s.k(C, [x])[:, 0]; c = s.Kinv[a] @ kv
            ald = 1.0 - kv @ c                     # 사전으로 κ(x,·)를 얼마나 못 나타내는지
        if not C or ald > s.nu:                    # 새 중심 추가: f ← f + αδ κ(x,·)
            C.append(x); s.B[a] = np.r_[s.B[a], s.al * d]
            s.Kinv[a] = np.linalg.inv(s.k(C, C) + 1e-8 * np.eye(len(C)))
        else:                                      # 사전 위로 사영한 뒤 갱신
            s.B[a] = s.B[a] + s.al * d * c

ag = sarsa(KernelSarsa(), seed=0)
print(evaluate(ag), [len(c) for c in ag.C])
```

결과는 문제 16.7의 표에 함께 실었습니다. 성공률 1.000, 평균 단계 수 5.00(최적과 같음), $V^*$와의 RMSE 0.495로 세 방법 중 가치 함수를 가장 정확하게 맞혔습니다. 3,000 에피소드 동안 사전에 남은 중심점은 왼쪽 액션 23개, 오른쪽 액션 22개뿐이었습니다. 희소화가 없었다면 학습에 쓴 전이 수만큼 항이 늘었을 것입니다. 시드 0~4로 반복해도 모두 성공률 1.0이었고 RMSE는 0.46~0.66이었습니다.

## 문제 16.9

> 목표 기반(goal-directed)의 강화 학습 과업에서 목표는 어떤 상태에 달하는 것인데, 예를 들면 자동차를 운전해 예정된 위치로 이동하는 것이다. 이러한 과업을 위해서 보상 함수를 설정하고, 서로 다른 보상 함수의 효과에 대해 논의하라.

**풀이**

목표 상태 집합을 $X_g$, 상태 $x$에서 목표까지의 거리를 $d(x)$라 하겠습니다. 자주 쓰는 보상 함수는 다음과 같습니다.

**① 희소 보상: 목표에 도착하면 $+1$, 나머지는 0.** "도착"이라는 의도를 가장 정직하게 표현합니다. 다만 할인이 있어야 빨리 도착하는 것을 선호합니다. γ할인 누적 보상에서 $k$단계 만에 도착하면 가치가 $\gamma^{k-1}$이라 짧은 경로가 유리하지만, $\gamma=1$이면 언제 도착하든 가치가 1로 같아 멀리 돌아가는 정책도 최적이 됩니다. 책의 T단계 누적 보상(평균)을 쓴다면 목표를 흡수 상태로 두고 머무는 동안 매 단계 $+1$을 주어야 빨리 도착할수록 평균이 커집니다. 가장 큰 단점은 탐색입니다. 처음 목표에 우연히 닿기 전까지는 보상 신호가 전혀 없어서 상태 공간이 넓으면 학습이 시작조차 안 될 수 있습니다.

**② 시간 벌점: 목표에 도착할 때까지 매 단계 $-1$.** 누적 보상이 곧 "걸린 시간의 음수"라서 $\gamma=1$로도 최단 시간 정책을 바로 표현합니다. $Q$를 0으로 초기화하면 아직 가 보지 않은 액션이 상대적으로 좋아 보이는 낙관적 초기화가 되어 체계적으로 탐색하는 효과도 있습니다. 주의할 점은 실패로 끝나는 종료 상태(충돌 등)가 있을 때입니다. 충돌해서 에피소드가 일찍 끝나면 벌점이 덜 쌓이므로, 충돌 벌점이 충분히 크지 않으면 "빨리 부딪혀 끝내기"가 최적이 될 수 있습니다. 목표에 도달할 수 없는 경우를 대비해 최대 단계 수도 정해 두어야 합니다.

**③ 거리 기반의 촘촘한 보상.** 매 단계 $-d(x')$를 주거나, 목표에 가까워지면 보상을 주는 방식입니다. 신호가 촘촘해 학습이 빨라질 수 있지만, 진짜 목표(도착)와 다른 것을 최적화하게 만들 위험이 큽니다. 직선 거리가 실제 경로 길이와 다르면(벽이나 일방통행 도로가 있으면) 장애물 앞에서 멈추는 국소 최적에 빠질 수 있고, 가까워질 때만 보상하고 멀어질 때 벌주지 않으면 목표 근처를 왔다 갔다 하며 보상을 계속 받는 편이 도착하는 것보다 나아집니다. 아래 실험의 C가 그런 경우입니다.

**④ 퍼텐셜 기반 보상 셰이핑.** 원래 보상(①이나 ②)에 $F(x,x')=\gamma\Phi(x')-\Phi(x)$를 더합니다. 예를 들어 $\Phi(x)=-d(x)$입니다. 이 형태는 최적 정책을 바꾸지 않는다는 것이 증명되어 있습니다(Ng, Harada, Russell, 1999). 어떤 경로든 $F$의 할인 합이 $\gamma^T\Phi(x_T)-\Phi(x_0)$으로 시작과 끝 상태에만 의존하므로(종료 상태의 $\Phi$는 0으로 둠), 새로운 Q 함수가 원래 Q 함수에서 $\Phi(x)$만큼 평행 이동한 것이 되기 때문입니다. ③의 장점(촘촘한 신호)을 가지면서 ③의 함정은 피하는 방법입니다. 다만 최적 정책이 같다는 것이 보장될 뿐, 학습이 반드시 빨라지는 것은 아니고 $\Phi$를 얼마나 잘 고르느냐에 달려 있습니다.

**⑤ 그 밖의 항.** 실제 운전이라면 충돌·차선 이탈 벌점, 연료 소모, 급가속·급제동(승차감) 벌점 등을 더합니다. 이 항들의 가중치가 행동을 크게 바꿉니다. 충돌 벌점이 시간 벌점에 비해 너무 작으면 위험하게 운전하고, 너무 크면 아예 출발하지 않는 소극적 정책이 나올 수 있습니다. 여러 항을 더할수록 에이전트가 설계자가 의도하지 않은 허점을 찾아낼 가능성(보상 해킹)도 커집니다. 16.6.2절의 역강화 학습은 이런 가중치를 사람의 운전 기록에서 거꾸로 추정하려는 접근입니다.

**실험.** 칸 0~9로 된 1차원 도로에서 칸 0에서 출발해 칸 9(목표)로 가는 과업으로 위 보상들을 비교했습니다. 액션은 왼쪽·오른쪽, 이동은 결정론적이고 양 끝은 벽입니다. 표 형태 Q-학습($\alpha=0.1$, $\epsilon=0.1$, $Q$ 초깃값 0, 에피소드 최대 100단계)으로 학습한 뒤, 탐욕 정책(동률은 무작위)으로 목표에 도착하는지 봤습니다. 최단 경로는 9단계이고, 시드 0~19의 20번 평균입니다.

```python
import numpy as np
N, GOAL, MAXT = 10, 9, 100                 # 칸 0..9, 출발 0, 목표 9, 액션 0=왼쪽 1=오른쪽
dist = lambda s: GOAL - s
rewards = {   # (s, s2, done) -> r
    "A 목표 +1 (γ=0.9)":       (0.9, lambda s, s2, d: 1.0 if d else 0.0),
    "B 매 단계 -1 (γ=1)":      (1.0, lambda s, s2, d: -1.0),
    "C 가까워지면 +1 (γ=0.9)": (0.9, lambda s, s2, d: 1.0 if dist(s2) < dist(s) else 0.0),
    "D A + 퍼텐셜 셰이핑":     (0.9, lambda s, s2, d: (1.0 if d else 0.0)
                                 + 0.9 * (0 if d else -dist(s2)) - (-dist(s))),
}
def greedy(Q, s, rng):                     # 동률이면 임의로
    return rng.choice(np.flatnonzero(Q[s] == Q[s].max()))
def train(gamma, rf, episodes=300, alpha=0.1, eps=0.1, seed=0):
    rng = np.random.default_rng(seed); Q = np.zeros((N, 2)); total = 0
    for _ in range(episodes):
        s = 0
        for t in range(MAXT):
            a = rng.integers(2) if rng.random() < eps else greedy(Q, s, rng)
            s2 = min(max(s + (1 if a else -1), 0), N - 1); d = s2 == GOAL
            target = rf(s, s2, d) + (0 if d else gamma * Q[s2].max())
            Q[s, a] += alpha * (target - Q[s, a]); total += 1
            s = s2
            if d: break
    return Q, total
def test(Q, runs=200, seed=1):
    rng = np.random.default_rng(seed); ok, steps = 0, []
    for _ in range(runs):
        s = 0
        for t in range(MAXT):
            s = min(max(s + (1 if greedy(Q, s, rng) else -1), 0), N - 1)
            if s == GOAL: ok += 1; steps.append(t + 1); break
    return ok / runs, np.mean(steps) if steps else float('nan')
if __name__ == "__main__":
    for name, (g, rf) in rewards.items():
        for ep in [50, 300]:
            res = np.array([(*test(Q), tot) for Q, tot in [train(g, rf, ep, seed=sd) for sd in range(20)]])
            print(f"{name:20s} ep {ep} success {res[:,0].mean():.2f} steps {np.nanmean(res[:,1]) if res[:,0].any() else float('nan'):.2f} train-steps {res[:,2].mean():.0f}")
    Q, _ = train(*rewards["C 가까워지면 +1 (γ=0.9)"], 300, seed=0)
    print("C Q[7], Q[8]:", Q[7].round(3), Q[8].round(3), "theory", round(0.9 / (1 - 0.81), 3))
```

| 보상 함수 | 50 에피소드 후 성공률 | 300 에피소드 후 성공률 | 성공 시 단계 수 | 300 에피소드 동안 쓴 총 단계 수 |
|---|---|---|---|---|
| A: 목표 $+1$, $\gamma=0.9$ | 1.00 | 1.00 | 9 | 3,263 |
| B: 매 단계 $-1$, $\gamma=1$ | 0.30 | 1.00 | 9 | 3,562 |
| C: 가까워지면 $+1$, $\gamma=0.9$ | 0.05 | 0.00 | (도착 못 함) | 16,541 |
| D: A + 퍼텐셜 셰이핑 $\Phi=-d$ | 0.45 | 0.85 | 9 | 8,926 |

- A는 이 작은 문제에서는 무작위 탐색으로도 금방 목표에 닿기 때문에 가장 빨리 배웠습니다. 상태 공간이 커지면 이 장점은 사라집니다.
- B는 300 에피소드 후에는 모두 최단 경로를 찾았습니다. 초반에 느린 것은 0으로 초기화한 $Q$가 낙관적이라 가 보지 않은 액션을 골고루 시도하기 때문입니다.
- C는 학습할수록 오히려 나빠져 300 에피소드 후에는 20번 모두 도착하지 못했습니다. 학습된 값을 보면 칸 8에서 $Q(8,\text{왼쪽})=4.737$, $Q(8,\text{오른쪽})=1.000$입니다. 오른쪽으로 가면 $+1$을 받고 끝나지만, 왼쪽으로 물러났다가(0) 다시 다가오면(+1) 이를 끝없이 반복할 수 있어서 가치가 $\gamma+\gamma^3+\dots=\gamma/(1-\gamma^2)=4.737$이 됩니다. 이론값과 정확히 같습니다. 목표에 도착하는 것보다 목표 근처에서 서성이는 것이 더 이익인 보상을 설계한 셈입니다.
- D는 최적 정책은 A와 같지만(300 에피소드 후 성공한 경우 모두 9단계), 이 사슬에서는 학습이 A보다 느렸습니다. 셰이핑 항은 Q-학습에서 $Q$의 초깃값을 $\Phi$만큼 바꾸는 것과 같은 효과를 내는데(Wiewiora, 2003), 여기서 고른 $\Phi=-d$와 초깃값 0의 조합이 탐색에 도움이 되지 않은 것으로 보입니다. 셰이핑은 정책을 망가뜨리지 않는다는 보장이지 학습 속도의 보장은 아니라는 점을 보여 줍니다.

결론적으로 목표 기반 과업에서는 ①이나 ②처럼 "도착" 자체를 보상하는 것을 기본으로 두고, 학습을 돕는 촘촘한 신호가 필요하면 ③처럼 임의로 더하기보다 ④의 퍼텐셜 형태로 더하는 것이 안전합니다.

## 문제 16.10\* (심화)

> 전통적인 지도 학습과 다르게 직접 모방 학습은 다른 시각(time stamp)에 직면하는 데이터 분포가 다를 수 있다. 다른 시각에서의 데이터 분포 변화를 고려하지 않는 모방 학습 알고리즘을 만들어 보아라.

**풀이**

문장 그대로 읽으면 분포 변화를 "고려하지 않는" 알고리즘을 만들라는 뜻인데, 그것은 16.6.1절의 직접적 이미테이션 러닝(모든 상태-액션 쌍을 모아 지도 학습) 그 자체입니다. 문제 앞부분이 분포 변화를 문제점으로 지적하고 있으므로, 문제의 의도를 **시각마다 달라지는 데이터 분포를 고려하는** 모방 학습 알고리즘을 설계하라는 것으로 해석했습니다.

**문제가 생기는 이유.** 정책 $\pi$를 따를 때 시각 $t$의 상태 분포를 $d_t^\pi$라 하겠습니다. 직접적 이미테이션 러닝은 전문가 경로에서 데이터를 모으므로 학습 데이터는 $d_t^{\pi^*}$에서 나오지만, 학습한 정책 $\hat\pi$를 실제로 쓰면 상태는 $d_t^{\hat\pi}$에서 나옵니다. 처음 몇 단계는 두 분포가 비슷해도, $\hat\pi$가 한 번 실수해서 전문가가 가지 않는 상태로 들어가면 그 뒤로는 학습 데이터에 없던 상태만 만나 실수가 연쇄적으로 쌓입니다. 시각이 뒤로 갈수록 $d_t^{\hat\pi}$와 $d_t^{\pi^*}$의 차이가 커지는 것입니다.

이 효과의 크기는 간단한 계산으로 가늠할 수 있습니다. 전문가 정책은 결정론적이고, 매 단계 비용은 $[0,1]$ 안에 있으며, 전문가가 시각 $s$에 만나는 상태 분포 $d_s^{\pi^*}$에서 $\hat\pi$가 전문가와 다른 액션을 고를 확률이 $\epsilon$ 이하라고 하겠습니다. 전문가와 학습자를 같은 무작위성(같은 전이 결과)으로 나란히 실행한다고 생각하면, 학습자가 처음 실수하기 전까지 두 경로는 완전히 같습니다. 그래서 첫 실수는 반드시 전문가 경로 위의 상태에서 일어나고, 시각 $s$에 첫 실수가 일어날 확률은 $\epsilon$ 이하입니다. 따라서 시각 $t$까지 경로가 갈라졌을 확률은 $t\epsilon$ 이하이고, 시각 $t$에서 학습자가 전문가보다 더 치르는 비용은 경로가 갈라진 경우에만 생기며 최대 1이므로 그 기댓값도 $t\epsilon$ 이하입니다. 이를 $t=1,\dots,T$에 대해 더하면 총 비용 차이는 최대 $\sum_{t=1}^{T}t\epsilon=\frac{T(T+1)}{2}\epsilon$입니다. 경로가 갈라진 뒤에는 학습 데이터에 없던 상태에서 계속 비용을 치를 수 있으므로 이 제곱 크기의 손실은 실제로 나타날 수 있습니다(Ross and Bagnell, 2010). 시각마다 독립적으로 판단하는 보통의 지도 학습이었다면 오차는 $T\epsilon$처럼 선형으로만 쌓였을 것입니다.

**설계 1: 시각별 정책을 앞에서부터 차례로 학습(전진 학습).** 문제의 "시각마다 분포가 다르다"는 점을 그대로 반영해 시각마다 정책 $\pi_t$를 따로 두고, $\pi_t$는 학습자가 실제로 시각 $t$에 도달하는 상태 분포에서 학습합니다.

**입력**: 환경 $E$, 초기 상태 분포, 전문가 $\pi^*$(상태를 주면 액션을 알려 줌), 경로 길이 $T$, 시각마다 모을 샘플 수 $m$, 분류(회귀) 알고리즘 $\mathfrak L$

**과정**:

1. **for** $t=1,2,\dots,T$ **do**
2. &emsp; 이미 학습한 $\pi_1,\dots,\pi_{t-1}$을 차례로 실행해 시각 $t$의 상태 $x_t^{(1)},\dots,x_t^{(m)}$을 얻음 ($t=1$이면 초기 상태)
3. &emsp; 각 상태에서 전문가에게 액션을 물어 $D_t=\{(x_t^{(j)},\pi^*(x_t^{(j)}))\}_{j=1}^m$을 만듦
4. &emsp; $\pi_t=\mathfrak L(D_t)$
5. **end for**

**출력**: 시각별 정책 $(\pi_1,\pi_2,\dots,\pi_T)$

$\pi_t$를 학습한 데이터는 학습자가 시각 $t$에 실제로 만나는 분포 $d_t^{(\pi_1,\dots,\pi_{t-1})}$에서 나왔고, 앞 시각의 정책은 이후 바뀌지 않으므로 학습 분포와 사용 분포가 시각마다 정확히 일치합니다. 앞에서 실수해 이상한 상태로 갔더라도, 그런 상태에서 "어떻게 복구하는지"를 전문가 레이블로 배웁니다. 이 경우 성능 차이는 $T$에 대해 선형인 $O(uT\epsilon)$ 수준으로 줄어든다는 것이 알려져 있습니다(Ross and Bagnell, 2010; $u$는 한 단계 실수가 이후 비용을 얼마나 늘리는지에 대한 상수). 단점은 정책이 $T$개 필요하고, 경로 길이만큼 학습을 반복해야 하며, 학습 중 전문가에게 질의할 수 있어야 한다는 것입니다.

**설계 2: 데이터 집계(DAgger).** 정책 하나로 모든 시각을 다루면서 같은 효과를 내는 방법입니다(Ross, Gordon, Bagnell, 2011).

**입력**: 환경 $E$, 전문가 $\pi^*$, 반복 횟수 $N$, 혼합 비율 $\beta_1,\dots,\beta_N$(예: $\beta_1=1$, $\beta_i=p^{i-1}$), 분류 알고리즘 $\mathfrak L$

**과정**:

1. 전문가 경로로 $D=\{(x,\pi^*(x))\}$를 만들고 $\hat\pi_1=\mathfrak L(D)$ (직접적 이미테이션 러닝과 같음)
2. **for** $i=1,2,\dots,N$ **do**
3. &emsp; 매 단계 확률 $\beta_i$로 전문가, $1-\beta_i$로 $\hat\pi_i$의 액션을 실행하는 혼합 정책 $\pi_i$로 경로를 생성
4. &emsp; 경로에서 방문한 모든 상태 $x$에 대해 전문가 액션을 물어 $D_i=\{(x,\pi^*(x))\}$를 만듦 (실행한 액션이 아니라 전문가의 답을 레이블로 씀)
5. &emsp; $D=D\cup D_i$, $\hat\pi_{i+1}=\mathfrak L(D)$
6. **end for**

**출력**: $\hat\pi_1,\dots,\hat\pi_{N+1}$ 중 검증 성능이 가장 좋은 정책

반복할수록 $D$에는 학습자 자신이 만드는 시각별 분포 $d_t^{\hat\pi_i}$의 상태가 쌓이므로, 학습 분포가 점점 사용 분포를 따라갑니다. 정책이 시각에 따라 달라야 하는 과업이라면 시각 $t$(또는 남은 단계 수)를 특성에 추가하면 되고, 시각마다 분포 차이가 큰 구간의 샘플에 가중치를 더 줄 수도 있습니다. 이렇게 얻은 정책은 16.6.1절에서 말한 대로 강화 학습의 초기 정책으로 써서 보상 피드백으로 더 개선할 수 있습니다.

두 설계 모두 학습 도중 전문가가 "이 상태에서는 무엇을 하겠는가"에 답해 줄 수 있어야 한다는 가정이 필요합니다. 수박 재배라면 학습 중인 에이전트가 만든 밭의 상태를 농업 전문가에게 보여 주고 다음 작업을 물어보는 셈입니다. 전문가에게 계속 물어볼 수 없다면 16.6.2절의 역강화 학습처럼 시연에서 보상 함수를 추정하고, 분포가 달라진 상태에서는 강화 학습으로 스스로 행동을 정하게 하는 쪽이 대안입니다.
