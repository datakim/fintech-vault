이 장의 실험 코드는 모두 numpy(일부 데이터 로딩에 scikit-learn)로 작성했고, 무작위성이 있는 실험은 시드를 고정했습니다. 기호는 책 5.3절(그림 5.7)을 따릅니다. 입력층 $i$번째 뉴런과 은닉층 $h$번째 뉴런 사이의 가중치는 $v_{ih}$, 은닉층 $h$번째 뉴런과 출력층 $j$번째 뉴런 사이의 가중치는 $w_{hj}$, 은닉층과 출력층의 임곗값은 각각 $\gamma_h$, $\theta_j$입니다. 또 $\alpha_h=\sum_i v_{ih}x_i$, $\beta_j=\sum_h w_{hj}b_h$, $b_h=f(\alpha_h-\gamma_h)$, $\hat{y}_j=f(\beta_j-\theta_j)$입니다.

## 문제 5.1

> 선형 함수 $f(\boldsymbol{x}) = \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}$를 신경망 활성화 함수로 사용했을 때의 결함에 대해 설명하라.

**풀이**

활성화 함수가 선형이면 각 뉴런의 출력은 입력의 가중합(에서 임곗값을 뺀 값)이 그대로 나갑니다. 단일 은닉층 신경망을 행렬로 쓰면 다음과 같습니다. $\mathbf{V}\in\mathbb{R}^{d\times q}$, $\mathbf{W}\in\mathbb{R}^{q\times l}$이고 $\boldsymbol{\gamma}$, $\boldsymbol{\theta}$는 임곗값 벡터입니다.

$$
\begin{aligned}
\boldsymbol{b} &= \mathbf{V}^{\mathrm{T}}\boldsymbol{x}-\boldsymbol{\gamma},\\
\hat{\boldsymbol{y}} &= \mathbf{W}^{\mathrm{T}}\boldsymbol{b}-\boldsymbol{\theta}
= (\mathbf{V}\mathbf{W})^{\mathrm{T}}\boldsymbol{x}-(\mathbf{W}^{\mathrm{T}}\boldsymbol{\gamma}+\boldsymbol{\theta})
= \mathbf{A}^{\mathrm{T}}\boldsymbol{x}+\boldsymbol{c}.
\end{aligned}
$$

은닉층을 몇 개 쌓아도 같은 계산이 반복될 뿐이라, 네트워크 전체는 결국 하나의 선형(아핀) 사상 $\hat{\boldsymbol{y}}=\mathbf{A}^{\mathrm{T}}\boldsymbol{x}+\boldsymbol{c}$가 됩니다. 여기서 다음 결함들이 나옵니다.

1. **층을 쌓는 의미가 사라집니다.** 다층 네트워크의 표현 능력이 은닉층 없는 선형 모델(3장의 선형 회귀)과 같아집니다. 오히려 $\mathbf{A}=\mathbf{V}\mathbf{W}$의 랭크가 $q$ 이하로 묶이므로, 은닉 뉴런 수 $q$가 $d$나 $l$보다 작으면 일반 선형 모델보다 표현 범위가 더 좁아집니다. 깊이는 표현력을 늘리지 못하고 제약만 더합니다.
2. **선형 분리 불가능한 문제를 풀 수 없습니다.** 출력에 임곗값 판정을 붙이더라도 결정 경계는 초평면 $\mathbf{A}^{\mathrm{T}}\boldsymbol{x}+\boldsymbol{c}=0$입니다. 그림 5.4 (d)의 XOR 문제처럼 단층 퍼셉트론이 못 푸는 문제는 선형 활성화를 쓴 다층 네트워크도 풀지 못합니다. 129쪽에 소개된 Hornik 등(1989)의 보편 근사 결과도 시그모이드 같은 비선형(스쿼싱) 활성화 함수를 전제로 한 것이어서, 선형 활성화 함수에는 성립하지 않습니다.
3. **출력이 유계가 아닙니다.** 출력이 $(-\infty,\infty)$ 범위를 가지므로 시그모이드처럼 $(0,1)$ 사이의 값으로 해석하거나 확률로 읽을 수 없습니다. 분류 문제에서는 레이블 근처에 출력을 모으는 성질도 없습니다.
4. **파라미터가 중복됩니다.** 임의의 가역 행렬 $\mathbf{M}$에 대해 $(\mathbf{V}\mathbf{M})(\mathbf{M}^{-1}\mathbf{W})=\mathbf{V}\mathbf{W}$이므로 같은 함수를 나타내는 파라미터 조합이 무수히 많습니다. 학습할 파라미터는 $(d+l+1)q+l$개로 늘었지만 실제로 표현되는 함수는 $\mathbf{A}$, $\boldsymbol{c}$뿐입니다.

정리하면 선형 함수를 활성화 함수로 쓴 신경망은 "비용이 더 드는 선형 모델"입니다. 다만 이 결함은 은닉층에 선형 함수를 쓸 때의 이야기입니다. 회귀 문제의 출력층이나 RBF 신경망의 출력층(식 5.18)처럼, 은닉층이 이미 비선형 변환을 해 준 뒤 마지막 층에서 선형 결합을 하는 것은 흔하고 문제가 없습니다.

## 문제 5.2

> 그림 5.2 (b) 활성화 함수의 신경망을 사용하는 것과 로지스틱 회귀의 관계에 대해 기술하라.

**풀이**

그림 5.2 (b)는 시그모이드 함수 $\operatorname{sigmoid}(x)=\dfrac{1}{1+e^{-x}}$이고, 이는 식 3.17의 로지스틱 함수와 같습니다.

**1. 은닉층이 없는 뉴런 하나는 로지스틱 회귀 모델과 같습니다.**

입력을 받아 바로 출력하는 뉴런 하나(그림 5.1)의 출력은

$$
\hat{y} = \frac{1}{1+e^{-(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}-\theta)}}
$$

입니다. $b=-\theta$로 두면 식 3.18 $y=\dfrac{1}{1+e^{-(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}+b)}}$와 완전히 같은 모델입니다. 따라서 출력 $\hat{y}$는 로지스틱 회귀처럼 $p(y=1\mid\boldsymbol{x})$의 추정값으로 해석할 수 있고, $\ln\dfrac{\hat{y}}{1-\hat{y}}=\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}-\theta$이므로 로그 오즈를 선형 함수로 근사하는 셈입니다.

**2. 차이는 손실 함수와 최적화 방법에 있습니다.**

책의 오차 역전파는 제곱 오차(식 5.4) $E_k=\frac12(\hat{y}_k-y_k)^2$을 최소화하고, 로지스틱 회귀는 로그 우도(식 3.25)를 최대화, 즉 식 3.27을 최소화합니다. 이 차이는 기울기에서 드러납니다.

- 제곱 오차: 식 5.10에 따라 출력층 기울기 항은 $g=\hat{y}(1-\hat{y})(y-\hat{y})$이고 $\Delta\boldsymbol{w}=\eta\,\hat{y}(1-\hat{y})(y-\hat{y})\,\boldsymbol{x}$입니다.
- 로그 우도: 한 샘플의 손실 $-\big[y\ln\hat{y}+(1-y)\ln(1-\hat{y})\big]$을 $z=\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}-\theta$로 미분하면 $\dfrac{\partial}{\partial z}=\hat{y}-y$이므로 $\Delta\boldsymbol{w}=\eta\,(y-\hat{y})\,\boldsymbol{x}$입니다. 이는 식 3.30의 기울기와 같습니다.

제곱 오차 쪽에는 $\hat{y}(1-\hat{y})$라는 인수가 더 붙어 있어서, 출력이 0이나 1 근처에서 포화된 채로 틀렸을 때 기울기가 거의 0이 되어 학습이 느려집니다. 또 제곱 오차는 $\boldsymbol{w}$에 대해 컨벡스가 아니지만(연습문제 3.2), 식 3.27은 컨벡스라서 경사하강법이나 뉴턴법으로 전역 최적해를 구할 수 있습니다. 반대로 말하면, **시그모이드 뉴런 하나를 교차 엔트로피(음의 로그 우도) 손실로 훈련시키면 그것이 바로 경사하강법으로 푸는 로지스틱 회귀**입니다.

**3. 은닉층이 있으면 "학습된 특성 위의 로지스틱 회귀"가 됩니다.**

출력 뉴런이 시그모이드이면 $\hat{y}_j=\operatorname{sigmoid}\big(\sum_h w_{hj}b_h-\theta_j\big)$이므로, 출력층은 은닉층 출력 $\boldsymbol{b}=(b_1,\dots,b_q)$를 입력으로 받는 로지스틱 회귀입니다. 은닉 뉴런 하나하나도 원래 입력 $\boldsymbol{x}$에 대한 로지스틱 회귀 단위이고요. 그래서 시그모이드 다층 신경망은 로지스틱 회귀 단위를 여러 층 쌓은 모델로 볼 수 있고, 로지스틱 회귀는 은닉층이 없는 특수한 경우입니다. 다만 은닉층 파라미터까지 함께 학습하므로 목표 함수는 더 이상 컨벡스가 아니고, 5.4절에서 말한 로컬 미니멈 문제가 생깁니다.

| 구분 | 로지스틱 회귀 | 시그모이드 신경망(책의 BP) |
|---|---|---|
| 모델 | $\operatorname{sigmoid}(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}+b)$ | 은닉층 없으면 동일, 있으면 $\boldsymbol{b}(\boldsymbol{x})$ 위의 로지스틱 회귀 |
| 결정 경계 | 초평면 | 은닉층이 있으면 비선형 |
| 손실 | 음의 로그 우도(식 3.27) | 제곱 오차(식 5.4) |
| 목표 함수 | 컨벡스 | 일반적으로 넌컨벡스 |
| 출력 여러 개 | 클래스마다 독립된 모델 | 출력 뉴런 $l$개가 은닉층을 공유 |

## 문제 5.3

> 그림 5.7의 $v_{ih}$에 대해, BP 알고리즘 중의 갱신 공식인 식 5.13을 유도하라.

**풀이**

보일 식은 식 5.13 $\Delta v_{ih}=\eta e_h x_i$입니다. 여기서 $e_h$는 식 5.15의 은닉층 기울기 항입니다.

**Step 1. 경사하강법 형태.** 식 5.6과 같은 방식으로

$$
\Delta v_{ih} = -\eta\frac{\partial E_k}{\partial v_{ih}}.
$$

**Step 2. 체인 룰.** $v_{ih}$는 먼저 은닉층 $h$번째 뉴런의 입력 $\alpha_h$에, 다음으로 그 출력 $b_h$에 영향을 주고, $b_h$는 모든 출력 뉴런의 입력 $\beta_1,\dots,\beta_l$을 거쳐 $E_k$에 영향을 줍니다.

$$
\frac{\partial E_k}{\partial v_{ih}}
= \frac{\partial E_k}{\partial b_h}\cdot\frac{\partial b_h}{\partial \alpha_h}\cdot\frac{\partial \alpha_h}{\partial v_{ih}}.
$$

**Step 3. 각 인수 계산.**

(1) $\alpha_h=\sum_{i=1}^{d}v_{ih}x_i$이므로 $\dfrac{\partial \alpha_h}{\partial v_{ih}}=x_i$입니다.

(2) $b_h=f(\alpha_h-\gamma_h)$이고 식 5.9 $f'(x)=f(x)(1-f(x))$를 쓰면 $\dfrac{\partial b_h}{\partial \alpha_h}=f'(\alpha_h-\gamma_h)=b_h(1-b_h)$입니다.

(3) $b_h$는 $\beta_j=\sum_h w_{hj}b_h$를 통해 모든 $j$에 들어가므로

$$
\frac{\partial E_k}{\partial b_h}=\sum_{j=1}^{l}\frac{\partial E_k}{\partial \beta_j}\cdot\frac{\partial \beta_j}{\partial b_h}
=\sum_{j=1}^{l}\frac{\partial E_k}{\partial \beta_j}\,w_{hj}.
$$

여기서 식 5.10의 정의에 의해

$$
\frac{\partial E_k}{\partial \beta_j}=\frac{\partial E_k}{\partial \hat{y}_j^k}\cdot\frac{\partial \hat{y}_j^k}{\partial \beta_j}
=(\hat{y}_j^k-y_j^k)\,f'(\beta_j-\theta_j)=-g_j
$$

이므로 $\dfrac{\partial E_k}{\partial b_h}=-\sum_{j=1}^{l}w_{hj}g_j$입니다.

**Step 4. 정리.** 세 인수를 곱하면

$$
\frac{\partial E_k}{\partial v_{ih}}=-\,b_h(1-b_h)\sum_{j=1}^{l}w_{hj}g_j\cdot x_i=-e_h x_i,
\qquad e_h=b_h(1-b_h)\sum_{j=1}^{l}w_{hj}g_j .
$$

$e_h$의 정의는 식 5.15와 정확히 같습니다. Step 1에 대입하면

$$
\Delta v_{ih}=-\eta\frac{\partial E_k}{\partial v_{ih}}=\eta\,e_h x_i
$$

가 되어 식 5.13이 유도됩니다. 같은 방식으로 $\dfrac{\partial b_h}{\partial \gamma_h}=-b_h(1-b_h)$를 쓰면 $\dfrac{\partial E_k}{\partial \gamma_h}=e_h$이므로 식 5.14 $\Delta\gamma_h=-\eta e_h$도 얻습니다.

## 문제 5.4

> 식 5.6에서 학습률의 값이 신경망 훈련에 미치는 영향에 대해 기술하라.

**풀이**

학습률 $\eta$는 식 5.6 $\Delta w_{hj}=-\eta\,\partial E_k/\partial w_{hj}$에서 한 번 갱신할 때 기울기 반대 방향으로 얼마나 움직일지를 정합니다.

- **너무 작으면** 매 갱신의 이동량이 작아 수렴이 매우 느립니다. 정해진 에포크 안에 훈련 오차가 충분히 내려가지 않고, 평평한 구간(플래토)에서 오래 머뭅니다.
- **너무 크면** 최솟값을 지나쳐 오차가 진동하거나 발산합니다. 시그모이드 신경망에서는 특히 가중치가 한 번에 크게 바뀌면서 뉴런 입력이 커져 시그모이드가 포화되는 일이 생깁니다. 포화되면 $f'=f(1-f)\approx 0$이라 식 5.10, 5.15의 기울기 항이 거의 0이 되고, 그 뒤로는 학습이 사실상 멈춥니다.
- **적절하면** 빠르게 내려가면서도 안정적으로 수렴합니다. 다만 적절한 값은 데이터, 네트워크 크기, 표준 BP인지 누적 BP인지(누적 BP는 기울기를 평균하므로 같은 $\eta$라도 에포크당 이동량이 작습니다. 문제 5.5 참고)에 따라 달라집니다.
- 표준 BP(스토캐스틱 경사하강법)에서는 $\eta$가 기울기 잡음의 크기도 정합니다. 어느 정도 큰 $\eta$는 로컬 미니멈에서 빠져나오는 데 도움이 될 수 있지만, 끝까지 크면 최솟값 근처에서 계속 흔들립니다. 그래서 처음엔 크게, 갈수록 작게 하는 감쇠 스케줄이나 문제 5.6과 같은 동적 조정을 씁니다. 책 127쪽처럼 층마다 다른 학습률 $\eta_1$, $\eta_2$를 줄 수도 있습니다.

실제로 확인해 보았습니다. 문제 5.5와 같은 설정(수박 데이터 세트 3.0, 은닉 뉴런 10개, 표준 BP, 가중치와 임곗값을 $(0,1)$ 균등분포로 초기화)에서 $\eta$만 바꿔 1000 에포크씩, 시드 0~9로 10번 돌린 결과의 중앙값입니다($E$는 식 5.16의 누적 오차).

| $\eta$ | 10 에포크 후 $E$ | 100 에포크 후 $E$ | 1000 에포크 후 $E$ |
|---|---|---|---|
| 0.001 | 0.2606 | 0.2603 | 0.25263 |
| 0.01 | 0.2603 | 0.2526 | 0.11525 |
| 0.1 | 0.2528 | 0.1148 | 0.01995 |
| 1 | 0.1396 | 0.0237 | 0.00010 |
| 10 | 0.2500 | 0.2353 | 0.02934 |
| 50 | 0.2353 | 0.2353 | 0.23529 |

$\eta=0.001$은 1000 에포크 동안 거의 움직이지 않았고, 이 작은 데이터에서는 $\eta=1$이 가장 빨랐습니다. $\eta=50$에서는 10번 모두 모든 샘플의 출력이 정확히 0 또는 1로 포화되어(전부 "아니오"나 전부 "예"로 예측) 오차가 $0.5\times 8/17\approx0.2353$ 또는 $0.5\times 9/17\approx0.2647$에서 멈췄습니다. $\eta=10$에서도 10번 중 3번이 같은 식으로 포화되었고, 4번은 샘플 하나만 포화된 채 틀려 $E\approx0.5/17\approx0.0294$에서 멈췄습니다. 학습률이 너무 크면 "진동"보다 먼저 "포화로 인한 학습 정지"가 나타날 수 있다는 점을 보여 줍니다.

## 문제 5.5

> 표준 BP 알고리즘과 누적 BP 알고리즘에 대한 코드를 작성하고, 수박 데이터 세트 3.0상에서 각각 두 알고리즘을 이용하여 단일 은닉층 신경망을 훈련시켜 비교해 보아라.

**풀이**

**구현.** 그림 5.8의 알고리즘과 식 5.10~5.15를 그대로 옮겼습니다. 표준 BP는 샘플 하나마다 갱신하고, 누적 BP는 식 5.16의 누적 오차 $E=\frac1m\sum_k E_k$의 기울기, 즉 샘플별 갱신량의 평균으로 한 에포크에 한 번만 갱신합니다.

```python
import numpy as np
from wm3 import load

sig = lambda z: 1 / (1 + np.exp(-z))

def init(d, q, l, rng):          # 그림 5.8 1행: (0,1) 균등분포로 초기화
    return [rng.random((d, q)), rng.random(q), rng.random((q, l)), rng.random(l)]

def forward(P, X):
    V, g, W, t = P
    B = sig(X @ V - g)            # 은닉층 출력 b_h
    Yh = sig(B @ W - t)           # 식 5.3
    return B, Yh

def grads(P, X, Y):
    V, g, W, t = P
    B, Yh = forward(P, X)
    G = Yh * (1 - Yh) * (Y - Yh)  # 식 5.10
    Eh = B * (1 - B) * (G @ W.T)  # 식 5.15
    # 식 5.11~5.14 (여러 샘플이면 합산)
    return [X.T @ Eh, -Eh.sum(0), B.T @ G, -G.sum(0)]

def loss(P, X, Y):
    return 0.5 * ((forward(P, X)[1] - Y) ** 2).sum(1).mean()   # 식 5.16

def train(X, Y, q, eta, epochs, mode, seed):
    rng = np.random.default_rng(seed)
    P = init(X.shape[1], q, Y.shape[1], rng)
    hist = []
    for ep in range(epochs):
        if mode == "standard":                     # 샘플 하나마다 갱신
            for k in rng.permutation(len(X)):
                dP = grads(P, X[k:k+1], Y[k:k+1])
                P = [p + eta * d for p, d in zip(P, dP)]
        else:                                      # 누적 BP: 한 에포크에 한 번 갱신
            dP = grads(P, X, Y)
            P = [p + eta * d / len(X) for p, d in zip(P, dP)]
        hist.append(loss(P, X, Y))
    return P, np.array(hist)

if __name__ == "__main__":
    X, y = load(); Y = y[:, None]                  # 입력 19차원, 출력 1개
    for mode, eta in [("standard", 0.1), ("accumulated", 0.1), ("accumulated", 1.7)]:
        for seed in range(10):
            P, h = train(X, Y, q=10, eta=eta, epochs=20000, mode=mode, seed=seed)
            reach = [int(np.argmax(h < t)) + 1 if (h < t).any() else None for t in (0.1, 0.05, 0.01)]
            acc = ((forward(P, X)[1][:, 0] > 0.5) == y).mean()
            print(mode, eta, seed, reach, h[-1], acc)
```

수치 미분과 비교해 `grads`가 $-\partial(\sum_k E_k)/\partial(\cdot)$와 일치하는 것을 확인했습니다.

**결과.** 은닉 뉴런 $q=10$, 최대 20000 에포크, 시드 0~9로 10번 돌렸습니다. 에포크 수는 누적 오차 $E$가 처음으로 기준 아래로 내려간 에포크이고 10번의 중앙값입니다. 정확도는 훈련 세트 정확도의 평균입니다.

| 방법 | $\eta$ | $E<0.1$ | $E<0.05$ | $E<0.01$ | 20000 에포크 후 $E$ (중앙값) | 훈련 정확도 |
|---|---|---|---|---|---|---|
| 표준 BP | 0.1 | 124.5 | 204 | 1450 | 0.00004 | 1.000 |
| 누적 BP | 0.1 | 2161.5 | 3572 | 10번 중 2번만 도달 | 0.01654 | 0.953 |
| 누적 BP | 1.7 | 130 | 212.5 | 1415 | 0.00005 | 1.000 |

관찰한 점은 다음과 같습니다.

1. **같은 $\eta=0.1$이면 에포크 기준으로 표준 BP가 훨씬 빠릅니다.** $E<0.05$까지 표준 BP는 약 200 에포크, 누적 BP는 약 3600 에포크가 걸렸습니다. 누적 BP는 20000 에포크 뒤에도 10번 중 7번이 샘플 1~2개를 틀린 상태로 남았습니다.
2. **그러나 "파라미터 갱신 횟수"로 세면 비슷합니다.** 표준 BP는 에포크당 17번 갱신하므로 $E<0.1$까지 약 $124.5\times17\approx2100$번, 누적 BP는 약 2160번 갱신했습니다. 누적 BP의 한 번 갱신량은 샘플별 갱신량의 평균이라, $\eta$가 작을 때는 표준 BP가 한 에포크 동안 움직이는 거리의 대략 $1/m$만 움직입니다.
3. **그래서 누적 BP의 학습률을 $m$배 정도($0.1\times17=1.7$) 키우면 두 방법이 거의 같아집니다.** 같은 시드끼리 비교하면 $E<0.1$, $E<0.05$ 도달 에포크가 10번 모두 5% 이내로 비슷했습니다(예: 시드 0에서 표준 BP 158/242, 누적 BP 164/250). $E<0.01$은 대부분 비슷했지만 시드 9처럼 3392 대 2245로 벌어진 경우도 있었습니다. 샘플이 17개뿐이고 학습률이 작아서, 한 에포크 동안 샘플 단위로 조금씩 움직인 결과가 평균 기울기로 한 번에 움직인 결과와 거의 같기 때문입니다.

책 129쪽의 설명처럼 표준 BP는 갱신이 잦아 빨리 내려가지만 샘플마다 방향이 달라 서로 상쇄되기도 하고, 누적 BP는 갱신 빈도가 낮습니다. 이 실험에서 같은 학습률일 때의 차이는 대부분 "에포크당 갱신 횟수와 이동량" 차이로 설명되었습니다. 훈련 세트가 크고 비슷한 샘플이 많을수록 표준 BP는 한 에포크 안에서도 여러 번 의미 있는 갱신을 하므로 장점이 커지는데, 17개짜리 데이터에서는 그 효과를 보기 어렵습니다.

## 문제 5.6

> BP 개선 알고리즘을 만들고, 학습률의 동적 조정을 통해 수렴 속도를 높일 수 있도록 하라. 해당 알고리즘에 대한 코드를 작성하고, UCI 데이터 세트에서 두 개의 데이터 세트를 골라 표준 BP 알고리즘과 비교해 보아라.

**풀이**

**알고리즘.** 표준 BP는 그대로 두고, 에포크가 끝날 때마다 누적 오차 $E$를 보고 학습률을 조정합니다. "bold driver"라고 불리는 고전적인 방식입니다(Vogl et al., 1988; Battiti, 1989).

1. 한 에포크 동안 표준 BP로 갱신한 뒤 훈련 세트의 누적 오차 $E^{(t)}$를 계산합니다.
2. $E^{(t)}<E^{(t-1)}$이면 갱신을 받아들이고 $\eta\leftarrow 1.05\,\eta$로 조금 키웁니다.
3. 그렇지 않으면 이번 에포크의 갱신을 버리고 이전 파라미터로 되돌린 뒤 $\eta\leftarrow 0.5\,\eta$로 크게 줄입니다.

오차가 잘 내려가는 동안은 학습률을 키워 가속하고, 너무 크게 움직여 오차가 오르면 즉시 되돌리고 보폭을 줄이는 원리입니다.

**데이터.** 인터넷 다운로드 없이 재현할 수 있도록, 원래 UCI 저장소에 있는 데이터 중 scikit-learn에 내장된 두 개로 대체했습니다.

- iris(붓꽃): 150개 샘플, 속성 4개, 3클래스 → 출력 뉴런 3개(원-핫)
- breast cancer(위스콘신 유방암 진단): 569개 샘플, 속성 30개, 2클래스 → 출력 뉴런 2개

각각 7:3으로 층화 분할(`random_state=0`)하고 훈련 세트 기준으로 표준화했습니다. 은닉 뉴런 10개, 초기 학습률 0.1, 300 에포크이고, 네트워크와 기울기 계산은 문제 5.5의 `init`, `forward`, `grads`, `loss`를 그대로 씁니다.

```python
import numpy as np
from sklearn.datasets import load_iris, load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from ex5_5 import init, forward, grads, loss          # 문제 5.5의 함수

def train(X, Y, q, eta, epochs, adaptive, seed, up=1.05, down=0.5):
    rng = np.random.default_rng(seed)
    P = init(X.shape[1], q, Y.shape[1], rng)
    E_prev, hist = loss(P, X, Y), []
    for ep in range(epochs):
        P_old = [p.copy() for p in P]
        for k in rng.permutation(len(X)):              # 표준 BP와 같은 샘플 단위 갱신
            dP = grads(P, X[k:k+1], Y[k:k+1])
            P = [p + eta * d for p, d in zip(P, dP)]
        E = loss(P, X, Y)
        if adaptive:                                    # 에포크마다 학습률 조정
            if E < E_prev:
                eta *= up                               # 오차가 줄면 조금 키운다
            else:
                eta *= down; P, E = P_old, E_prev       # 늘면 되돌리고 크게 줄인다
        E_prev = E; hist.append(E)
    return P, np.array(hist), eta

def run(name, X, y, epochs=300):
    Y = np.eye(y.max() + 1)[y]                          # 출력 뉴런 l = 클래스 수
    Xtr, Xte, Ytr, Yte = train_test_split(X, Y, test_size=0.3, stratify=y, random_state=0)
    sc = StandardScaler().fit(Xtr); Xtr, Xte = sc.transform(Xtr), sc.transform(Xte)
    for adaptive in (False, True):
        R = []
        for seed in range(10):
            P, h, eta = train(Xtr, Ytr, 10, 0.1, epochs, adaptive, seed)
            acc = (forward(P, Xte)[1].argmax(1) == Yte.argmax(1)).mean()
            reach = [np.argmax(h < t) + 1 if (h < t).any() else np.nan for t in (0.05, 0.02, 0.01)]
            R.append(reach + [h[49], h[-1], acc])
        R = np.array(R)
        print(name, "adaptive" if adaptive else "standard", np.nanmedian(R[:, :5], 0).round(4),
              "reached", (~np.isnan(R[:, :3])).sum(0), "acc", R[:, 5].mean().round(3))

run("iris", *load_iris(return_X_y=True))
run("breast_cancer", *load_breast_cancer(return_X_y=True))
```

**결과.** 시드 0~9로 10번 돌린 중앙값입니다. 에포크 수는 훈련 세트 누적 오차가 기준 아래로 처음 내려간 에포크, 정확도는 테스트 세트 정확도의 평균입니다.

| 데이터 | 방법 | $E<0.05$ | $E<0.02$ | $E<0.01$ | 50 에포크 후 $E$ | 300 에포크 후 $E$ | 테스트 정확도 |
|---|---|---|---|---|---|---|---|
| iris | 표준 BP | 49.5 | 198.5 | 도달 못 함 | 0.0488 | 0.0185 | 0.996 |
| iris | 동적 학습률 | 26.5 | 218 | 도달 못 함 | 0.0276 | 0.0193 | 0.998 |
| breast cancer | 표준 BP | 6 | 10 | 24 | 0.0070 | 0.0051 | 0.958 |
| breast cancer | 동적 학습률 | 5.5 | 8.5 | 16 | 0.0057 | 0.0025 | 0.957 |

- **초반 수렴은 확실히 빨라졌습니다.** iris에서 $E<0.05$까지의 에포크가 49.5에서 26.5로 약 절반이 되었고, breast cancer에서 $E<0.01$까지가 24에서 16 에포크로 줄었습니다. 300 에포크 뒤의 오차도 breast cancer에서는 절반 정도입니다.
- **후반에는 이득이 사라지기도 합니다.** iris에서 $E<0.02$ 도달은 오히려 조금 늦었고 300 에포크 뒤 오차도 비슷합니다. 표준 BP는 샘플 순서에 따라 에포크 오차가 조금씩 오르내리는데, 이 방식은 오차가 한 번 오를 때마다 학습률을 절반으로 줄이기 때문에 최솟값 근처에서는 학습률이 계속 작아집니다. iris의 누적 오차가 0.018 근처에서 더 내려가지 않는 것은 두 방법 모두 훈련 샘플 2개를 끝까지 틀리기 때문입니다(시드 0~2에서 확인).
- **테스트 정확도는 거의 같습니다.** 학습률 조정은 같은 곳에 더 빨리 가게 해 줄 뿐, 일반화 성능 자체를 바꾸지는 않았습니다.

이 외에도 학습률을 동적으로 다루는 방법은 많습니다. 파라미터마다 따로 학습률을 두는 delta-bar-delta(Jacobs, 1988), 이전 갱신 방향을 섞는 모멘텀, 기울기 크기의 이동 평균으로 학습률을 나누는 AdaGrad, RMSProp, Adam 등이 대표적입니다.

## 문제 5.7

> 식 5.18과 5.19에 기반하여 이역(异域) 문제를 해결하는 단층 RBF 신경망을 만들어라.

**풀이**

이역 문제는 XOR 문제입니다(책의 역주). 훈련 세트는 $(0,0)\to0$, $(0,1)\to1$, $(1,0)\to1$, $(1,1)\to0$의 4개 샘플입니다.

**모델.** 식 5.18과 5.19 그대로

$$
\varphi(\boldsymbol{x})=\sum_{i=1}^{q}w_i\,\rho(\boldsymbol{x},\boldsymbol{c}_i),\qquad
\rho(\boldsymbol{x},\boldsymbol{c}_i)=e^{-\beta_i\lVert\boldsymbol{x}-\boldsymbol{c}_i\rVert^2}.
$$

**훈련.** 133쪽의 두 단계를 따릅니다.

1. 중심 $\boldsymbol{c}_i$를 정합니다. 샘플이 4개뿐이므로 4개 샘플을 모두 중심으로 씁니다($q=4$).
2. 오차 역전파(경사하강법)로 $w_i$와 $\beta_i$를 학습합니다. 오차를 $E=\frac12\sum_k(\varphi(\boldsymbol{x}_k)-y_k)^2$로 두고 $\rho_{ki}=\rho(\boldsymbol{x}_k,\boldsymbol{c}_i)$라 하면

$$
\frac{\partial E}{\partial w_i}=\sum_k(\varphi(\boldsymbol{x}_k)-y_k)\,\rho_{ki},\qquad
\frac{\partial E}{\partial \beta_i}=-\sum_k(\varphi(\boldsymbol{x}_k)-y_k)\,w_i\,\rho_{ki}\,\lVert\boldsymbol{x}_k-\boldsymbol{c}_i\rVert^2 .
$$

두 번째 식은 $\dfrac{\partial\rho_{ki}}{\partial\beta_i}=-\lVert\boldsymbol{x}_k-\boldsymbol{c}_i\rVert^2\rho_{ki}$에서 나옵니다.

```python
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float)
y = np.array([0, 1, 1, 0], float)                  # XOR

def rbf(X, C, beta):                               # 식 5.19: rho_i(x) = exp(-beta_i ||x - c_i||^2)
    D2 = ((X[:, None, :] - C[None, :, :]) ** 2).sum(2)
    return np.exp(-beta * D2), D2

def train(X, y, C, eta=0.1, epochs=2000, seed=0):
    rng = np.random.default_rng(seed)
    w = rng.random(len(C)); beta = np.ones(len(C))
    for ep in range(epochs):                       # 2단계: 오차 역전파로 w_i, beta_i 학습
        R, D2 = rbf(X, C, beta)
        err = R @ w - y                            # 식 5.18의 출력 phi(x)와 정답의 차이
        gw = R.T @ err                             # dE/dw_i
        gb = -((err[:, None] * R * D2) * w).sum(0) # dE/dbeta_i
        w -= eta * gw; beta -= eta * gb
    E = 0.5 * ((rbf(X, C, beta)[0] @ w - y) ** 2).sum()
    return w, beta, E

C = X.copy()                                       # 1단계: 중심 = 훈련 샘플 4개
w, beta, E = train(X, y, C)
out = rbf(X, C, beta)[0] @ w
print("w =", w.round(4)); print("beta =", beta.round(4)); print("E =", E)
print("phi(x) =", out.round(4), "-> 예측", (out > 0.5).astype(int))
```

**결과**(시드 0, $\eta=0.1$, 2000 에포크, $w_i$는 $(0,1)$ 균등분포, $\beta_i=1$로 초기화):

```
w = [-0.4781  1.278   1.2805 -0.4496]
beta = [0.9286 1.5966 1.5739 1.1381]
E = 3.300658738690845e-30
phi(x) = [0. 1. 1. 0.] -> 예측 [0 1 1 0]
```

네 점의 출력이 정답과 일치하고 오차는 부동소수점 오차 수준까지 내려갔습니다. 학습된 가중치를 보면 양성 샘플 $(0,1)$, $(1,0)$에 놓인 중심의 가중치는 양수(약 1.28), 음성 샘플 $(0,0)$, $(1,1)$에 놓인 중심의 가중치는 음수(약 $-0.46$)입니다. 각 가우스 "봉우리"가 자기 근처를 정답 쪽으로 끌어올리거나 내리는 구조입니다.

XOR이 선형 분리 불가능한데도 풀리는 이유는, 은닉층의 방사 함수가 입력을 $(\rho_1,\dots,\rho_q)$라는 새 공간으로 비선형 변환하고, 그 공간에서는 출력층의 선형 결합만으로 충분하기 때문입니다. 모든 $\beta_i$가 같은 양수일 때, 서로 다른 점을 중심으로 하는 가우스 함수의 행렬 $[\rho_{ki}]$는 양의 정부호라서 가역입니다. 따라서 중심을 샘플 수만큼 두면 $w_i$만 풀어도 어떤 레이블이든 정확히 보간할 수 있습니다. 참고로 중심이 꼭 4개일 필요는 없습니다. 양성 샘플 $(0,1)$, $(1,0)$ 두 곳에만 중심을 두고 같은 코드를 20000 에포크 돌렸더니 $w\approx(1,1)$, $\beta\approx(4.84,4.84)$, $E\approx0.0003$으로 역시 네 점을 모두 맞혔습니다.

## 문제 5.8

> SOM 신경망에 대한 코드를 작성하고, 수박 데이터 세트 3.0$\alpha$상에서의 결과를 관찰하라.

**풀이**

수박 데이터 세트 3.0$\alpha$(표 4.5)는 표 4.3에서 밀도와 당도만 남긴 2차원 데이터이므로, 앞의 `wm3.py`에서 마지막 두 열을 씁니다. SOM은 비지도 학습이므로 레이블은 훈련에 쓰지 않고, 훈련이 끝난 뒤 결과를 해석할 때만 겹쳐 봅니다.

**알고리즘**(135쪽). 출력층은 $4\times4$ 격자의 뉴런 16개이고 각 뉴런은 입력과 같은 2차원 가중치 벡터 $\boldsymbol{w}_u$를 가집니다. 샘플 $\boldsymbol{x}$가 들어오면

1. 가중치가 가장 가까운 뉴런을 최적 매칭 유닛(BMU) $u^*$로 고릅니다.
2. 격자 위 거리 기준의 이웃 함수 $h_u=\exp\!\big(-\lVert\boldsymbol{r}_u-\boldsymbol{r}_{u^*}\rVert^2/2\sigma^2\big)$로 BMU와 이웃의 가중치를 샘플 쪽으로 당깁니다: $\boldsymbol{w}_u\leftarrow\boldsymbol{w}_u+\eta\,h_u(\boldsymbol{x}-\boldsymbol{w}_u)$.
3. 학습률 $\eta$와 이웃 반경 $\sigma$는 훈련이 진행될수록 줄입니다.

```python
import numpy as np
from wm3 import load
X, y = load(); X = X[:, -2:]                         # 수박 데이터 세트 3.0α: 밀도, 당도

def som(X, rows=4, cols=4, epochs=200, eta0=0.5, sigma0=1.5, seed=0):
    rng = np.random.default_rng(seed)
    grid = np.array([(i, j) for i in range(rows) for j in range(cols)], float)
    W = rng.uniform(X.min(0), X.max(0), (rows * cols, X.shape[1]))   # 출력 뉴런 가중치
    T = epochs * len(X); t = 0
    for ep in range(epochs):
        for k in rng.permutation(len(X)):
            frac = t / T
            eta, sigma = eta0 * (1 - frac), sigma0 * (1 - frac) + 0.3
            bmu = np.argmin(((W - X[k]) ** 2).sum(1))               # 최적 매칭 유닛
            h = np.exp(-((grid - grid[bmu]) ** 2).sum(1) / (2 * sigma ** 2))  # 이웃 함수
            W += eta * h[:, None] * (X[k] - W)                       # BMU와 이웃을 샘플 쪽으로
            t += 1
    return W, grid

W, grid = som(X)
bmu = np.array([np.argmin(((W - x) ** 2).sum(1)) for x in X])
qe = np.mean(np.sqrt(((X - W[bmu]) ** 2).sum(1)))                  # 양자화 오차
for i in range(4):
    print(" ".join(("".join("+" if y[k] else "-" for k in np.where(bmu == i * 4 + j)[0]) or ".").ljust(5) for j in range(4)))
print("quantization error =", qe.round(4))
```

**결과**(시드 0, 200 에포크, $\eta$는 0.5에서 0으로, $\sigma$는 1.8에서 0.3으로 선형 감소). 훈련된 16개 뉴런의 가중치(밀도, 당도)를 격자 모양 그대로 적으면 다음과 같습니다.

```
(0.31,0.32)  (0.39,0.24)  (0.35,0.11)  (0.26,0.07)
(0.42,0.29)  (0.44,0.21)  (0.47,0.15)  (0.43,0.09)
(0.62,0.32)  (0.56,0.23)  (0.59,0.16)  (0.61,0.06)
(0.73,0.41)  (0.64,0.27)  (0.65,0.18)  (0.69,0.10)
```

각 샘플이 어느 뉴런에 매핑되었는지 레이블을 겹쳐 보면(`+`는 잘 익은 수박, `-`는 아닌 수박, `.`은 매핑된 샘플 없음, 괄호는 표 4.5의 번호) 다음과 같습니다. 양자화 오차(샘플과 BMU 가중치 사이 거리의 평균)는 0.0296입니다.

```
-- (10,15)   +  (6)     -  (12)    -  (11)
.            +  (8)     +  (7)     .
+  (4)       +  (5)     .          -  (16)
++ (1,2)     +  (3)     -- (13,14) -- (9,17)
```

관찰한 내용은 다음과 같습니다.

1. **위상 구조가 보존되었습니다.** 격자의 아래쪽으로 갈수록 밀도가 커지고(0.26~0.47 → 0.56~0.73), 오른쪽으로 갈수록 당도가 작아집니다(0.29~0.41 → 0.06~0.10). 2차원 입력 공간이 격자 위에 거의 그대로 펼쳐졌고, 이웃한 뉴런은 입력 공간에서도 가까운 영역을 담당합니다.
2. **레이블 없이도 클래스가 어느 정도 모였습니다.** 잘 익은 수박 8개는 모두 왼쪽 아래에서 가운데로 이어지는 뉴런들(가중치 기준 밀도 0.39 이상, 당도 0.15 이상)에 매핑되었습니다. 반면 당도가 낮은 오른쪽 열에는 아닌 수박만(9, 11, 16, 17), 밀도가 낮은 맨 위 행에는 6번 하나를 빼면 아닌 수박만(10, 11, 12, 15) 모였습니다.
3. **겹치는 영역도 그대로 드러납니다.** 아닌 수박 13, 14는 잘 익은 수박 3 바로 옆 뉴런에, 아닌 수박 10, 15는 잘 익은 수박 6 바로 옆 뉴런에 매핑되었습니다. 밀도와 당도 두 속성만으로는 두 클래스가 깔끔하게 나뉘지 않는다는 뜻이고, 4장에서 3.0$\alpha$로 만든 의사결정 트리(그림 4.10)가 여러 번 분할해야 했던 것과 같은 현상입니다.

SOM은 클러스터 개수를 따로 정하지 않고도 데이터의 분포와 이웃 관계를 저차원 격자로 요약해 준다는 점을 확인할 수 있습니다. 격자 크기, 에포크, $\eta$와 $\sigma$의 감소 방식에 따라 격자 위의 위치(뒤집히거나 회전한 배치)는 달라질 수 있지만, 위의 위상 보존 성질은 유지됩니다.

## 문제 5.9\* (심화)

> 엘만 신경망에 사용되는 BP 알고리즘을 유도하라.

**풀이**

**네트워크 정의.** 그림 5.13처럼 은닉층 출력이 다음 시점의 입력으로 되돌아갑니다. 시점 $t=1,\dots,T$의 입력 $\boldsymbol{x}(t)\in\mathbb{R}^d$, 정답 $\boldsymbol{y}(t)\in\mathbb{R}^l$에 대해 기호를 5.3절에 맞추고, 되먹임 가중치 $u_{h'h}$(시점 $t-1$의 은닉 뉴런 $h'$에서 시점 $t$의 은닉 뉴런 $h$로)를 추가합니다.

$$
\begin{aligned}
\alpha_h(t)&=\sum_{i=1}^{d}v_{ih}x_i(t)+\sum_{h'=1}^{q}u_{h'h}\,b_{h'}(t-1), & b_h(t)&=f\big(\alpha_h(t)-\gamma_h\big),\\
\beta_j(t)&=\sum_{h=1}^{q}w_{hj}\,b_h(t), & \hat{y}_j(t)&=f\big(\beta_j(t)-\theta_j\big).
\end{aligned}
$$

$f$는 시그모이드, $\boldsymbol{b}(0)$은 정해진 초기 문맥(예: 0 또는 0.5)입니다. 오차는 시퀀스 전체에 대해

$$
E=\sum_{t=1}^{T}E(t),\qquad E(t)=\frac12\sum_{j=1}^{l}\big(\hat{y}_j(t)-y_j(t)\big)^2 .
$$

**출력층 기울기 항.** $\beta_j(t)$는 $E(t)$에만 영향을 주므로 식 5.10과 같습니다.

$$
g_j(t)=-\frac{\partial E}{\partial \beta_j(t)}=\hat{y}_j(t)\big(1-\hat{y}_j(t)\big)\big(y_j(t)-\hat{y}_j(t)\big).
$$

**은닉층 기울기 항(시간 역전파).** 다층 순방향 신경망과 다른 점은 $b_h(t)$가 두 경로로 오차에 영향을 준다는 것입니다. 하나는 같은 시점의 출력 $\beta_j(t)$, 다른 하나는 다음 시점의 은닉 입력 $\alpha_{h''}(t+1)$입니다. $e_h(t)=-\dfrac{\partial E}{\partial \alpha_h(t)}$로 정의하면(임곗값을 뺀 $\alpha_h(t)-\gamma_h$에 대한 미분과 같습니다)

$$
\frac{\partial E}{\partial b_h(t)}
=\sum_{j=1}^{l}\frac{\partial E}{\partial \beta_j(t)}w_{hj}+\sum_{h''=1}^{q}\frac{\partial E}{\partial \alpha_{h''}(t+1)}u_{hh''}
=-\sum_{j=1}^{l}w_{hj}g_j(t)-\sum_{h''=1}^{q}u_{hh''}e_{h''}(t+1),
$$

$$
e_h(t)=-\frac{\partial E}{\partial b_h(t)}\cdot f'\big(\alpha_h(t)-\gamma_h\big)
=b_h(t)\big(1-b_h(t)\big)\Big[\sum_{j=1}^{l}w_{hj}g_j(t)+\sum_{h''=1}^{q}u_{hh''}e_{h''}(t+1)\Big]
$$

입니다. 마지막 시점에는 다음 시점이 없으므로 $e_h(T+1)=0$으로 두고 $t=T,T-1,\dots,1$ 순서로 거꾸로 계산합니다. 대괄호 안의 첫 항이 식 5.15와 같은 부분이고, 둘째 항이 미래 시점에서 거슬러 온 오차입니다.

**가중치와 임곗값 갱신.** 같은 가중치가 모든 시점에서 공유되므로, 각 시점의 기여를 모두 더합니다.

$$
\begin{aligned}
\Delta w_{hj}&=\eta\sum_{t=1}^{T}g_j(t)\,b_h(t), & \Delta\theta_j&=-\eta\sum_{t=1}^{T}g_j(t),\\
\Delta v_{ih}&=\eta\sum_{t=1}^{T}e_h(t)\,x_i(t), & \Delta\gamma_h&=-\eta\sum_{t=1}^{T}e_h(t),\\
\Delta u_{h'h}&=\eta\sum_{t=1}^{T}e_h(t)\,b_{h'}(t-1). & &
\end{aligned}
$$

각 줄은 식 5.11~5.14와 같은 모양이고, 되먹임 가중치 $u_{h'h}$는 "입력이 $b_{h'}(t-1)$인 입력 가중치"처럼 갱신됩니다. 행렬로 쓰면 $\boldsymbol{e}(t)=\boldsymbol{b}(t)\odot(1-\boldsymbol{b}(t))\odot\big(\mathbf{W}\boldsymbol{g}(t)+\mathbf{U}\boldsymbol{e}(t+1)\big)$, $\Delta\mathbf{U}=\eta\sum_t\boldsymbol{b}(t-1)\boldsymbol{e}(t)^{\mathrm{T}}$입니다. 이 방식을 시간 역전파(backpropagation through time, BPTT)라고 부릅니다. 작은 네트워크($d=3$, $q=4$, $l=2$, $T=6$)를 무작위로 만들어 위 식으로 구한 기울기를 수치 미분과 비교했더니 모든 파라미터에서 일곱 자리 이상 일치했습니다.

**엘만의 원래 훈련 방식(절단된 BP).** 엘만(1990)은 문맥 유닛 $\boldsymbol{b}(t-1)$을 "그 시점에 주어진 고정 입력"으로 보고, 시점마다 일반 BP를 한 번씩 수행했습니다. 위 식에서 $\mathbf{U}\boldsymbol{e}(t+1)$ 항을 버리고 매 시점 바로 갱신하는 것과 같습니다.

$$
e_h(t)=b_h(t)\big(1-b_h(t)\big)\sum_{j=1}^{l}w_{hj}g_j(t),\qquad
\Delta u_{h'h}=\eta\,e_h(t)\,b_{h'}(t-1),
$$

나머지는 식 5.11~5.14와 같습니다. 계산이 간단하고 온라인 학습이 가능하지만, 한 시점 이전까지만 오차를 전달하므로 정확한 기울기가 아닌 근사입니다. 거꾸로 전달하는 시점 수를 $\tau$개로 제한하는 절단 BPTT는 두 방식의 중간입니다.

마지막으로, BPTT에서는 $e(t)$를 구할 때 $\mathbf{U}$와 $f'\le\frac14$가 시점마다 곱해지므로, 먼 과거로 갈수록 오차가 기하급수적으로 작아지거나(기울기 소실) 커질(기울기 폭주) 수 있습니다. 긴 시퀀스에서 엘만 신경망 훈련이 어려운 이유이고, 이후 LSTM 같은 구조가 나온 배경입니다.

## 문제 5.10

> 합성곱 신경망에 대한 코드를 작성하고, MNIST 데이터를 사용해 학습을 진행하라.

**풀이**

**데이터 대체.** 인터넷 다운로드 없이 재현할 수 있도록 MNIST($28\times28$, 7만 장) 대신 scikit-learn에 내장된 손글씨 숫자 데이터 `load_digits`($8\times8$, 회색조 0~16, 1797장, 10클래스)를 썼습니다. 이미지가 작아서 그림 5.15의 LeNet-5보다 훨씬 작은 네트워크를 만들었고, 실행 환경에 딥러닝 프레임워크가 없어 순전파와 역전파를 모두 numpy로 직접 구현했습니다. 7:3으로 층화 분할(`random_state=0`)하여 훈련 1257장, 테스트 540장입니다.

**구조.** 141쪽 설명처럼 합성곱 레이어, 풀링 레이어, 연결층을 차례로 둡니다. 활성화 함수는 141쪽 날개 설명의 ReLU를 썼습니다.

| 층 | 내용 | 출력 크기 |
|---|---|---|
| 입력 | $8\times8$ 이미지 | $1@8\times8$ |
| 합성곱 | $3\times3$ 필터 8개, 가중치 공유, ReLU | $8@6\times6$ |
| 풀링 | $2\times2$ 최대 풀링 | $8@3\times3$ |
| 연결층(출력) | 72 → 10, 소프트맥스 | 10 |

파라미터는 합성곱 $8\times9+8=80$개, 연결층 $72\times10+10=730$개로 모두 810개입니다. 필터 하나를 이미지의 모든 위치에서 공유하므로(가중치 공유) 합성곱 층의 파라미터가 매우 적습니다. 손실은 교차 엔트로피, 최적화는 미니배치 32의 확률적 경사하강법(학습률 0.1)입니다.

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

X, y = load_digits(return_X_y=True)                   # 8x8 손글씨 숫자 1797장 (MNIST 대체)
X = X.reshape(-1, 8, 8) / 16.0
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
rng = np.random.default_rng(0)
F, K = 8, 3                                           # 필터 8개, 3x3 커널
P = {"Wc": rng.normal(0, 0.3, (F, K * K)), "bc": np.zeros(F),
     "Wf": rng.normal(0, 0.1, (F * 3 * 3, 10)), "bf": np.zeros(10)}

def im2col(X):                                        # (N,8,8) -> (N,36,9): 3x3 패치 펼치기
    return np.stack([X[:, i:i+K, j:j+K].reshape(len(X), -1)
                     for i in range(8 - K + 1) for j in range(8 - K + 1)], 1)

def forward(X):
    cols = im2col(X)                                  # 합성곱: 모든 위치에서 같은 가중치 공유
    Z = cols @ P["Wc"].T + P["bc"]                    # (N,36,F)
    A = np.maximum(Z, 0).reshape(-1, 6, 6, F)         # ReLU
    Ab = A.reshape(-1, 3, 2, 3, 2, F)
    M = Ab.max((2, 4))                                # 2x2 최대 풀링 -> (N,3,3,F)
    logits = M.reshape(len(X), -1) @ P["Wf"] + P["bf"]
    return cols, Z, Ab, M, logits

def step(X, y, lr):
    cols, Z, Ab, M, logits = forward(X)
    p = np.exp(logits - logits.max(1, keepdims=True)); p /= p.sum(1, keepdims=True)
    N = len(X); d = p.copy(); d[np.arange(N), y] -= 1; d /= N          # softmax + 교차 엔트로피
    g = {"Wf": M.reshape(N, -1).T @ d, "bf": d.sum(0)}
    dM = (d @ P["Wf"].T).reshape(M.shape)
    win = Ab.transpose(0, 1, 3, 5, 2, 4).reshape(N, 3, 3, F, 4)     # 풀링 창별 4칸
    mask = np.eye(4)[win.argmax(-1)] * dM[..., None]  # 최댓값 한 칸으로만 기울기 전달
    dA = mask.reshape(N, 3, 3, F, 2, 2).transpose(0, 1, 4, 2, 5, 3)
    dZ = dA.reshape(N, 36, F) * (Z > 0)
    g["Wc"] = np.einsum("npf,npk->fk", dZ, cols); g["bc"] = dZ.sum((0, 1))
    for k in P: P[k] -= lr * g[k]
    return -np.log(p[np.arange(N), y]).mean()

for ep in range(30):
    idx = rng.permutation(len(Xtr)); L = []
    for b in range(0, len(idx), 32):
        L.append(step(Xtr[idx[b:b+32]], ytr[idx[b:b+32]], lr=0.1))
    if ep % 5 == 4:
        acc = (forward(Xte)[-1].argmax(1) == yte).mean()
        print(f"epoch {ep+1:2d}  train loss {np.mean(L):.4f}  test acc {acc:.4f}")
```

역전파에서 손이 가는 부분은 두 곳입니다. 최대 풀링은 창 안의 최댓값 위치 한 칸으로만 기울기를 보내고, 합성곱 가중치의 기울기는 공유된 필터가 쓰인 36개 위치의 기울기를 모두 더한 값입니다(`einsum`). 수치 미분과 비교해 네 종류 파라미터의 기울기가 모두 일치하는 것을 확인했습니다. 풀링 창 안에 같은 최댓값이 여럿일 때(배경이 0인 패치에서 자주 생깁니다) 모든 칸에 기울기를 보내면 기울기가 어긋나므로, `argmax`로 한 칸만 고릅니다.
