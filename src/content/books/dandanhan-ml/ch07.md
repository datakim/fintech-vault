## 문제 7.1

> 최대 우도법으로 수박 데이터 세트 3.0에서 앞 3개 속성의 클래스 조건 확률을 구하라.

**풀이**

앞 3개 속성은 표 4.3의 색깔, 꼭지 모양, 소리입니다. 셋 다 이산 속성이므로, 클래스 $c$가 주어졌을 때 속성 $i$의 분포를 범주형(categorical) 분포로 놓고 그 파라미터를 최대 우도로 추정합니다.

**최대 우도 추정량 유도.** 클래스 $c$의 샘플 집합 $D_c$에서 속성 $i$가 값 $v$를 갖는 샘플 수를 $n_v = |D_{c,v}|$, 파라미터를 $\theta_v = P(x_i = v \mid c)$라고 두면 식 7.10의 로그 우도는 다음과 같습니다.

$$LL(\boldsymbol{\theta}) = \sum_{\boldsymbol{x} \in D_c} \log P(x_i \mid c) = \sum_{v} n_v \log \theta_v , \qquad \text{s.t. } \sum_v \theta_v = 1 .$$

라그랑주 승수 $\lambda$를 붙여 $L = \sum_v n_v \log\theta_v + \lambda\left(1 - \sum_v \theta_v\right)$를 $\theta_v$로 미분하면 $n_v / \theta_v - \lambda = 0$, 즉 $\theta_v = n_v / \lambda$입니다. 제약식 $\sum_v \theta_v = 1$에 넣으면 $\lambda = \sum_v n_v = |D_c|$이므로

$$\hat{\theta}_v = \hat{P}(x_i = v \mid c) = \frac{|D_{c,v}|}{|D_c|}$$

가 됩니다. $LL$은 $\theta$에 대해 오목 함수이므로 이 정류점이 최댓값입니다. 결국 이산 속성의 최대 우도 추정은 식 7.17의 빈도 비율과 같습니다.

**계산.** 표 4.3에서 잘 익은 수박(예)은 8개, 아니오는 9개입니다. 각 값의 개수를 세어 나누면 다음과 같습니다. (Python으로 개수를 다시 세어 확인했습니다.)

| 속성 | 값 | $P(\cdot \mid \text{예})$ | $P(\cdot \mid \text{아니오})$ |
|------|----|------------------|------------------|
| 색깔 | 청록색 | $3/8 = 0.375$ | $3/9 \approx 0.333$ |
| | 진녹색 | $4/8 = 0.500$ | $2/9 \approx 0.222$ |
| | 연녹색 | $1/8 = 0.125$ | $4/9 \approx 0.444$ |
| 꼭지 모양 | 말림 | $5/8 = 0.625$ | $3/9 \approx 0.333$ |
| | 약간 말림 | $3/8 = 0.375$ | $4/9 \approx 0.444$ |
| | 곧음 | $0/8 = 0$ | $2/9 \approx 0.222$ |
| 소리 | 혼탁 | $6/8 = 0.750$ | $4/9 \approx 0.444$ |
| | 둔탁 | $2/8 = 0.250$ | $3/9 \approx 0.333$ |
| | 맑음 | $0/8 = 0$ | $2/9 \approx 0.222$ |

각 클래스 안에서 같은 속성의 확률을 더하면 1이 되는 것도 확인할 수 있습니다. '곧음'과 '맑음'은 잘 익은 수박에서 한 번도 나오지 않아 최대 우도 추정값이 0입니다. 이 0이 곱셈 전체를 0으로 만드는 문제가 7.3절에서 라플라스 보정을 도입하는 이유이고, 문제 7.3에서 다시 다룹니다.

## 문제 7.2\* (심화)

> 다음을 증명하라. 조건독립 가설이 성립하지 않을 때 나이브 베이즈 분류기는 여전히 최적의 베이즈 분류기를 생성할 가능성이 있다.

**풀이**

"가능성이 있다"를 보이면 되므로, 조건독립 가설이 깨진 분포인데도 나이브 베이즈의 판별이 베이즈 최적 분류기와 모든 샘플에서 같아지는 예를 하나 구성하면 됩니다.

**무엇을 보여야 하는가.** 오차율(0/1 손실)을 기준으로 하면 베이즈 최적 분류기는 식 7.6입니다.

$$h^*(\boldsymbol{x}) = \arg\max_{c} P(c \mid \boldsymbol{x}) = \arg\max_{c} P(c)\,P(\boldsymbol{x} \mid c)$$

나이브 베이즈 분류기는 식 7.15입니다.

$$h_{nb}(\boldsymbol{x}) = \arg\max_{c} P(c) \prod_{i=1}^{d} P(x_i \mid c)$$

추정 오차와 섞이지 않도록 $P(c)$와 $P(x_i \mid c)$는 참값을 정확히 안다고 가정합니다. 이때 $P(\boldsymbol{x}) > 0$인 모든 $\boldsymbol{x}$에서 $h_{nb}(\boldsymbol{x}) = h^*(\boldsymbol{x})$이면 두 분류기의 기대 위험이 같으므로 나이브 베이즈는 베이즈 최적 분류기입니다. 확률값 자체가 같을 필요는 없고 **argmax만 같으면 된다**는 점이 핵심입니다.

**구성.** 이진 분류 $c \in \{+, -\}$에서 $P(+) = P(-) = 1/2$로 둡니다. 이진 속성 $x_1$의 조건부 분포를 $P(x_1 = 1 \mid +) = p$, $P(x_1 = 1 \mid -) = r$ ($0 < p, r < 1$, $p \ne r$)로 두고, 두 번째 속성은 항상 $x_2 = x_1$인 복사본이라고 합니다.

1. 조건독립 가설이 깨집니다. 예를 들어 $P(x_1 = 1, x_2 = 1 \mid +) = P(x_1 = 1 \mid +) = p$인데, 조건독립이라면 이 값은 $P(x_1 = 1 \mid +)P(x_2 = 1 \mid +) = p^2$이어야 합니다. $0 < p < 1$이므로 $p \ne p^2$입니다.

2. 확률이 0이 아닌 샘플은 $\boldsymbol{x} = (v, v)$, $v \in \{0, 1\}$뿐입니다. 이런 $\boldsymbol{x}$에 대해 $P(\boldsymbol{x} \mid c) = P(x_1 = v \mid c)$이므로
$$P(c)P(\boldsymbol{x} \mid c) = \tfrac{1}{2}\, P(x_1 = v \mid c) .$$

3. 나이브 베이즈가 쓰는 값은 $P(x_2 = v \mid c) = P(x_1 = v \mid c)$이므로
$$P(c)P(x_1 = v \mid c)P(x_2 = v \mid c) = \tfrac{1}{2}\, P(x_1 = v \mid c)^2 .$$

4. $t \mapsto t^2$은 $[0, 1]$에서 순증가 함수이므로 $P(x_1 = v \mid +) > P(x_1 = v \mid -)$와 $P(x_1 = v \mid +)^2 > P(x_1 = v \mid -)^2$는 동치입니다. 따라서 두 $\boldsymbol{x}$ 모두에서 $h_{nb}(\boldsymbol{x}) = h^*(\boldsymbol{x})$입니다.

따라서 조건독립 가설이 성립하지 않는데도 나이브 베이즈 분류기는 베이즈 최적 분류기와 같은 판별을 내리고, 같은 (최소) 오차율을 얻습니다. $\blacksquare$

**수치 예.** $p = 0.8$, $r = 0.3$이면 다음과 같습니다.

| $\boldsymbol{x}$ | 참 사후 확률 $P(+ \mid \boldsymbol{x})$ | 나이브 베이즈가 계산한 $P(+ \mid \boldsymbol{x})$ | 판별 |
|------|------|------|------|
| $(1, 1)$ | $0.4/(0.4+0.15) \approx 0.727$ | $0.32/(0.32+0.045) \approx 0.877$ | 둘 다 $+$ |
| $(0, 0)$ | $0.1/(0.1+0.35) \approx 0.222$ | $0.02/(0.02+0.245) \approx 0.075$ | 둘 다 $-$ |

나이브 베이즈는 중복된 증거를 두 번 세기 때문에 사후 확률을 과신(0.727 → 0.877)하지만, 판별은 바뀌지 않습니다.

**참고.** 이 구성에서 같은 사전 확률은 중요합니다. 예를 들어 $P(+) = 0.6$, $p = 0.4$, $r = 0.55$로 바꾸면 $\boldsymbol{x} = (1, 1)$에서 참값은 $0.6 \times 0.4 = 0.24 > 0.4 \times 0.55 = 0.22$로 $+$인데, 나이브 베이즈는 $0.6 \times 0.4^2 = 0.096 < 0.4 \times 0.55^2 = 0.121$로 $-$를 고릅니다. 즉 조건독립이 깨졌을 때 나이브 베이즈가 언제나 최적인 것은 아니고, 클래스 간 순서가 보존되는 경우에 한해 최적입니다. 7.7절에서 소개한 [Domingos and Pazzani, 1997]은 이처럼 확률값이 틀려도 순서만 맞으면 0/1 손실에서 최적일 수 있다는 점을 더 일반적인 조건으로 분석한 논문입니다.

## 문제 7.3

> 라플라스 수정 나이브 베이즈 분류기의 코드를 작성하고, 수박 데이터 세트 3.0$\alpha$를 훈련 데이터로 사용해 182쪽 '테스트1' 샘플에 대한 판별을 진행하라.

**풀이**

먼저 데이터 세트를 짚고 넘어갑니다. 수박 데이터 세트 3.0$\alpha$(표 4.5)에는 밀도와 당도 두 속성만 있는데, '테스트1' 샘플은 색깔부터 당도까지 8개 속성을 모두 가지고 있고 182쪽 본문 예제도 표 4.3의 수박 데이터 세트 3.0으로 계산합니다. 그래서 이 풀이는 **수박 데이터 세트 3.0**(표 4.3)을 훈련 데이터로 사용합니다.

**모델.** 이산 속성 6개에는 라플라스 보정(식 7.19, 7.20)을, 연속 속성인 밀도와 당도에는 정규 분포(식 7.18)를 씁니다. 라플라스 보정은 개수에 1을 더하는 것이므로 연속 속성에는 적용되지 않습니다. 정규 분포의 표준편차는 본문 예제(밀도 $\sigma = 0.129$)와 맞추기 위해 $n-1$로 나눈 표본 표준편차를 썼습니다. 또 문제 7.4에서 다루는 언더플로를 피하려고 확률을 곱하는 대신 로그를 더합니다.

```python
import numpy as np

# 수박 데이터 세트 3.0 (표 4.3)
RAW = """청록색 말림 혼탁 선명함 움푹패임 단단함 0.697 0.460 예
진녹색 말림 둔탁 선명함 움푹패임 단단함 0.774 0.376 예
진녹색 말림 혼탁 선명함 움푹패임 단단함 0.634 0.264 예
청록색 말림 둔탁 선명함 움푹패임 단단함 0.608 0.318 예
연녹색 말림 혼탁 선명함 움푹패임 단단함 0.556 0.215 예
청록색 약간말림 혼탁 선명함 약간패임 물렁함 0.403 0.237 예
진녹색 약간말림 혼탁 약간흐림 약간패임 물렁함 0.481 0.149 예
진녹색 약간말림 혼탁 선명함 약간패임 단단함 0.437 0.211 예
진녹색 약간말림 둔탁 약간흐림 약간패임 단단함 0.666 0.091 아니오
청록색 곧음 맑음 선명함 평평함 물렁함 0.243 0.267 아니오
연녹색 곧음 맑음 흐림 평평함 단단함 0.245 0.057 아니오
연녹색 말림 혼탁 흐림 평평함 단단함 0.343 0.099 아니오
청록색 약간말림 혼탁 약간흐림 움푹패임 단단함 0.639 0.161 아니오
연녹색 약간말림 둔탁 약간흐림 움푹패임 단단함 0.657 0.198 아니오
진녹색 약간말림 혼탁 선명함 약간패임 물렁함 0.360 0.370 아니오
연녹색 말림 혼탁 흐림 평평함 단단함 0.593 0.042 아니오
청록색 말림 둔탁 약간흐림 약간패임 단단함 0.719 0.103 아니오"""
DATA = [[*t[:6], float(t[6]), float(t[7]), t[8]] for t in map(str.split, RAW.splitlines())]
N_VAL = [3, 3, 3, 3, 3, 2]          # 이산 속성 6개가 취할 수 있는 값의 개수 N_i
CLASSES = ["예", "아니오"]
TEST1 = ["청록색", "말림", "혼탁", "선명함", "움푹패임", "단단함", 0.697, 0.460]

def gauss(x, mu, sd):
    return np.exp(-(x - mu) ** 2 / (2 * sd ** 2)) / (np.sqrt(2 * np.pi) * sd)

def fit(data):
    m, N, model = len(data), len(CLASSES), {}
    for c in CLASSES:
        Dc = [r for r in data if r[-1] == c]
        prior = (len(Dc) + 1) / (m + N)                                   # 식 7.19
        disc = [{v: (sum(r[j] == v for r in Dc) + 1) / (len(Dc) + N_VAL[j])  # 식 7.20
                 for v in {r[j] for r in data}} for j in range(6)]
        cont = [(np.mean([r[j] for r in Dc]), np.std([r[j] for r in Dc], ddof=1))
                for j in (6, 7)]                                          # 식 7.18
        model[c] = (prior, disc, cont)
    return model

def log_scores(model, x):
    out = {}
    for c, (prior, disc, cont) in model.items():
        s = np.log(prior) + sum(np.log(disc[j][x[j]]) for j in range(6))
        s += sum(np.log(gauss(x[6 + k], mu, sd)) for k, (mu, sd) in enumerate(cont))
        out[c] = s
    return out

model = fit(DATA)
s = log_scores(model, TEST1)
post = {c: np.exp(v - max(s.values())) for c, v in s.items()}
z = sum(post.values())
for c in CLASSES:
    print(c, f"log점수={s[c]:.3f}", f"점수={np.exp(s[c]):.3e}", f"사후확률={post[c] / z:.4f}")
print("판별:", max(s, key=s.get))
```

실행 결과는 다음과 같습니다.

```
예 log점수=-3.664 점수=2.563e-02 사후확률=0.9966
아니오 log점수=-9.335 점수=8.826e-05 사후확률=0.0034
판별: 예
```

곱에 들어간 각 항은 다음과 같습니다.

| 항 | 잘 익은 수박 = 예 | 잘 익은 수박 = 아니오 |
|----|------|------|
| $\hat{P}(c)$ | $9/19 \approx 0.474$ | $10/19 \approx 0.526$ |
| 색깔 = 청록색 | $4/11 \approx 0.364$ | $4/12 \approx 0.333$ |
| 꼭지 모양 = 말림 | $6/11 \approx 0.545$ | $4/12 \approx 0.333$ |
| 소리 = 혼탁 | $7/11 \approx 0.636$ | $5/12 \approx 0.417$ |
| 줄무늬 = 선명함 | $8/11 \approx 0.727$ | $3/12 = 0.250$ |
| 배꼽 모양 = 움푹 패임 | $6/11 \approx 0.545$ | $3/12 = 0.250$ |
| 감촉 = 단단함 | $7/10 = 0.700$ | $8/11 \approx 0.727$ |
| $p(\text{밀도} = 0.697 \mid c)$ | $\mu = 0.574,\ \sigma = 0.129 \Rightarrow 1.959$ | $\mu = 0.496,\ \sigma = 0.195 \Rightarrow 1.203$ |

$2.563 \times 10^{-2} > 8.826 \times 10^{-5}$이므로 라플라스 보정 나이브 베이즈 분류기는 '테스트1'을 **잘 익은 수박**으로 판별합니다. 클래스 사전 확률 $9/19 \approx 0.474$와 $\hat{P}_{\text{청록}\vert\text{○}} = 4/11 \approx 0.364$는 185쪽 본문 값과 일치합니다.

**본문 예제와의 대조.** 보정 없이 같은 코드를 돌려 183~184쪽 예제와 비교하면 결론(잘 익은 수박)은 같지만 숫자 몇 개가 다릅니다.

| 항목 | 책에 적힌 값 | 데이터로 다시 센 값 |
|------|------|------|
| $P_{\text{움푹 패임}\vert\text{○}}$ | $6/8 \approx 0.750$ | $5/8 = 0.625$ (1~5번만 움푹 패임) |
| $P_{\text{단단함}\vert\times}$ | $2/9 \approx 0.667$ | $7/9 \approx 0.778$ (9, 11, 12, 13, 14, 16, 17번). 12번 감촉이 '물렁함'이면 $6/9 \approx 0.667$ |
| $p_{\text{밀도}:0.697\vert\times}$ | $\mu = 0.574,\ \sigma = 0.129$로 $1.959$ | $\mu = 0.496,\ \sigma = 0.195$로 $1.203$ |
| 예 쪽 곱 | $0.063$ | $0.052$ |
| 아니오 쪽 곱 | $6.80 \times 10^{-5}$ | $8.00 \times 10^{-5}$ |

책의 곱 $0.063$은 $6/8$을, $6.80 \times 10^{-5}$은 $6/9$와 $1.203$을 넣었을 때 나오는 값이라, 아니오 쪽 밀도 항은 식 표기만 잘못 옮겨진 것으로 보이고 $2/9$도 $6/9$를 옮기다 생긴 오기로 보입니다. $6/9$는 표 4.3의 12번 샘플 감촉을 '물렁함'으로 두었을 때의 값인데, 4장 풀이(문제 4.3)에서 본 것처럼 책의 정보 이득 계산도 12번을 '물렁함'으로 두어야 맞습니다. 이 풀이의 코드는 표에 인쇄된 대로 '단단함'을 썼고, '물렁함'으로 바꿔도 판별 결과는 같습니다. 또 182쪽 표에는 '테스트1'의 밀도가 0.679로 적혀 있지만 본문 계산은 0.697을 씁니다. 이 풀이는 본문 계산을 따라 0.697을 썼고, 0.679로 바꿔도 라플라스 보정 결과는 예 $2.899 \times 10^{-2}$, 아니오 $9.667 \times 10^{-5}$로 판별이 같습니다.

## 문제 7.4

> 실전에서 식 7.15를 사용해 클래스를 분류할 때 만약 데이터의 차원수가 매우 높다면, 확률의 연속 곱 $\prod_{i=1}^{d} P(x_i \mid c)$의 결과는 0에 매우 근접해서 오버플로(overflow)가 발생할 것이다. 오버플로를 방지할 수 있는 방안을 논의하라.

**풀이**

먼저 현상을 정확히 짚으면, 1보다 작은 확률을 수백, 수천 개 곱하면 값이 부동소수점으로 표현할 수 있는 가장 작은 양수(배정밀도에서 약 $10^{-308}$, 비정규화 수까지 쳐도 약 $10^{-324}$)보다 작아져 0이 됩니다. 수치 계산 용어로는 언더플로(underflow)라고 부르는 현상이고, 문제(와 180쪽 본문)의 '오버플로'는 이것을 가리킵니다. 예를 들어 $P(x_i \mid c) \approx 0.1$인 속성이 400개만 있어도 곱은 $10^{-400}$이 되어 모든 클래스의 점수가 0이 되고, argmax를 비교할 수 없게 됩니다.

**방안 1. 로그를 취해 덧셈으로 바꾼다 (가장 표준적인 방법).** $\log$는 단조증가 함수이므로 argmax가 바뀌지 않습니다.

$$h_{nb}(\boldsymbol{x}) = \arg\max_{c \in \mathcal{Y}} \left[ \log P(c) + \sum_{i=1}^{d} \log P(x_i \mid c) \right]$$

각 항은 크기가 적당한 음수이므로 $d$가 커져도 합은 $-d$배 정도로만 커지고 언더플로가 생기지 않습니다. 180쪽에서 우도 대신 로그 우도(식 7.10)를 쓰는 것과 같은 이유입니다. 문제 7.3의 코드도 이 방식입니다.

**방안 2. 0 확률을 없앤다.** 로그를 쓰면 $\log 0 = -\infty$가 문제가 되므로 라플라스 보정(식 7.19, 7.20) 같은 평활화를 함께 써서 모든 $P(x_i \mid c) > 0$이 되도록 합니다.

**방안 3. 사후 확률 값이 필요하면 log-sum-exp로 정규화한다.** 판별만 할 때는 방안 1로 충분하지만, $P(c \mid \boldsymbol{x})$ 자체가 필요하면 로그 점수 $s_c$를 지수화해야 해서 다시 언더플로가 생길 수 있습니다. 이때는 최댓값 $s_{\max} = \max_c s_c$를 빼고 계산합니다.

$$P(c \mid \boldsymbol{x}) = \frac{\exp(s_c - s_{\max})}{\sum_{c'} \exp(s_{c'} - s_{\max})}$$

가장 큰 항이 $\exp(0) = 1$이 되므로 분모가 0이 되지 않습니다.

**그 밖의 방법.** 곱을 계산하는 중간중간 모든 클래스의 점수를 같은 상수로 나누어(혹은 합이 1이 되도록 정규화하여) 크기를 유지하는 스케일링, 이진 분류라면 비율 $\frac{P(x_i \mid +)}{P(x_i \mid -)}$들의 로그합(로그 오즈)만 계산하는 방법, 고정밀 수 표현을 쓰는 방법도 있습니다. 다만 고정밀 표현은 비용이 크고 차원이 더 커지면 같은 문제가 반복되므로, 실무에서는 방안 1~3의 조합이 기본입니다.

## 문제 7.5

> 다음을 증명하라. 이진 분류 문제에서 두 개의 클래스 데이터가 가우스 분포를 만족하고 분산이 같을 때, 선형 판별분석은 베이즈 최적 분류기를 생성한다.

**풀이**

**가정.** 클래스 $c \in \{0, 1\}$의 사전 확률을 $\pi_c$, 클래스 조건 분포를 $p(\boldsymbol{x} \mid c) = \mathcal{N}(\boldsymbol{\mu}_c, \boldsymbol{\Sigma})$라고 둡니다. 두 클래스가 같은 공분산 행렬 $\boldsymbol{\Sigma}$(양의 정부호)를 가진다는 것이 '분산이 같다'는 조건입니다. 손실은 0/1 손실로 보고, 베이즈 최적 분류기는 식 7.6의 $h^*(\boldsymbol{x}) = \arg\max_c P(c \mid \boldsymbol{x})$입니다.

**1단계: 베이즈 최적 분류기를 구한다.** $\boldsymbol{x}$를 클래스 0으로 판별하는 조건은 $\pi_0\, p(\boldsymbol{x} \mid 0) > \pi_1\, p(\boldsymbol{x} \mid 1)$이고, 로그를 취하면

$$\ln \frac{p(\boldsymbol{x} \mid 0)}{p(\boldsymbol{x} \mid 1)} > \ln\frac{\pi_1}{\pi_0}$$

입니다. 두 정규 분포의 정규화 상수 $(2\pi)^{-d/2}|\boldsymbol{\Sigma}|^{-1/2}$는 같으므로 지수 부분만 남습니다.

$$
\begin{aligned}
\ln \frac{p(\boldsymbol{x} \mid 0)}{p(\boldsymbol{x} \mid 1)}
&= -\tfrac{1}{2}(\boldsymbol{x}-\boldsymbol{\mu}_0)^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}(\boldsymbol{x}-\boldsymbol{\mu}_0) + \tfrac{1}{2}(\boldsymbol{x}-\boldsymbol{\mu}_1)^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}(\boldsymbol{x}-\boldsymbol{\mu}_1) \\
&= (\boldsymbol{\mu}_0-\boldsymbol{\mu}_1)^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\boldsymbol{x} - \tfrac{1}{2}\left(\boldsymbol{\mu}_0^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1\right) \\
&= (\boldsymbol{\mu}_0-\boldsymbol{\mu}_1)^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\left(\boldsymbol{x} - \frac{\boldsymbol{\mu}_0+\boldsymbol{\mu}_1}{2}\right) .
\end{aligned}
$$
둘째 줄에서 $\boldsymbol{x}^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\boldsymbol{x}$ 항이 서로 지워집니다(공분산이 같아서 가능한 일입니다). 셋째 줄은 $\boldsymbol{\Sigma}^{-1}$이 대칭이므로 $\boldsymbol{\mu}_0^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1 = (\boldsymbol{\mu}_0-\boldsymbol{\mu}_1)^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_0+\boldsymbol{\mu}_1)$임을 쓴 것입니다. 따라서 $\boldsymbol{w}^* = \boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$로 두면 베이즈 최적 분류기는

$$h^*(\boldsymbol{x}) = 0 \iff \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x} > \boldsymbol{w}^{*\mathrm{T}}\frac{\boldsymbol{\mu}_0+\boldsymbol{\mu}_1}{2} + \ln\frac{\pi_1}{\pi_0}$$

인 선형 분류기입니다. 결정 경계가 $\boldsymbol{x}$에 오직 $\boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x}$를 통해서만 의존한다는 점이 중요합니다.

**2단계: LDA의 투영 방향이 같음을 보인다.** LDA의 해는 식 3.39의 $\boldsymbol{w} = \mathbf{S}_w^{-1}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$입니다. 식 3.33의 집단 내 산포행렬 $\mathbf{S}_w = \sum_{\boldsymbol{x} \in X_0}(\boldsymbol{x}-\boldsymbol{\mu}_0)(\boldsymbol{x}-\boldsymbol{\mu}_0)^{\mathrm{T}} + \sum_{\boldsymbol{x} \in X_1}(\boldsymbol{x}-\boldsymbol{\mu}_1)(\boldsymbol{x}-\boldsymbol{\mu}_1)^{\mathrm{T}}$는 3.4절의 정의대로 평균을 내지 않은 합입니다. 클래스 $c$의 샘플 수를 $m_c$라고 하면 두 클래스의 공분산이 모두 $\boldsymbol{\Sigma}$이므로 각 합은 $m_c\boldsymbol{\Sigma}$에 해당하고(표본 평균을 쓰면 기댓값은 $(m_c - 1)\boldsymbol{\Sigma}$), 분포 수준에서 $\mathbf{S}_w = \alpha^{-1}\boldsymbol{\Sigma}$ 꼴입니다($\alpha^{-1} = m$ 또는 $m - 2$인 양수). 따라서

$$\boldsymbol{w} = \alpha\,\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1) = \alpha\,\boldsymbol{w}^*, \qquad \alpha > 0$$

입니다. 양의 상수배는 방향을 바꾸지 않으므로(3.4절에서 말하듯 LDA의 해는 길이와 무관합니다) LDA의 투영 방향은 베이즈 최적 경계의 법선 방향과 같습니다. 유한 표본에서도 $\mathbf{S}_w / m$은 두 클래스의 공통 공분산에 대한 합동(pooled) 최대 우도 추정량이므로, LDA는 '공통 공분산 정규 분포'를 데이터에 맞춘 뒤 1단계 공식을 적용한 것과 같은 방향을 얻습니다.

**3단계: 판별 규칙까지 같음을 보인다.** LDA는 새 샘플을 직선 위로 투영한 뒤 투영된 두 중심 $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{\mu}_0$, $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{\mu}_1$ 중 가까운 쪽으로 분류합니다. 여기서

$$\boldsymbol{w}^{\mathrm{T}}\boldsymbol{\mu}_0 - \boldsymbol{w}^{\mathrm{T}}\boldsymbol{\mu}_1 = \alpha(\boldsymbol{\mu}_0-\boldsymbol{\mu}_1)^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_0-\boldsymbol{\mu}_1) > 0$$

이므로 ($\boldsymbol{\Sigma}^{-1}$이 양의 정부호이고 $\boldsymbol{\mu}_0 \ne \boldsymbol{\mu}_1$) 클래스 0의 중심이 더 큰 쪽에 있습니다. 따라서 '가까운 중심' 규칙은 두 중심의 중점을 임계값으로 쓰는 규칙과 같습니다.

$$h_{\text{LDA}}(\boldsymbol{x}) = 0 \iff \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} > \boldsymbol{w}^{\mathrm{T}}\frac{\boldsymbol{\mu}_0+\boldsymbol{\mu}_1}{2}$$

양변을 $\alpha > 0$으로 나누면 1단계 식에서 $\ln(\pi_1/\pi_0)$ 항만 빠진 형태입니다. 두 클래스의 사전 확률이 같으면 ($\pi_0 = \pi_1$) $\ln(\pi_1/\pi_0) = 0$이 되어 두 규칙이 완전히 일치하므로, LDA는 베이즈 최적 분류기입니다. $\blacksquare$

**사전 확률이 다를 때.** 사전 확률이 다르더라도 투영 방향 $\boldsymbol{w}$는 그대로 베이즈 최적이고, 달라지는 것은 임계값뿐입니다. 투영 후 1차원 공간에서 두 클래스는 $\mathcal{N}(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{\mu}_c,\ \boldsymbol{w}^{\mathrm{T}}\boldsymbol{\Sigma}\boldsymbol{w})$로 분산이 같으므로, 임계값을 중점에서 $\alpha\ln(\pi_1/\pi_0)$만큼 옮기면 정확히 베이즈 최적 분류기가 됩니다. 결정 경계가 $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}$에만 의존하므로 1차원으로 투영하면서 잃는 정보도 없습니다. 많은 교재가 이 명제를 '사전 확률이 같을 때' 또는 '임계값을 사전 확률로 보정할 때'라는 조건과 함께 서술하는 이유입니다.

## 문제 7.6

> AODE 분류기에 대한 코드를 작성하고, 수박 데이터 세트 3.0$\alpha$를 훈련 데이터로 사용해, 182쪽 '테스트1' 샘플에 대한 판별을 진행하라.

**풀이**

문제 7.3과 같은 이유로 수박 데이터 세트 3.0(표 4.3)을 사용합니다. 구현하면서 정해야 할 것이 두 가지 있습니다.

1. **임곗값 $m'$.** 식 7.23은 $|D_{x_i}| \geqslant m'$인 속성만 상위 부모로 쓰고, 187쪽 보조 설명은 $m' = 30$을 기본값으로 소개합니다. 그런데 이 데이터는 샘플이 17개뿐이라 $m' = 30$이면 모든 속성이 빠져 두 클래스의 점수가 모두 0이 됩니다(실제로 돌려도 그렇습니다). 그래서 $m' = 0$, 즉 모든 이산 속성을 상위 부모로 씁니다.
2. **연속 속성.** 식 7.24, 7.25는 개수를 세는 식이라 이산 속성을 전제로 합니다. 기본 결과는 이산 속성 6개만으로 계산하고, 비교용으로 밀도와 당도를 $D_{c,x_i}$ 위의 정규 분포 $p(x_j \mid c, x_i)$로 넣은 결과도 함께 적습니다. 연속 속성은 상위 부모로 쓰지 않습니다.

식 7.23의 곱은 $j = 1$부터 $d$까지이므로 $j = i$인 항 $\hat{P}(x_i \mid c, x_i)$도 그대로 포함했습니다. (이 항을 빼고 계산해도 예 $0.1089$, 아니오 $0.0048$로 판별은 바뀌지 않습니다.) 아래 코드는 문제 7.3 코드의 `DATA`, `N_VAL`, `CLASSES`, `TEST1`, `gauss`를 그대로 씁니다.

```python
def aode(data, x, m_min=0, use_cont=False):
    m, N, out = len(data), len(CLASSES), {}
    for c in CLASSES:
        total = 0.0
        for i in range(6):                                   # 상위 부모 후보: 이산 속성
            if sum(r[i] == x[i] for r in data) < m_min:      # |D_{x_i}| >= m' 조건
                continue
            Dci = [r for r in data if r[-1] == c and r[i] == x[i]]
            p = (len(Dci) + 1) / (m + N * N_VAL[i])          # 식 7.24
            for j in range(6):                               # 식 7.25 (j = i 포함, 식 7.23 그대로)
                p *= (sum(r[j] == x[j] for r in Dci) + 1) / (len(Dci) + N_VAL[j])
            if use_cont:                                     # 연속 속성: D_{c,x_i} 위 정규분포
                for j in (6, 7):
                    v = [r[j] for r in Dci]
                    p *= gauss(x[j], np.mean(v), np.std(v, ddof=1))
            total += p
        out[c] = total
    return out

for use_cont in (False, True):
    s = aode(DATA, TEST1, use_cont=use_cont)
    z = sum(s.values())
    print("연속 속성 사용" if use_cont else "이산 속성만",
          {c: f"{v:.4e} ({v / z:.4f})" for c, v in s.items()}, "→", max(s, key=s.get))
print("m'=30:", aode(DATA, TEST1, m_min=30))
```

실행 결과입니다. 괄호 안은 두 점수를 합이 1이 되도록 정규화한 값입니다.

```
이산 속성만 {'예': '8.5036e-02 (0.9625)', '아니오': '3.3115e-03 (0.0375)'} → 예
연속 속성 사용 {'예': '3.5649e-01 (0.9990)', '아니오': '3.7387e-04 (0.0010)'} → 예
m'=30: {'예': 0.0, '아니오': 0.0}
```

이산 속성만 쓴 경우 각 상위 부모(SPODE) 항은 다음과 같습니다.

| 상위 부모 $x_i$ | $\lvert D_{\text{예},x_i}\rvert$ | 예 쪽 항 | $\lvert D_{\text{아니오},x_i}\rvert$ | 아니오 쪽 항 |
|------|------|------|------|------|
| 색깔 = 청록색 | 3 | $5.797 \times 10^{-3}$ | 3 | $8.588 \times 10^{-4}$ |
| 꼭지 모양 = 말림 | 5 | $1.769 \times 10^{-2}$ | 3 | $4.294 \times 10^{-4}$ |
| 소리 = 혼탁 | 6 | $6.494 \times 10^{-3}$ | 4 | $1.035 \times 10^{-3}$ |
| 줄무늬 = 선명함 | 7 | $1.870 \times 10^{-2}$ | 2 | $1.252 \times 10^{-4}$ |
| 배꼽 모양 = 움푹 패임 | 5 | $1.769 \times 10^{-2}$ | 2 | $3.757 \times 10^{-4}$ |
| 감촉 = 단단함 | 6 | $1.867 \times 10^{-2}$ | 7 | $4.876 \times 10^{-4}$ |
| 합 | | $8.504 \times 10^{-2}$ | | $3.312 \times 10^{-3}$ |

여섯 개 SPODE 모두 '예' 쪽이 더 크고, 합으로도 $8.504 \times 10^{-2} > 3.312 \times 10^{-3}$이므로 AODE는 '테스트1'을 **잘 익은 수박**으로 판별합니다. 연속 속성을 넣어도 결론은 같습니다. 코드가 계산하는 중간값 $\hat{P}(\text{예}, \text{소리} = \text{혼탁}) = (6+1)/(17+3 \times 2) \approx 0.304$와 $\hat{P}(\text{배꼽 모양} = \text{움푹 패임} \mid \text{예}, \text{혼탁}) = (3+1)/(6+3) \approx 0.444$는 188쪽 본문 예와 일치합니다.

연속 속성을 넣은 변형은 $|D_{c,x_i}|$가 2~7개뿐인 부분집합에서 평균과 표준편차를 추정하므로(예를 들어 '아니오, 줄무늬 = 선명함'은 2개) 추정이 매우 불안정합니다. 결과는 참고용으로만 보는 것이 좋습니다.

## 문제 7.7

> $d$개의 이산 속성의 이진 분류 문제에서 임의의 사전 확률 항의 계산에 대해 최소 30개의 샘플이 필요하다고 가정하면, 나이브 베이즈 분류기 식 7.15에 사전 확률 항 계산 $P(c)$는 $30 \times 2 = 60$개의 샘플이 필요하다. AODE 식 7.23에서 사전 확률 항 $P(c, \boldsymbol{x}_i)$ 계산에 필요한 샘플 수를 계산하라. (가장 좋은 상황과 나쁜 상황, 둘 다 고려하라)

**풀이**

**문제의 해석.** 나이브 베이즈의 $60$은 두 클래스 $c \in \{+, -\}$ 각각에 대해 $|D_c| \geqslant 30$이어야 한다는 계산입니다. 같은 기준을 AODE에 적용하면, 판별할 샘플 $\boldsymbol{x} = (x_1, \dots, x_d)$에 대해 식 7.23에 등장하는 사전 확률 항 $P(c, x_i)$ ($c \in \{+, -\}$, $i = 1, \dots, d$), 모두 $2d$개의 항마다

$$|D_{c, x_i}| \geqslant 30$$

이 필요합니다. 여기서 $D_{c,x_i}$는 클래스가 $c$이면서 $i$번째 속성값이 $x_i$인 샘플들의 집합입니다. 핵심은 한 샘플이 여러 항의 개수에 동시에 기여할 수 있다는 점입니다. 클래스가 $c$인 샘플은 자기 속성값이 $\boldsymbol{x}$와 일치하는 모든 $i$에 대해 $D_{c, x_i}$에 들어갑니다.

**가장 좋은 상황: 60개.** 클래스가 $+$이고 $d$개 속성값이 모두 $x_1, \dots, x_d$와 같은 샘플 30개, 클래스가 $-$이고 역시 모든 속성값이 일치하는 샘플 30개가 있으면, 이 60개만으로 $2d$개 항이 모두 $|D_{c,x_i}| = 30$을 만족합니다. 반대로 $D_{+,x_1}$과 $D_{-,x_1}$은 클래스가 달라 서로 겹치지 않으므로 60개보다 적게는 불가능합니다. 따라서 최선은 **60개**로, 나이브 베이즈와 같습니다.

**가장 나쁜 상황: $60d$개.** 샘플들이 서로 다른 항을 전혀 공유하지 않는 경우입니다. 예를 들어 속성 $i$ 몫으로 모은 샘플 60개(클래스별 30개)는 $i$번째 속성값만 $x_i$와 같고 나머지 속성값은 모두 $\boldsymbol{x}$와 다르다고 합시다(각 속성이 2개 이상의 값을 가질 수 있으면 가능합니다). 그러면 각 샘플은 정확히 한 항의 개수에만 기여하므로 $d$개 속성에 대해 $60 \times d$개가 필요합니다. 이보다 많을 수는 없습니다. 쓸모없는 샘플(어떤 항에도 필요하지 않은 샘플)을 빼고 생각하면, 각 샘플은 개수가 정확히 30인 항에 적어도 하나 속해야 하고 그런 항은 최대 $2d$개, 항마다 30개이므로 많아야 $30 \times 2d = 60d$개입니다. 따라서 최악은 **$60d$개**입니다.

| | 나이브 베이즈 $P(c)$ | AODE $P(c, x_i)$ |
|---|---|---|
| 필요한 항의 수 | 2 | $2d$ |
| 가장 좋은 상황 | 60 | 60 |
| 가장 나쁜 상황 | 60 | $60d$ |

참고로 판별할 샘플 하나가 아니라 모든 속성의 모든 값 $v$에 대해 $P(c, v)$를 미리 추정해 두려면, 속성 $i$의 $N_i$개 값 각각에 클래스별 30개씩 필요하므로 가장 좋은 상황에서도 $60 \max_i N_i$개가 필요합니다. 어느 쪽으로 보든 AODE의 사전 확률 항은 나이브 베이즈보다 훨씬 많은 데이터를 요구하고, 187쪽에서 $|D_{x_i}| \geqslant m'$인 속성만 상위 부모로 쓰도록 거르는 이유가 여기에 있습니다.

## 문제 7.8

> 그림 7.3을 살펴보고 다음을 증명하라. 같은 부모 구조에서 만약 $x_1$의 값을 모른다면, $x_3 \perp\!\!\!\perp x_4$는 성립하지 않는다. 순차적 구조에서 $y \perp z \mid x$지만, $y \perp\!\!\!\perp z$는 성립하지 않는다.

**풀이**

'성립하지 않는다'는 것은 그래프 구조만으로는 독립성이 보장되지 않는다, 즉 그 구조를 따르면서 독립이 아닌 분포가 존재한다는 뜻입니다. 그래서 각 경우에 결합 분포를 식 7.26으로 쓰고, 독립성이 일반적으로 깨지는 이유를 보인 뒤 구체적인 반례를 하나씩 듭니다. 모든 변수는 이산이라고 둡니다(연속이면 합을 적분으로 바꾸면 됩니다).

**(1) 같은 부모 구조: $x_1 \to x_3$, $x_1 \to x_4$**

식 7.26에 따라 결합 분포는

$$P(x_1, x_3, x_4) = P(x_1)\,P(x_3 \mid x_1)\,P(x_4 \mid x_1)$$

입니다. $x_1$이 주어지면 $P(x_3, x_4 \mid x_1) = P(x_3 \mid x_1)P(x_4 \mid x_1)$이므로 $x_3 \perp x_4 \mid x_1$이 성립합니다. 그러나 $x_1$의 값을 모르면 $x_1$에 대해 주변화해야 합니다.

$$P(x_3, x_4) = \sum_{x_1} P(x_1)\,P(x_3 \mid x_1)\,P(x_4 \mid x_1)$$

반면 $P(x_3) = \sum_{x_1} P(x_1)P(x_3 \mid x_1)$, $P(x_4) = \sum_{x_1} P(x_1)P(x_4 \mid x_1)$입니다. $a(x_1) = P(x_3 \mid x_1)$, $b(x_1) = P(x_4 \mid x_1)$로 두면

$$P(x_3, x_4) - P(x_3)P(x_4) = \mathbb{E}_{x_1}[a\,b] - \mathbb{E}_{x_1}[a]\,\mathbb{E}_{x_1}[b] = \operatorname{Cov}_{x_1}\!\big(a(x_1),\, b(x_1)\big)$$

입니다. 두 자식이 모두 부모 값에 따라 달라지면 이 공분산은 일반적으로 0이 아니므로 $x_3 \perp\!\!\!\perp x_4$는 성립하지 않습니다.

반례: $x_1, x_3, x_4 \in \{0, 1\}$, $P(x_1 = 1) = 0.5$, $P(x_3 = 1 \mid x_1) = P(x_4 = 1 \mid x_1) = 0.9$ ($x_1 = 1$일 때), $0.1$ ($x_1 = 0$일 때)로 둡니다. 그러면

$$P(x_3 = 1) = P(x_4 = 1) = 0.5 \times 0.9 + 0.5 \times 0.1 = 0.5,$$

$$P(x_3 = 1, x_4 = 1) = 0.5 \times 0.9^2 + 0.5 \times 0.1^2 = 0.41 \ne 0.25 = P(x_3 = 1)P(x_4 = 1)$$

이므로 $x_3$과 $x_4$는 독립이 아닙니다. 직관적으로는 $x_3 = 1$을 보면 $x_1 = 1$일 가능성이 높아지고, 그 결과 $x_4 = 1$일 가능성도 높아집니다. 공통 원인을 통해 정보가 흐르는 것입니다.

**(2) 순서 구조: $z \to x \to y$**

그림 7.3의 순서 구조는 $z$에서 $x$로, $x$에서 $y$로 화살표가 있으므로 결합 분포는

$$P(x, y, z) = P(z)\,P(x \mid z)\,P(y \mid x)$$

입니다.

*$y \perp z \mid x$의 증명.* $P(x) > 0$인 $x$에 대해

$$P(y, z \mid x) = \frac{P(z)P(x \mid z)P(y \mid x)}{P(x)} = \frac{P(x, z)}{P(x)}\,P(y \mid x) = P(z \mid x)\,P(y \mid x)$$

이므로 $x$가 주어지면 $y$와 $z$는 조건독립입니다.

*$y \perp\!\!\!\perp z$가 일반적으로 성립하지 않음.* $x$를 주변화하면

$$P(y, z) = P(z)\sum_{x} P(x \mid z)P(y \mid x) = P(z)\,P(y \mid z)$$

이고, 독립이려면 모든 $z$에서 $P(y \mid z) = \sum_x P(x \mid z)P(y \mid x)$가 $P(y)$와 같아야 합니다. $x$가 $z$에 의존하고 $y$가 $x$에 의존하면 이 값은 일반적으로 $z$에 따라 달라집니다.

반례: 모두 이진 변수로 $P(z = 1) = 0.5$, $P(x = 1 \mid z) = 0.9$ ($z = 1$), $0.1$ ($z = 0$), $P(y = 1 \mid x) = 0.9$ ($x = 1$), $0.1$ ($x = 0$)로 둡니다.

$$P(y = 1 \mid z = 1) = 0.9 \times 0.9 + 0.1 \times 0.1 = 0.82, \qquad P(y = 1 \mid z = 0) = 0.1 \times 0.9 + 0.9 \times 0.1 = 0.18$$

$P(y = 1) = 0.5 \times 0.82 + 0.5 \times 0.18 = 0.5$이므로

$$P(y = 1, z = 1) = 0.5 \times 0.82 = 0.41 \ne 0.25 = P(y = 1)P(z = 1)$$

입니다. 따라서 $y \perp z \mid x$는 성립하지만 $y \perp\!\!\!\perp z$는 성립하지 않습니다. $x$를 모르면 $z$의 정보가 $x$를 거쳐 $y$까지 전달되고, $x$를 알면 그 경로가 막힌다고 이해하면 됩니다. $\blacksquare$

방향성 분리로 보아도 같은 결론입니다. 두 구조 모두 V형 구조가 없으므로 도덕화해도 간선이 추가되지 않고, 모럴 그래프는 $x_3 - x_1 - x_4$, $y - x - z$입니다. 가운데 노드를 관측하면(제거하면) 양 끝이 분리되지만, 관측하지 않으면 연결된 채로 남습니다.

## 문제 7.9

> 수박 데이터 2.0을 훈련 데이터로 사용해서 BIC 기준에 기반해 베이지안 네트워크를 만들어 보아라.

**풀이**

**설정.** 수박 데이터 세트 2.0(표 4.1)은 수박 데이터 세트 3.0에서 밀도와 당도를 뺀 것과 같습니다. 192쪽 보조 설명처럼 클래스(잘 익은 수박)도 하나의 속성으로 보고, 변수 7개(색깔, 꼭지 모양, 소리, 줄무늬, 배꼽 모양, 감촉, 잘 익은 수박) 위에서 식 7.31의 BIC를 최소화하는 구조를 찾습니다.

**BIC가 노드별로 분해된다는 점.** 변수 $x_i$의 값 개수를 $r_i$, 부모 집합 $\pi_i$가 취할 수 있는 값 조합의 수를 $q_i$라고 하면 파라미터 수는 $|B| = \sum_i (r_i - 1)q_i$입니다. 구조가 정해지면 파라미터는 식 7.32의 경험 분포 $\hat{\theta}_{x_i|\pi_i} = m_{ijk}/m_{ij}$로 정해지고($m_{ij}$는 부모 조합이 $j$인 샘플 수, $m_{ijk}$는 그중 $x_i = k$인 샘플 수), 로그 우도도 노드별 합이 됩니다. 따라서

$$\mathrm{BIC}(B \mid D) = \sum_{i=1}^{d}\left[ \frac{\log m}{2}(r_i - 1)q_i - \sum_{j=1}^{q_i}\sum_{k=1}^{r_i} m_{ijk}\log\frac{m_{ijk}}{m_{ij}} \right]$$

입니다. 두 항에 같은 밑의 로그를 쓰면 로그의 밑은 BIC 전체에 상수를 곱할 뿐이라 최적 구조에 영향이 없습니다. 아래 계산은 자연로그를 씁니다.

**탐색 방법.** 193쪽 설명처럼 구조 탐색은 일반적으로 NP-hard라 탐욕 탐색을 많이 쓰지만, 이 문제는 변수가 7개뿐이라 전역 최적해를 정확히 구할 수 있습니다. BIC가 노드별로 분해되므로, 노드 부분집합 $S$ 위의 최적 DAG는 '$S$에서 순서상 가장 마지막에 오는 노드 하나를 고르고, 그 노드의 부모는 나머지 $S$ 안에서 가장 좋은 것으로 고른다'는 점화식으로 구할 수 있습니다. 부분집합은 $2^7 = 128$개뿐입니다. 아래 코드는 문제 7.3 코드의 `DATA`를 그대로 씁니다.

```python
import numpy as np
from itertools import combinations

# 수박 데이터 세트 2.0 = 3.0에서 밀도·당도를 뺀 것 (7.3의 DATA 재사용)
NAMES = ["색깔", "꼭지 모양", "소리", "줄무늬", "배꼽 모양", "감촉", "잘 익은 수박"]
VALS = [["청록색", "진녹색", "연녹색"], ["말림", "약간말림", "곧음"], ["혼탁", "둔탁", "맑음"],
        ["선명함", "약간흐림", "흐림"], ["움푹패임", "약간패임", "평평함"],
        ["단단함", "물렁함"], ["예", "아니오"]]
X = np.array([[VALS[k].index(v) for k, v in enumerate(r[:6] + [r[8]])] for r in DATA])
m, d = X.shape
R = [len(v) for v in VALS]                              # r_i: 변수 i의 값 개수

def local_bic(i, pa, X=X, w=None):
    """노드 i의 BIC 기여분: (log m / 2)(r_i - 1)q_i - sum log theta_{x_i | pa_i}"""
    w = np.ones(len(X)) if w is None else w
    q = int(np.prod([R[p] for p in pa]))                # 부모 값 조합의 수 q_i
    cfg = np.zeros(len(X), dtype=int)
    for p in pa:
        cfg = cfg * R[p] + X[:, p]
    cnt = np.zeros((q, R[i]))
    np.add.at(cnt, (cfg, X[:, i]), w)
    theta = cnt / np.maximum(cnt.sum(1, keepdims=True), 1e-300)   # 식 7.32 (경험 분포)
    ll = (cnt[cnt > 0] * np.log(theta[cnt > 0])).sum()
    return np.log(w.sum()) / 2 * (R[i] - 1) * q - ll

def best_network(score):
    """BIC는 노드별로 분해되므로, 노드 부분집합 S 위의 최적 DAG를 동적 계획법으로 쌓는다."""
    def best_pa(i, S):
        return min((score[i][frozenset(c)], frozenset(c))
                   for k in range(len(S) + 1) for c in combinations(sorted(S), k))
    memo = {frozenset(): (0.0, {})}
    for size in range(1, d + 1):
        for S in map(frozenset, combinations(range(d), size)):
            cands = []
            for sink in S:                              # S 안에서 가장 마지막 순서인 노드
                s0, g0 = memo[S - {sink}]
                s1, pa = best_pa(sink, S - {sink})
                cands.append((s0 + s1, {**g0, sink: pa}))
            memo[S] = min(cands, key=lambda t: t[0])
    return memo[frozenset(range(d))]

score = [{frozenset(c): local_bic(i, c) for k in range(d)
          for c in combinations([j for j in range(d) if j != i], k)} for i in range(d)]
bic, G = best_network(score)
print(f"BIC = {bic:.3f}")
for i in range(d):
    print(f"{NAMES[i]:8s} <- {[NAMES[p] for p in sorted(G[i])]}")
```

실행 결과입니다.

```

꼭지 모양    <- ['감촉']
소리       <- ['꼭지 모양']
줄무늬      <- ['배꼽 모양']
배꼽 모양    <- ['꼭지 모양']

```

**결과 구조.** 간선은 다음 6개입니다.

$$\text{감촉} \to \text{꼭지 모양},\quad \text{꼭지 모양} \to \text{소리},\quad \text{꼭지 모양} \to \text{배꼽 모양},$$

$$\text{배꼽 모양} \to \text{줄무늬},\quad \text{줄무늬} \to \text{잘 익은 수박},\quad \text{감촉} \to \text{잘 익은 수박}$$

색깔은 어떤 변수와도 연결되지 않습니다. 이 구조의 로그 우도는 $LL = -74.680$, 파라미터 수는 $|B| = 31$이고, $\frac{\ln 17}{2} \times 31 + 74.680 = 43.915 + 74.680 = 118.595$로 출력과 일치합니다. 비교하면 간선이 하나도 없는 구조는 BIC가 $124.166$, 클래스가 모든 속성의 부모인 나이브 베이즈 구조는 $127.233$($LL = -94.651$, $|B| = 23$)입니다.

**검증과 해석.** 코드와 별도로 7개 노드의 모든 순서($7! = 5040$가지)를 하나씩 따져 같은 최적값 $118.595$를 확인했고, 빈 그래프에서 시작해 간선 추가·삭제·뒤집기를 반복하는 언덕 오르기 탐색도 같은 점수에 도달했습니다. 다만 최적 BIC를 갖는 DAG는 하나가 아니라 5개입니다. 모두 같은 골격(위 6개 간선에서 방향을 뺀 것)과 같은 V형 구조 '줄무늬 → 잘 익은 수박 ← 감촉'을 가지고, 나머지 간선의 방향만 다릅니다. 예를 들어 '꼭지 모양 → 감촉'으로 뒤집은 구조도 BIC가 똑같습니다. 이런 구조들은 같은 조건독립 관계를 표현하므로(마르코프 동치) 데이터만으로는 구분할 수 없고, 위 구조는 그중 하나로 보면 됩니다.

'잘 익은 수박'의 조건 확률표를 개수로 보면 구조가 왜 이렇게 나왔는지 알 수 있습니다.

| 줄무늬 | 감촉 | 예 | 아니오 |
|------|------|----|------|
| 선명함 | 단단함 | 6 | 0 |
| 선명함 | 물렁함 | 1 | 2 |
| 약간 흐림 | 단단함 | 0 | 4 |
| 약간 흐림 | 물렁함 | 1 | 0 |
| 흐림 | 단단함 | 0 | 3 |
| 흐림 | 물렁함 | 0 | 0 |

줄무늬와 감촉 두 속성의 조합마다 다수 클래스로 판별하면 17개 중 16개를 맞힐 수 있습니다. 4장 의사결정 트리에서 줄무늬가 루트 분할 속성으로 뽑힌 것과도 맞아떨어집니다. '흐림, 물렁함' 조합은 훈련 데이터에 없어 최대 우도 추정값이 정의되지 않으므로, 실제로 쓰려면 라플라스 보정 같은 평활화가 필요합니다.

샘플이 17개뿐이라 BIC의 벌점 항 $\frac{\log m}{2}|B|$이 상대적으로 커서 간선이 적은 구조가 선택됩니다. 같은 데이터라도 샘플이 많아지면 더 조밀한 구조가 나올 수 있으므로, 이 결과는 '이 작은 데이터가 지지하는 의존관계'로 해석하는 것이 맞습니다.

## 문제 7.10

> 수박 데이터 2.0에서 속성 '배꼽 모양'을 은닉 변수로 설정하여 EM 알고리즘에 기반한 베이지안 네트워크를 만들어 보아라.

**풀이**

**문제의 해석.** 배꼽 모양 열을 지우고 관측되지 않는 변수 $z$(3개 값)로 두고, 문제 7.9에서 얻은 구조를 그대로 쓴 채 EM 알고리즘으로 조건 확률표를 학습합니다. 즉 구조는 고정하고 파라미터를 EM으로 추정합니다. (구조까지 EM 안에서 다시 고르는 방식은 마지막에 따로 적었습니다.) 7.9의 구조에서 $z$(배꼽 모양)는 부모가 꼭지 모양, 자식이 줄무늬입니다.

**E 단계.** 식 7.26에 따라 샘플 $\boldsymbol{x}_n$과 $z$의 결합 확률은 모든 노드의 조건 확률의 곱입니다. $z$를 포함하지 않는 인자는 $z$에 대해 상수이므로 분자와 분모에서 약분되고, 사후 분포는

$$q_n(z) = P(z \mid \boldsymbol{x}_n, \Theta^t) = \frac{P(z \mid \text{꼭지}_n)\,P(\text{줄무늬}_n \mid z)}{\sum_{z'} P(z' \mid \text{꼭지}_n)\,P(\text{줄무늬}_n \mid z')}$$

입니다. 이것이 식 7.36의 기대값을 계산하는 데 필요한 전부입니다.

**M 단계.** 식 7.36의 $Q(\Theta \mid \Theta^t) = \sum_n \sum_z q_n(z) \ln P(\boldsymbol{x}_n, z \mid \Theta)$를 최대화하면, 개수를 기대 개수로 바꾼 최대 우도 추정이 됩니다(문제 7.1의 라그랑주 유도에서 $n_v$를 가중 개수로 바꾸면 됩니다).

$$\hat{P}(z = k \mid \text{꼭지} = a) = \frac{\sum_{n:\, \text{꼭지}_n = a} q_n(k)}{|\{n : \text{꼭지}_n = a\}|}, \qquad \hat{P}(\text{줄무늬} = b \mid z = k) = \frac{\sum_{n:\, \text{줄무늬}_n = b} q_n(k)}{\sum_n q_n(k)}$$

$z$와 무관한 노드(색깔, 감촉, 꼭지 모양, 소리, 잘 익은 수박)의 조건 확률표는 관측된 개수 그대로입니다. 반복마다 관측 데이터의 로그 주변 우도(식 7.35) $LL(\Theta \mid \mathbf{X}) = \sum_n \ln \sum_z P(\boldsymbol{x}_n, z \mid \Theta)$를 계산해 수렴을 판정합니다.

구현은 샘플마다 $z = 0, 1, 2$를 채운 세 줄을 만들고 각 줄에 가중치 $q_n(z)$를 주는 방식으로 했습니다. 이렇게 하면 M 단계는 가중 개수 세기 하나로 끝납니다. 아래 코드는 문제 7.9 코드의 `X`, `R`, `NAMES`, `m`, `d`, `G`를 그대로 씁니다.

```python
from itertools import permutations

Z = NAMES.index("배꼽 모양")                     # 은닉 변수
PA = {i: tuple(sorted(G[i])) for i in range(d)}  # 7.9에서 얻은 구조를 그대로 사용

def cfg(Xe, pa):
    c = np.zeros(len(Xe), dtype=int)
    for p in pa:
        c = c * R[p] + Xe[:, p]
    return c

def m_step(Xe, w):                               # 기대 카운트로 각 노드의 조건 확률표 추정
    th = {}
    for i, pa in PA.items():
        cnt = np.zeros((int(np.prod([R[p] for p in pa])), R[i]))
        np.add.at(cnt, (cfg(Xe, pa), Xe[:, i]), w)
        tot = cnt.sum(1, keepdims=True)
        th[i] = np.where(tot > 0, cnt / np.where(tot > 0, tot, 1), 1 / R[i])
    return th

def joint(Xe, th):                               # 각 행의 P(x, z | Θ) (식 7.26)
    p = np.ones(len(Xe))
    for i, pa in PA.items():
        p *= th[i][cfg(Xe, pa), Xe[:, i]]
    return p

# 샘플마다 z = 0, 1, 2 세 줄로 펼친다 (배꼽 모양 열의 원래 값은 쓰지 않음)
Xe = np.repeat(X, R[Z], axis=0)
Xe[:, Z] = np.tile(np.arange(R[Z]), m)

def em(seed, tol=1e-10, max_iter=1000):
    rng = np.random.default_rng(seed)
    w = rng.dirichlet(np.ones(R[Z]), size=m).ravel()   # 초기 q(z | x)를 무작위로
    th, hist = m_step(Xe, w), []
    for _ in range(max_iter):
        pj = joint(Xe, th).reshape(m, R[Z])
        hist.append(np.log(pj.sum(1)).sum())           # 식 7.35: 관측 데이터의 로그 주변 우도
        w = (pj / pj.sum(1, keepdims=True)).ravel()    # E 단계: P(z | x, Θ^t)
        th = m_step(Xe, w)                             # M 단계: 식 7.37
        if len(hist) > 1 and hist[-1] - hist[-2] < tol:
            break
    return hist, th, w.reshape(m, R[Z])

for seed in range(20):
    hist, th, q = em(seed)
    z = q.argmax(1)
    acc = max(np.mean(np.array(p)[z] == X[:, Z]) for p in permutations(range(3)))
    print(seed, f"LL={hist[-1]:.4f}", f"반복={len(hist)}",
          f"단조증가={np.all(np.diff(hist) > -1e-12)}", f"배꼽 복원 일치율={acc:.3f}")
```

초기값은 각 샘플의 $q_n(z)$를 디리클레 분포에서 무작위로 뽑아 정했고, 시드 0~19로 20번 돌렸습니다. 마지막 열은 학습이 끝난 뒤 $\arg\max_z q_n(z)$를 실제 배꼽 모양과 비교한 일치율입니다. 은닉 상태의 번호는 의미가 없으므로(0번 상태가 '움푹 패임'이라는 보장이 없음) 3! = 6가지 번호 대응 중 가장 잘 맞는 것을 골랐습니다. 결과를 요약하면 다음과 같습니다.

| 항목 | 결과 |
|------|------|
| 수렴한 로그 주변 우도 | 20번 모두 $-66.0630$ |
| 로그 우도의 단조 증가 | 20번 모두 성립 |
| 반복 횟수 | 103~785회 (허용 오차 $10^{-10}$) |
| 배꼽 모양 복원 일치율 | 0.882 (16번), 0.824 (1번), 0.647 (3번) |

시드 0의 로그 우도는 $-69.680 \to -69.396 \to -68.982 \to -68.372 \to \cdots \to -66.063$으로 한 번도 줄지 않고 증가했습니다. EM이 매 반복 관측 데이터의 우도를 감소시키지 않는다는 성질을 그대로 보여 줍니다.

시드 1의 결과를 실제 배꼽 모양 값에 맞춰 번호를 붙이면 학습된 조건 확률표는 다음과 같습니다. 괄호 안은 배꼽 모양을 실제로 관측했을 때의 최대 우도 추정값입니다.

| $P(z \mid \text{꼭지 모양})$ | 움푹 패임 | 약간 패임 | 평평함 |
|------|------|------|------|
| 말림 | 0.404 (0.625) | 0.096 (0.125) | 0.500 (0.250) |
| 약간 말림 | 0.205 (0.286) | 0.795 (0.714) | 0.000 (0) |
| 곧음 | 0.000 (0) | 0.000 (0) | 1.000 (1) |

| $P(\text{줄무늬} \mid z)$ | 선명함 | 약간 흐림 | 흐림 |
|------|------|------|------|
| 움푹 패임 | 0.853 (0.714) | 0.147 (0.286) | 0.000 (0) |
| 약간 패임 | 0.319 (0.500) | 0.681 (0.500) | 0.000 (0) |
| 평평함 | 0.500 (0.250) | 0.000 (0) | 0.500 (0.750) |

이때 17개 샘플 중 13번, 14번 두 개(실제로는 움푹 패임)만 '약간 패임'으로 복원되어 일치율이 15/17 = 0.882입니다.

**왜 로그 우도는 같은데 파라미터는 다른가.** 시드마다 로그 우도는 소수점 넷째 자리까지 같은데, 학습된 표와 복원 일치율은 다릅니다. 이유는 이 구조에서 $z$가 관측 변수와 맺는 관계가 '꼭지 모양 → $z$ → 줄무늬' 하나뿐이기 때문입니다. 관측 데이터의 우도에서 $z$는

$$P(\text{줄무늬} \mid \text{꼭지}) = \sum_{z} P(z \mid \text{꼭지})\,P(\text{줄무늬} \mid z)$$

의 형태로만 등장합니다. $z$가 3개 값을 가지므로 이 곱은 임의의 $3 \times 3$ 조건부 확률표를 만들 수 있고(예를 들어 $z$를 줄무늬의 복사본으로 두면 됩니다), 우도의 최댓값은 이 표가 데이터의 경험 분포 $\hat{P}(\text{줄무늬} \mid \text{꼭지})$와 같아질 때 달성됩니다. 실제로 20개 해 모두 두 표의 곱이 경험 분포(말림 행 $0.625, 0.125, 0.250$, 약간 말림 행 $0.429, 0.571, 0$, 곧음 행 $0.5, 0, 0.5$)와 일치했습니다(최대 차이 약 $8 \times 10^{-6}$, 수렴 허용 오차 수준). 그런데 곱이 같아지는 두 표의 쌍은 무수히 많으므로, EM은 전역 최댓값에 도달하더라도 그중 어느 해에 멈출지는 초기값이 결정합니다. 은닉 변수 모형에서 흔히 생기는 식별 불가능성(non-identifiability)입니다.

참고로 실제 배꼽 모양 값으로 추정한 파라미터를 넣고 $z$를 주변화하면 로그 주변 우도는 $-66.965$로, EM 해($-66.063$)보다 낮습니다. EM은 '실제 배꼽 모양'을 복원하는 것이 목적이 아니라 관측 데이터의 우도를 최대화하는 것이 목적이므로 이런 결과가 나올 수 있습니다.

**구조까지 함께 학습하는 경우.** 위 방법에 더해, E 단계에서 얻은 $q_n(z)$로 가중 데이터를 만들고 그 위에서 7.9의 BIC 최적 구조를 다시 찾은 뒤 파라미터 EM을 돌리는 과정을 반복해 보았습니다(구조적 EM). 시드 0~2에서 6번씩 반복했는데, 구조는 7.9와 같은 골격과 같은 V형 구조를 유지했고 간선 방향만 마르코프 동치 범위 안에서 바뀌었습니다. 이 데이터에서는 배꼽 모양을 숨겨도 꼭지 모양과 줄무늬 사이를 잇는 위치가 그대로 유지된다는 뜻입니다.

정리하면, 배꼽 모양을 은닉 변수로 둔 베이지안 네트워크는 7.9의 구조에 위 조건 확률표를 붙인 것이고, EM은 매 반복 우도를 높이며 같은 최대 우도에 수렴하지만 은닉 변수의 파라미터는 하나로 정해지지 않습니다. 은닉 변수가 더 많은 관측 변수와 연결되어 있거나 샘플이 많으면 이런 자유도가 줄어듭니다.
