## 문제 11.1

> Relief 알고리즘에 대한 코드를 작성하고, 수박 데이터 세트 3.0상에서 결과를 얻어 보아라.

**풀이**

11.2절의 Relief는 각 샘플 $\boldsymbol{x}_i$마다 같은 클래스에서 가장 가까운 샘플(near-hit) $\boldsymbol{x}_{i,\text{nh}}$와 다른 클래스에서 가장 가까운 샘플(near-miss) $\boldsymbol{x}_{i,\text{nm}}$를 찾고, 속성 $j$의 관련 통계량을 식 11.3으로 누적합니다.

$$\delta^j = \sum_i -\operatorname{diff}(x_i^j, x_{i,\text{nh}}^j)^2 + \operatorname{diff}(x_i^j, x_{i,\text{nm}}^j)^2$$

구현에서 정한 사항은 다음과 같습니다.

- $\operatorname{diff}$: 이산 속성(색깔, 꼭지 모양, 소리, 줄무늬, 배꼽 모양, 감촉)은 값이 같으면 0, 다르면 1입니다. 연속 속성(밀도, 당도)은 최솟값-최댓값 정규화로 $[0,1]$에 맞춘 뒤 $|x_a^j - x_b^j|$를 씁니다. 책의 정의 그대로입니다.
- 이웃을 찾는 거리: 책은 거리를 따로 정하지 않으므로, 모든 속성의 diff를 모은 유클리드 거리 $\sqrt{\sum_j \operatorname{diff}(x_a^j, x_b^j)^2}$를 썼습니다.
- 샘플링 없이 17개 샘플을 모두 사용했습니다. 그래서 무작위성이 없습니다.

데이터는 책의 표 4.3(104~105쪽)을 그대로 옮겼습니다. 11.3, 11.4, 11.8의 실험도 같은 데이터를 씁니다.

rows = [r.split() for r in raw.splitlines()]
Xd = np.array([r[:6] for r in rows])                          # 이산 속성 6개
Xc = np.array([[float(r[6]), float(r[7])] for r in rows])     # 연속 속성 2개
y = np.array([int(r[8]) for r in rows])                       # 1 = 잘 익은 수박

def diff_matrix(Xd, Xc):
    """모든 샘플 쌍, 모든 속성의 diff 값. shape = (m, m, d)"""
    Dd = (Xd[:, None, :] != Xd[None, :, :]).astype(float)    # 이산: 같으면 0, 다르면 1
    Xn = (Xc - Xc.min(0)) / (Xc.max(0) - Xc.min(0))          # 연속: [0,1] 정규화
    Dc = np.abs(Xn[:, None, :] - Xn[None, :, :])
    return np.concatenate([Dd, Dc], axis=2)

def relief(Xd, Xc, y):
    D = diff_matrix(Xd, Xc)
    dist = np.sqrt(np.square(D).sum(axis=2))
    np.fill_diagonal(dist, np.inf)                            # 자기 자신 제외
    delta = np.zeros(D.shape[2])
    for i in range(len(y)):
        same = (y == y[i])
        nh = np.where(same, dist[i], np.inf).argmin()         # near-hit
        nm = np.where(~same, dist[i], np.inf).argmin()        # near-miss
        delta += -np.square(D[i, nh]) + np.square(D[i, nm])               # 식 11.3
    return delta

delta = relief(Xd, Xc, y)
for r, j in enumerate(np.argsort(-delta)):
    print(r + 1, cols[j], round(delta[j], 4), round(delta[j] / len(y), 4))

## 문제 11.2

> Relief-F의 알고리즘에 대해 서술하라.

**풀이**

Relief는 이진 분류만 다룰 수 있습니다. near-miss가 "다른 클래스"에서 하나뿐이기 때문입니다. Relief-F는 다중 분류에서 다른 클래스마다 near-miss를 하나씩 찾고, 그 클래스가 데이터에서 차지하는 비율로 가중합니다. 책의 식 11.4를 따라 알고리즘을 정리하면 다음과 같습니다.

**입력**: 데이터 세트 $D = \{(\boldsymbol{x}_1, y_1), \dots, (\boldsymbol{x}_m, y_m)\}$, 클래스 집합 $\mathcal{Y}$, 샘플링 횟수 $n$($n = m$이면 전체 사용), 임곗값 $\tau$ 또는 선택할 특성 수 $k$

**과정**:

1. 모든 속성 $j$에 대해 $\delta^j = 0$으로 둡니다. 클래스 비율 $p_l = |\{i : y_i = l\}| / m$을 계산합니다. 연속 속성은 $[0,1]$로 정규화합니다.
2. $n$번 반복합니다. 샘플 $\boldsymbol{x}_i$를 하나 뽑고, 그 클래스를 $k_i$라 합니다.
   - 같은 클래스 $k_i$에서 $\boldsymbol{x}_i$와 가장 가까운 샘플 $\boldsymbol{x}_{i,\text{nh}}$(near-hit)를 찾습니다.
   - $k_i$가 아닌 각 클래스 $l$에서 가장 가까운 샘플 $\boldsymbol{x}_{i,l,\text{nm}}$(near-miss)를 찾습니다. near-miss는 $|\mathcal{Y}| - 1$개입니다.
   - 모든 속성 $j$에 대해 다음을 더합니다.
   $$\delta^j \leftarrow \delta^j - \operatorname{diff}(x_i^j, x_{i,\text{nh}}^j)^2 + \sum_{l \neq k_i} p_l \times \operatorname{diff}(x_i^j, x_{i,l,\text{nm}}^j)^2$$
3. $\delta^j$를 $n$으로 나눠 평균을 냅니다.

**출력**: $\delta^j > \tau$인 특성, 또는 $\delta^j$가 큰 순서로 $k$개의 특성

해석은 Relief와 같습니다. 같은 클래스의 가까운 이웃과는 속성 $j$의 값이 비슷하고 다른 클래스의 가까운 이웃과는 값이 다를수록 $\delta^j$가 커집니다. 다른 클래스가 여러 개이므로, 흔한 클래스에서 온 near-miss일수록 큰 가중치 $p_l$을 줍니다. 계산량은 샘플 하나마다 모든 샘플과의 거리를 재야 하므로 대략 $O(n \cdot m \cdot d)$이고, Relief와 마찬가지로 샘플링 횟수와 특성 수에 선형입니다.

덧붙이면, Relief-F를 처음 제안한 [Kononenko, 1994]는 책의 식 11.4와 두 가지가 조금 다릅니다.

| 항목 | 책의 식 11.4 | Kononenko(1994)의 ReliefF |
|---|---|---|
| 이웃 수 | 클래스마다 가장 가까운 1개 | 클래스마다 가장 가까운 $k$개의 평균(흔히 $k = 10$) |
| near-miss 가중치 | $p_l$ | $p_l / (1 - p_{k_i})$ |

$k$개의 이웃을 평균하면 잡음 샘플 하나에 결과가 흔들리는 것을 줄일 수 있습니다. 가중치를 $1 - p_{k_i}$로 나누면 near-miss 가중치의 합이 $\sum_{l \neq k_i} p_l / (1 - p_{k_i}) = 1$이 되어 near-hit 항의 가중치 1과 균형이 맞고, 클래스가 두 개일 때 정확히 Relief(식 11.3)로 돌아갑니다. 책의 식 11.4를 그대로 쓰면 이진 분류에서 near-miss 항에 $p_l$이 곱해진 형태가 됩니다.

## 문제 11.3

> Relief 알고리즘은 각 속성의 중요성을 고려하고 있다. 각 속성의 중요성을 고려하는 다른 개선 알고리즘을 만들어 보아라.

**풀이**

Relief는 속성마다 통계량 $\delta^j$를 따로 계산하고, 특성 부분집합의 중요도는 각 특성 통계량의 합으로 봅니다(294쪽). 이렇게 하면 "두 속성을 함께 볼 때만 드러나는 정보"(상호작용)나 "두 속성이 같은 정보를 담고 있다"(중복)는 사실이 합에 반영되지 않습니다. 이 문제는 이 한계를 개선하라는 취지로 보고, **속성 쌍**의 중요성을 직접 평가하는 알고리즘을 설계합니다.

**아이디어: 부분공간 Relief**

속성 부분집합 $S$가 주어지면, $S$에 속한 속성만으로 거리를 재서 near-hit과 near-miss를 찾고, 그 거리 차이를 통계량으로 씁니다.

$$\delta^S = \frac{1}{m} \sum_{i=1}^m \left[ -\operatorname{dist}_S(\boldsymbol{x}_i, \boldsymbol{x}_{i,\text{nh}}^S)^2 + \operatorname{dist}_S(\boldsymbol{x}_i, \boldsymbol{x}_{i,\text{nm}}^S)^2 \right], \quad \operatorname{dist}_S(\boldsymbol{a}, \boldsymbol{b})^2 = \sum_{j \in S} \operatorname{diff}(a^j, b^j)^2$$

여기서 $\boldsymbol{x}_{i,\text{nh}}^S$, $\boldsymbol{x}_{i,\text{nm}}^S$는 $S$ 부분공간에서 찾은 near-hit과 near-miss입니다. 이산 속성만 있으면 거리가 같은 이웃이 여러 개 생기므로, 동점 이웃들의 제곱 거리를 평균합니다.

- $S = \{j\}$이면 속성 $j$ 하나만 보는 중요도 $\delta^{\{j\}}$입니다.
- $S = \{j, l\}$이면 속성 쌍의 중요도 $\delta^{\{j,l\}}$입니다.
- $\delta^{\{j,l\}} - (\delta^{\{j\}} + \delta^{\{l\}})$가 크게 양수이면 두 속성이 함께 있을 때 더 잘 구별하는 상호작용(시너지)이 있고, 음수이면 정보가 겹치거나 함께 쓰면 오히려 이웃 구조가 흐려진다는 뜻입니다.

모든 쌍을 계산하면 $\binom{d}{2}$개의 부분공간을 보므로 계산량은 Relief의 약 $d/2$배입니다. 특성 선택에서는 단일 특성 순위 대신 쌍 점수가 높은 쌍부터 특성을 모으거나, 시너지가 큰 쌍을 함께 넣는 식으로 쓸 수 있습니다.

```python
import itertools
# Xd, Xc, y, cols, diff_matrix 는 문제 11.1과 같다

def subspace_relief(D, y, S):
    """속성 부분집합 S 위에서만 거리를 재는 Relief. 동점 이웃은 평균."""
    d2 = np.square(D[:, :, S]).sum(axis=2)
    m = len(y); score = 0.0
    for i in range(m):
        hit = (np.arange(m) != i) & (y == y[i]); miss = (y != y[i])
        h = d2[i, hit]; s = d2[i, miss]
        score += -h[np.isclose(h, h.min())].mean() + s[np.isclose(s, s.min())].mean()
    return score / m

def pair_relief(D, y):
    d = D.shape[2]
    single = np.array([subspace_relief(D, y, [j]) for j in range(d)])
    pair = {(j, l): subspace_relief(D, y, [j, l])
            for j, l in itertools.combinations(range(d), 2)}
    return single, pair

D = diff_matrix(Xd, Xc)
single, pair = pair_relief(D, y)

# 상호작용 확인용: y = x1 XOR x2, x3~x5는 잡음 (시드 0)
rng = np.random.default_rng(0)
Z = rng.integers(0, 2, size=(40, 5)); yx = Z[:, 0] ^ Z[:, 1]
Dz = (Z[:, None, :] != Z[None, :, :]).astype(float)
s1, p1 = pair_relief(Dz, yx)
```

**먼저 XOR 데이터로 확인합니다.** $y = x_1 \oplus x_2$이고 $x_3, x_4, x_5$는 무작위 잡음인 40개 샘플에서, 속성 하나만 보는 점수 $\delta^{\{j\}}$는 다섯 속성 모두 0.000이었습니다. $x_1$ 하나의 값만 알아서는 클래스를 전혀 알 수 없기 때문입니다. 반면 쌍 점수는 $\delta^{\{1,2\}} = 1.000$이고 나머지 쌍은 모두 0.000 이하였습니다. 단일 점수의 합(0)으로는 보이지 않던 상호작용을 쌍 점수가 잡아냅니다.

**수박 데이터 세트 3.0의 결과**는 다음과 같습니다. 단일 점수는 배꼽 모양 0.235, 꼭지 모양·소리·줄무늬 각 0.118, 밀도 0.012, 당도 0.001, 감촉 0.000, 색깔 −0.059였습니다(이산 속성 하나만 보면 거리 0인 이웃이 많아서 문제 11.1의 전체 공간 Relief와는 값과 순위가 다릅니다). 시너지 $\delta^{\{j,l\}} - (\delta^{\{j\}} + \delta^{\{l\}})$가 큰 쌍과 작은 쌍은 다음과 같습니다.

| 속성 쌍 | 쌍 점수 | 단일 점수 합 | 시너지 |
|---|---|---|---|
| 줄무늬, 감촉 | 0.706 | 0.118 | 0.588 |
| 꼭지 모양, 배꼽 모양 | 0.765 | 0.353 | 0.412 |

| 색깔, 감촉 | −0.353 | −0.059 | −0.294 |
| 색깔, 소리 | −0.412 | 0.059 | −0.471 |

감촉은 혼자서는 점수가 0이지만 줄무늬와 함께 보면 쌍 점수가 0.706으로 꼭지 모양·배꼽 모양 쌍(0.765) 다음으로 높습니다. 단일 속성 점수의 합만 보는 Relief에서는 이런 정보를 얻을 수 없습니다. 다만 샘플이 17개뿐이고 동점 이웃이 많아서 수치 자체는 크게 흔들릴 수 있으므로, 경향을 보는 정도로 해석하는 것이 좋습니다.

## 문제 11.4

> LVW를 위해 개선 알고리즘을 만들고, 제한 시간에 상관없이 해를 구하도록 설정하라.

**풀이**

**원래 LVW의 문제점**

그림 11.1의 LVW는 "$T$번 연속으로 더 나은 부분집합을 찾지 못하면" 멈추고 그때의 $A^*$를 출력합니다. 라스베이거스법이므로 이 종료 조건을 만족하기 전에 시간이 다 되면 해를 내지 못합니다(297쪽). 원인은 두 가지입니다.

1. 해를 돌려주는 시점이 종료 조건 하나뿐입니다. 시간 제한을 알고리즘이 알지 못합니다.
2. 6행에서 특성 부분집합을 매번 완전히 무작위로 만듭니다. 이전에 찾은 좋은 부분집합의 정보를 쓰지 않으므로, $|A|$가 크면 개선이 드물게 일어나고 종료 조건까지 오래 걸립니다. 같은 부분집합을 여러 번 평가하는 낭비도 있습니다.

**개선 알고리즘 (언제 멈춰도 해가 있는 LVW)**

입력에 시간 예산 $T_{\max}$를 추가하고 다음처럼 바꿉니다.

1. **초기화에서 해를 하나 확보합니다.** $A^* = A$로 두고 전체 특성 집합의 교차 검증 오차를 먼저 계산해 $E$에 넣습니다. 이 순간부터 언제 멈춰도 출력할 해가 있습니다.
2. **반복 조건에 시간을 넣습니다.** `while t < T and 경과 시간 < T_max`로 바꿉니다. 시간이 다 되면 루프를 빠져나와 현재의 $A^*$를 출력합니다. 즉 라스베이거스법을 "언제든 해를 내는(anytime)" 알고리즘으로 바꿉니다.
3. **후보를 현재 최선해 근처에서 만듭니다.** 6행을 "$A^*$에서 특성 1~2개를 무작위로 넣거나 빼서 $A'$를 만든다"로 바꿉니다. 좋은 부분집합 주변을 탐색하므로 적은 평가 횟수로도 오차가 줄어듭니다.
4. **이미 평가한 부분집합은 기억해 두고 다시 평가하지 않습니다.**

9행의 갱신 규칙(오차가 작거나, 오차가 같고 특성 수가 적으면 갱신)은 그대로 둡니다. 따라서 출력 $A^*$는 지금까지 평가한 부분집합 가운데 그림 11.1의 기준으로 가장 좋은 것이고, 시간이 넉넉하면 원래 LVW처럼 $T$번 연속 실패 시 멈춥니다.

**실험**

학습기 $\mathfrak{L}$은 1-최근접 이웃(문제 11.1과 같은 diff 기반 거리)으로, 교차 검증은 leave-one-out으로 정했습니다. 샘플이 17개뿐이라 최근접 이웃이 동점이면 다수결을 하고, 표가 같으면 오류 0.5개로 셉니다(무작위로 고를 때의 기댓값). 결과가 실행 환경에 따라 달라지지 않도록 "시간"은 교차 검증 평가 횟수(budget)로 셌습니다.

```python
# Xd, Xc, y, cols, diff_matrix 는 문제 11.1과 같다
D = diff_matrix(Xd, Xc); d = D.shape[2]; m = len(y)

def cv_error(S):
    """부분집합 S에서 1-NN의 leave-one-out 오차"""
    dist = np.sqrt(np.square(D[:, :, list(S)]).sum(axis=2)); np.fill_diagonal(dist, np.inf)
    err = 0.0
    for i in range(m):
        nn = np.isclose(dist[i], dist[i].min()); p = y[nn].mean()
        err += 0.5 if p == 0.5 else float((p > 0.5) != y[i])
    return err / m

def better(E1, d1, E, dcur):                    # 그림 11.1의 9행 조건
    return E1 < E or (E1 == E and d1 < dcur)

def lvw_anytime(T, budget, rng):
    best = tuple(range(d)); E = cv_error(best)  # 개선 1: 전체 집합을 먼저 평가
    used, t, seen = 1, 0, {best}
    while t < T and used < budget:              # 개선 2: 시간(평가 횟수) 제한
        S = set(best)                           # 개선 3: 최선해에서 1~2개 넣고 빼기
        for j in rng.choice(d, size=rng.integers(1, 3), replace=False):
            S ^= {j}
        S = tuple(sorted(S))
        if not S or S in seen:                  # 개선 4: 평가한 집합은 건너뜀
            t += 1; continue
        seen.add(S); E1 = cv_error(S); used += 1
        if better(E1, len(S), E, len(best)): best, E, t = S, E1, 0
        else: t += 1
    return best, E                              # 언제 멈춰도 해가 있다
```

비교용 원래 LVW는 그림 11.1 그대로(각 특성을 확률 0.5로 넣는 무작위 부분집합) 구현하고, 종료 조건을 만족하기 전에 예산이 다 되면 "해 없음"으로 처리했습니다. 정답을 알기 위해 $2^8 - 1 = 255$개 부분집합을 모두 평가해 보면, 전체 특성의 오차는 $5/17 \approx 0.294$이고 가장 작은 오차는 $1/17 \approx 0.059$입니다. 이 오차를 내는 부분집합은 7개이고, 그중 가장 작은 것은 {배꼽 모양, 밀도, 당도}입니다.

$T = 30$으로 두고 시드 0~99로 100번씩 돌린 결과입니다.

| 평가 예산 | 원래 LVW: 해 없음 | 원래 LVW: 평균 오차 | 원래 LVW: 최소 오차 도달 | 개선: 평균 오차 | 개선: 최소 오차 도달 |
|---|---|---|---|---|---|
| 20 | 100/100 | 없음 | 0% | 0.087 | 58% |
| 50 | 49/100 | 0.087 | 31% | 0.076 | 71% |
| 255 | 0/100 | 0.079 | 70% | 0.076 | 71% |

(원래 LVW의 평균 오차는 해를 낸 실행만으로 계산했고, "최소 오차 도달"은 100번 중 오차 $1/17$을 얻은 비율입니다.)

예산이 $T$보다 작으면 원래 LVW는 종료 조건을 만족할 수 없으므로 한 번도 해를 내지 못합니다. 개선 알고리즘은 예산과 관계없이 항상 해를 내고, 같은 예산에서 평균 오차도 더 작습니다. 예산이 충분하면 두 방법의 결과는 비슷해집니다. 예를 들어 시드 0, 예산 20에서 개선 알고리즘은 {꼭지 모양, 소리, 배꼽 모양, 감촉, 당도}(오차 $1/17$)를 냈습니다. 최소 오차에는 도달했지만 가장 작은 부분집합은 아니므로, 시간이 더 주어지면 특성을 줄이는 방향으로 계속 갱신됩니다.

## 문제 11.5

> 그림 11.2와 결합해 $\text{L}_1$ 정규화가 어떤 상황에서 희소해를 생성할 수 없는지 예를 들어 설명하라.

**풀이**

그림 11.2에서 식 11.7의 해는 제곱 오차 항의 등치선과 $\text{L}_1$ 노름 등치선(마름모)이 처음 만나는 점입니다. 마름모의 꼭짓점은 좌표축 위에 있으므로 꼭짓점에서 만나면 $w_1$이나 $w_2$가 0인 희소해가 됩니다. 반대로 **마름모의 변 내부에서 만나면** 두 성분이 모두 0이 아니므로 희소해가 나오지 않습니다. 변 내부에서 만나는 대표적인 상황은 두 가지입니다.

**상황 1: 정규화가 약해서 등치선의 중심이 두 축에서 모두 멀리 있을 때**

직교하는 두 특성 $\boldsymbol{x}_1 = (1, 0)$, $\boldsymbol{x}_2 = (0, 1)$과 $y_1 = y_2 = 1$을 생각합니다. 식 11.7의 목적 함수는

$$(1 - w_1)^2 + (1 - w_2)^2 + \lambda(|w_1| + |w_2|)$$

이고 각 성분이 분리되므로, 문제 11.8과 같은 방법으로 $w_j = \operatorname{sign}(\hat{w}_j)\max(|\hat{w}_j| - \lambda/2,\ 0)$을 얻습니다. 여기서 $\hat{w} = (1, 1)$은 제곱 오차만 최소화한 해입니다. $\lambda = 1$이면 $\boldsymbol{w} = (0.5, 0.5)$로 희소하지 않습니다. 등치선은 $(1,1)$을 중심으로 하는 원이고, 원이 마름모와 처음 닿는 곳은 $w_1 = w_2$ 방향의 변 한가운데입니다. 같은 설정에서 $\boldsymbol{y} = (2, 0.3)$이면 $\hat{w} = (2, 0.3)$이고 $|0.3| \le \lambda / 2$이므로 $\boldsymbol{w} = (1.5, 0)$으로 희소해가 나옵니다. 즉 이 경우 $|\hat{w}_j| > \lambda/2$인 성분은 모두 살아남으므로, 모든 성분의 크기가 $\lambda/2$보다 크면 희소해가 생기지 않습니다.

**상황 2: 등치선 타원이 마름모의 변과 나란할 때**

두 특성이 강하게 상관된 경우입니다. 샘플 세 개 $\boldsymbol{x} = (1, 1), (1, 0.9), (0.9, 1)$에 $y = w_1 x_1 + w_2 x_2$, $(w_1, w_2) = (1, 1)$로 $\boldsymbol{y} = (2, 1.9, 1.9)$를 만듭니다.

$$\mathbf{X}^{\mathrm{T}}\mathbf{X} = \begin{pmatrix} 2.81 & 2.80 \\ 2.80 & 2.81 \end{pmatrix}
$$
의 고윳값은 $(1,1)$ 방향으로 5.61, $(1,-1)$ 방향으로 0.01입니다. 그래서 제곱 오차의 등치선은 $(1,-1)$ 방향으로 아주 길쭉한 타원이고, 이 방향은 1사분면에 있는 마름모의 변 $w_1 + w_2 = c$와 나란합니다. 타원이 변에 나란히 닿으므로 접점은 변 내부가 됩니다.

실제로 대칭성 때문에 해는 $w_1 = w_2 = t$이고, 이때 오차 항은 $(1-t)^2\|\boldsymbol{y}\|^2 = 11.22(1-t)^2$, 정규화 항은 $2\lambda t$이므로 $t = 1 - \lambda / 11.22$입니다. KKT 조건 $2\boldsymbol{x}_{(j)}^{\mathrm{T}}(\boldsymbol{y} - \mathbf{X}\boldsymbol{w}) = \lambda$($\boldsymbol{x}_{(j)}$는 $j$번째 열)도 $2(1-t) \times 5.61 = \lambda$로 성립합니다. 따라서 $\lambda < 11.22$이면 두 계수가 항상 같은 크기로 함께 남고, $\lambda \ge 11.22$가 되어야 한꺼번에 0이 됩니다. 근위 경사하강법(문제 11.8의 코드)으로 확인하면 $\lambda = 0.5$에서 $(0.9554, 0.9554)$, $\lambda = 2$에서 $(0.8217, 0.8217)$로 식과 일치합니다.

일반적으로 $\text{L}_1$ 정규화의 해에서 $w_j = 0$이 되려면 KKT 조건 $|2\boldsymbol{x}_{(j)}^{\mathrm{T}}(\boldsymbol{y} - \mathbf{X}\boldsymbol{w})| \le \lambda$를 만족해야 합니다. 모든 특성이 잔차와 이보다 강하게 상관되어 있으면, 즉 정규화가 약하거나 모든 특성이 고르게 중요하면 $\text{L}_1$ 정규화도 희소해를 만들지 못합니다.

## 문제 11.6

> 능형 회귀와 서포트 벡터 머신 사이의 관계에 대해 분석하라.

**풀이**

**1. 같은 틀(식 6.42) 안의 두 모델입니다.**

$$\text{능형 회귀(식 11.6)}: \min_{\boldsymbol{w}} \sum_{i=1}^m (y_i - \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i)^2 + \lambda\|\boldsymbol{w}\|_2^2$$

$$\text{서포트 벡터 머신(식 6.34)}: \min_{\boldsymbol{w}, b} \frac{1}{2}\|\boldsymbol{w}\|^2 + C\sum_{i=1}^m \max\left(0,\ 1 - y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b)\right)$$

서포트 벡터 머신의 목적 함수를 $C$로 나누면 $\sum_i \ell_{\text{hinge}} + \frac{1}{2C}\|\boldsymbol{w}\|^2$이 됩니다. 둘 다 "경험적 위험 + $\text{L}_2$ 정규화 항(구조적 위험)" 꼴이고, 정규화 강도는 $\lambda \leftrightarrow 1/(2C)$로 대응합니다. 차이는 손실 함수뿐입니다. 능형 회귀는 제곱 손실, 서포트 벡터 머신은 힌지 손실을 씁니다. 둘 다 $\text{L}_2$ 정규화이므로 특성 측면의 희소성(일부 $w_j = 0$)은 만들지 않습니다.

**2. 힌지 손실을 제곱 손실로 바꾸면 서포트 벡터 머신은 능형 회귀가 됩니다.**

클래스를 $y_i \in \{-1, +1\}$로 두면 $y_i^2 = 1$이므로

$$\left(1 - y_i f(\boldsymbol{x}_i)\right)^2 = y_i^2\left(y_i - f(\boldsymbol{x}_i)\right)^2 = \left(y_i - f(\boldsymbol{x}_i)\right)^2$$

입니다. 그래서 서포트 벡터 머신의 부등식 제약 $y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b) \ge 1 - \xi_i$를 등식 $y_i(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b) = 1 - e_i$로 바꾸고 $\sum \xi_i$ 대신 $\frac{1}{2}\sum e_i^2$을 벌점으로 쓰는 최소제곱 서포트 벡터 머신(LS-SVM)은, 레이블 $\pm 1$을 회귀 목표로 하는 능형 회귀($\lambda = 1/C$, 절편은 정규화하지 않음)와 같은 문제입니다. 유방암 데이터(sklearn `load_breast_cancer`, 569개, 30개 특성, 표준화)에 $C = 1$로 확인하면 능형 회귀의 정규방정식 해와 LS-SVM 쌍대문제의 선형 시스템 해에서 얻은 $\boldsymbol{w}$의 차이는 최대 $6.3 \times 10^{-14}$로, 수치 오차 범위에서 같았습니다.

**3. 쌍대 형태와 커널화에서 보면 해의 꼴은 같고 희소성이 다릅니다.**

능형 회귀의 해는 $\boldsymbol{w} = (\mathbf{X}^{\mathrm{T}}\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^{\mathrm{T}}\boldsymbol{y}$이고, 항등식 $(\mathbf{X}^{\mathrm{T}}\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^{\mathrm{T}} = \mathbf{X}^{\mathrm{T}}(\mathbf{X}\mathbf{X}^{\mathrm{T}} + \lambda\mathbf{I})^{-1}$을 쓰면

$$\boldsymbol{w} = \sum_{i=1}^m \alpha_i \boldsymbol{x}_i, \qquad \boldsymbol{\alpha} = (\mathbf{K} + \lambda\mathbf{I})^{-1}\boldsymbol{y}, \quad \mathbf{K}_{ij} = \boldsymbol{x}_i^{\mathrm{T}}\boldsymbol{x}_j$$

입니다. 서포트 벡터 머신의 해도 $\boldsymbol{w} = \sum_i \alpha_i y_i \boldsymbol{x}_i$ 꼴이고, 두 모델 모두 내적을 커널 함수로 바꿔 커널 능형 회귀와 커널 서포트 벡터 머신으로 확장됩니다. 이것은 6장의 표현정리(정리 6.1)가 말하는 결과와 같습니다.

차이는 $\boldsymbol{\alpha}$의 희소성입니다. 힌지 손실은 $y_i f(\boldsymbol{x}_i) \ge 1$인 샘플에서 0이므로 그런 샘플의 $\alpha_i$는 0이 되고, 서포트 벡터만 해에 남습니다. 제곱 손실은 마진 바깥에서 잘 맞힌 샘플에도 손실을 주므로 거의 모든 $\alpha_i$가 0이 아닙니다. 같은 유방암 데이터에서 LS-SVM(능형 회귀)의 $\alpha_i$는 569개 모두 0이 아니었고, 선형 커널 서포트 벡터 머신($C = 1$)의 서포트 벡터는 40개였습니다. 그래서 예측할 때 서포트 벡터 머신이 더 가볍습니다. 대신 능형 회귀는 해가 닫힌 형태(선형 시스템 하나)로 구해지고, 서포트 벡터 머신은 이차 계획 문제를 풀어야 합니다.

| 항목 | 능형 회귀 | 서포트 벡터 머신 |
|---|---|---|
| 손실 | 제곱 손실 | 힌지 손실 |
| 정규화 | $\lambda\|\boldsymbol{w}\|_2^2$ | $\frac{1}{2}\|\boldsymbol{w}\|^2$ ($\lambda \leftrightarrow 1/(2C)$) |
| 해 구하기 | 닫힌 해 | 이차 계획(쌍대문제) |
| 쌍대 계수 $\alpha_i$ | 대부분 0이 아님 | 서포트 벡터만 0이 아님 |
| 커널화 | 커널 능형 회귀 | 커널 서포트 벡터 머신 |

회귀 쪽에서는 서포트 벡터 회귀(6.5절)가 같은 관계에 있습니다. 서포트 벡터 회귀는 $\epsilon$-불감 손실을 쓰기 때문에 $\epsilon$ 간격 안에 있는 샘플의 계수가 0이 되고, 제곱 손실을 쓰는 능형 회귀는 그렇지 않습니다.

## 문제 11.7

> $\text{L}_0$ 노름 정규화의 해를 직접 구할 때 부딪칠 수 있는 어려움을 설명하라.

**풀이**

$\text{L}_0$ 노름 정규화 문제는

$$\min_{\boldsymbol{w}} \sum_{i=1}^m (y_i - \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i)^2 + \lambda\|\boldsymbol{w}\|_0$$

이고, $\|\boldsymbol{w}\|_0$은 0이 아닌 성분의 개수입니다. 직접 풀 때의 어려움은 다음과 같습니다.

**1. 비볼록입니다.** $\boldsymbol{w} = (1, 0)$, $\boldsymbol{w}' = (0, 1)$이면 $\|\boldsymbol{w}\|_0 = \|\boldsymbol{w}'\|_0 = 1$인데 중점 $(0.5, 0.5)$는 $\|\cdot\|_0 = 2$입니다. 볼록 함수라면 중점의 값이 1 이하여야 하므로 볼록이 아닙니다. 따라서 지역 최적해가 전역 최적해라는 보장이 없고, 볼록 최적화 이론과 알고리즘을 쓸 수 없습니다. 엄밀히는 $\|c\boldsymbol{w}\|_0 = \|\boldsymbol{w}\|_0$이라 노름의 성질(동차성)도 만족하지 않습니다.

**2. 불연속이고 기울기 정보가 없습니다.** $\|\boldsymbol{w}\|_0$은 각 성분이 0에서 0이 아닌 값으로 바뀌는 순간 1씩 뛰는 계단 함수입니다. 0이 아닌 곳에서는 기울기가 0이고 0에서는 미분이 정의되지 않습니다. 그래서 경사하강법이나 근위 경사하강법이 "어느 성분을 0으로 만들어야 하는지"에 대한 정보를 얻지 못합니다.

**3. 조합 최적화 문제가 되어 계산량이 지수적으로 늘어납니다.** 0이 아닌 성분의 위치(support) $S$를 정하면 나머지는 $S$ 위의 최소제곱 문제이므로, 정확한 해를 구하려면 가능한 $S$를 모두 시도해야 합니다. 그 수는 $\sum_{s=0}^d \binom{d}{s} = 2^d$입니다. $d = 30$이면 약 $10^9$개, $d = 100$이면 약 $1.3 \times 10^{30}$개의 최소제곱 문제를 풀어야 합니다. 11.6절에서 말한 것처럼 $\text{L}_0$ 노름 최소화는 일반적으로 NP-hard 문제입니다.

**4. 근사 알고리즘은 국소해에 머물고 결과가 불안정합니다.** 근위 경사하강법을 흉내 내면 $\text{L}_0$의 근위 연산은 $|z^i| > \sqrt{2\lambda/L}$이면 $z^i$를 그대로, 아니면 0으로 두는 하드 임계(hard thresholding)가 됩니다. 계산은 쉽지만 비볼록이므로 초깃값에 따라 다른 국소해로 수렴합니다. 또 해가 데이터와 $\lambda$에 대해 불연속으로 변해서, 샘플 하나나 $\lambda$가 조금만 바뀌어도 선택되는 특성이 통째로 바뀔 수 있습니다.

이런 이유로 실제로는 탐욕적 방법(순방향 탐색, OMP 등)으로 근사하거나, $\text{L}_0$ 노름을 볼록 함수인 $\text{L}_1$ 노름으로 완화해 풉니다(LASSO, 식 11.7). $\|\boldsymbol{w}\|_\infty \le 1$인 범위에서 $\text{L}_1$ 노름은 $\text{L}_0$ 노름보다 크지 않은 볼록 함수 가운데 가장 큰 것(볼록 포락선)이므로, 볼록 함수로 바꿀 때 가장 자연스러운 선택입니다. 11.6절의 설명처럼 일정한 조건(예: RIP)에서는 $\text{L}_1$ 노름 최소화가 $\text{L}_0$ 노름 최소화와 같은 해를 줍니다.

## 문제 11.8

> $\text{L}_1$ 노름 최소화 문제에서 닫힌 형태(식 11.14)의 해를 구하는 상세한 유도 과정을 서술하라.

**풀이**

**0단계: 식 11.13의 $\boldsymbol{z}$가 무엇인지 확인합니다.**

식 11.10의 둘째 줄은 첫째 줄에서 제곱을 완성한 것입니다. $\boldsymbol{g} = \nabla f(\boldsymbol{x}_k)$로 두면

$$\frac{L}{2}\left\|\boldsymbol{x} - \left(\boldsymbol{x}_k - \frac{1}{L}\boldsymbol{g}\right)\right\|_2^2 = \frac{L}{2}\|\boldsymbol{x} - \boldsymbol{x}_k\|_2^2 + \langle \boldsymbol{g}, \boldsymbol{x} - \boldsymbol{x}_k \rangle + \frac{1}{2L}\|\boldsymbol{g}\|_2^2$$

이므로 $\hat{f}(\boldsymbol{x})$에서 $\boldsymbol{x}$와 무관한 $f(\boldsymbol{x}_k) - \frac{1}{2L}\|\boldsymbol{g}\|_2^2$를 const로 묶으면 식 11.10이 됩니다. 식 11.12는 여기에 $\lambda\|\boldsymbol{x}\|_1$을 더한 것이고,

$$\boldsymbol{z} = \boldsymbol{x}_k - \frac{1}{L}\nabla f(\boldsymbol{x}_k)$$

로 두면 식 11.13이 됩니다. 즉 $\boldsymbol{z}$는 보통의 경사하강법 한 걸음(식 11.11)을 간 점이고, 식 11.13은 "$\boldsymbol{z}$에 가까우면서 $\text{L}_1$ 노름이 작은 점"을 찾는 문제입니다. 아래에서는 $L > 0$, $\lambda > 0$입니다.

**1단계: 성분별로 분리합니다.**

$$\frac{L}{2}\|\boldsymbol{x} - \boldsymbol{z}\|_2^2 + \lambda\|\boldsymbol{x}\|_1 = \sum_{i=1}^d \left[\frac{L}{2}(x^i - z^i)^2 + \lambda|x^i|\right]$$

우변의 각 항은 $x^i$ 하나에만 의존하고 $x^i x^j\ (i \ne j)$ 같은 교차 항이 없습니다. 따라서 전체를 최소화하는 것은 각 $i$에 대해 다음 일변수 문제를 따로 최소화하는 것과 같습니다.

$$g(x) = \frac{L}{2}(x - z)^2 + \lambda|x| \qquad (x = x^i,\ z = z^i)$$

**2단계: 최솟값은 하나뿐입니다.**

$\frac{L}{2}(x-z)^2$은 강볼록이고 $\lambda|x|$는 볼록이므로 $g$는 강볼록입니다. 또 $|x| \to \infty$이면 $g(x) \to \infty$입니다. 따라서 $g$의 최솟점은 존재하고 유일하며, 볼록 함수이므로 국소 최솟점이면 곧 전역 최솟점입니다.

**3단계: 경우를 나눕니다.**

(a) $x > 0$인 영역에서는 $|x| = x$이므로 $g$는 미분 가능하고

$$g'(x) = L(x - z) + \lambda = 0 \;\Rightarrow\; x = z - \frac{\lambda}{L}$$

입니다. 이 점이 실제로 $x > 0$ 영역에 있으려면 $z - \lambda/L > 0$, 즉 $z > \lambda/L$이어야 합니다. 이때 $x^* = z - \lambda/L$은 $g$가 미분 가능한 열린 구간 안의 정류점이므로 국소 최솟점이고, 2단계에 의해 전역 최솟점입니다.

(b) $x < 0$인 영역에서는 $|x| = -x$이므로

$$g'(x) = L(x - z) - \lambda = 0 \;\Rightarrow\; x = z + \frac{\lambda}{L}$$

이고, $x < 0$이려면 $z < -\lambda/L$이어야 합니다. 같은 이유로 이때 $x^* = z + \lambda/L$이 전역 최솟점입니다.

(c) $|z| \le \lambda/L$이면 $x^* = 0$입니다. 미분이 정의되지 않는 점이므로 직접 비교합니다. 모든 $x$에 대해

$$g(x) - g(0) = \frac{L}{2}x^2 - Lzx + \lambda|x| \;\ge\; \frac{L}{2}x^2 - L|z||x| + \lambda|x| = \frac{L}{2}x^2 + |x|\,(\lambda - L|z|) \;\ge\; 0$$

입니다. 첫 번째 부등호는 $zx \le |z||x|$에서, 두 번째 부등호는 $\lambda - L|z| \ge 0$에서 나옵니다. 따라서 $x = 0$이 최솟점입니다. (같은 결론을 부분 미분으로 쓰면 $\partial g(0) = \{-Lz + \lambda s : s \in [-1, 1]\}$이고, $0 \in \partial g(0) \iff |z| \le \lambda/L$입니다.)

세 경우 $z > \lambda/L$, $z < -\lambda/L$, $|z| \le \lambda/L$은 실수 전체를 빠짐없이 겹치지 않게 나누고, 각 경우의 최솟점이 유일하므로 다음 식 11.14를 얻습니다.

$$x_{k+1}^i = \begin{cases} z^i - \lambda/L, & \lambda/L < z^i \\ 0, & |z^i| \le \lambda/L \\ z^i + \lambda/L, & z^i < -\lambda/L \end{cases}
$$
한 줄로 쓰면 $x_{k+1}^i = \operatorname{sign}(z^i)\max(|z^i| - \lambda/L,\ 0)$이고, 이를 소프트 임계(soft thresholding) 연산이라고 부릅니다. $|z^i|$가 $\lambda/L$ 이하인 성분은 정확히 0이 되므로 PGD의 반복 결과가 희소해집니다.

**확인: PGD로 LASSO 풀기**

식 11.7에서 $f(\boldsymbol{w}) = \|\boldsymbol{y} - \mathbf{X}\boldsymbol{w}\|_2^2$이면 $\nabla f = -2\mathbf{X}^{\mathrm{T}}(\boldsymbol{y} - \mathbf{X}\boldsymbol{w})$이고, 립시츠 상수는 $L = 2\lambda_{\max}(\mathbf{X}^{\mathrm{T}}\mathbf{X})$로 잡을 수 있습니다. 수박 데이터 세트 3.0의 이산 속성을 원-핫 인코딩해 17개 열을 만들고 밀도·당도를 더한 19개 특성을 표준화한 뒤, 레이블(1/0)을 중심화해 절편 없이 풀었습니다.

```python
def soft(z, t):                                  # 식 11.14
    return np.sign(z) * np.maximum(np.abs(z) - t, 0.0)

def lasso_pgd(X, y, lam, iters=20000):
    """식 11.7: min ||y - Xw||^2 + lam*||w||_1"""
    L = 2 * np.linalg.eigvalsh(X.T @ X).max()    # grad f 의 립시츠 상수
    w = np.zeros(X.shape[1])
    for _ in range(iters):
        z = w - (-2 * X.T @ (y - X @ w)) / L     # z = x_k - (1/L) grad f(x_k)
        w = soft(z, lam / L)                     # 식 11.13 -> 식 11.14
    return w

names, F = [], []
for j in range(6):                               # 이산 속성 원-핫 인코딩
    for v in np.unique(Xd[:, j]):
        names.append(f"{cols[j]}={v}"); F.append((Xd[:, j] == v).astype(float))
names += cols[6:]; F += [Xc[:, 0], Xc[:, 1]]
X = np.array(F).T; X = (X - X.mean(0)) / X.std(0); yc = y - y.mean()
for lam in [1.0, 4.0, 8.0]:
    w = lasso_pgd(X, yc, lam)
    print(lam, [(names[k], round(w[k], 3)) for k in np.flatnonzero(np.abs(w) > 1e-8)])
```

| $\lambda$ | 0이 아닌 계수 (19개 중) |
|---|---|
| 1 | 7개: 줄무늬=선명함 0.175, 배꼽 모양=평평함 −0.179, 꼭지 모양=말림 0.066, 소리=혼탁 0.058, 줄무늬=약간흐림 −0.053, 색깔=진녹색 0.018, 배꼽 모양=움푹패임 0.013 |
| 4 | 2개: 줄무늬=선명함 0.181, 배꼽 모양=평평함 −0.087 |
| 8 | 1개: 줄무늬=선명함 0.091 |

$\lambda$가 커질수록 0이 아닌 계수가 줄어들고, 끝까지 남는 특성은 줄무늬=선명함입니다. 같은 문제를 sklearn의 `Lasso`(목적 함수 스케일이 달라 $\alpha = \lambda / (2m)$로 맞춤)로 풀어 비교하면 계수 차이는 세 경우 모두 $2 \times 10^{-12}$ 이하였습니다.

## 문제 11.9

> 사전 학습과 압축 센싱의 희소성 사용에 대한 차이점을 설명하라.

**풀이**

두 방법 모두 "신호를 어떤 기저(사전)의 소수 원자로 표현할 수 있다"는 희소성을 쓰고, 계산도 $\text{L}_1$ 노름 최소화로 비슷하게 풉니다. 차이는 희소성을 **만들어 내는가, 전제로 이용하는가**에 있습니다.

| 항목 | 사전 학습(11.5절) | 압축 센싱(11.6절) |
|---|---|---|
| 목적 | 조밀한 데이터에 맞는 희소 표현을 찾아 학습을 쉽게 함 | 적은 측정값으로 원래 신호를 복원함 |
| 희소성의 역할 | 학습으로 얻어 내는 결과물(만들어진 성질) | 신호가 원래 가지고 있다고 가정하는 사전 지식 |
| 관측 | 샘플 $\boldsymbol{x}_i$ 전체를 관측함 | $\boldsymbol{y} = \boldsymbol{\Phi}\boldsymbol{x}$만 관측($n \ll m$) |
| 사전/기저 | 데이터에서 사전 $\mathbf{B}$를 학습함 | 희소 기저 $\boldsymbol{\Psi}$는 보통 주어짐(푸리에, 웨이블릿 등), 측정 행렬 $\boldsymbol{\Phi}$는 설계함 |
| 최적화 변수 | $\mathbf{B}$와 $\boldsymbol{\alpha}_i$ 모두(식 11.15) | $\boldsymbol{s}$만($\mathbf{A} = \boldsymbol{\Phi}\boldsymbol{\Psi}$는 고정, 식 11.23) |
| 희소성이 하는 일 | 표현을 단순하게 하고 계산·저장 비용을 줄이며 해석력을 높임 | 부정 방정식 $\boldsymbol{y} = \mathbf{A}\boldsymbol{s}$의 해를 하나로 좁혀 줌 |
| 이론적 관심 | 재구성 오차와 희소성의 절충 | 정확한 복원 조건(RIP 등) |
| 결과물의 용도 | 희소 표현 $\boldsymbol{\alpha}_i$를 다음 학습기의 입력으로 씀 | 복원한 신호 $\boldsymbol{x} = \boldsymbol{\Psi}\boldsymbol{s}$ 자체 |

정리하면, 사전 학습에서 희소성은 데이터를 학습하기 좋은 형태로 **바꾸기 위해 부과하는 목표**이고, 압축 센싱에서 희소성은 정보가 부족한 복원 문제를 **풀 수 있게 해 주는 전제**입니다. 두 방법은 함께 쓰이기도 합니다. 신호가 고정된 기저에서는 희소하지 않을 때 사전 학습으로 얻은 $\mathbf{B}$를 압축 센싱의 $\boldsymbol{\Psi}$로 쓸 수 있고, 305쪽에서도 센싱 측정 단계의 관련 방법으로 사전 학습과 희소 코딩을 들고 있습니다.

## 문제 11.10\* (심화)

> 식 11.15를 개선해서 그룹 분리 희소성을 가진 사전을 학습하라.

**풀이**

11.7절에서 소개한 그룹 희소성(group sparsity)을 사전 학습에 넣는 문제로 해석합니다. 사전의 원자(열) $k$개를 미리 $G$개의 그룹 $\mathcal{G}_1, \dots, \mathcal{G}_G$로 나누고, 표현 $\boldsymbol{\alpha}_i$가 "원자 몇 개"가 아니라 "그룹 몇 개"만 쓰도록 만듭니다. 한 그룹을 쓰면 그 그룹의 원자들은 함께 쓰입니다.

**1. 목적 함수**

식 11.15의 $\text{L}_1$ 노름을 그룹별 $\text{L}_2$ 노름의 합($\text{L}_1$/$\text{L}_2$ 혼합 노름)으로 바꿉니다.

$$\min_{\mathbf{B}, \boldsymbol{\alpha}_i} \sum_{i=1}^m \|\boldsymbol{x}_i - \mathbf{B}\boldsymbol{\alpha}_i\|_2^2 + \lambda\sum_{i=1}^m \sum_{g=1}^G \|\boldsymbol{\alpha}_{i,g}\|_2 \qquad \text{s.t. } \|\boldsymbol{b}_j\|_2 \le 1,\ j = 1, \dots, k$$

여기서 $\boldsymbol{\alpha}_{i,g}$는 $\boldsymbol{\alpha}_i$에서 그룹 $g$에 속한 성분만 모은 벡터입니다. $\|\cdot\|_2$는 0에서만 미분이 안 되는 원뿔 모양이라, $\text{L}_1$ 노름이 성분을 정확히 0으로 만들듯 그룹 벡터 전체를 정확히 0으로 만듭니다. 그룹 안에서는 $\text{L}_2$ 노름이므로 성분끼리 희소해지지 않습니다. 그룹 크기가 1이면 식 11.15와 같아집니다. 원자 노름 제약은 식 11.15에도 암묵적으로 필요한 것으로, 없으면 $\mathbf{B}$를 키우고 $\boldsymbol{\alpha}_i$를 줄여 정규화 항을 얼마든지 작게 만들 수 있습니다.

**2. 1단계: $\mathbf{B}$를 고정하고 그룹 희소 코딩**

식 11.16에 해당하는 문제는 $\min_{\boldsymbol{\alpha}} \|\boldsymbol{x} - \mathbf{B}\boldsymbol{\alpha}\|_2^2 + \lambda\sum_g \|\boldsymbol{\alpha}_g\|_2$(그룹 LASSO)이고, 11.4절의 근위 경사하강법으로 풉니다. $\boldsymbol{z} = \boldsymbol{\alpha}_k - \frac{1}{L}\nabla f(\boldsymbol{\alpha}_k)$로 둔 뒤 식 11.13에 해당하는 문제는 그룹별로 분리되고, 각 그룹에서

$$\min_{\boldsymbol{v}} \frac{L}{2}\|\boldsymbol{v} - \boldsymbol{z}_g\|_2^2 + \lambda\|\boldsymbol{v}\|_2$$

를 풀면 됩니다. $\boldsymbol{v}$를 $\boldsymbol{z}_g$와 다른 방향으로 두면 같은 크기에서 첫 항만 커지므로 최솟점은 $\boldsymbol{v} = r\,\boldsymbol{z}_g / \|\boldsymbol{z}_g\|_2$ ($r \ge 0$) 꼴입니다. 이를 대입하면 $\frac{L}{2}(r - \|\boldsymbol{z}_g\|_2)^2 + \lambda r$을 $r \ge 0$에서 최소화하는 일변수 문제가 되고, 문제 11.8과 같은 계산으로 $r = \max(\|\boldsymbol{z}_g\|_2 - \lambda/L,\ 0)$입니다. 따라서

$$\boldsymbol{\alpha}_{k+1, g} = \max\left(1 - \frac{\lambda / L}{\|\boldsymbol{z}_g\|_2},\ 0\right)\boldsymbol{z}_g$$

입니다(블록 소프트 임계). $\|\boldsymbol{z}_g\|_2 \le \lambda / L$이면 그룹 전체가 0이 됩니다.

**3. 2단계: $\boldsymbol{\alpha}_i$를 고정하고 사전 갱신**

KSVD가 식 11.18에서 열 하나씩 갱신한 것처럼, 그룹 하나씩 갱신합니다. 그룹 $g$의 원자 행렬을 $\mathbf{B}_g$, $\mathbf{A}$에서 그룹 $g$에 해당하는 행들을 $\mathbf{A}_g$라 하면

$$\min_{\mathbf{B}_g} \|\mathbf{E}_g - \mathbf{B}_g\mathbf{A}_g\|_F^2, \qquad \mathbf{E}_g = \mathbf{X} - \sum_{h \ne g}\mathbf{B}_h\mathbf{A}_h$$

이고, 해는 $\mathbf{B}_g = \mathbf{E}_g\mathbf{A}_g^{\mathrm{T}}(\mathbf{A}_g\mathbf{A}_g^{\mathrm{T}})^{-1}$입니다. 그 뒤 각 원자를 단위 노름으로 나누고 그만큼 $\mathbf{A}$의 행에 곱해 $\mathbf{B}\mathbf{A}$를 유지합니다(노름 제약을 근사적으로 처리하는 흔한 방법입니다). 어떤 샘플도 쓰지 않는 그룹은 재구성 오차가 큰 샘플로 다시 초기화합니다.

```python
d, G, s = 16, 4, 3                             # 차원, 그룹 수, 그룹 크기
k = G * s; groups = np.arange(k).reshape(G, s)

def prox_group(Z, t):                          # 블록 소프트 임계
    Zg = Z.reshape(G, s, -1); n = np.linalg.norm(Zg, axis=1, keepdims=True)
    return (np.maximum(1 - t / np.maximum(n, 1e-12), 0) * Zg).reshape(k, -1)

def prox_l1(Z, t):                             # 식 11.14 (비교용, 식 11.15)
    return np.sign(Z) * np.maximum(np.abs(Z) - t, 0)

def sparse_code(X, B, lam, prox, A, iters=300):   # 1단계: 모든 alpha_i를 PGD로
    L = 2 * np.linalg.eigvalsh(B.T @ B).max()
    for _ in range(iters):
        A = prox(A - 2 * B.T @ (B @ A - X) / L, lam / L)
    return A

def dict_learn(X, lam, prox, n_outer=150, seed=0):
    r = np.random.default_rng(seed)
    B = X[:, r.choice(X.shape[1], k, replace=False)].copy(); B /= np.linalg.norm(B, axis=0)
    A = np.zeros((k, X.shape[1]))
    for _ in range(n_outer):
        A = sparse_code(X, B, lam, prox, A)
        for gr in groups:                      # 2단계: 그룹 단위 사전 갱신
            Ag = A[gr]
            if np.abs(Ag).sum() < 1e-10:       # 안 쓰이는 그룹은 재초기화
                i = np.argsort(-np.linalg.norm(X - B @ A, axis=0))[:s]
                B[:, gr] = X[:, i] / np.linalg.norm(X[:, i], axis=0); continue
            E = X - B @ A + B[:, gr] @ Ag      # 이 그룹이 설명할 잔차
            Bg = E @ Ag.T @ np.linalg.pinv(Ag @ Ag.T)
            n = np.linalg.norm(Bg, axis=0); n[n < 1e-12] = 1
            B[:, gr] = Bg / n; A[gr] = Ag * n[:, None]
    return B, sparse_code(X, B, lam, prox, A)
```

**4. 실험**

정답 구조를 알 수 있도록 합성 데이터를 만들었습니다(시드 0). 16차원에서 단위 노름 원자 12개를 3개씩 4그룹으로 나눈 실제 사전 $\mathbf{B}_0$를 만들고, 샘플 1,000개 각각은 그룹 하나를 무작위로 골라 그 그룹 원자 3개를 표준정규분포 계수로 섞은 뒤 표준편차 0.01의 잡음을 더했습니다. $\lambda = 0.5$, 바깥 반복 150회로 두고, 교대 최적화는 비볼록이라 초기 사전을 뽑는 시드 0~7로 8번 돌려 목적 함수가 가장 작은 결과를 골랐습니다. 같은 설정으로 식 11.15($\text{L}_1$)도 학습해 비교했습니다.

평가는 "실제 그룹이 생성하는 3차원 부분공간마다, 가장 가까운 학습 그룹의 부분공간과 이루는 주각(principal angle) 코사인의 최솟값"으로 했습니다. 그룹 안의 원자는 회전해도 같은 부분공간을 만들므로 원자 하나하나보다 부분공간을 비교하는 것이 맞습니다. 1이면 부분공간이 정확히 일치합니다.

| 항목 | 식 11.15 ($\text{L}_1$) | 그룹 희소 |
|---|---|---|
| 샘플당 0이 아닌 계수 수 | 2.48 | 2.98 |
| 샘플당 활성 그룹 수 (실제 1) | 2.07 | 0.99 |
| 활성 그룹에서 원자 3개를 모두 쓰는 비율 | 0.00 | 1.00 |
| 재구성 상대 오차 $\|\mathbf{X} - \mathbf{B}\mathbf{A}\|_F / \|\mathbf{X}\|_F$ | 0.230 | 0.147 |
| 실제 그룹 4개의 부분공간 일치도 | 0.37, 0.30, 0.08, 0.18 | 1.000, 1.000, 1.000, 1.000 |

그룹 희소 사전은 샘플마다 거의 정확히 그룹 하나만 쓰고, 쓰는 그룹의 원자는 모두 함께 씁니다. 학습된 4개 그룹의 부분공간은 실제 그룹과 일치했습니다. $\text{L}_1$은 원자를 개별적으로 고르므로 계수 개수는 비슷하게 적어도 원자들이 그룹 구조와 무관하게 흩어집니다. $\text{L}_1$ 쪽의 낮은 일치도는 $\text{L}_1$이 그룹 번호를 쓰지 않으니 당연한 결과이고, 요점은 그룹 정규화를 넣어야 그룹 구조가 사전에 반영된다는 것입니다. 재구성 오차가 0이 아닌 이유는 $\lambda$에 의한 축소(shrinkage) 편향 때문이며, 활성 그룹 수가 1보다 약간 작은 것은 노름이 작은 몇몇 샘플의 표현이 통째로 0이 되었기 때문입니다.

주의할 점도 있습니다. 8번의 시작 가운데 실제 구조를 모두 찾은 것은 목적 함수가 가장 작았던 시드 0(목적 함수 739.9) 하나였고, 나머지 7번(807.6~868.8)은 그룹 1~2개만 맞힌 국소해에 머물렀습니다. 그래서 여러 번 시작해 목적 함수가 가장 작은 결과를 고르는 과정이 필요합니다.

**5. 다른 형태의 그룹 희소성**

11.7절에서 인용한 [Bengio et al., 2009]의 그룹 희소 코딩은 그룹을 원자가 아니라 샘플 쪽에 둡니다. 예를 들어 이미지 하나에서 나온 패치들 $\{\boldsymbol{x}_i\}_{i \in I}$를 한 그룹으로 보고, 그 그룹의 표현 행렬 $\mathbf{A}_I$에 대해 $\sum_{j=1}^k \|\boldsymbol{\alpha}^j_I\|_2$($\boldsymbol{\alpha}^j_I$는 $\mathbf{A}_I$의 $j$번째 행)를 벌점으로 씁니다. 그러면 같은 그룹의 샘플들이 같은 원자 집합을 공유하게 됩니다. 1단계의 근위 연산이 행 단위 블록 소프트 임계로 바뀔 뿐 풀이 구조는 위와 같습니다. 문제의 "그룹 분리 희소성"이 어느 쪽을 뜻하는지는 문맥상 하나로 정해지지 않아, 여기서는 원자 그룹 형태로 구현하고 이 변형을 함께 적었습니다.
