## 문제 6.1

> 샘플 공간의 임의의 점 $\boldsymbol{x}$에서 초평면$(\boldsymbol{w}, b)$ 사이의 거리는 식 6.2임을 증명하라.

**풀이**

초평면을 $H = \{\boldsymbol{z} \mid \boldsymbol{w}^{\mathrm{T}}\boldsymbol{z} + b = 0\}$ ($\boldsymbol{w} \neq \boldsymbol{0}$)라 하고, 점 $\boldsymbol{x}$와 $H$ 사이의 거리를 "$\boldsymbol{x}$에서 $H$ 위의 점까지 거리 중 가장 짧은 것"으로 정의합니다.

$$
r = \min_{\boldsymbol{z} \in H} \lVert \boldsymbol{x} - \boldsymbol{z} \rVert
$$

이 최솟값이 식 6.2의 $\dfrac{|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b|}{\lVert \boldsymbol{w} \rVert}$와 같다는 것을 하한과 등호 달성 두 단계로 보이겠습니다.

**Step 1. 하한.** $H$ 위의 임의의 점 $\boldsymbol{z}$는 $\boldsymbol{w}^{\mathrm{T}}\boldsymbol{z} = -b$를 만족합니다. 따라서

$$
\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b = \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} - \boldsymbol{w}^{\mathrm{T}}\boldsymbol{z} = \boldsymbol{w}^{\mathrm{T}}(\boldsymbol{x} - \boldsymbol{z})
$$

입니다. 코시-슈바르츠 부등식 $|\boldsymbol{a}^{\mathrm{T}}\boldsymbol{c}| \le \lVert \boldsymbol{a} \rVert \lVert \boldsymbol{c} \rVert$를 쓰면

$$
|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b| = |\boldsymbol{w}^{\mathrm{T}}(\boldsymbol{x} - \boldsymbol{z})| \le \lVert \boldsymbol{w} \rVert \, \lVert \boldsymbol{x} - \boldsymbol{z} \rVert
\quad\Longrightarrow\quad
\lVert \boldsymbol{x} - \boldsymbol{z} \rVert \ge \frac{|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b|}{\lVert \boldsymbol{w} \rVert}
$$

가 모든 $\boldsymbol{z} \in H$에 대해 성립합니다.

**Step 2. 등호를 만드는 점.** 코시-슈바르츠의 등호는 $\boldsymbol{x} - \boldsymbol{z}$가 $\boldsymbol{w}$와 평행할 때 성립하므로, $\boldsymbol{x}$에서 $\boldsymbol{w}$ 방향으로 내린 점을 잡습니다.

$$
\boldsymbol{z}^* = \boldsymbol{x} - \frac{\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b}{\lVert \boldsymbol{w} \rVert^2}\,\boldsymbol{w}
$$

이 점이 $H$ 위에 있는지 확인합니다.

$$
\boldsymbol{w}^{\mathrm{T}}\boldsymbol{z}^* + b = \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} - \frac{\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b}{\lVert \boldsymbol{w} \rVert^2}\,\boldsymbol{w}^{\mathrm{T}}\boldsymbol{w} + b = \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} - (\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b) + b = 0
$$

그리고 거리는

$$
\lVert \boldsymbol{x} - \boldsymbol{z}^* \rVert = \frac{|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b|}{\lVert \boldsymbol{w} \rVert^2}\,\lVert \boldsymbol{w} \rVert = \frac{|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b|}{\lVert \boldsymbol{w} \rVert}
$$

로 Step 1의 하한과 정확히 같습니다.

**결론.** 하한이 실제로 달성되므로

$$
r = \min_{\boldsymbol{z} \in H} \lVert \boldsymbol{x} - \boldsymbol{z} \rVert = \frac{|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b|}{\lVert \boldsymbol{w} \rVert}
$$

이고, 이것이 식 6.2입니다. $\boldsymbol{z}^*$는 $\boldsymbol{x}$를 초평면에 정사영한 점(수선의 발)입니다. 절댓값을 떼어 낸 $\dfrac{\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b}{\lVert \boldsymbol{w} \rVert}$는 부호가 있는 거리로, 양수이면 $\boldsymbol{x}$가 $\boldsymbol{w}$가 가리키는 쪽에 있다는 뜻입니다. 서포트 벡터는 $|\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b| = 1$을 만족하므로 초평면까지 거리가 각각 $1/\lVert \boldsymbol{w} \rVert$이고, 양쪽을 더한 것이 식 6.4의 마진 $\gamma = 2/\lVert \boldsymbol{w} \rVert$입니다.

## 문제 6.2

> LIBSVM을 사용하고, 수박 데이터 세트 3.0$\alpha$상에서 선형 커널과 가우스 커널을 사용하여 SVM을 훈련하라. 그리고 각 서포트 벡터의 차이에 대해 비교하라.

**풀이**

17개 샘플 전체로 소프트 마진 SVM(식 6.35)을 훈련하고, $C$와 가우스 커널의 $\gamma$를 바꿔 가며 서포트 벡터(SV)를 기록했습니다. 입력은 표 그대로(밀도, 당도 모두 0~1 범위) 썼고, 해를 정확히 보기 위해 LIBSVM의 종료 허용 오차를 `tol=1e-8`로 낮췄습니다.

```python
import numpy as np
from sklearn.svm import SVC
from wm import X, y
for C in [1, 10, 100, 1000, 1e4]:
    for kern, kw in [("linear", {}), ("rbf", {"gamma": 1}), ("rbf", {"gamma": 10}), ("rbf", {"gamma": 100})]:
        m = SVC(kernel=kern, C=C, tol=1e-8, **kw).fit(X, y)
        sv = m.support_ + 1
        a = np.abs(m.dual_coef_[0])
        bound = [int(i) for i, ai in zip(sv, a) if np.isclose(ai, C)]
        print(f"C={C:<6} {kern:6} {kw}  nSV={len(sv):2d}  acc={m.score(X,y):.3f}  SV={sorted(sv.tolist())}  alpha=C:{sorted(bound)}")
```

**선형 커널 ($C=100$).** 얻은 초평면은 $\boldsymbol{w} = (0.220,\ 8.867)$, $b = -1.953$입니다. 당도 계수가 밀도 계수의 약 40배이므로 경계는 "당도 $\approx 0.22 - 0.025 \times$ 밀도", 즉 당도 0.22 근처의 거의 수평인 직선입니다. 7, 10, 15번 세 개를 틀려 훈련 정확도는 14/17입니다. SV 13개 가운데 마진 경계 위에 정확히 놓인 것($0 < \alpha_i < C$, $y_i f(\boldsymbol{x}_i) = 1$)은 4, 9, 12번 셋뿐이고, 나머지 10개는 $\alpha_i = C$로 마진 안쪽에 들어왔거나 아예 잘못 분류된 샘플입니다. 수박 데이터 세트 3.0α는 직선 하나로 나눌 수 없기 때문에 $C$를 $10^4$까지 키워도 SV가 12개 아래로 줄지 않고 정확도도 0.824에 머뭅니다. $C=1$에서는 $\boldsymbol{w}$가 너무 작아져서 모든 샘플을 음성(다수 클래스, 9/17 = 0.529)으로 예측합니다.

**가우스 커널 ($\gamma=10$, $C=100$).** SV는 2, 3, 6, 7번(양성)과 12, 14, 15번(음성) 7개이고, 7개 모두 $0 < \alpha_i < C$, $y_i f(\boldsymbol{x}_i) = 1.000$으로 마진 경계 위에 정확히 놓여 있습니다. 즉 특성 공간에서 훈련 데이터가 완전히 분리되어 사실상 하드 마진 해가 되었고, $C$를 $10^4$까지 키워도 SV 집합이 변하지 않습니다.

**두 커널의 서포트 벡터 비교.**

- **개수.** 선형 커널은 데이터를 분리하지 못하므로 틀린 샘플과 마진 침범 샘플이 모두 $\alpha_i = C$인 SV가 되어 13개나 됩니다. 가우스 커널은 분리에 성공해 마진 경계 위의 7개만 SV로 남습니다.
- **구성.** 두 집합의 공통 SV는 3, 6, 7, 12, 14, 15번 여섯 개로, 두 클래스가 맞닿아 있는 영역의 샘플은 어느 커널에서든 SV가 됩니다. 선형 커널에서만 SV인 4, 5, 8, 9, 10, 13, 17번은 직선으로는 제대로 나뉘지 않아 마진 안쪽에 들어왔거나(10번은 잘못 분류) 직선 경계 가까이에 놓인 샘플인데, 가우스 커널의 곡선 경계에서는 $y_i f(\boldsymbol{x}_i) \ge 1$을 만족해 SV에서 빠집니다. 반대로 2번은 가우스 커널에서만 SV입니다. 가우스 커널의 경계는 샘플 주변의 국소적인 모양을 따르므로, 직선 경계에서는 멀리 떨어져 있던 샘플도 곡선 경계에서는 마진 경계 위에 놓일 수 있습니다.
- **의미.** 선형 커널 SV의 대부분은 $\alpha_i = C$인 "오류 쪽" SV이고, 가우스 커널 SV는 모두 경계 위의 "자유" SV입니다. 다만 가우스 커널의 SV 수는 $\gamma$에 민감해서, $\gamma=100$처럼 커널 폭을 너무 좁히면 각 샘플이 자기 주변만 설명하게 되어 SV가 다시 13개로 늘어납니다. 17개 샘플로 훈련 정확도 100%를 얻은 것은 과적합일 가능성이 크므로, 실제로 커널과 $\gamma$, $C$를 고를 때는 교차 검증으로 판단해야 합니다.

## 문제 6.3

> 두 개의 UCI 데이터 세트를 선택하여 선형 커널과 가우스 커널을 사용하여 SVM을 훈련하고 BP 신경망, C4.5 의사결정 트리와 비교하라.

**풀이**

인터넷 다운로드 없이 재현할 수 있도록 scikit-learn에 내장된 UCI 데이터 세트 두 개를 골랐습니다.

- **iris**: 150개 샘플, 속성 4개, 3클래스(각 50개)
- **breast_cancer** (Breast Cancer Wisconsin Diagnostic): 569개 샘플, 속성 30개, 2클래스(212/357)

실험 설정은 다음과 같습니다.

- 평가: 10겹 계층 교차 검증(`StratifiedKFold`, `shuffle=True`, `random_state=0`). 모든 모델이 같은 분할을 씁니다.
- SVM: 표준화 후 `SVC`, $C=1$. 가우스 커널의 $\gamma$는 `gamma="scale"`(표준화 후에는 $1/d$)입니다. iris처럼 다중 클래스이면 LIBSVM이 일대일(OvO) 방식으로 처리합니다.
- BP 신경망: 표준화 후 은닉층 1개(뉴런 10개), 오차 역전파 + 확률적 경사하강법(학습률 0.1, 모멘텀 0.9), 최대 2000 에포크, `random_state=0`.
- C4.5: scikit-learn에는 C4.5가 없어서 4장 방식대로 직접 구현했습니다. 연속 속성을 이분법(4.4.1절)으로 나누고, 정보 이득이 평균 이상인 속성 중에서 이득율이 가장 큰 것을 고르는 휴리스틱(4.2.2절)을 씁니다. 가지치기는 하지 않았습니다. 참고용으로 scikit-learn의 엔트로피 기준 의사결정 트리(CART 구조에 정보 이득 사용)도 함께 돌렸습니다.

```python
# c45.py : 연속 속성용 C4.5 (이분법 + 이득율 휴리스틱, 가지치기 없음)
import numpy as np
from collections import Counter

def ent(y):
    p = np.bincount(y) / len(y); p = p[p > 0]
    return -(p * np.log2(p)).sum()

def best_split(x, y):
    xs = np.unique(x); best = (-1, None, 0)
    for t in (xs[:-1] + xs[1:]) / 2:                     # 인접 값의 중간점 후보
        l = x <= t; r = ~l
        g = ent(y) - (l.mean() * ent(y[l]) + r.mean() * ent(y[r]))
        if g > best[0]:
            iv = -(l.mean() * np.log2(l.mean()) + r.mean() * np.log2(r.mean()))
            best = (g, t, g / iv)
    return best                                          # (이득, 분할점, 이득율)

def build(X, y):
    if len(set(y)) == 1: return int(y[0])
    cands = [(j,) + best_split(X[:, j], y) for j in range(X.shape[1]) if len(np.unique(X[:, j])) > 1]
    cands = [c for c in cands if c[1] > 1e-12]
    if not cands: return Counter(y).most_common(1)[0][0]
    avg = np.mean([c[1] for c in cands])
    j, g, t, gr = max([c for c in cands if c[1] >= avg - 1e-12], key=lambda c: c[3])
    l = X[:, j] <= t
    return (j, t, build(X[l], y[l]), build(X[~l], y[~l]))

def predict1(node, x):
    while isinstance(node, tuple):
        j, t, L, R = node; node = L if x[j] <= t else R
    return node

class C45:
    def fit(self, X, y): self.root = build(np.asarray(X), np.asarray(y)); return self
    def predict(self, X): return np.array([predict1(self.root, x) for x in np.asarray(X)])
    def score(self, X, y): return (self.predict(X) == y).mean()
```

```python
# 비교 실험
import numpy as np
from sklearn.datasets import load_iris, load_breast_cancer
from sklearn.model_selection import StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.neural_network import MLPClassifier
from sklearn.tree import DecisionTreeClassifier
from c45 import C45

models = {
    "SVM 선형": lambda: make_pipeline(StandardScaler(), SVC(kernel="linear", C=1)),
    "SVM 가우스": lambda: make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1, gamma="scale")),
    "BP": lambda: make_pipeline(StandardScaler(), MLPClassifier(hidden_layer_sizes=(10,), solver="sgd",
                     learning_rate_init=0.1, momentum=0.9, max_iter=2000, random_state=0)),
    "C4.5": lambda: C45(),
    "sk-entropy": lambda: DecisionTreeClassifier(criterion="entropy", random_state=0),
}
for dname, loader in [("iris", load_iris), ("breast_cancer", load_breast_cancer)]:
    X, y = loader(return_X_y=True)
    cv = StratifiedKFold(n_splits=10, shuffle=True, random_state=0)
    for mname, mk in models.items():
        accs, nsv = [], []
        for tr, te in cv.split(X, y):
            m = mk().fit(X[tr], y[tr]); accs.append(m.score(X[te], y[te]))
            if mname.startswith("SVM"): nsv.append(m[-1].support_.size)
        print(dname, mname, np.mean(accs), np.std(accs), np.mean(nsv) if nsv else "")
```

SV 개수는 각 겹의 훈련 세트(iris 135개, breast_cancer 512~513개)에서 얻은 값의 평균입니다.

결과를 정리하면 다음과 같습니다.

- **정확도.** 두 데이터 세트 모두 SVM 두 가지와 BP 신경망이 비슷하고, C4.5가 가장 낮습니다. breast_cancer에서는 C4.5와 나머지의 차이(약 5%p)가 표준편차보다 커서 뚜렷한 차이로 볼 수 있지만, SVM과 BP 사이의 차이(0.1~0.4%p)나 iris에서 선형과 가우스 커널의 차이는 표준편차 안에 있어 우열을 말하기 어렵습니다.
- **커널.** 두 데이터 세트 모두 선형 경계로도 잘 나뉘는 문제여서 가우스 커널의 이점이 드러나지 않았습니다. 대신 가우스 커널은 SV가 선형 커널보다 2~3배 많습니다. 예측할 때 SV마다 커널을 계산해야 하므로 모델이 그만큼 무겁습니다.
- **C4.5의 특징.** 축에 평행한 경계(4.5절)만 만들 수 있어서 30개의 연속 속성이 서로 상관된 breast_cancer에서 특히 불리합니다. 가지치기를 하지 않은 것도 과적합 요인입니다. 대신 표준화가 필요 없고 결과를 규칙으로 읽을 수 있다는 장점이 있습니다.
- **조정 부담.** SVM은 표준화와 $C$, $\gamma$ 선택이 성능을 좌우하고, BP 신경망은 은닉층 크기, 학습률, 초깃값(난수 시드)에 따라 결과가 달라집니다. 이번 실험은 모두 기본에 가까운 설정이므로, 하이퍼파라미터를 교차 검증으로 고르면 순위가 바뀔 수 있습니다.

## 문제 6.4

> 선형 판별분석과 선형 커널 서포트 벡터 머신이 어떤 조건에서 같은지 논의하라.

**풀이**

**1. 두 모델이 같다는 것의 의미.** 두 모델 모두 결국 선형 분류기 $\operatorname{sign}(\boldsymbol{w}^{\mathrm{T}}\boldsymbol{x} + b)$를 내놓으므로, "같다"는 것은 두 초평면이 일치한다는 뜻입니다. 두 클래스를 $X_0, X_1$, 평균을 $\boldsymbol{\mu}_0, \boldsymbol{\mu}_1$, 클래스 내 산포행렬을 $\mathbf{S}_w$(식 3.33, 가역이라고 가정)라 하겠습니다. SVM 레이블은 $X_1$이 $+1$, $X_0$이 $-1$입니다.

- 선형 판별분석의 방향은 식 3.39의 $\boldsymbol{w}_{\text{LDA}} \propto \mathbf{S}_w^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)$입니다(부호는 $X_1$ 쪽을 향하도록 잡았습니다). 분류는 투영점이 어느 클래스 중심의 투영점에 가까운지로 하므로, 경계는 두 중심의 중점 $\boldsymbol{m} = (\boldsymbol{\mu}_0 + \boldsymbol{\mu}_1)/2$를 지나고 $\boldsymbol{w}_{\text{LDA}}$에 수직인 초평면입니다(두 클래스를 동등하게 본다는 해석입니다).
- 선형 커널 SVM의 방향은 식 6.9의 $\boldsymbol{w}_{\text{SVM}} = \sum_i \alpha_i y_i \boldsymbol{x}_i$이고, 서포트 벡터만으로 결정됩니다.

따라서 필요충분조건은 다음 두 가지입니다.

$$
\text{(가)}\ \ \boldsymbol{w}_{\text{SVM}} \parallel \mathbf{S}_w^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0), \qquad
\text{(나)}\ \ \boldsymbol{w}_{\text{SVM}}^{\mathrm{T}}\boldsymbol{m} + b_{\text{SVM}} = 0
$$

(가)는 두 초평면의 방향이 같다는 조건, (나)는 SVM 초평면이 두 중심의 중점을 지난다는 조건입니다. 방향이 같다는 뜻으로 "같다"를 해석한다면 (가)만 요구하면 됩니다. 하드 마진 SVM에서 데이터가 선형 분리 가능하면 $\boldsymbol{w}_{\text{SVM}}^{\mathrm{T}}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) \ge 2 > 0$이고(양성 샘플 제약 $\ge 1$, 음성 샘플 제약 $\le -1$을 각각 평균내어 빼면 나옵니다), $(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)^{\mathrm{T}}\mathbf{S}_w^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) > 0$이므로 평행하기만 하면 향하는 쪽도 같습니다.

일반적으로 (가)는 성립하지 않습니다. 선형 판별분석은 모든 샘플의 평균과 공분산(1차, 2차 통계량)으로 방향을 정하고, SVM은 경계 근처의 몇몇 서포트 벡터만으로 방향을 정하기 때문입니다. 두 방법이 같아지려면 "전체 분포가 가리키는 방향"과 "경계 근처 샘플이 가리키는 방향"이 우연히 일치하거나, 데이터의 대칭성 때문에 일치할 수밖에 없어야 합니다. 아래에서 후자를 충분조건으로 증명합니다.

**2. 충분조건: 대칭성.**

> **조건 A** (클래스별 대칭) 어떤 단위 벡터 $\boldsymbol{u}$(대칭축 방향)에 대해, 거울 반사들 $T(\boldsymbol{x}) = \boldsymbol{c} + \mathbf{R}(\boldsymbol{x} - \boldsymbol{c})$가 있어서, 각 $T$가 $X_0$을 $X_0$으로, $X_1$을 $X_1$으로 옮긴다. 여기서 $\mathbf{R}$은 대칭 직교 행렬($\mathbf{R}^{\mathrm{T}} = \mathbf{R}$, $\mathbf{R}^2 = \mathbf{I}$)이고, 모든 $\mathbf{R}$이 공통으로 고정하는 벡터는 $\boldsymbol{u}$의 배수뿐이다. (2차원이면 $\boldsymbol{u}$ 방향 직선에 대한 거울 대칭 하나, $d$차원이면 $\boldsymbol{u}$를 포함하고 법선이 서로 수직인 $d-1$개의 거울면이면 됩니다.)
>
> **조건 B** (클래스 간 대칭) 축에 수직인 거울 반사 $S(\boldsymbol{x}) = \boldsymbol{c}' + \mathbf{Q}(\boldsymbol{x} - \boldsymbol{c}')$ ($\mathbf{Q}\boldsymbol{u} = -\boldsymbol{u}$)가 $X_0$과 $X_1$을 서로 맞바꾼다.

데이터가 선형 분리 가능하고 $\mathbf{S}_w$가 가역일 때, 조건 A가 성립하면 (가)가, 조건 A와 B가 함께 성립하면 (가)와 (나)가 모두 성립합니다. 즉 하드 마진 선형 SVM과 선형 판별분석이 완전히 같은 분류기가 됩니다.

**증명 (가), SVM 쪽.** $(\boldsymbol{w}^*, b^*)$를 하드 마진 SVM의 해라 하고, 조건 A의 반사 $T$ 하나에 대해

$$
\boldsymbol{w}' = \mathbf{R}\boldsymbol{w}^*, \qquad b' = b^* + \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{c} - \boldsymbol{w}'^{\mathrm{T}}\boldsymbol{c}
$$

를 정의합니다. 임의의 샘플 $\boldsymbol{x}_j$에 대해 $\boldsymbol{x}_i = T(\boldsymbol{x}_j)$로 두면 $T$가 자기 역함수이므로 $\boldsymbol{x}_j = T(\boldsymbol{x}_i)$이고, 조건 A에 따라 $\boldsymbol{x}_i$는 같은 클래스($y_i = y_j$)입니다. 그러면 $\mathbf{R}^{\mathrm{T}}\mathbf{R} = \mathbf{I}$를 써서

$$
\begin{aligned}
\boldsymbol{w}'^{\mathrm{T}}\boldsymbol{x}_j + b'
&= \boldsymbol{w}'^{\mathrm{T}}\boldsymbol{c} + (\mathbf{R}\boldsymbol{w}^*)^{\mathrm{T}}\mathbf{R}(\boldsymbol{x}_i - \boldsymbol{c}) + b^* + \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{c} - \boldsymbol{w}'^{\mathrm{T}}\boldsymbol{c} \\
&= \boldsymbol{w}^{*\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{c}) + b^* + \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{c} = \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x}_i + b^*
\end{aligned}
$$

이므로 $y_j(\boldsymbol{w}'^{\mathrm{T}}\boldsymbol{x}_j + b') = y_i(\boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x}_i + b^*) \ge 1$입니다. 즉 $(\boldsymbol{w}', b')$도 실행 가능한 해이고 $\lVert \boldsymbol{w}' \rVert = \lVert \boldsymbol{w}^* \rVert$이므로 목적 함수 값도 같습니다. 그런데 식 6.6의 목적 함수 $\frac{1}{2}\lVert \boldsymbol{w} \rVert^2$은 $\boldsymbol{w}$에 대해 강볼록이고 실행 가능 영역은 볼록이므로 최적의 $\boldsymbol{w}$는 하나뿐입니다(최적해가 둘이면 그 중점이 더 작은 목적 함숫값을 가져 모순). 따라서 $\mathbf{R}\boldsymbol{w}^* = \boldsymbol{w}^*$이고, 이것이 조건 A의 모든 $\mathbf{R}$에 대해 성립하므로 $\boldsymbol{w}^* \parallel \boldsymbol{u}$입니다.

**증명 (가), 선형 판별분석 쪽.** $T$는 $X_k$ 위의 일대일 대응이고 아핀 변환이므로 평균을 보존합니다. $T(\boldsymbol{\mu}_k) = \frac{1}{m_k}\sum_{\boldsymbol{x} \in X_k} T(\boldsymbol{x}) = \boldsymbol{\mu}_k$이고, 이는 $\mathbf{R}(\boldsymbol{\mu}_k - \boldsymbol{c}) = \boldsymbol{\mu}_k - \boldsymbol{c}$를 뜻합니다. 두 식을 빼면 $\mathbf{R}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) = \boldsymbol{\mu}_1 - \boldsymbol{\mu}_0$이므로 $\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0 \parallel \boldsymbol{u}$입니다. 또 $\boldsymbol{x} = T(\boldsymbol{x}')$로 치환하면 $\boldsymbol{x} - \boldsymbol{\mu}_k = T(\boldsymbol{x}') - T(\boldsymbol{\mu}_k) = \mathbf{R}(\boldsymbol{x}' - \boldsymbol{\mu}_k)$이므로

$$
\mathbf{S}_w = \sum_{k}\sum_{\boldsymbol{x}' \in X_k} \mathbf{R}(\boldsymbol{x}' - \boldsymbol{\mu}_k)(\boldsymbol{x}' - \boldsymbol{\mu}_k)^{\mathrm{T}}\mathbf{R}^{\mathrm{T}} = \mathbf{R}\mathbf{S}_w\mathbf{R}
$$

입니다. 양변 왼쪽에 $\mathbf{R}$을 곱하면 $\mathbf{R}\mathbf{S}_w = \mathbf{S}_w\mathbf{R}$, 즉 $\mathbf{S}_w$와 $\mathbf{R}$이 교환 가능하고, 따라서 $\mathbf{S}_w^{-1}$도 $\mathbf{R}$과 교환 가능합니다. 그러면

$$
\mathbf{R}\,\mathbf{S}_w^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) = \mathbf{S}_w^{-1}\mathbf{R}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) = \mathbf{S}_w^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)
$$

이므로 $\boldsymbol{w}_{\text{LDA}}$도 모든 $\mathbf{R}$의 고정 벡터, 즉 $\boldsymbol{u}$의 배수입니다. 두 방향이 모두 $\boldsymbol{u}$와 평행하므로 (가)가 성립합니다.

**증명 (나).** 이번에는 조건 B의 $S$를 써서 $\boldsymbol{w}'' = -\mathbf{Q}\boldsymbol{w}^*$, $b'' = -b^* + \boldsymbol{w}^{*\mathrm{T}}\mathbf{Q}\boldsymbol{c}' - \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{c}'$로 두면, 위와 같은 계산으로 $\boldsymbol{w}''^{\mathrm{T}}S(\boldsymbol{x}) + b'' = -(\boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x} + b^*)$가 됩니다. $S$는 레이블을 뒤집으므로 $(\boldsymbol{w}'', b'')$ 역시 같은 크기의 실행 가능한 해입니다. 하드 마진 SVM에서는 $\boldsymbol{w}^*$뿐 아니라 $b^*$도 유일합니다(양성 쪽 최소 $\boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x}$와 음성 쪽 최대 $\boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x}$의 차이가 정확히 2여야 하며, 2보다 크면 $\boldsymbol{w}^*$를 조금 줄일 수 있어 최적성에 모순입니다). 따라서 $g(\boldsymbol{x}) = \boldsymbol{w}^{*\mathrm{T}}\boldsymbol{x} + b^*$는 $g(S(\boldsymbol{x})) = -g(\boldsymbol{x})$를 만족합니다. $S$는 $X_0$을 $X_1$로 일대일 대응시키므로 $S(\boldsymbol{\mu}_0) = \boldsymbol{\mu}_1$이고, $g(\boldsymbol{\mu}_1) = -g(\boldsymbol{\mu}_0)$입니다. $g$가 아핀 함수이므로 $g(\boldsymbol{m}) = \frac{1}{2}\big(g(\boldsymbol{\mu}_0) + g(\boldsymbol{\mu}_1)\big) = 0$, 즉 SVM 초평면이 중점 $\boldsymbol{m}$을 지납니다. $\square$

소프트 마진 SVM(식 6.35)에서도 목적 함수가 $\boldsymbol{w}$에 대해 강볼록이므로 $\boldsymbol{w}$는 유일하고, (가)의 증명은 그대로 성립합니다. 다만 소프트 마진에서는 $b$가 유일하지 않은 경우가 있어 (나)는 별도로 확인해야 합니다.

**3. 수치 확인.** 2차원 데이터 세 가지에서 하드 마진에 가까운 선형 SVM($C=10^6$, `tol=1e-10`)과 선형 판별분석의 방향 차이, 그리고 SVM 결정 함수의 중점 값 $g(\boldsymbol{m})$을 계산했습니다(`numpy.random.default_rng(0)`).

```python
import numpy as np
from sklearn.svm import SVC
rng = np.random.default_rng(0)

def compare(Xp, Xn, tag):
    X = np.vstack([Xp, Xn]); y = np.r_[np.ones(len(Xp)), -np.ones(len(Xn))]
    m = SVC(kernel="linear", C=1e6, tol=1e-10).fit(X, y)
    w_svm, b_svm = m.coef_[0], m.intercept_[0]
    mu1, mu0 = Xp.mean(0), Xn.mean(0)
    Sw = (Xp - mu1).T @ (Xp - mu1) + (Xn - mu0).T @ (Xn - mu0)
    w_lda = np.linalg.solve(Sw, mu1 - mu0)
    cos = w_svm @ w_lda / np.linalg.norm(w_svm) / np.linalg.norm(w_lda)
    print(tag, np.degrees(np.arccos(np.clip(cos, -1, 1))), w_svm @ ((mu0 + mu1) / 2) + b_svm)

A = rng.normal([2.5, 1.0], [0.6, 0.8], size=(15, 2))
Xp = np.vstack([A, A * [1, -1]])          # x축에 대해 거울 대칭 (조건 A)
compare(Xp, Xp * [-1, 1], "A+B")          # y축 대칭으로 음성 클래스 생성 (조건 B)
B = rng.normal([-3.0, 1.0], [1.2, 1.5], size=(25, 2))
compare(Xp, np.vstack([B, B * [1, -1]]), "A만")
Xp = rng.multivariate_normal([2, 1], [[1, .8], [.8, 1]], 30)
Xn = rng.multivariate_normal([-2, -1], [[1, -.3], [-.3, .5]], 30)
compare(Xp, Xn, "대칭 없음")
```

| 데이터 | 방향 차이(도) | SVM 결정 함수의 중점 값 $g(\boldsymbol{m})$ |
|------|------|------|
| 조건 A와 B 모두 성립 | 0.0000 | 0.0000 |
| 조건 A만 성립 | 0.0000 | −0.3277 |
| 대칭 없음 | 16.0808 | +0.8937 |

조건 A만 있으면 방향은 같지만 SVM 경계가 중점을 지나지 않아(선형 판별분석 경계와 평행하게 어긋남) 분류 결과가 달라질 수 있고, A와 B가 모두 있으면 두 경계가 완전히 일치합니다. 대칭이 없는 일반적인 데이터에서는 두 방향이 16도나 차이 납니다.

## 문제 6.5

> 가우스 SVM과 RBF 신경망 사이의 관계에 대해 기술하라.

**풀이**

가우스 커널 SVM의 예측 함수(식 6.24)와 RBF 신경망(식 5.18, 5.19)을 나란히 쓰면 형태가 같습니다.

$$
f(\boldsymbol{x}) = \sum_{i \in \text{SV}} \alpha_i y_i \exp\!\left(-\frac{\lVert \boldsymbol{x} - \boldsymbol{x}_i \rVert^2}{2\sigma^2}\right) + b,
\qquad
\varphi(\boldsymbol{x}) = \sum_{i=1}^{q} w_i \exp\!\left(-\beta_i \lVert \boldsymbol{x} - \boldsymbol{c}_i \rVert^2\right)
$$

| RBF 신경망 | 가우스 SVM |
|------|------|
| 은닉층 뉴런 수 $q$ | 서포트 벡터 수 |
| 뉴런 중심 $\boldsymbol{c}_i$ | 서포트 벡터 $\boldsymbol{x}_i$ |
| 폭 $\beta_i$ (뉴런마다 다를 수 있음) | $1/(2\sigma^2)$ (모든 뉴런 공통) |
| 출력층 가중치 $w_i$ | $\alpha_i y_i$ |
| (식 5.18에는 없음) | 편향 $b$ |

즉 가우스 SVM은 **은닉층 뉴런의 중심을 서포트 벡터에 두고, 모든 뉴런이 같은 폭을 쓰며, 출력에 편향이 있는 RBF 신경망**으로 볼 수 있습니다. 175쪽 "머신러닝 쉼터"의 옆주에서도, 은닉층 뉴런 수를 훈련 샘플 수로 두고 각 뉴런 중심을 훈련 샘플 하나씩에 맞추면 RBF 네트워크의 예측 함수가 가우스 커널 SVM과 같아진다고 설명합니다.

실제로 문제 6.2의 가우스 SVM($\gamma=10$, $C=100$)에서 서포트 벡터 7개를 중심으로, $\beta_i = \gamma = 10$, $w_i = \alpha_i y_i$, 편향 $b$를 그대로 가져와 RBF 신경망을 만들면, 17개 샘플 모두에서 두 모델의 출력 차이가 최대 $6.2 \times 10^{-15}$(부동소수점 오차 수준)였습니다.

```python
import numpy as np
from sklearn.svm import SVC
from wm import X, y
g = 10
m = SVC(kernel="rbf", gamma=g, C=100).fit(X, y)
centers, w = m.support_vectors_, m.dual_coef_[0]      # c_i = SV,  w_i = alpha_i * y_i
def rbf_net(x):                                       # 식 5.18, 5.19 (beta_i = gamma) + 편향
    rho = np.exp(-g * ((x[:, None, :] - centers[None]) ** 2).sum(-1))
    return rho @ w + m.intercept_[0]
print(len(centers), np.abs(rbf_net(X) - m.decision_function(X)).max())
```

형태는 같지만 학습 방식은 크게 다릅니다.

| 구분 | RBF 신경망 | 가우스 SVM |
|------|------|------|
| 은닉층 뉴런 수 | 미리 정해야 하는 하이퍼파라미터 | 서포트 벡터 수로 자동 결정 |
| 중심 정하기 | 랜덤 샘플링이나 클러스터링(1단계) | 쌍대문제의 해 $\alpha_i > 0$인 훈련 샘플 |
| 가중치 정하기 | 오차 역전파로 제곱 오차 최소화(2단계) | 마진 최대화 + 힌지 손실, 볼록 이차 프로그래밍 |
| 최적성 | 국소 최솟값에 빠질 수 있음 | 볼록 문제라 전역 최적해 |
| 폭 | 뉴런마다 학습 가능 | 하나의 $\sigma$를 사람이 정함(교차 검증 등) |

정리하면, 가우스 SVM은 RBF 신경망의 구조를 가지면서 중심 선택과 가중치 학습을 하나의 볼록 최적화 문제로 동시에 푸는 방법이라고 할 수 있습니다. 반대로 RBF 신경망은 중심 개수와 위치, 폭을 더 자유롭게 정할 수 있어 서포트 벡터보다 적은 뉴런으로 같은 함수를 근사할 여지가 있습니다(문제 6.10과 연결됩니다).

## 문제 6.6

> SVM이 노이즈에 대해 민감한 이유를 설명하라.

**풀이**

이유는 크게 세 가지입니다.

**1. 해가 소수의 서포트 벡터로만 결정됩니다.** 식 6.12에서 보듯이 최종 모델은 $\alpha_i > 0$인 샘플만으로 만들어집니다. 경계 근처에 있는 노이즈 샘플(레이블이 잘못 붙었거나 측정 오차가 큰 샘플)은 거의 반드시 서포트 벡터가 되고, 서포트 벡터의 수 자체가 적기 때문에 그 하나가 $\boldsymbol{w}$와 $b$에 미치는 영향이 큽니다. 모든 샘플의 평균과 공분산을 쓰는 선형 판별분석이나 모든 샘플의 우도를 쓰는 로지스틱 회귀에서는 샘플 하나의 영향이 전체에 희석되는 것과 대조적입니다.

**2. 마진 최대화는 "가장 가까운 샘플" 기준입니다.** 마진(식 6.4)은 두 클래스에서 초평면에 가장 가까운 샘플까지의 거리로 정의되므로, 평균이 아닌 최악의 경우를 기준으로 경계를 정합니다. 하드 마진(식 6.6)이면 잘못 붙은 레이블 하나가 상대 클래스 안쪽에 있을 때 마진이 급격히 줄거나, 아예 선형 분리가 불가능해져 해가 존재하지 않게 됩니다.

**3. 힌지 손실은 상한이 없습니다.** 소프트 마진에서는 힌지 손실 $\max(0, 1-z)$(식 6.31)가 $z$가 작아질수록 선형으로 계속 커집니다. 상대 클래스 깊숙이 들어가 있는 이상치는 손실이 매우 크므로 최적화가 그 샘플을 줄이려고 경계를 끌어당깁니다. KKT 조건(식 6.41)에서 이런 샘플은 $\alpha_i = C$, 즉 허용된 최대 가중치를 받습니다. $C$가 클수록 이 영향이 커집니다.

간단한 실험으로 확인해 보았습니다. 두 가우스 분포(중심 $(1.5, 1.5)$, $(-1.5, -1.5)$, 표준편차 0.5)에서 클래스당 20개를 뽑아 훈련하고(`default_rng(0)`), 음성 클래스 쪽인 $(-1.0, -0.6)$에 레이블이 $+1$인 노이즈 샘플 하나를 추가했습니다. 테스트는 같은 분포의 4000개 샘플입니다.

```python
import numpy as np
from sklearn.svm import SVC
rng = np.random.default_rng(0)
def make(n):
    Xp = rng.normal([1.5, 1.5], 0.5, (n, 2)); Xn = rng.normal([-1.5, -1.5], 0.5, (n, 2))
    return np.vstack([Xp, Xn]), np.r_[np.ones(n), -np.ones(n)]
Xtr, ytr = make(20); Xte, yte = make(2000)
Xn, yn = np.vstack([Xtr, [[-1.0, -0.6]]]), np.r_[ytr, 1]   # 레이블이 +1인 노이즈 샘플 추가
for C in [1e4, 0.1]:
    for A, b in [(Xtr, ytr), (Xn, yn)]:
        m = SVC(kernel="linear", C=C).fit(A, b); w = m.coef_[0]
        print(C, np.degrees(np.arctan2(w[1], w[0])), 2 / np.linalg.norm(w), m.support_.size, m.score(Xte, yte))
```

| $C$ | 데이터 | 법선 벡터 각도 | 마진 $2/\lVert \boldsymbol{w} \rVert$ | SV 수 | 테스트 정확도 |
|------|------|------|------|------|------|
| $10^4$ | 깨끗한 데이터 | 57.2° | 2.206 | 3 | 1.0000 |
| $10^4$ | 노이즈 1개 추가 | 88.4° | 1.440 | 4 | 0.9985 |
| 0.1 | 깨끗한 데이터 | 51.6° | 2.800 | 6 | 1.0000 |
| 0.1 | 노이즈 1개 추가 | 48.5° | 2.781 | 8 | 1.0000 |

$C = 10^4$(하드 마진에 가까움)에서는 노이즈 샘플 하나가 $\alpha = C = 10^4$를 받는 서포트 벡터가 되면서 경계가 31도 회전하고 마진이 35% 줄었습니다. 그런데도 그 노이즈 샘플은 여전히 잘못 분류됩니다($y f(\boldsymbol{x}) = -1.12$). 반면 $C = 0.1$에서는 같은 노이즈를 넣어도 방향이 3도, 마진이 1% 미만으로만 바뀌었습니다.

그래서 실전에서는 $C$를 교차 검증으로 충분히 작게 고르거나, 상한이 있는 램프 손실(ramp loss)처럼 이상치의 영향을 잘라내는 손실 함수를 쓰는 방법이 연구되어 있습니다. 다만 노이즈의 영향은 서포트 벡터가 되는 노이즈에 한정된다는 점도 함께 기억해 두면 좋습니다. 경계에서 멀리 올바른 쪽에 있는 샘플은 $\alpha_i = 0$이라 그 값이 조금 틀려도 모델에 전혀 영향을 주지 않습니다.

## 문제 6.7

> 식 6.52의 완전한 KKT 조건을 설명하라.

**풀이**

식 6.52는 상보 여유성(complementary slackness)만 적어 둔 것입니다. 완전한 KKT 조건은 정류 조건, 원문제 실행 가능성, 쌍대 실행 가능성, 상보 여유성 네 묶음으로 이루어집니다(부록 B.1 참조).

SVR의 원문제(식 6.45)를 부등식 제약 $g \le 0$ 꼴로 정리하면 다음과 같습니다. 여기서 $f(\boldsymbol{x}_i) = \boldsymbol{w}^{\mathrm{T}}\boldsymbol{x}_i + b$입니다.

$$
\begin{aligned}
\min_{\boldsymbol{w}, b, \boldsymbol{\xi}, \hat{\boldsymbol{\xi}}}\ \ & \frac{1}{2}\lVert \boldsymbol{w} \rVert^2 + C\sum_{i=1}^{m}(\xi_i + \hat{\xi}_i) \\
\text{s.t.}\ \ & f(\boldsymbol{x}_i) - y_i - \epsilon - \xi_i \le 0, \quad y_i - f(\boldsymbol{x}_i) - \epsilon - \hat{\xi}_i \le 0, \\
& -\xi_i \le 0, \quad -\hat{\xi}_i \le 0, \qquad i = 1, \dots, m.
\end{aligned}
$$

이 네 제약에 각각 라그랑주 승수 $\alpha_i, \hat{\alpha}_i, \mu_i, \hat{\mu}_i$를 붙인 것이 식 6.46입니다. 목적 함수가 볼록이고 제약이 모두 아핀(선형)이므로 KKT 조건은 최적해의 필요충분조건입니다. 모든 $i = 1, \dots, m$에 대해 완전한 KKT 조건은 다음과 같습니다.

**(1) 정류 조건** (식 6.46을 $\boldsymbol{w}, b, \xi_i, \hat{\xi}_i$로 편미분해 0으로 둔 것, 식 6.47~6.50)

$$
\boldsymbol{w} = \sum_{i=1}^{m}(\hat{\alpha}_i - \alpha_i)\boldsymbol{x}_i, \qquad
\sum_{i=1}^{m}(\hat{\alpha}_i - \alpha_i) = 0, \qquad
C = \alpha_i + \mu_i, \qquad
C = \hat{\alpha}_i + \hat{\mu}_i
$$

**(2) 원문제 실행 가능성**

$$
f(\boldsymbol{x}_i) - y_i \le \epsilon + \xi_i, \qquad
y_i - f(\boldsymbol{x}_i) \le \epsilon + \hat{\xi}_i, \qquad
\xi_i \ge 0, \qquad \hat{\xi}_i \ge 0
$$

**(3) 쌍대 실행 가능성**

$$
\alpha_i \ge 0, \qquad \hat{\alpha}_i \ge 0, \qquad \mu_i \ge 0, \qquad \hat{\mu}_i \ge 0
$$

(1)의 $C = \alpha_i + \mu_i$, $C = \hat{\alpha}_i + \hat{\mu}_i$와 합치면 $0 \le \alpha_i \le C$, $0 \le \hat{\alpha}_i \le C$가 되고, 이것이 쌍대문제(식 6.51)의 상자 제약입니다.

**(4) 상보 여유성**

$$
\alpha_i\big(f(\boldsymbol{x}_i) - y_i - \epsilon - \xi_i\big) = 0, \qquad
\hat{\alpha}_i\big(y_i - f(\boldsymbol{x}_i) - \epsilon - \hat{\xi}_i\big) = 0,
$$

$$
\mu_i\xi_i = (C - \alpha_i)\xi_i = 0, \qquad \hat{\mu}_i\hat{\xi}_i = (C - \hat{\alpha}_i)\hat{\xi}_i = 0
$$

**(5) 위에서 유도되는 조건** (식 6.52의 셋째 줄)

- $\alpha_i\hat{\alpha}_i = 0$: 둘 다 양수라고 하면 (4)에서 두 제약이 모두 등호가 되어 $f(\boldsymbol{x}_i) - y_i = \epsilon + \xi_i$, $y_i - f(\boldsymbol{x}_i) = \epsilon + \hat{\xi}_i$입니다. 두 식을 더하면 $0 = 2\epsilon + \xi_i + \hat{\xi}_i$인데, $\epsilon > 0$, $\xi_i, \hat{\xi}_i \ge 0$이므로 모순입니다. ($\epsilon = 0$이면 이 논리로는 강제되지 않지만, 그때는 쌍대 목적 함수가 $\hat{\alpha}_i - \alpha_i$에만 의존하므로 두 값에서 $\min(\alpha_i, \hat{\alpha}_i)$를 빼도 최적해가 유지되어 $\alpha_i\hat{\alpha}_i = 0$인 해를 고를 수 있습니다.)
- $\xi_i\hat{\xi}_i = 0$: $\xi_i > 0$이면 (4)에서 $\alpha_i = C > 0$이고, $\hat{\xi}_i > 0$이면 $\hat{\alpha}_i = C > 0$입니다. 둘 다 양수이면 $\alpha_i\hat{\alpha}_i = C^2 \neq 0$이 되어 위 결과와 모순입니다.

**각 샘플의 위치에 따른 해석.** 위 조건들을 조합하면 샘플이 $\epsilon$-튜브(그림 6.6)의 어디에 있는지에 따라 승수가 정해집니다.

| 샘플 위치 | $\alpha_i$ | $\hat{\alpha}_i$ | 여유 변수 |
|------|------|------|------|
| 튜브 안: $\lvert f(\boldsymbol{x}_i) - y_i \rvert < \epsilon$ | 0 | 0 | $\xi_i = \hat{\xi}_i = 0$ |
| 튜브 아래쪽 경계: $f(\boldsymbol{x}_i) - y_i = \epsilon$ | $[0, C]$ | 0 | $\xi_i = \hat{\xi}_i = 0$ |
| 튜브 아래쪽 바깥: $f(\boldsymbol{x}_i) - y_i > \epsilon$ | $C$ | 0 | $\xi_i = f(\boldsymbol{x}_i) - y_i - \epsilon > 0$, $\hat{\xi}_i = 0$ |
| 튜브 위쪽 경계: $y_i - f(\boldsymbol{x}_i) = \epsilon$ | 0 | $[0, C]$ | $\xi_i = \hat{\xi}_i = 0$ |
| 튜브 위쪽 바깥: $y_i - f(\boldsymbol{x}_i) > \epsilon$ | 0 | $C$ | $\xi_i = 0$, $\hat{\xi}_i = y_i - f(\boldsymbol{x}_i) - \epsilon > 0$ |

근거를 한 줄씩 적으면 다음과 같습니다.

- 튜브 안이면 $f(\boldsymbol{x}_i) - y_i - \epsilon - \xi_i < 0$이므로 (4)에서 $\alpha_i = 0$입니다. 같은 이유로 $\hat{\alpha}_i = 0$입니다. 그러면 $\mu_i = C > 0$이므로 $\xi_i = 0$, 마찬가지로 $\hat{\xi}_i = 0$입니다.
- 튜브 아래쪽 바깥($y_i$가 $f(\boldsymbol{x}_i) - \epsilon$보다 아래)이면 (2)에서 $\xi_i \ge f(\boldsymbol{x}_i) - y_i - \epsilon > 0$이고, $(C - \alpha_i)\xi_i = 0$에서 $\alpha_i = C$입니다. 이때 첫 제약이 등호여야 하므로 $\xi_i = f(\boldsymbol{x}_i) - y_i - \epsilon$입니다.
- 튜브 아래쪽 경계에서는 $\xi_i > 0$이라면 $\alpha_i = C > 0$이어서 $f(\boldsymbol{x}_i) - y_i = \epsilon + \xi_i > \epsilon$이 되므로 모순이고, 따라서 $\xi_i = 0$입니다. $\alpha_i$는 $[0, C]$의 어떤 값이든 될 수 있습니다.
- $f(\boldsymbol{x}_i) - y_i \ge \epsilon$인 샘플은 $y_i - f(\boldsymbol{x}_i) \le -\epsilon$이므로 $y_i - f(\boldsymbol{x}_i) - \epsilon - \hat{\xi}_i \le -2\epsilon < 0$이고, 따라서 $\hat{\alpha}_i = 0$입니다. 튜브 위쪽에 있는 샘플은 $\alpha_i$와 $\hat{\alpha}_i$의 역할을 바꾸어 똑같이 보일 수 있습니다.

결국 $\hat{\alpha}_i - \alpha_i \neq 0$인 샘플, 즉 SVR의 서포트 벡터는 튜브 경계 위나 바깥에 있는 샘플뿐이고(식 6.53 아래 설명), 튜브 안의 샘플은 모델에 영향을 주지 않습니다.

**$b$ 구하기.** $0 < \alpha_i < C$이면 $(C - \alpha_i)\xi_i = 0$에서 $\xi_i = 0$이고, $\alpha_i > 0$이므로 첫 제약이 등호입니다. 따라서 $f(\boldsymbol{x}_i) = y_i + \epsilon$이고, 식 6.47을 대입하면 식 6.54

$$
b = y_i + \epsilon - \sum_{j=1}^{m}(\hat{\alpha}_j - \alpha_j)\boldsymbol{x}_j^{\mathrm{T}}\boldsymbol{x}_i
$$

를 얻습니다. 마찬가지로 $0 < \hat{\alpha}_i < C$인 샘플에서는 $f(\boldsymbol{x}_i) = y_i - \epsilon$이므로 $b = y_i - \epsilon - \sum_{j}(\hat{\alpha}_j - \alpha_j)\boldsymbol{x}_j^{\mathrm{T}}\boldsymbol{x}_i$입니다.

## 문제 6.8

> 수박 데이터 세트 3.0$\alpha$의 '밀도'를 입력으로, '당도'를 출력으로 설정하여, LIBSVM을 사용해 SVR을 훈련하라.

**풀이**

입력 $x$ = 밀도, 출력 $y$ = 당도인 17개 샘플로 `SVR`(LIBSVM의 $\epsilon$-SVR)을 훈련했습니다. 커널, $C$, $\epsilon$을 바꿔 가며 서포트 벡터 수, 훈련 MSE, 리브-원-아웃(LOO) MSE를 비교했습니다. 비교 기준으로 "훈련 세트 당도의 평균으로 예측"하는 가장 단순한 모델의 LOO MSE도 계산했습니다.

```python
import numpy as np
from sklearn.svm import SVR
from sklearn.model_selection import LeaveOneOut, cross_val_predict
from wm import X
x, t = X[:, :1], X[:, 1]                       # 입력: 밀도, 출력: 당도
print("corr =", np.corrcoef(x[:, 0], t)[0, 1])
loo = LeaveOneOut()
print("평균 예측 LOO MSE =", np.mean([(t[te] - t[tr].mean())**2 for tr, te in loo.split(x)]))
for kern, kw in [("linear", {}), ("rbf", {"gamma": 1}), ("rbf", {"gamma": 10}), ("rbf", {"gamma": 100})]:
    for C in [1, 10, 100]:
        for eps in [0.01, 0.05]:
            m = SVR(kernel=kern, C=C, epsilon=eps, tol=1e-8, **kw).fit(x, t)
            tr_mse = np.mean((m.predict(x) - t)**2)
            loo_mse = np.mean((cross_val_predict(SVR(kernel=kern, C=C, epsilon=eps, tol=1e-8, **kw),
                                                 x, t, cv=loo) - t)**2)
            print(kern, kw, C, eps, m.support_.size, tr_mse, loo_mse)
```

먼저 데이터 자체를 보면 밀도와 당도의 상관계수는 0.196이고, 당도의 분산은 0.01353입니다. 평균으로 예측했을 때의 LOO MSE는 0.01527입니다.

결과를 해석하면 다음과 같습니다.

- **$\epsilon$과 서포트 벡터.** $\epsilon$이 커질수록 튜브 안에 들어오는 샘플이 늘어나 SV가 16 → 12 → 9 → 5개로 줄어듭니다. 문제 6.7의 KKT 조건대로 튜브 안의 샘플은 $\alpha_i = \hat{\alpha}_i = 0$이 되어 모델에서 빠지기 때문입니다.
- **예측력.** 어떤 설정도 LOO MSE가 평균 예측(0.01527)보다 낮지 않았습니다. 상관계수 0.196에서 짐작할 수 있듯이, 수박 데이터 세트 3.0α에서 밀도만으로는 당도를 거의 설명할 수 없습니다. 훈련 MSE도 당도의 분산 0.01353에서 거의 줄지 않습니다.
- **가우스 커널의 과적합.** $\gamma$와 $C$를 키우면 훈련 MSE는 비슷하거나 조금 낮아지지만 LOO MSE는 크게 나빠집니다($\gamma=100$, $C=100$에서 0.25). 샘플 17개로 1차원 함수를 유연하게 맞추면 빈 구간에서 예측이 크게 흔들립니다.

SVR을 돌리는 것 자체가 문제의 요구이지만, 결과를 정리하면 "이 데이터에서는 밀도와 당도 사이에 학습할 만한 관계가 거의 없다"는 것이 가장 정확한 답이라고 생각합니다.

## 문제 6.9

> 커널 트릭을 로지스틱 회귀로 확장하여 사용하라. (커널 로지스틱 회귀를 만들어라)

**풀이**

**1. 모델 유도.** 로지스틱 회귀를 특성 공간에서 하되, 과적합을 막기 위해 $L_2$ 정규화를 붙인 문제를 생각합니다. 레이블은 3.3절처럼 $y_i \in \{0, 1\}$입니다.

$$
\min_{h \in \mathbb{H},\, b}\ \sum_{i=1}^{m}\Big(-y_i z_i + \ln\big(1 + e^{z_i}\big)\Big) + \frac{\lambda}{2}\lVert h \rVert_{\mathbb{H}}^2,
\qquad z_i = h(\boldsymbol{x}_i) + b
$$

첫 항은 식 3.27의 로그 우도 손실이고, 둘째 항은 $\lVert h \rVert_{\mathbb{H}}$의 단조 증가 함수입니다. 따라서 표현정리(식 6.57, 6.58)에 의해 최적해는 훈련 샘플의 커널 함수 선형 조합으로 쓸 수 있습니다. (정규화하지 않는 편향 $b$가 추가된 경우에도 같은 결론이 성립합니다. 이를 준모수적 표현정리라고 합니다.)

$$
h(\boldsymbol{x}) = \sum_{j=1}^{m}\alpha_j\kappa(\boldsymbol{x}, \boldsymbol{x}_j), \qquad
p(y = 1 \mid \boldsymbol{x}) = \frac{1}{1 + e^{-(h(\boldsymbol{x}) + b)}}
$$

커널 행렬 $\mathbf{K}$($\mathbf{K}_{ij} = \kappa(\boldsymbol{x}_i, \boldsymbol{x}_j)$)를 쓰면 $\boldsymbol{z} = \mathbf{K}\boldsymbol{\alpha} + b\mathbf{1}$이고, $\lVert h \rVert_{\mathbb{H}}^2 = \boldsymbol{\alpha}^{\mathrm{T}}\mathbf{K}\boldsymbol{\alpha}$입니다. 따라서 풀어야 할 문제는 $\boldsymbol{\theta} = (\boldsymbol{\alpha}; b)$에 대한

$$
\ell(\boldsymbol{\theta}) = \sum_{i=1}^{m}\Big(-y_i z_i + \ln\big(1 + e^{z_i}\big)\Big) + \frac{\lambda}{2}\boldsymbol{\alpha}^{\mathrm{T}}\mathbf{K}\boldsymbol{\alpha}
$$

의 최소화이고, $\mathbf{K}$가 양의 준정부호(정리 6.1)이므로 볼록 함수입니다.

**2. 뉴턴법.** $\hat{\mathbf{K}} = [\mathbf{K}\ \ \mathbf{1}]$ ($m \times (m+1)$), $p_i = 1/(1 + e^{-z_i})$, $\mathbf{W} = \operatorname{diag}\big(p_i(1 - p_i)\big)$, $\mathbf{R} = \begin{bmatrix}\mathbf{K} & \mathbf{0} \\ \mathbf{0}^{\mathrm{T}} & 0\end{bmatrix}$이라 하면 식 3.30, 3.31과 같은 방식으로

$$
\frac{\partial \ell}{\partial \boldsymbol{\theta}} = \hat{\mathbf{K}}^{\mathrm{T}}(\boldsymbol{p} - \boldsymbol{y}) + \lambda\mathbf{R}\boldsymbol{\theta}, \qquad
\frac{\partial^2 \ell}{\partial \boldsymbol{\theta}\,\partial \boldsymbol{\theta}^{\mathrm{T}}} = \hat{\mathbf{K}}^{\mathrm{T}}\mathbf{W}\hat{\mathbf{K}} + \lambda\mathbf{R}
$$

이고, 식 3.29의 뉴턴 업데이트 $\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \big(\partial^2\ell\big)^{-1}\partial\ell$를 반복합니다. 커널로는 가우스 커널을 썼습니다.

```python
import numpy as np

def rbf_kernel(A, B, gamma):
    return np.exp(-gamma * ((A[:, None, :] - B[None, :, :]) ** 2).sum(-1))

class KernelLogReg:
    """z(x) = sum_j alpha_j k(x, x_j) + b,  p = sigmoid(z),  y in {0,1}
       min  sum_i [-y_i z_i + ln(1+exp(z_i))] + (lam/2) alpha^T K alpha   (뉴턴법)"""
    def __init__(self, gamma=1.0, lam=1e-2, iters=50):
        self.gamma, self.lam, self.iters = gamma, lam, iters

    def fit(self, X, y):
        self.X = X; m = len(X)
        K = rbf_kernel(X, X, self.gamma)
        Kh = np.c_[K, np.ones(m)]                    # z = Kh @ theta, theta = (alpha; b)
        R = np.zeros((m + 1, m + 1)); R[:m, :m] = K  # 정규화 항: (lam/2) theta^T R theta
        theta = np.zeros(m + 1)
        for _ in range(self.iters):
            p = 1 / (1 + np.exp(-Kh @ theta))
            g = Kh.T @ (p - y) + self.lam * R @ theta
            H = Kh.T @ (Kh * (p * (1 - p))[:, None]) + self.lam * R
            step = np.linalg.solve(H + 1e-10 * np.eye(m + 1), g)
            theta -= step
            if np.abs(step).max() < 1e-10: break
        self.alpha, self.b = theta[:m], theta[m]
        return self

    def proba(self, Xn):
        return 1 / (1 + np.exp(-(rbf_kernel(Xn, self.X, self.gamma) @ self.alpha + self.b)))

    def predict(self, Xn):
        return (self.proba(Xn) > 0.5).astype(int)
```

헤세 행렬은 $\mathbf{K}$의 고윳값이 매우 작을 때 수치적으로 특이에 가까워질 수 있어서 $10^{-10}\mathbf{I}$를 더해 풀었습니다. 구현이 맞는지 확인하기 위해 같은 목적 함수를 scipy의 BFGS로 따로 최소화해 보았고, 세 가지 설정에서 뉴턴법의 목적 함숫값이 BFGS와 같거나 조금 더 낮았으며 예측 레이블도 모두 일치했습니다.

**3. 실험.** 수박 데이터 세트 3.0α(17개)에서 훈련 정확도와 LOO 정확도를 구하고, 정규화 없는 선형 로지스틱 회귀(scikit-learn `LogisticRegression(C=1e6)`)와 비교했습니다.

## 문제 6.10\* (심화)

> SVM의 서포트 벡터의 숫자를 확연히 줄이면서 일반화 성능은 많이 떨어지지 않는 방법에 대해 설명하라.

**풀이**

**1. 서포트 벡터가 많아지는 이유.** 예측 함수 $f(\boldsymbol{x}) = \sum_{i \in \text{SV}}\alpha_i y_i\kappa(\boldsymbol{x}, \boldsymbol{x}_i) + b$는 서포트 벡터마다 커널 계산이 한 번씩 필요하므로 SV 수가 곧 예측 비용입니다. 식 6.41의 KKT 조건에서 마진 경계 위의 샘플($0 < \alpha_i < C$)뿐 아니라 마진을 침범하거나 잘못 분류된 샘플($\alpha_i = C$)도 전부 SV가 됩니다. 그래서 두 클래스가 겹치는 문제에서는 SV 수가 훈련 샘플 수에 비례해 늘어난다는 이론 결과가 있습니다 [Steinwart, 2003]. 따라서 SV를 줄이는 방법은 "학습이 끝난 뒤 예측 함수를 더 적은 벡터로 근사하기"와 "학습 단계부터 희소한 해가 나오게 하기"로 나눌 수 있습니다.

**2. 대표적인 방법.**

| 방법 | 핵심 아이디어 |
|------|------|
| 축소 집합(reduced set) 방법 [Burges, 1996; Burges and Schölkopf, 1997] | 학습 후 $\boldsymbol{\Psi} = \sum_{i}\alpha_i y_i\phi(\boldsymbol{x}_i)$를 $k$개 벡터의 조합 $\boldsymbol{\Psi}' = \sum_{j=1}^{k}\beta_j\phi(\boldsymbol{z}_j)$로 근사합니다($k \ll$ SV 수). |
| 정확한 단순화 [Downs et al., 2001] | 특성 공간에서 다른 SV들의 선형 조합으로 표현되는 SV는 계수를 다른 SV에 넘겨 예측 함수를 바꾸지 않고 제거합니다. 선형 커널이면 $\boldsymbol{w}$ 하나만 저장하면 되는 것이 극단적인 예입니다. |
| 축소 SVM(RSVM) [Lee and Mangasarian, 2001], 기저 선택 [Keerthi et al., 2006] | 처음부터 예측 함수를 $f(\boldsymbol{x}) = \sum_{j=1}^{k}\beta_j\kappa(\boldsymbol{x}, \boldsymbol{z}_j) + b$로 제한하고, 기저 $\boldsymbol{z}_j$를 무작위로 또는 탐욕적으로 고릅니다. |
| 손실 함수 바꾸기: 램프 손실 [Collobert et al., 2006] | 힌지 손실에 상한을 둔 $\min\big(1 - s, \max(0, 1 - z)\big)$꼴 손실을 써서, 크게 틀린 샘플이 $\alpha_i = C$인 SV가 되지 않게 합니다. 볼록성을 잃는 대신 SV 수가 줄고 노이즈에도 강해집니다(문제 6.6). |
| 희소성을 직접 유도 | 계수에 $L_1$ 정규화를 거는 1-노름 SVM, 희소 베이지안 모델인 관련 벡터 머신(RVM) [Tipping, 2001] 등. 11장의 $L_1$ 정규화와 같은 원리입니다. |
| 하이퍼파라미터 조정 | $C$를 키우면 $\alpha_i = C$인 SV가 줄고, $\nu$-SVM [Schölkopf et al., 2000]에서는 $\nu$가 SV 비율의 하한이므로 $\nu$를 줄이면 SV가 줄어듭니다. SVR에서는 $\epsilon$을 키우면 됩니다(문제 6.8). 일반화 성능과 맞바꾸는 관계라 교차 검증이 필요합니다. |
| 명시적 특성 근사 | 170쪽에 소개된 니스트롬 방법이나 랜덤 푸리에 특성으로 $\phi$를 저차원 벡터로 근사하고 선형 SVM을 학습합니다. 예측 비용이 SV 수와 무관해집니다. |

축소 집합 방법의 근사 오차는 커널만으로 계산할 수 있어서 실제로 최적화가 가능합니다.

$$
\lVert \boldsymbol{\Psi} - \boldsymbol{\Psi}' \rVert^2
= \sum_{i,i'}\alpha_i\alpha_{i'}y_iy_{i'}\kappa(\boldsymbol{x}_i, \boldsymbol{x}_{i'})
- 2\sum_{i,j}\alpha_i y_i\beta_j\kappa(\boldsymbol{x}_i, \boldsymbol{z}_j)
+ \sum_{j,j'}\beta_j\beta_{j'}\kappa(\boldsymbol{z}_j, \boldsymbol{z}_{j'})
$$

$\boldsymbol{z}_j$를 고정하면 $\boldsymbol{\beta}$는 선형 방정식으로 구해지고, $\boldsymbol{z}_j$는 경사하강법 등으로 최적화합니다. 특성 공간에서 $\boldsymbol{w}$를 잘 근사하면 모든 $\boldsymbol{x}$에서 $|f(\boldsymbol{x}) - f'(\boldsymbol{x})| \le \lVert \boldsymbol{\Psi} - \boldsymbol{\Psi}' \rVert\sqrt{\kappa(\boldsymbol{x}, \boldsymbol{x})}$ (코시-슈바르츠)이므로 예측 함수도 크게 변하지 않습니다. 가우스 커널이면 $\kappa(\boldsymbol{x}, \boldsymbol{x}) = 1$입니다.

**3. 실험.** breast_cancer 데이터(scikit-learn 내장 UCI 데이터)를 7:3으로 계층 분할하고(`random_state=0`, 훈련 398개, 테스트 171개), 표준화 후 가우스 커널($\gamma = 1/(d \cdot \operatorname{Var}) = 0.0333$)로 세 가지 방법을 비교했습니다. 축소 기저 방법은 RSVM 방식을 단순화한 것으로, 훈련 세트를 $k$-평균으로 묶은 $k$개의 중심 $\boldsymbol{z}_j$를 기저로 정하고 특성 $\big(\kappa(\boldsymbol{x}, \boldsymbol{z}_1), \dots, \kappa(\boldsymbol{x}, \boldsymbol{z}_k)\big)$ 위에서 선형 SVM($C=1$)을 학습했습니다.

```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC, NuSVC, LinearSVC
from sklearn.cluster import KMeans
from sklearn.metrics.pairwise import rbf_kernel

X, y = load_breast_cancer(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
sc = StandardScaler().fit(Xtr); Xtr, Xte = sc.transform(Xtr), sc.transform(Xte)
g = 1 / (Xtr.shape[1] * Xtr.var())          # gamma='scale'과 같은 값
for C in [1, 10, 100]:
    m = SVC(kernel="rbf", gamma=g, C=C).fit(Xtr, ytr)
    print("SVC", C, m.support_.size, m.score(Xte, yte))
for nu in [0.02, 0.05, 0.1, 0.2]:
    m = NuSVC(kernel="rbf", gamma=g, nu=nu).fit(Xtr, ytr)
    print("NuSVC", nu, m.support_.size, m.score(Xte, yte))
for k in [2, 5, 10, 20, 40]:                 # 축소 기저: k-평균 중심 k개만 커널 계산
    Z = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xtr).cluster_centers_
    Ftr, Fte = rbf_kernel(Xtr, Z, gamma=g), rbf_kernel(Xte, Z, gamma=g)
    m = LinearSVC(C=1, max_iter=100000, random_state=0).fit(Ftr, ytr)
    print("reduced", k, m.score(Fte, yte))
```

- 축소 기저 방법은 기저 20개(SV의 약 1/5)로 0.9415, 40개(약 0.4배)로 0.9649를 얻어 기준 SVM(96개, 0.9532)과 비슷한 성능을 냈습니다. 테스트 샘플이 171개라 샘플 하나가 약 0.6%p이므로 0.94~0.96 사이의 차이는 몇 개 샘플 차이일 뿐이고, 분할 하나에서 얻은 결과라는 점도 감안해야 합니다.

정리하면, 단순히 하이퍼파라미터를 조정하는 것만으로는 SV를 "확연히" 줄이기 어렵고, 예측 함수의 기저를 SV에서 분리하는 방법(축소 집합, RSVM 계열, 명시적 특성 근사)이나 손실 함수 자체를 바꾸는 방법(램프 손실, 희소 모델)이 SV 수를 크게 줄이면서 일반화 성능을 유지하는 데 효과적입니다.
