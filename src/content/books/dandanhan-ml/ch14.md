## 문제 14.1

> 판 표기법(plate notation)을 사용해서 조건 랜덤 필드와 나이브 베이즈 분류기를 표현하라.

**풀이**

판 표기법(14.5.2절, 그림 14.10)은 같은 메커니즘으로 반복해서 생성되는 변수들을 직사각형 판 하나로 묶고, 반복 횟수를 판 귀퉁이에 적는 표기입니다. 관측되는 변수는 음영으로 칠합니다. 아래 그림에서 원은 확률 변수, 작은 검은 점은 파라미터입니다.

![나이브 베이즈 분류기와 체인식 조건 랜덤 필드의 판 표기](/ddml-ch14-plate.svg)
_(a) 나이브 베이즈 분류기. (b) 체인식 조건 랜덤 필드. 음영은 관측 변수입니다._

**(a) 나이브 베이즈 분류기.** 7.3절의 나이브 베이즈 분류기는 클래스가 정해지면 $d$개의 속성이 서로 독립이라고 가정합니다(식 7.14, 7장 표기의 $c$를 여기서는 $y$로 씁니다). 샘플 하나의 생성 과정은 "클래스 $y$를 $P(y)$에서 뽑고, 각 속성 $x_i$를 $P(x_i \mid y)$에서 따로 뽑는다"이므로 방향성 그래프 $y \to x_i$가 되고, 속성 $d$개가 같은 구조로 반복되므로 $x_i$를 판 $d$에 넣습니다. 훈련 세트의 샘플 $m$개도 독립적으로 같은 방식으로 생성되므로 바깥에 판 $m$을 둡니다.

- $\pi$: 클래스 사전 확률 $P(y)$의 파라미터. 모든 샘플이 공유하므로 두 판 밖에 둡니다.
- $\theta_i$: 속성 $i$의 클래스 조건 확률 $P(x_i \mid y)$의 파라미터(모든 클래스의 표를 묶은 것). 샘플끼리는 공유하지만 속성마다 다르므로 판 $d$ 안, 판 $m$ 밖에 둡니다. 그래서 두 판이 겹치고, 겹친 칸에 $x_{j,i}$(샘플 $j$의 $i$번째 속성)가 놓입니다.

그림이 나타내는 분해는 다음과 같습니다.

$$
P\big(\{y_j, \mathbf{x}_j\}_{j=1}^m \mid \pi, \theta\big) = \prod_{j=1}^{m} \Big[ P(y_j \mid \pi) \prod_{i=1}^{d} P(x_{j,i} \mid y_j, \theta_i) \Big]
$$

훈련 단계에서는 $y_j$도 관측되므로 음영으로 칠해야 맞지만, 그림은 예측 시점(클래스가 미지)을 기준으로 그렸습니다.

**(b) 체인식 조건 랜덤 필드.** 식 14.11의 조건 랜덤 필드는 판별 모델이라서 관측 열 $\mathbf{x}$의 분포는 모델링하지 않고 조건으로만 씁니다. 그래서 $\mathbf{x}$는 음영 노드 하나(열 전체)로 두고, 에지는 방향이 없습니다. 반복되는 단위는 "이웃한 레이블 쌍 $\{y_i, y_{i+1}\}$과 관측 열 $\mathbf{x}$로 이루어진 클리크"이고 $i = 1, \dots, n-1$에서 같은 특성 함수와 같은 파라미터를 씁니다. 따라서 이 클리크를 판 $n-1$에 넣고, 훈련 열 $m$개를 바깥 판으로 묶습니다.

- $\lambda$: 전이 특성 함수 $t_j(y_{i+1}, y_i, \mathbf{x}, i)$의 가중치. 이웃 레이블 사이의 에지(클리크 $\{y_i, y_{i+1}\}$)에 걸립니다.
- $\mu$: 상태 특성 함수 $s_k(y_i, \mathbf{x}, i)$의 가중치. 각 위치의 레이블에 걸립니다.

두 파라미터는 모든 위치와 모든 훈련 열이 공유하므로 판 밖에 있습니다. 그림이 나타내는 분해는 식 14.11을 클리크별로 쓴 것입니다.

$$
P(\mathbf{y} \mid \mathbf{x}) = \frac{1}{Z(\mathbf{x})} \prod_{i=1}^{n-1} \exp\Big( \sum_j \lambda_j t_j(y_{i+1}, y_i, \mathbf{x}, i) \Big) \prod_{i=1}^{n} \exp\Big( \sum_k \mu_k s_k(y_i, \mathbf{x}, i) \Big)
$$

한 가지 짚어둘 점이 있습니다. 판 표기는 원래 "판 안의 변수들이 서로 겹치지 않게 복제된다"는 전제를 깔고 있는데, 체인에서는 $i$번째 복제의 $y_{i+1}$이 $(i+1)$번째 복제의 $y_i$와 같은 변수입니다. 그래서 그림 (b)의 판은 노드가 아니라 클리크(포텐셜 함수)를 복제한다고 읽어야 하며, 마지막 위치 $y_n$의 상태 특성 항은 그림에서 생략했습니다. 체인 구조는 판 표기만으로는 완전히 나타낼 수 없어서 그림 14.6처럼 펼쳐 그리는 경우가 많습니다.

두 모델을 정리하면 다음과 같습니다.

| | 나이브 베이즈 분류기 | 체인식 조건 랜덤 필드 |
|---|---|---|
| 모델 종류 | 생성 모델, 방향성 그래프 | 판별 모델, 무방향성 그래프 |
| 모델링 대상 | $P(y, \mathbf{x}) = P(y)\prod_i P(x_i \mid y)$ | $P(\mathbf{y} \mid \mathbf{x})$ |
| 판이 복제하는 것 | 속성 $x_i$ ($d$개), 샘플 ($m$개) | 레이블 쌍 클리크 ($n-1$개), 훈련 열 ($m$개) |
| 출력 | 레이블 하나 | 레이블 열(구조화 출력) |

## 문제 14.2

> 그래피컬 모델에서의 국소 마르코프 성질을 증명하라.

**풀이**

마르코프 랜덤 필드의 결합 확률이 식 14.2처럼 클리크 위의 포텐셜 함수의 곱으로 분해되고, 포텐셜 함수가 양수(예: 식 14.8의 지수 함수 꼴)라고 가정합니다. 그러면 모든 조건부 확률이 잘 정의됩니다.

노드 $v$에 대해 $n(v)$를 인접 노드 집합, $n^*(v) = n(v) \cup \{v\}$, 나머지를 $R = V \setminus n^*(v)$라고 두겠습니다. 보일 것은 다음입니다.

$$
\mathbf{x}_v \perp \mathbf{x}_R \mid \mathbf{x}_{n(v)}
$$

**Step 1. 결합 확률을 두 부분으로 나눕니다.** 클리크 집합 $\mathcal{C}$를 $v$를 포함하는 클리크 $\mathcal{C}_v$와 나머지로 나눕니다.

$$
P(\mathbf{x}) = \frac{1}{Z} \underbrace{\prod_{Q \in \mathcal{C}_v} \psi_Q(\mathbf{x}_Q)}_{F} \; \underbrace{\prod_{Q \notin \mathcal{C}_v} \psi_Q(\mathbf{x}_Q)}_{G}
$$

$Q \in \mathcal{C}_v$이면 $Q$는 클리크이므로 $Q$의 모든 노드가 $v$와 에지로 연결되어 있습니다. 따라서 $Q \subseteq n^*(v)$이고, $F$는 $\mathbf{x}_v$와 $\mathbf{x}_{n(v)}$만의 함수입니다. 한편 $Q \notin \mathcal{C}_v$인 클리크에는 $v$가 없으므로 $G$는 $\mathbf{x}_{n(v)}$와 $\mathbf{x}_R$만의 함수입니다. 즉,

$$
P(\mathbf{x}_v, \mathbf{x}_{n(v)}, \mathbf{x}_R) = \frac{1}{Z} F(\mathbf{x}_v, \mathbf{x}_{n(v)}) \, G(\mathbf{x}_{n(v)}, \mathbf{x}_R)
$$

**Step 2. 조건부 확률을 계산합니다.** 표기를 줄이려고 $\mathbf{x}_{n(v)}$를 $\mathbf{x}_n$으로 쓰겠습니다. 식 14.5와 같은 방법으로,

$$
\begin{aligned}
P(\mathbf{x}_v, \mathbf{x}_R \mid \mathbf{x}_n)
&= \frac{F(\mathbf{x}_v, \mathbf{x}_n) G(\mathbf{x}_n, \mathbf{x}_R)}{\sum_{\mathbf{x}_v'} \sum_{\mathbf{x}_R'} F(\mathbf{x}_v', \mathbf{x}_n) G(\mathbf{x}_n, \mathbf{x}_R')} \\
&= \frac{F(\mathbf{x}_v, \mathbf{x}_n)}{\sum_{\mathbf{x}_v'} F(\mathbf{x}_v', \mathbf{x}_n)} \cdot \frac{G(\mathbf{x}_n, \mathbf{x}_R)}{\sum_{\mathbf{x}_R'} G(\mathbf{x}_n, \mathbf{x}_R')}
\end{aligned}
$$

분모의 이중합이 두 합의 곱으로 갈라지는 것은 $F$에 $\mathbf{x}_R$이 없고 $G$에 $\mathbf{x}_v$가 없기 때문입니다($1/Z$는 분자와 분모에서 약분됩니다).

**Step 3. 각 인자가 조건부 주변 확률임을 보입니다.** 위 식을 $\mathbf{x}_R$에 대해 합하면 두 번째 인자의 합이 1이 되므로

$$
P(\mathbf{x}_v \mid \mathbf{x}_n) = \frac{F(\mathbf{x}_v, \mathbf{x}_n)}{\sum_{\mathbf{x}_v'} F(\mathbf{x}_v', \mathbf{x}_n)}
$$

이고, 같은 방식으로 $\mathbf{x}_v$에 대해 합하면 $P(\mathbf{x}_R \mid \mathbf{x}_n)$이 두 번째 인자와 같습니다. 따라서

$$
P(\mathbf{x}_v, \mathbf{x}_R \mid \mathbf{x}_{n(v)}) = P(\mathbf{x}_v \mid \mathbf{x}_{n(v)}) \, P(\mathbf{x}_R \mid \mathbf{x}_{n(v)})
$$

가 성립하고, 이것이 국소 마르코프 성질 $\mathbf{x}_v \perp \mathbf{x}_{V \setminus n^*(v)} \mid \mathbf{x}_{n(v)}$입니다. $\blacksquare$

**다른 증명(전역 마르코프 성질에서 바로 유도).** $v$에서 $R$의 어떤 노드로 가는 경로든 첫 걸음은 $v$의 이웃, 즉 $n(v)$의 노드를 지나야 합니다. 그러므로 $n(v)$는 $\{v\}$와 $R$의 분리 집합이고, 전역 마르코프 성질(14.2절)에 의해 $\mathbf{x}_v \perp \mathbf{x}_R \mid \mathbf{x}_{n(v)}$입니다. 위의 직접 증명은 이 논리를 분해식 수준에서 풀어 쓴 것입니다.

같은 결론을 다르게 쓰면 $P(\mathbf{x}_v \mid \mathbf{x}_{V \setminus \{v\}}) = P(\mathbf{x}_v \mid \mathbf{x}_{n(v)})$입니다. 노드 하나의 조건부 분포가 인접 노드(마르코프 블랭킷)만으로 정해진다는 뜻이고, 문제 14.7의 깁스 샘플링이 효율적인 이유가 바로 이것입니다. 수치 확인은 문제 14.3에서 함께 합니다.

## 문제 14.3

> 그래피컬 모델에서의 페어와이즈(Pairwise) 마르코프 성질에 대해 증명하라.

**풀이**

문제 14.2와 같은 가정(식 14.2의 분해, 양의 포텐셜 함수)에서, 에지로 연결되지 않은 두 노드 $u, v$($\langle u, v \rangle \notin E$)에 대해 $W = V \setminus \{u, v\}$로 두고 다음을 보입니다.

$$
\mathbf{x}_u \perp \mathbf{x}_v \mid \mathbf{x}_W
$$

**Step 1.** $u$와 $v$ 사이에 에지가 없으므로 $u$와 $v$를 동시에 포함하는 클리크는 없습니다(클리크는 모든 노드 쌍이 연결된 집합이므로). 따라서 클리크를 $u$를 포함하는 것과 포함하지 않는 것으로 나누면,

- $u$를 포함하는 클리크에는 $v$가 없으므로 그 곱 $f$는 $(\mathbf{x}_u, \mathbf{x}_W)$만의 함수,
- $u$를 포함하지 않는 클리크의 곱 $g$는 $(\mathbf{x}_v, \mathbf{x}_W)$만의 함수

입니다.

$$
P(\mathbf{x}_u, \mathbf{x}_v, \mathbf{x}_W) = \frac{1}{Z} f(\mathbf{x}_u, \mathbf{x}_W) \, g(\mathbf{x}_v, \mathbf{x}_W)
$$

**Step 2.** 문제 14.2의 Step 2, 3과 똑같이 계산하면

$$
\begin{aligned}
P(\mathbf{x}_u, \mathbf{x}_v \mid \mathbf{x}_W)
&= \frac{f(\mathbf{x}_u, \mathbf{x}_W) \, g(\mathbf{x}_v, \mathbf{x}_W)}{\sum_{\mathbf{x}_u'} f(\mathbf{x}_u', \mathbf{x}_W) \sum_{\mathbf{x}_v'} g(\mathbf{x}_v', \mathbf{x}_W)} \\
&= \underbrace{\frac{f(\mathbf{x}_u, \mathbf{x}_W)}{\sum_{\mathbf{x}_u'} f(\mathbf{x}_u', \mathbf{x}_W)}}_{P(\mathbf{x}_u \mid \mathbf{x}_W)} \cdot \underbrace{\frac{g(\mathbf{x}_v, \mathbf{x}_W)}{\sum_{\mathbf{x}_v'} g(\mathbf{x}_v', \mathbf{x}_W)}}_{P(\mathbf{x}_v \mid \mathbf{x}_W)}
\end{aligned}
$$

이고, 각 인자가 조건부 주변 확률이라는 것은 다른 쪽 변수에 대해 합해 보면 확인됩니다. 따라서 $\mathbf{x}_u \perp \mathbf{x}_v \mid \mathbf{x}_{V \setminus \langle u, v \rangle}$입니다. $\blacksquare$

**다른 증명(국소 마르코프 성질에서 유도).** $u$와 $v$가 인접하지 않으므로 $v \notin n^*(u)$입니다. 문제 14.2에서 $\mathbf{x}_u \perp \mathbf{x}_{R} \mid \mathbf{x}_{n(u)}$이고($R = V \setminus n^*(u)$, $v \in R$), $R = \{v\} \cup R'$로 나누면 조건부 독립의 약한 합병(weak union) 성질 "$X \perp (Y, Z) \mid S \Rightarrow X \perp Y \mid (S, Z)$"에 의해 $\mathbf{x}_u \perp \mathbf{x}_v \mid (\mathbf{x}_{n(u)}, \mathbf{x}_{R'})$입니다. 여기서 $n(u) \cup R' = W$입니다. 약한 합병 성질은 $P(x, y \mid s, z) = P(x \mid s, y, z) P(y \mid s, z) = P(x \mid s) P(y \mid s, z)$이고 같은 가정에서 $P(x \mid s, z) = P(x \mid s)$이므로 바로 나옵니다.

정리하면 "분해(식 14.2) $\Rightarrow$ 전역 $\Rightarrow$ 국소 $\Rightarrow$ 페어와이즈" 순으로 약해집니다. 반대 방향은 일반적으로 성립하지 않고, 분포가 모든 곳에서 양수일 때에만 세 성질과 분해가 모두 동치가 됩니다(Hammersley-Clifford 정리). 예를 들어 에지가 없는 그래프에서 이진 변수 세 개가 항상 같은 값을 갖는 분포($P(000) = P(111) = 1/2$)를 생각하면, 하나가 주어지면 나머지 둘이 결정되므로 페어와이즈 성질은 만족하지만, 국소 성질이 요구하는 $x_1 \perp (x_2, x_3)$는 성립하지 않습니다.

**수치 확인.** 그림 14.2의 마르코프 랜덤 필드(극대 클리크 $\{x_1,x_2\}, \{x_1,x_3\}, \{x_2,x_4\}, \{x_3,x_5\}, \{x_2,x_5,x_6\}$)에 값이 3개인 변수와 무작위 양수 포텐셜(시드 0)을 주고, 결합 확률을 $3^6 = 729$개 조합 전체에 대해 계산해 두 성질을 확인했습니다.

```python
import numpy as np
from itertools import product
rng = np.random.default_rng(0); k = 3
cliques = [(0,1), (0,2), (1,3), (2,4), (1,4,5)]          # 그림 14.2 (x1..x6 -> 0..5)
psi = {Q: rng.uniform(0.1, 2.0, size=(k,)*len(Q)) for Q in cliques}
P = np.ones((k,)*6)
for x in product(range(k), repeat=6):                     # 식 14.3 전수 계산
    P[x] = np.prod([psi[Q][tuple(x[i] for i in Q)] for Q in cliques])
P /= P.sum()
V = range(6)
nbr = {v: set().union(*[set(Q) - {v} for Q in cliques if v in Q]) for v in V}

def cond(A, B):                                           # P(x_A | x_B), 나머지 축은 크기 1
    PAB = P.sum(axis=tuple(i for i in V if i not in set(A) | set(B)), keepdims=True)
    return PAB / P.sum(axis=tuple(i for i in V if i not in B), keepdims=True)

loc = max(np.abs(cond([v], [u for u in V if u != v]) - cond([v], sorted(nbr[v]))).max() for v in V)
pw = max(np.abs(cond([u, v], W) - cond([u], W) * cond([v], W)).max()
         for u in V for v in V if u < v and v not in nbr[u]
         for W in [[w for w in V if w not in (u, v)]])
print(loc, pw)
```

- 국소 마르코프 성질: 6개 노드 모두에서 $P(x_v \mid \mathbf{x}_{V \setminus \{v\}})$와 $P(x_v \mid \mathbf{x}_{n(v)})$의 최대 차이 $4.4 \times 10^{-16}$
- 페어와이즈 마르코프 성질: 인접하지 않은 8개 쌍 모두에서 최대 차이 $1.7 \times 10^{-16}$

둘 다 부동소수점 오차 수준이라 성질이 정확히 성립합니다. 대조군으로 인접한 쌍 $(x_2, x_5)$에 같은 검사를 하면 차이가 $0.116$으로, 나머지 변수가 모두 주어져도 독립이 아닙니다.

## 문제 14.4

> 마르코프 랜덤 필드에서 왜 극대 클리크에 대해 포텐셜 함수를 정의해줘야 하는지에 대해 서술하라.

**풀이**

핵심은 "극대 클리크는 그래프 구조를 어기지 않고 포텐셜 함수를 정의할 수 있는 가장 큰 단위"라는 점입니다. 이유를 네 가지로 정리합니다.

**1. 표현력을 잃지 않습니다.** 극대 클리크가 아닌 클리크 $Q$는 반드시 어떤 극대 클리크 $Q^*$에 포함됩니다($\mathbf{x}_Q \subseteq \mathbf{x}_{Q^*}$, 380쪽). 그러므로 $\psi_Q$를 $\psi_{Q^*}$에 곱해 넣은 $\psi'_{Q^*} = \psi_{Q^*} \psi_Q$도 $\mathbf{x}_{Q^*}$만의 함수입니다. 즉 모든 클리크에 대한 식 14.2로 표현되는 분포는 전부 극대 클리크에 대한 식 14.3으로도 표현됩니다. 반대 방향도 자명하므로 두 식은 같은 분포 집합을 나타냅니다.

**2. 더 큰 집합에는 정의하면 안 됩니다.** 에지로 연결되지 않은 두 노드 $u, v$를 함께 포함하는 집합 위에 포텐셜을 두면, 그 포텐셜이 $\mathbf{x}_u$와 $\mathbf{x}_v$를 직접 엮어서 일반적으로 $\mathbf{x}_u \perp \mathbf{x}_v \mid \mathbf{x}_{V \setminus \langle u,v \rangle}$가 깨집니다. 문제 14.3의 증명이 "$u$와 $v$를 동시에 포함하는 인자가 없다"는 사실 하나에 기대고 있었던 것을 떠올리면 됩니다. 따라서 포텐셜의 정의역은 클리크여야 하고, 그중 가장 큰 것이 극대 클리크입니다.

**3. 표현이 간결하고 중복이 없습니다.** 모든 클리크에 포텐셜을 두면 인자의 개수가 많아지고(380쪽), 같은 분포를 나타내는 파라미터 조합이 무수히 많아집니다(작은 클리크의 포텐셜을 큰 클리크 쪽으로 옮겨도 분포가 그대로이므로). 극대 클리크만 쓰면 인자 수가 최소가 되고 계산과 학습이 단순해집니다.

**4. 이론적 근거가 있습니다.** Hammersley-Clifford 정리에 따르면, 양의 분포가 그래프의 (전역·국소·페어와이즈) 마르코프 성질을 만족하는 것과 극대 클리크 위의 포텐셜 곱으로 분해되는 것은 동치입니다. 극대 클리크 분해는 "그 그래프가 허용하는 모든 분포"를 정확히 덮는 표현입니다.

**주의할 점.** 반대로, 포텐셜을 극대 클리크보다 작은 단위(예: 식 14.9의 노드 쌍)로만 두면 표현력이 줄어듭니다. 이진 변수 3개로 된 극대 클리크 $\{x_2, x_5, x_6\}$에서 로그 포텐셜은 $2^3 = 8$차원 함수 공간인데, 쌍 단위 포텐셜의 합으로는 상수 1개, 단일 변수 3개, 쌍 3개, 합 7차원밖에 만들 수 없어 "세 변수의 동시 상호작용" 한 차원이 빠집니다. 구체적인 예로 패리티가 짝수인 조합에 3, 홀수인 조합에 1을 주는 포텐셜을 생각하면, 이 분포는 모든 단일·쌍 주변분포가 균등이므로 쌍 단위 포텐셜로 만들 수 있는 가장 가까운 분포가 균등분포가 됩니다.

```python
import numpy as np
P = np.array([[[3. if (a+b+c) % 2 == 0 else 1. for c in (0,1)] for b in (0,1)] for a in (0,1)])
P /= P.sum()
Q = np.ones((2,2,2)) / 8                     # 쌍 단위 포텐셜 모델을 IPF로 적합
for _ in range(200):
    for ax in (0, 1, 2):
        Q *= P.sum(axis=ax, keepdims=True) / Q.sum(axis=ax, keepdims=True)
print(Q.ravel(), (P * np.log(P / Q)).sum())
```

반복 비례 맞춤(IPF)으로 모든 쌍 주변분포를 맞춘 최적 근사는 8개 조합 모두 0.125인 균등분포였고, $\mathrm{KL}(P \,\|\, Q) = 0.1308$로 해석해 $\tfrac{3}{4}\ln 1.5 - \tfrac{1}{4}\ln 2 = 0.1308$과 일치했습니다. 극대 클리크 위의 포텐셜이라야 이런 고차 상호작용까지 담을 수 있습니다.

## 문제 14.5

> 조건 랜덤 필드와 로그 회귀를 비교하고 차이점에 대해 설명하라.

**풀이**

문제의 "로그 회귀"는 3.3절의 로지스틱 회귀를 가리킵니다(383쪽 방주에서도 조건 랜덤 필드를 로지스틱 회귀의 확장으로 볼 수 있다고 합니다).

**공통점: 로지스틱 회귀는 조건 랜덤 필드의 가장 단순한 경우입니다.** 식 14.11에서 레이블 열의 길이를 $n = 1$로 두면 전이 특성 함수가 사라지고

$$
P(y \mid \mathbf{x}) = \frac{1}{Z(\mathbf{x})} \exp\Big( \sum_k \mu_k s_k(y, \mathbf{x}) \Big), \qquad Z(\mathbf{x}) = \sum_{y'} \exp\Big( \sum_k \mu_k s_k(y', \mathbf{x}) \Big)
$$

가 됩니다. $y \in \{0, 1\}$이고 상태 특성 함수를 $s_k(y, \mathbf{x}) = y \, x_k$ ($k = 1, \dots, d$), $s_0(y, \mathbf{x}) = y$로 잡고 $\mathbf{w} = (\mu_1, \dots, \mu_d)$, $b = \mu_0$이라 하면

$$
P(y = 1 \mid \mathbf{x}) = \frac{e^{\mathbf{w}^{\mathrm{T}} \mathbf{x} + b}}{1 + e^{\mathbf{w}^{\mathrm{T}} \mathbf{x} + b}}
$$

로 식 3.23과 정확히 같습니다. 다중 클래스면 소프트맥스 회귀가 됩니다. 따라서 둘은 다음을 공유합니다.

- 판별 모델: 조건분포 $P(\text{레이블} \mid \mathbf{x})$를 직접 모델링하고 $\mathbf{x}$의 분포에는 가정을 두지 않습니다.
- 로그 선형 모델: 로그 확률이 파라미터에 대해 선형인 특성의 합(에서 $\ln Z$를 뺀 것)입니다.
- 학습: 조건부 로그 우도를 최대화합니다(보통 L2 정규화 추가). $\ln Z$가 파라미터의 log-sum-exp라 볼록하므로 음의 로그 우도가 볼록 함수이고, 전역 최적해를 구할 수 있습니다. 기울기는 둘 다 "관측된 특성값 $-$ 모델이 기대하는 특성값" 꼴입니다.

**차이점.**

| | 로지스틱 회귀 | (체인식) 조건 랜덤 필드 |
|---|---|---|
| 출력 | 레이블 하나 $y$ | 레이블 열 $\mathbf{y} = (y_1, \dots, y_n)$, 구조화 출력 |
| 레이블 사이 의존성 | 없음(샘플마다 독립 예측) | 이웃 레이블 쌍의 전이 특성 함수로 모델링 |
| 특성 함수 | $y$와 $\mathbf{x}$의 함수 | $y_i$, $(y_i, y_{i+1})$과 관측 열 전체 $\mathbf{x}$, 위치 $i$의 함수 |
| 정규화 팩터 $Z(\mathbf{x})$ | 클래스 수만큼의 합 | $\lvert\mathcal{Y}\rvert^n$개 레이블 열의 합. 체인 구조를 이용해 전향 알고리즘(신뢰 전파)으로 $O(n\lvert\mathcal{Y}\rvert^2)$에 계산 |
| 학습 시 기댓값 계산 | 바로 계산 | 레이블 쌍의 주변분포 $P(y_i, y_{i+1} \mid \mathbf{x})$가 필요해 전향-후향 계산(14.4절의 추론)이 필요 |
| 예측 | $\arg\max_y P(y \mid \mathbf{x})$ | $\arg\max_{\mathbf{y}} P(\mathbf{y} \mid \mathbf{x})$를 비터비(최대-곱) 알고리즘으로 탐색 |
| 그래프 관점 | 출력 노드 하나 | 무방향성 그래프(마르코프 랜덤 필드)를 조건부로 쓴 것 |

예를 들어 품사 태깅(그림 14.5)에 로지스틱 회귀를 단어마다 따로 쓰면 "관사 다음에는 명사가 오기 쉽다" 같은 레이블 사이의 규칙을 직접 쓸 수 없습니다. 조건 랜덤 필드는 이런 규칙을 전이 특성 함수로 넣고 열 전체에서 가장 그럴듯한 레이블 조합을 고릅니다. 대가는 학습과 예측에 동적 프로그래밍 추론이 들어가 계산이 무거워진다는 것입니다.

덧붙이면 생성 모델과의 대응도 깔끔합니다. 나이브 베이즈 분류기의 조건분포를 판별식으로 학습하면 로지스틱 회귀가 되고, 은닉 마르코프 모델(그림 14.1)을 같은 방식으로 판별식으로 바꾸면 체인식 조건 랜덤 필드가 됩니다(Sutton and McCallum, 2012). 즉 "나이브 베이즈 : 로지스틱 회귀 = 은닉 마르코프 모델 : 조건 랜덤 필드"입니다.

## 문제 14.6

> 변수 소거법의 계산 복잡도는 그래피컬 모델에서 극대 클리크 규모의 증가와 함께 지수적으로 증가하지만, 노드 수가 증가함에 따라서는 지수적으로 증가하지 않는다는 것을 증명하라.

**풀이**

**설정.** 변수 $n$개가 각각 최대 $r$개 값을 갖고, 모델이 포텐셜 함수(인자) $F$개의 곱 $\prod_{Q} \psi_Q(\mathbf{x}_Q)$로 주어졌다고 합니다(방향성 모델이면 조건부 확률표 하나하나가 인자입니다). 변수 소거법은 정해진 순서로 변수를 하나씩 소거하는데, 변수 $x_i$를 소거하는 한 단계는 다음과 같습니다.

1. $x_i$를 포함하는 인자들 $\Phi_i$를 모두 모읍니다. 이들의 변수 범위의 합집합을 $S_i$라 합니다.
2. $\Phi_i$의 인자들을 곱해 $S_i$ 위의 표를 만들고, $x_i$에 대해 합해 새 인자 $m_i(\mathbf{x}_{S_i \setminus \{i\}})$를 만듭니다(식 14.15, 14.16의 $m_{ij}$).
3. $\Phi_i$를 지우고 $m_i$를 인자 목록에 넣습니다.

**Step 1. 한 단계의 비용.** 곱한 표의 원소 수는 최대 $r^{|S_i|}$이고, 원소 하나당 곱셈 $|\Phi_i| - 1$번, 합산에 덧셈 $r^{|S_i|}$번 이하가 듭니다. 따라서 단계 $i$의 연산 수는 $|\Phi_i| \cdot r^{|S_i|}$ 이하입니다.

**Step 2. 전체 비용의 상한.** 각 인자(처음 $F$개와 새로 만든 $n$개 이하)는 정확히 한 번 소거 단계에 들어가고 사라집니다. 따라서 $\sum_i |\Phi_i| \le F + n$이고, $w = \max_i |S_i|$라 하면

$$
\text{총 연산 수} \le \sum_i |\Phi_i| \, r^{|S_i|} \le (F + n) \, r^{w}
$$

입니다.

**Step 3. $w$와 극대 클리크의 관계.** $m_i$를 만들면 $S_i \setminus \{i\}$의 변수들이 하나의 인자로 묶이므로, 그래프에서 보면 이 변수들 사이에 에지(채움 에지, fill-in)를 추가한 것과 같습니다. 그러면 각 $S_i$는 "원래 그래프 + 채움 에지" 그래프의 클리크입니다. 그림 14.7처럼 트리 구조에서 잎부터 소거하는 경우, 더 일반적으로 소거할 때마다 남은 이웃들이 이미 서로 연결되어 있는 순서(완전 소거 순서)를 쓰면 채움 에지가 생기지 않으므로, 귀납적으로 모든 인자의 범위가 원래 그래프의 클리크이고 $S_i = \{i\} \cup (\text{아직 소거되지 않은 } x_i \text{의 이웃})$도 원래 그래프의 클리크입니다. 따라서 $w$는 극대 클리크의 크기 $\omega$ 이하입니다(이런 순서는 트리처럼 고리가 없는 그래프, 더 일반적으로 길이 4 이상의 고리마다 현이 있는 그래프에 존재합니다). 한편 크기 $\omega$인 극대 클리크의 포텐셜 표는 원소가 $r^{\omega}$개이고, 주변분포를 정확히 구하려면 이 원소들이 모두 어느 단계에서든 한 번은 계산에 들어가야 합니다. 따라서

$$
r^{\omega} \;\le\; \text{총 연산 수} \;\le\; (F + n)\, r^{\omega}
$$

**Step 4. 결론.**

- 극대 클리크 크기 $\omega$에 대해: 하한과 상한이 모두 $r^{\omega}$에 비례하므로 지수적으로 증가합니다. 극대 클리크의 포텐셜 표 자체가 $r^{\omega}$개 값을 가지므로 이것은 피할 수 없습니다.
- 노드 수 $n$에 대해: $\omega$가 고정이면 상한이 $(F + n) r^{\omega}$으로 $n$(과 인자 수 $F$)에 선형입니다. 모든 변수를 한꺼번에 합하는 직접 계산의 $O(r^n)$과 대비됩니다. $\blacksquare$

**주의: 소거 순서의 영향.** 위 결론은 채움 에지가 생기지 않는(또는 적게 생기는) 순서를 쓴다는 전제가 필요합니다. 순서가 나쁘면 채움 에지 때문에 $|S_i|$가 원래 극대 클리크보다 훨씬 커질 수 있습니다. 극단적인 예로 중심 노드 하나에 잎 $n-1$개가 달린 별 그래프(극대 클리크 크기 2)에서 중심을 먼저 소거하면 $S$가 모든 노드가 되어 비용이 $r^{n}$에 비례합니다. 일반 그래프에서는 최적 순서에서의 $\max_i |S_i| - 1$을 트리 너비(treewidth)라 부르며, 정확한 복잡도는 원래 그래프의 극대 클리크가 아니라 이 값에 대해 지수적입니다. 최적 순서를 찾는 문제 자체는 NP-난해입니다.

**실험.** 연속한 $c$개 변수가 하나의 극대 클리크를 이루는 띠 모양 그래프(이진 변수, 무작위 양수 포텐셜, 시드 0)를 만들고, 앞에서부터 소거하면서 Step 1의 연산 수 $|\Phi_i| \cdot r^{|S_i|}$를 셌습니다.

```python
import numpy as np
from string import ascii_letters as L
rng = np.random.default_rng(0)

def eliminate(factors, order, k):
    """factors: [(변수 번호 튜플, 표)], order: 소거 순서. 남은 인자와 연산 수 반환"""
    ops = 0
    for v in order:
        rel = [f for f in factors if v in f[0]]
        factors = [f for f in factors if v not in f[0]]
        scope = sorted(set().union(*[s for s, _ in rel]))
        sub = {u: L[i] for i, u in enumerate(scope)}
        out = [u for u in scope if u != v]
        table = np.einsum(",".join("".join(sub[u] for u in s) for s, _ in rel)
                          + "->" + "".join(sub[u] for u in out), *[t for _, t in rel])
        ops += len(rel) * k ** len(scope)
        factors.append((tuple(out), table))
    return factors, ops

def band(n, c, k):        # (x_i, ..., x_{i+c-1})가 극대 클리크인 그래프
    return [(tuple(range(i, i + c)), rng.uniform(0.5, 1.5, (k,) * c)) for i in range(n - c + 1)]

for n in (10, 20, 40, 80, 160):
    print(n, eliminate(band(n, 3, 2), list(range(n - 1)), 2)[1])
for c in range(2, 10):
    print(c, eliminate(band(20, c, 2), list(range(19)), 2)[1])
```

## 문제 14.7

> 깁스 샘플링은 MH 알고리즘의 특수한 예로 간주할 수 있다. 그러나 깁스 샘플링에서는 '기각 샘플링' 전략을 쓰지 않는다. 이러한 방법의 장점에 대해 기술하라.

**풀이**

**깁스 샘플링이 MH의 특수한 경우이고 채택률이 항상 1인 이유.** 현재 상태 $\mathbf{x}$에서 변수 $x_i$ 하나만 바꾸는 제안 분포를 완전 조건부 분포로 잡습니다.

$$
Q(\mathbf{x}^* \mid \mathbf{x}) = p(x_i^* \mid \mathbf{x}_{\bar{i}}), \qquad \mathbf{x}^*_{\bar{i}} = \mathbf{x}_{\bar{i}}
$$

$\mathbf{x}$와 $\mathbf{x}^*$는 $x_i$ 외의 성분이 같으므로 $p(\mathbf{x}) = p(x_i \mid \mathbf{x}_{\bar{i}}) p(\mathbf{x}_{\bar{i}})$, $p(\mathbf{x}^*) = p(x^*_i \mid \mathbf{x}_{\bar{i}}) p(\mathbf{x}_{\bar{i}})$이고, 역방향 제안은 $Q(\mathbf{x} \mid \mathbf{x}^*) = p(x_i \mid \mathbf{x}_{\bar{i}})$입니다. 이를 식 14.28에 넣으면

$$
\frac{p(\mathbf{x}^*) Q(\mathbf{x} \mid \mathbf{x}^*)}{p(\mathbf{x}) Q(\mathbf{x}^* \mid \mathbf{x})}
= \frac{p(x^*_i \mid \mathbf{x}_{\bar{i}}) p(\mathbf{x}_{\bar{i}}) \cdot p(x_i \mid \mathbf{x}_{\bar{i}})}{p(x_i \mid \mathbf{x}_{\bar{i}}) p(\mathbf{x}_{\bar{i}}) \cdot p(x^*_i \mid \mathbf{x}_{\bar{i}})} = 1
$$

이므로 $A(\mathbf{x}^* \mid \mathbf{x}) = \min(1, 1) = 1$입니다. 제안은 언제나 받아들여지고, 그림 14.9의 4~8행(균일 난수 $u$를 뽑아 기각 여부를 정하는 단계)이 필요 없습니다. 여러 변수를 차례로 갱신하는 것은 이런 MH 단계를 이어 붙인 것이고, 각 단계가 상세 균형(식 14.26)을 만족하므로 $p$가 정상 분포로 유지됩니다.

**장점.**

1. **계산 낭비가 없습니다.** MH에서는 기각된 후보를 만들고 평가하는 데 쓴 계산이 버려지고, 체인이 제자리에 머뭅니다. 깁스 샘플링은 매 단계 새 값을 그 변수의 정확한 조건부 분포에서 뽑으므로 버리는 제안이 없습니다.
2. **제안 분포를 설계·조정할 필요가 없습니다.** MH의 성능은 $Q$에 크게 좌우됩니다(아래 실험의 보폭). 깁스 샘플링은 제안 분포가 모델에서 자동으로 정해지므로 조정할 하이퍼파라미터가 없습니다.
3. **채택률 계산이 필요 없고, 정규화 팩터도 필요 없습니다.** $p(x_i \mid \mathbf{x}_{\bar{i}})$는 $x_i$에 대한 1차원 분포라서 결합분포의 정규화 팩터 $Z$ 없이 계산됩니다. 게다가 그래피컬 모델에서는 문제 14.2의 국소 마르코프 성질에 의해 $p(x_i \mid \mathbf{x}_{\bar{i}}) = p(x_i \mid \mathbf{x}_{n(i)})$이므로, 마르코프 블랭킷에 걸린 포텐셜 함수만 보면 됩니다. 한 번의 갱신이 그래프의 국소적인 계산으로 끝납니다.
4. **켤레 분포를 쓰는 모델에서 특히 간단합니다.** 이산 변수이거나 사전분포가 켤레이면(부록 C.2) 완전 조건부 분포가 표준 분포가 되어 바로 표본을 뽑을 수 있습니다. 문제 14.9의 LDA 깁스 샘플링이 대표적인 예입니다.

**한계도 함께 알아둘 것.** 채택률 1이 곧 빠른 수렴을 뜻하지는 않습니다. 변수들이 강하게 상관되어 있으면 한 번에 한 변수만 조금씩 움직여 혼합(mixing)이 느리고, 완전 조건부 분포에서 표본을 뽑기 어려운 모델에는 바로 쓸 수 없습니다. 그래서 상관된 변수를 묶어 한꺼번에 뽑는 블록 깁스 샘플링이나, 조건부 분포 안에 MH 단계를 넣는 방법을 함께 씁니다.

**실험 1: 상관된 2차원 정규분포.** 평균 0, 분산 1, 상관계수 0.9인 정규분포에서 깁스 샘플링($x_i \mid x_j \sim N(0.9 x_j, 1 - 0.9^2)$)과 한 변수씩 정규 랜덤 워크로 제안하는 MH를 같은 횟수(20,000회, 앞 1,000회 버림) 돌려 $\mathbb{E}[x_1^2] = 1$을 추정했습니다. 시드 0~19의 20번 반복 결과입니다.

```python
import numpy as np
rho, T, burn = 0.9, 20000, 1000
Sinv = np.linalg.inv(np.array([[1, rho], [rho, 1]]))
logp = lambda x: -0.5 * x @ Sinv @ x

def gibbs(seed):
    rng = np.random.default_rng(seed); x = np.zeros(2); out = []
    for t in range(T):
        i = t % 2
        x[i] = rho * x[1 - i] + np.sqrt(1 - rho**2) * rng.standard_normal()
        out.append(x.copy())
    return np.array(out), 1.0

def mh(seed, s):                      # 한 변수씩 랜덤 워크 제안, 보폭 s
    rng = np.random.default_rng(seed); x = np.zeros(2); out = []; acc = 0
    for t in range(T):
        y = x.copy(); y[t % 2] += s * rng.standard_normal()
        if np.log(rng.random()) <= logp(y) - logp(x):
            x = y; acc += 1
        out.append(x.copy())
    return np.array(out), acc / T

def report(f):
    res = [f(seed) for seed in range(20)]
    err = [(S[burn:, 0] ** 2).mean() - 1 for S, _ in res]
    return np.mean([a for _, a in res]), np.sqrt(np.mean(np.square(err)))

print("Gibbs", report(gibbs))
for s in (0.05, 0.2, 0.5, 1.0, 3.0, 10.0):
    print("MH", s, report(lambda seed: mh(seed, s)))
```

|---|---|---|
| 깁스 샘플링 | 1.000 | 0.026 |
| MH, 보폭 0.05 | 0.964 | 0.319 |
| MH, 보폭 0.2 | 0.857 | 0.097 |
| MH, 보폭 0.5 | 0.669 | 0.102 |
| MH, 보폭 1.0 | 0.457 | 0.070 |
| MH, 보폭 3.0 | 0.180 | 0.066 |
| MH, 보폭 10.0 | 0.056 | 0.219 |

MH는 보폭이 작으면 거의 다 채택되지만 조금씩만 움직여 오차가 크고, 보폭이 크면 대부분 기각되어 오차가 다시 커집니다. 가장 잘 맞춘 보폭에서도 RMSE가 0.066으로, 조정 없이 돌린 깁스 샘플링(0.026)보다 2.5배 큽니다.

**실험 2: 382쪽의 이진 마르코프 랜덤 필드.** 그림 14.4의 $x_A - x_C - x_B$에 책의 포텐셜($\psi_{AC}$: 같으면 1.5, 다르면 0.1, $\psi_{BC}$: 같으면 0.2, 다르면 1.3)을 주고, 8개 상태의 정확한 분포를 전수 계산해 비교했습니다. 먼저 모든 상태와 변수에 대해 깁스 제안의 MH 채택률을 식 14.28로 계산하면 최솟값이 1(부동소수점 오차 $10^{-14}$ 이내)이어서 위 유도가 확인됩니다. 같은 30,000회(시드 0~19)를 돌리면 깁스는 채택률 1.000, 실제로 상태가 바뀐 비율 0.145, 정확한 분포와의 총변동 거리 평균 0.0134였고, 값을 뒤집는 대칭 제안의 MH는 채택률 0.173(= 상태 변경률), 총변동 거리 0.0106이었습니다. 이진 변수에서는 깁스도 같은 값을 다시 뽑을 수 있기 때문에 "채택률 1"이 "매번 움직인다"는 뜻은 아니고, 이 경우 두 방법의 정확도는 비슷했습니다. 깁스 샘플링의 이점은 실험 1처럼 제안 분포를 잘 고르기 어려운 연속 변수나 값이 많은 변수에서 더 분명하게 드러납니다.

## 문제 14.8

> 평균 필드는 일종의 근사추론법이다. 식 14.22를 생각하고 평균 필드법으로 해를 구하는 근사 문제와 원 문제의 차이, 그리고 실제로 어떻게 변수가 따르는 사전분포를 선택하는지에 대해 설명하라.

**풀이**

먼저 참조 식부터 정리합니다. 식 14.22는 몬테카를로 표본 평균 $\hat{f} = \frac{1}{N}\sum_i f(x_i)$라서 평균 필드와 직접 관련이 없습니다. 평균 필드의 출발점은 식 14.32

$$
\ln p(\mathbf{x}) = \mathcal{L}(q) + \mathrm{KL}(q \,\|\, p)
$$

이므로, 문제의 의도를 식 14.32로 해석해 풉니다($\mathcal{L}(q)$는 식 14.33, $\mathrm{KL}(q \,\|\, p)$는 식 14.34이며 $p$는 사후분포 $p(\mathbf{z} \mid \mathbf{x})$).

**원 문제.** $\ln p(\mathbf{x})$는 $q$와 무관한 상수이고 KL 발산은 0 이상이므로, $\mathcal{L}(q)$를 최대화하는 것과 $\mathrm{KL}(q \,\|\, p(\mathbf{z} \mid \mathbf{x}))$를 최소화하는 것은 같은 문제입니다. 모든 분포 $q$ 중에서 찾으면 해는 $q(\mathbf{z}) = p(\mathbf{z} \mid \mathbf{x})$이고 KL이 0이 되어 $\mathcal{L}(q) = \ln p(\mathbf{x})$, 즉 하한이 정확해집니다. EM 알고리즘의 E 단계가 바로 이것이고, 문제는 이 사후분포를 계산할 수 없다는 데 있습니다(395쪽).

**평균 필드의 근사 문제.** 탐색 범위를 식 14.35의 분해 가능한 분포 $q(\mathbf{z}) = \prod_{i=1}^{M} q_i(\mathbf{z}_i)$로 제한하고, 그 안에서 $\mathcal{L}(q)$를 최대화합니다. 하나의 $q_j$만 남기고 나머지를 고정하면 해가 식 14.40으로 주어지므로, $q_1, \dots, q_M$을 번갈아 갱신합니다. 두 문제의 차이는 다음과 같습니다.

1. **근사 오차가 남습니다.** 실제 사후분포가 분해 가능하지 않으면 제한된 범위 안의 최적해 $q^*$도 $\mathrm{KL}(q^* \,\|\, p) > 0$이고, $\mathcal{L}(q^*) < \ln p(\mathbf{x})$입니다. 하한과 실제 로그 우도의 간격이 곧 KL 발산입니다. 이 하한으로 EM의 M 단계를 하면 $\ln p(\mathbf{x} \mid \Theta)$가 아니라 하한을 최대화하는 것이라, 얻은 파라미터에도 편향이 생길 수 있습니다.
2. **블록 사이의 상관관계를 잃습니다.** $q$에서 $\mathbf{z}_i$와 $\mathbf{z}_j$($i \ne j$)는 정의상 독립이므로, 사후분포에서 이 둘이 얼마나 강하게 상관되어 있든 근사분포는 그 상관을 0으로 둡니다.
3. **KL의 방향 때문에 분산을 작게 잡고 봉우리 하나에 몰립니다.** $\mathrm{KL}(q \,\|\, p) = \int q \ln (q/p)$는 $p$가 거의 0인 곳에 $q$가 질량을 두면 큰 벌점을 줍니다. 그래서 $q$는 $p$의 질량이 큰 곳 안쪽에 좁게 자리 잡아 불확실성을 과소평가하고, 사후분포의 봉우리가 여럿이면 그중 하나만 덮는 경향이 있습니다.
4. **최적화 성질이 다릅니다.** 원 문제는 $q$에 대해 볼록(KL은 $q$에 대해 볼록)이고 해가 유일하지만, 분해 제약을 걸면 $(q_1, \dots, q_M)$에 대해 볼록이 아니게 됩니다. 식 14.40을 번갈아 적용하면 $\mathcal{L}$이 매번 줄지 않고 수렴은 하지만, 국소 최적해에 머무를 수 있고 초깃값에 따라 결과가 달라집니다(394쪽 첫 문장의 "국소 최적해").

**수치 예.** 사후분포가 평균 $(1, -1)$, 분산 1, 상관계수 $\rho = 0.9$인 2차원 정규분포라고 하고, $q(\mathbf{z}) = q_1(z_1)q_2(z_2)$로 놓아 식 14.40을 격자 위에서 그대로 계산했습니다(함수 꼴을 미리 가정하지 않음).

```python
import numpy as np
rho = 0.9; Lam = np.linalg.inv(np.array([[1, rho], [rho, 1]])); mu = np.array([1., -1.])
g = np.linspace(-8, 8, 1601); dz = g[1] - g[0]
Z1, Z2 = np.meshgrid(g, g, indexing="ij"); D1, D2 = Z1 - mu[0], Z2 - mu[1]
logpt = -0.5 * (Lam[0,0]*D1**2 + 2*Lam[0,1]*D1*D2 + Lam[1,1]*D2**2)   # ln p~(z)
lnZ = np.log(2*np.pi / np.sqrt(np.linalg.det(Lam)))                  # 정확한 ln p(x) 역할
norm = lambda e: np.exp(e - e.max()) / (np.exp(e - e.max()).sum() * dz)
q1 = norm(-0.5*(g - 5)**2); q2 = norm(-0.5*(g + 5)**2)                # 일부러 먼 초깃값
for it in range(100):                                                # 식 14.40을 번갈아 적용
    q1 = norm((logpt * q2[None, :]).sum(1) * dz)
    q2 = norm((logpt * q1[:, None]).sum(0) * dz)
H = lambda q: -(q * np.log(q + 1e-300)).sum() * dz
L = (np.outer(q1, q2) * logpt).sum() * dz * dz + H(q1) + H(q2)         # 식 14.33
m1 = (g*q1).sum()*dz; v1 = ((g - m1)**2 * q1).sum()*dz
print(L, lnZ, lnZ - L, m1, v1)
```

- 수렴한 $q_1$의 평균 1.000, 분산 0.190. 이론값 $1/\Lambda_{11} = 1 - \rho^2 = 0.19$와 같고, 실제 주변분포의 분산 1보다 훨씬 작습니다. $q_2$도 평균 $-1.000$, 분산 0.190입니다.
- $\mathcal{L}(q) = 0.17715$, $\ln Z = 1.00751$이고 간격 $0.83037$은 닫힌 형태 $\mathrm{KL}(q \,\|\, p) = -\tfrac{1}{2}\ln(1 - \rho^2) = 0.83037$과 일치합니다. 평균은 정확히 맞추지만 상관(0.9)은 0으로, 분산은 0.19로 잡습니다. 차이 1과 2, 3이 그대로 보입니다.

봉우리가 두 개인 1차원 분포 $0.5\,N(-3, 1) + 0.5\,N(3, 1)$을 정규분포 하나로 근사해 보면, $\mathrm{KL}(q \,\|\, p)$를 최소화하는 $q$는 격자 탐색 결과 평균 3.00(대칭인 $-3$도 같은 값), 표준편차 1.00으로 봉우리 하나만 덮습니다(KL = 0.689, $\ln 2$에 가까움). 반대 방향 $\mathrm{KL}(p \,\|\, q)$를 최소화하는 정규분포는 평균과 분산을 맞추는 해이므로 평균 0, 표준편차 $\sqrt{10} = 3.16$으로 두 봉우리를 함께 덮습니다. 평균 필드는 앞쪽 방향을 쓰므로 봉우리 하나를 고르는 성향을 갖습니다.

**실제로 분포를 어떻게 고르는가.**

1. **분해 방법(어떤 변수를 한 블록으로 묶을지)이 가장 중요한 선택입니다.** 식 14.40을 보면 $q_j$의 함수 꼴은 우리가 정하는 것이 아니라 모델 $p(\mathbf{x}, \mathbf{z})$에서 결정됩니다. 우리가 정하는 것은 분해 방식이므로, 사후분포에서 강하게 얽힌 변수(위 예의 $z_1, z_2$)는 같은 블록에 넣고, 약하게 얽힌 변수끼리 나눕니다(구조적 평균 필드).
2. **사전분포는 우도와 켤레인 지수족 분포로 고릅니다.** 각 변수의 완전 조건부 분포가 지수족이고 사전분포가 켤레(부록 C.2)이면, $\mathbb{E}_{i \ne j}[\ln p(\mathbf{x}, \mathbf{z})]$가 $\mathbf{z}_j$의 충분통계량에 대해 선형이 되어 $q_j^*$가 사전분포와 같은 족의 분포로 닫힌 형태로 나옵니다(397쪽의 "항상 닫힌 형태"가 이 경우입니다). 예를 들어 다항(범주) 분포의 파라미터에는 디리클레 분포(LDA의 $\Theta_t$, $\boldsymbol{\beta}_k$), 정규분포의 평균에는 정규분포, 정밀도에는 감마 분포를 씁니다. 그러면 갱신 식이 파라미터 몇 개를 고치는 일로 줄어듭니다.
3. **켤레가 아니면 추가 근사가 필요합니다.** 예를 들어 로지스틱 우도에 정규 사전분포를 쓰면 기댓값이 닫힌 형태가 아니므로, 우도에 대한 하한을 한 번 더 쓰거나 $q_j$를 정규분포처럼 고정된 꼴로 두고 경사 기반으로 최적화합니다.
4. **사전분포의 하이퍼파라미터는** 약한 정보를 주는 값으로 두거나(예: LDA에서 문서가 소수의 토픽만 갖도록 $\alpha < 1$), 하한 $\mathcal{L}$을 하이퍼파라미터에 대해서도 최대화해(변분 EM, 식 14.43의 근사) 데이터로부터 정합니다.

## 문제 14.9\* (심화)

> LDA에 대한 코드를 작성하고, 문학작품의 토픽 변환 상황에 대해 분석하라.

**풀이**

**알고리즘: 붕괴된(collapsed) 깁스 샘플링.** 14.6절은 식 14.44의 사후분포를 깁스 샘플링이나 변분법으로 근사한다고만 하므로, 여기서는 깁스 샘플링을 씁니다. 디리클레 분포가 다항 분포의 켤레이므로 $\Theta_t$와 $\boldsymbol{\beta}_k$를 적분해 없애면 토픽 배정 $\mathbf{z}$만 남습니다. 문서 $t$에서 토픽 $k$에 배정된 단어 수를 $n_{t,k}$, 토픽 $k$에 배정된 단어 $w$의 수를 $n_{k,w}$, $n_k = \sum_w n_{k,w}$, 사전 크기를 $N$이라 하고 $B(\mathbf{a}) = \prod_i \Gamma(a_i) / \Gamma(\sum_i a_i)$로 두면

$$
p(\mathbf{W}, \mathbf{z} \mid \boldsymbol{\alpha}, \eta) = \prod_{t=1}^{T} \frac{B(\mathbf{n}_{t} + \boldsymbol{\alpha})}{B(\boldsymbol{\alpha})} \prod_{k=1}^{K} \frac{B(\mathbf{n}_{k} + \eta)}{B(\eta \mathbf{1})}
$$

입니다(식 14.41을 $\Theta$, $\boldsymbol{\beta}$에 대해 적분하고 식 14.42의 정규화 상수를 이용). 문서 $t$의 단어 하나($w_{t,n} = w$)의 토픽만 바꾸고 나머지를 고정하면, $\Gamma(a + 1) = a\Gamma(a)$에 의해 이 단어를 뺀 계수(위첨자 $-$)로

$$
p(z_{t,n} = k \mid \mathbf{z}^{-}, \mathbf{W}) \propto \left(n_{t,k}^{-} + \alpha_k\right) \frac{n_{k,w}^{-} + \eta}{n_k^{-} + N\eta}
$$

가 됩니다. 앞의 인자는 "이 문서가 토픽 $k$를 얼마나 쓰는가", 뒤의 인자는 "토픽 $k$가 단어 $w$를 얼마나 쓰는가"입니다. 표본이 모이면 $\hat{\Theta}_{t,k} = (n_{t,k} + \alpha_k)/(n_t + \sum_k \alpha_k)$, $\hat{\beta}_{k,w} = (n_{k,w} + \eta)/(n_k + N\eta)$로 추정합니다. 코드에서는 사전 크기를 `V`로 썼습니다.

```python
import numpy as np

def lda_gibbs(docs, K, V, alpha=0.1, eta=0.01, iters=500, seed=0, keep=None):
    """붕괴된 깁스 샘플링 LDA. docs: 단어 번호 배열의 리스트, V: 사전 크기(책의 N)"""
    rng = np.random.default_rng(seed)
    z = [rng.integers(K, size=len(d)) for d in docs]           # 토픽 무작위 초기화
    ndk = np.zeros((len(docs), K)); nkw = np.zeros((K, V)); nk = np.zeros(K)
    for d, (ws, zs) in enumerate(zip(docs, z)):
        for w, k in zip(ws, zs):
            ndk[d, k] += 1; nkw[k, w] += 1; nk[k] += 1
    for it in range(iters):
        for d, ws in enumerate(docs):
            for n, w in enumerate(ws):
                k = z[d][n]                                      # 이 단어를 계수에서 빼고
                ndk[d, k] -= 1; nkw[k, w] -= 1; nk[k] -= 1
                p = (ndk[d] + alpha) * (nkw[:, w] + eta) / (nk + V * eta)
                k = rng.choice(K, p=p / p.sum())                 # 완전 조건부에서 새 토픽
                z[d][n] = k
                ndk[d, k] += 1; nkw[k, w] += 1; nk[k] += 1
        if keep is not None:
            keep(it, z)                                          # 표본 수집용 콜백
    theta = (ndk + alpha) / (ndk + alpha).sum(1, keepdims=True)
    beta = (nkw + eta) / (nkw + eta).sum(1, keepdims=True)
    return theta, beta, z
```

**검증 1: 작은 말뭉치에서 정확한 사후분포와 비교.** 문서 3개(단어 4, 3, 4개, 사전 크기 4), $K = 2$, $\alpha = \eta = 0.5$인 경우 토픽 배정은 $2^{11} = 2048$가지뿐이므로 위의 $p(\mathbf{W}, \mathbf{z})$로 사후분포를 전수 계산할 수 있습니다. 토픽 번호는 서로 바꿔도 사후확률이 같아서(라벨 교환) $P(z_i = k)$는 모두 0.5가 되므로, 번호와 무관한 "두 단어가 같은 토픽에 배정될 확률" $P(z_i = z_j \mid \mathbf{W})$를 55개 단어 쌍 전부에 대해 비교했습니다.

from itertools import product
from scipy.special import gammaln
docs = [np.array([0, 0, 1, 2]), np.array([1, 2, 3]), np.array([3, 3, 0, 2])]
K, V, alpha, eta = 2, 4, 0.5, 0.5
flat = [(d, w) for d, ws in enumerate(docs) for w in ws]
lnB = lambda a: gammaln(a).sum() - gammaln(a.sum())
def log_joint(zs):                                  # ln p(W, z)
    ndk = np.zeros((3, K)); nkw = np.zeros((K, V))
    for (d, w), k in zip(flat, zs):
        ndk[d, k] += 1; nkw[k, w] += 1
    return sum(lnB(r + alpha) for r in ndk) + sum(lnB(r + eta) for r in nkw)
Zs = np.array(list(product(range(K), repeat=len(flat))))
lj = np.array([log_joint(zs) for zs in Zs]); pz = np.exp(lj - lj.max()); pz /= pz.sum()
exact = np.einsum("s,sij->ij", pz, (Zs[:, :, None] == Zs[:, None, :]).astype(float))

## 문제 14.10\* (심화)

> 사전에 토픽 개수를 지정해주지 않아도 되는 LDA 개량 모델을 만들어 보아라.

**풀이**

LDA에서 토픽 수 $K$는 디리클레 분포의 차원으로 고정되어 있습니다. 이를 데이터에서 정하게 하는 표준적인 방법은 14.7절이 소개한 비모수화 방법, 그중 계층적 디리클레 프로세스(HDP) 토픽 모델입니다(Teh et al., 2006). 토픽을 무한히 많이 준비해 두되, 실제로 쓰이는 토픽 수는 사후분포가 정하게 합니다.

**모델(HDP-LDA).** 디리클레 분포를 무한 차원으로 확장한 디리클레 프로세스를 두 층으로 씁니다. 생성 과정은 다음과 같습니다.

1. 전역 토픽 비율 $\boldsymbol{\beta} = (\beta_1, \beta_2, \dots)$를 막대 쪼개기로 만듭니다. $\beta'_k \sim \mathrm{Beta}(1, \gamma)$, $\beta_k = \beta'_k \prod_{l<k} (1 - \beta'_l)$. 길이 1인 막대에서 매번 남은 부분의 일부를 떼어 내는 것이라 합이 1이고, 뒤로 갈수록 대부분 작아집니다.
2. 토픽 $k = 1, 2, \dots$마다 단어 분포 $\boldsymbol{\phi}_k \sim \mathrm{Dir}(\eta)$를 뽑습니다(LDA의 $\boldsymbol{\beta}_k$에 해당. 여기서는 $\boldsymbol{\beta}$를 전역 비율로 썼으므로 기호를 바꿨습니다).
3. 문서 $t$마다 토픽 비율 $\Theta_t \sim \mathrm{DP}(\alpha, \boldsymbol{\beta})$를 뽑습니다. 모든 문서가 같은 $\boldsymbol{\beta}$를 기준 분포로 쓰므로 같은 토픽들을 공유합니다.
4. 단어마다 $z_{t,n} \sim \Theta_t$, $w_{t,n} \sim \boldsymbol{\phi}_{z_{t,n}}$.

LDA와 비교하면, LDA는 $\Theta_t \sim \mathrm{Dir}(\boldsymbol{\alpha})$에서 $\boldsymbol{\alpha}$가 고정된 $K$차원 벡터인데, HDP는 이를 $\alpha \boldsymbol{\beta}$로 두고 $\boldsymbol{\beta}$ 자체를 무한 차원 사전분포에서 학습합니다. 실제로 유한한 $L$개 토픽에서 $\boldsymbol{\beta} \sim \mathrm{Dir}(\gamma/L, \dots, \gamma/L)$, $\Theta_t \sim \mathrm{Dir}(\alpha \boldsymbol{\beta})$로 둔 LDA의 $L \to \infty$ 극한이 HDP입니다. 2층 구조가 필요한 이유는, 문서마다 따로 디리클레 프로세스를 두면 연속인 기준 분포에서 뽑힌 토픽이 문서끼리 겹칠 확률이 0이 되어 토픽이 공유되지 않기 때문입니다.

**추론: 직접 배정 깁스 샘플링(Teh et al., 2006, 5.3절).** 현재 쓰이는 토픽 $K$개의 비율 $\beta_1, \dots, \beta_K$와 "아직 쓰이지 않은 모든 토픽"의 몫 $\beta_u = 1 - \sum_k \beta_k$만 들고 다닙니다.

- 단어의 토픽: 문제 14.9와 같은 식에서 $\alpha_k$ 자리에 $\alpha\beta_k$가 들어가고, 새 토픽을 여는 칸이 하나 추가됩니다.

$$
p(z_{t,n} = k \mid \cdot) \propto
\begin{cases}
\left(n_{t,k}^{-} + \alpha\beta_k\right) \dfrac{n_{k,w}^{-} + \eta}{n_k^{-} + N\eta} & \text{기존 토픽 } k \\[2ex]
\alpha \beta_u \cdot \dfrac{1}{N} & \text{새 토픽}
\end{cases}
$$

  새 토픽의 $1/N$은 아직 단어가 없는 토픽이 단어 $w$를 낼 확률 $\int \phi_w \,\mathrm{Dir}(\boldsymbol{\phi} \mid \eta)\, d\boldsymbol{\phi} = 1/N$입니다. 새 토픽이 열리면 $b \sim \mathrm{Beta}(1, \gamma)$로 $\beta_u$를 $b\beta_u$(새 토픽)와 $(1-b)\beta_u$(남은 몫)로 쪼개고, 단어가 하나도 없어진 토픽은 지우고 그 몫을 $\beta_u$로 돌려줍니다.
- 전역 비율: 문서 $t$에서 토픽 $k$를 쓰는 단어 $n_{t,k}$개가 몇 개의 "테이블"(중국 음식점 프랜차이즈 표현의 보조 변수)을 이루는지 $m_{t,k} = \sum_{j=0}^{n_{t,k}-1} \mathrm{Bernoulli}\big(\tfrac{\alpha\beta_k}{\alpha\beta_k + j}\big)$로 뽑은 뒤, $(\beta_1, \dots, \beta_K, \beta_u) \sim \mathrm{Dir}(m_{\cdot 1}, \dots, m_{\cdot K}, \gamma)$로 갱신합니다.

```python
import numpy as np

def hdp_gibbs(docs, V, alpha=1.0, gamma=1.0, eta=0.01, iters=300, seed=0, K0=10, log=None):
    """HDP-LDA 직접 배정 깁스 샘플러. K0: 초기 토픽 수(결과의 토픽 수는 데이터가 정함)"""
    rng = np.random.default_rng(seed)
    z = [rng.integers(K0, size=len(d)) for d in docs]
    ndk = np.zeros((len(docs), K0)); nkw = np.zeros((K0, V))
    for d, (ws, zs) in enumerate(zip(docs, z)):
        np.add.at(ndk[d], zs, 1); np.add.at(nkw, (zs, ws), 1)
    nk = nkw.sum(1)
    beta = np.full(K0 + 1, 1.0 / (K0 + 1))             # [β_1, ..., β_K, β_u]
    for it in range(iters):
        for d, ws in enumerate(docs):
            for n, w in enumerate(ws):
                k = z[d][n]
                ndk[d, k] -= 1; nkw[k, w] -= 1; nk[k] -= 1
                if nk[k] == 0:                         # 빈 토픽 제거, 몫은 β_u로
                    beta[-1] += beta[k]; beta = np.delete(beta, k)
                    ndk = np.delete(ndk, k, 1); nkw = np.delete(nkw, k, 0); nk = np.delete(nk, k)
                    for zz in z: zz[zz > k] -= 1
                K = len(nk)
                p = np.append((ndk[d] + alpha * beta[:K]) * (nkw[:, w] + eta) / (nk + V * eta),
                              alpha * beta[K] / V)     # 마지막 칸: 새 토픽
                k = rng.choice(K + 1, p=p / p.sum())
                if k == K:                             # 새 토픽: 막대 쪼개기
                    b = rng.beta(1, gamma)
                    beta = np.append(beta[:K], [b * beta[K], (1 - b) * beta[K]])
                    ndk = np.hstack([ndk, np.zeros((len(docs), 1))])
                    nkw = np.vstack([nkw, np.zeros(V)]); nk = np.append(nk, 0)
                z[d][n] = k; ndk[d, k] += 1; nkw[k, w] += 1; nk[k] += 1
        K = len(nk); m = np.zeros(K)                   # 테이블 수 샘플링
        for d in range(len(docs)):
            for k in np.nonzero(ndk[d])[0]:
                j = np.arange(int(ndk[d, k]))
                m[k] += (rng.random(j.size) < alpha * beta[k] / (alpha * beta[k] + j)).sum()
        beta = rng.dirichlet(np.append(m, gamma))      # 전역 비율 갱신
        if log: log(it, K, nkw)
    return ndk, nkw, beta
```

**실험.** 문제 14.9의 가상 소설(실제 토픽 4개)에 토픽 수를 알려주지 않고 적용했습니다. $\alpha = \gamma = 1$, $\eta = 0.01$, 처음에 토픽 10개에 무작위로 배정해 600회 돌렸습니다(시드 0).

| 반복 | 토픽 수 | 토픽별 단어 수 |
|---|---|---|
| 100 | 7 | 1,223 / 1,193 / 1,164 / 587 / 485 / 84 / 64 |
| 200 | 9 | 1,269 / 1,259 / 1,172 / 973 / 91 / 19 / 11 / 5 / 1 |
| 300 | 6 | 1,313 / 1,263 / 1,157 / 1,055 / 11 / 1 |
| 400 | 4 | 1,334 / 1,279 / 1,132 / 1,055 |
| 600 | 5 | 1,377 / 1,278 / 1,134 / 1,008 / 3 |

- 남은 토픽 수 자체는 301~600회에서 4개(119회), 5개(146회), 6개(31회), 7개(4회)로 오르내립니다. 늘 단어 몇 개짜리 작은 토픽이 새로 열렸다가 사라지기 때문입니다(새 토픽 칸의 확률이 0이 아니므로 자연스러운 현상입니다).
- 전체 단어의 1% 이상을 가진 토픽만 세면 301~600회 300번 모두 정확히 4개였습니다. 시드 1, 2, 3으로 다시 돌려도 300번 모두 4개였습니다.
- 큰 토픽 4개를 실제 토픽과 짝지으면 L1 거리가 전쟁 0.273, 고향 0.165, 사랑 0.237, 바다 0.296이고 상위 단어도 문제 14.9의 LDA($K = 4$를 알려준 경우)와 같은 단어들이었습니다.

즉 토픽 수를 알려주지 않아도 사후분포가 실제 구조인 4개 토픽에 질량을 모읍니다. 다만 주의할 점이 두 가지 있습니다.

1. **초기화와 혼합.** 토픽 1개에서 시작하면(K0 = 1) 시드 0에서는 600회 뒤에도 단어 수 1,373 / 1,254 / 1,032 / 698 / 437로 큰 토픽이 5개인 상태에 머물렀고, 시드 1에서는 600회에 1,341 / 1,288 / 1,119 / 1,052의 4개로 정리되었습니다. 단어 하나씩 옮기는 깁스 샘플링은 토픽을 둘로 쪼개거나 둘을 합치는 큰 이동이 어려워서, 넉넉한 수의 토픽에서 시작하거나 분할-병합 이동을 추가하는 것이 실무적인 해법입니다.
2. **하이퍼파라미터는 남습니다.** $K$는 없어졌지만 $\gamma$(새 토픽을 얼마나 쉽게 여는지)와 $\alpha$, $\eta$가 토픽 수에 영향을 줍니다. 사전분포에서 토픽 수는 데이터 양에 대해 대략 로그적으로 늘어나며, 보통 $\alpha$, $\gamma$에도 감마 사전분포를 두어 함께 샘플링합니다.

이 밖에 토픽 수를 데이터로 정하는 더 단순한 방법으로, 여러 $K$에 대해 LDA를 학습하고 검증 문서의 로그 우도(혹은 퍼플렉서티)가 가장 좋은 $K$를 고르는 모델 선택이 있습니다. 하지만 이것은 $K$를 바꿔 가며 여러 번 학습하는 절차이고, 모델 자체가 $K$를 정하는 것은 HDP 같은 비모수 모델입니다.
