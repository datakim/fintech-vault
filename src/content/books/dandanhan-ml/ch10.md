## 문제 10.1

> k최근접 분류기의 코드를 작성하고, 수박 데이터 세트 3.0$\alpha$상에서 그들의 분류 경계와 의사결정 트리 분류 경계의 차이를 비교해 보아라.

**풀이**

수박 데이터 세트 3.0$\alpha$(4장 표 4.5)는 밀도와 당도 두 개의 연속 속성과 17개 샘플로 이루어져 있습니다. 두 속성 모두 0~1 범위에 있어서 따로 정규화하지 않고 유클리드 거리를 그대로 썼습니다. 비교 대상인 의사결정 트리는 책의 그림 4.10(같은 데이터로 학습한 트리)을 규칙으로 그대로 옮겼습니다.

```python
import numpy as np

# 표 4.5 수박 데이터 세트 3.0α (밀도, 당도, 잘 익은 수박: 1=예, 0=아니오)
data = np.array([
    [0.697, 0.460, 1], [0.774, 0.376, 1], [0.634, 0.264, 1], [0.608, 0.318, 1],
    [0.556, 0.215, 1], [0.403, 0.237, 1], [0.481, 0.149, 1], [0.437, 0.211, 1],
    [0.666, 0.091, 0], [0.243, 0.267, 0], [0.245, 0.057, 0], [0.343, 0.099, 0],
    [0.639, 0.161, 0], [0.657, 0.198, 0], [0.360, 0.370, 0], [0.593, 0.042, 0],
    [0.719, 0.103, 0]])
X, y = data[:, :2], data[:, 2].astype(int)

def knn_predict(X_train, y_train, X_test, k):
    d = np.sqrt(((X_test[:, None, :] - X_train[None, :, :]) ** 2).sum(-1))
    idx = np.argsort(d, axis=1, kind="stable")[:, :k]   # k개 최근접 이웃
    return (y_train[idx].mean(axis=1) > 0.5).astype(int)  # 다수결 투표 (k 홀수)

def tree_predict(X):            # 그림 4.10의 의사결정 트리
    out = []
    for den, sug in X:
        if sug <= 0.126:   out.append(0)
        elif den <= 0.381: out.append(0)
        elif sug > 0.205:  out.append(1)
        else:              out.append(1 if den <= 0.560 else 0)
    return np.array(out)

def loo_acc(k):                 # Leave-one-out 정확도
    hit = 0
    for i in range(len(X)):
        m = np.arange(len(X)) != i
        hit += knn_predict(X[m], y[m], X[i:i+1], k)[0] == y[i]
    return hit / len(X)

for k in (1, 3, 5, 7):
    tr = (knn_predict(X, y, X, k) == y).mean()
    print(f"k={k}: 훈련 정확도 {tr:.3f}, LOO 정확도 {loo_acc(k):.3f}")
print("트리 훈련 정확도", (tree_predict(X) == y).mean())
```

4. **학습 방식.** 트리는 열정적 학습이라 훈련 때 규칙을 만들고 예측은 몇 번의 비교로 끝나며 규칙을 해석하기 쉽습니다. kNN은 게으른 학습이라 훈련 비용은 없지만 예측할 때마다 모든 훈련 샘플과의 거리를 계산하고, 속성의 스케일이 다르면 거리척도가 바뀌어 경계도 달라집니다.

## 문제 10.2

> $err$와 $err^*$를 각각 최근접 분류기와 베이즈 최적 분류기의 기대 오차율로 설정하고 다음을 증명하라.
>
> $$err^* \leqslant err \leqslant err^*\left(2 - \frac{|\mathcal{Y}|}{|\mathcal{Y}|-1} \times err^*\right). \quad (\text{식 } 10.40)$$

**풀이**

10.1절의 가정을 그대로 씁니다. 샘플은 독립항등분포이고 밀도 샘플링이 성립해서, 테스트 샘플 $\boldsymbol{x}$의 최근접 이웃 $\boldsymbol{z}$가 $\boldsymbol{x}$에 한없이 가까워지고 $P(c \mid \boldsymbol{z}) \simeq P(c \mid \boldsymbol{x})$라고 봅니다. 그러면 식 10.1, 10.2와 같이 한 점 $\boldsymbol{x}$에서의 오분류 확률은 다음과 같습니다.

$$err(\boldsymbol{x}) = 1 - \sum_{c \in \mathcal{Y}} P(c \mid \boldsymbol{x})P(c \mid \boldsymbol{z}) \simeq 1 - \sum_{c \in \mathcal{Y}} P^2(c \mid \boldsymbol{x}).$$

기호를 줄이기 위해 $K = |\mathcal{Y}|$, $p_c = P(c \mid \boldsymbol{x})$, $c^* = \arg\max_c p_c$, $p^* = p_{c^*}$로 두겠습니다. 베이즈 최적 분류기는 $c^*$를 출력하므로 한 점에서의 오차율은

$$err^*(\boldsymbol{x}) = 1 - p^* = \sum_{c \neq c^*} p_c$$

이고, 기대 오차율은 $err = \mathbb{E}_{\boldsymbol{x}}[err(\boldsymbol{x})]$, $err^* = \mathbb{E}_{\boldsymbol{x}}[err^*(\boldsymbol{x})]$입니다.

**Step 1. 하한 $err^* \leqslant err$.** 모든 $c$에 대해 $p_c \leqslant p^*$이므로

$$\sum_c p_c^2 \leqslant \sum_c p_c \, p^* = p^* \sum_c p_c = p^*.$$

따라서 $err(\boldsymbol{x}) = 1 - \sum_c p_c^2 \geqslant 1 - p^* = err^*(\boldsymbol{x})$이고, 양변의 기댓값을 취하면 $err \geqslant err^*$입니다. (베이즈 최적 분류기는 모든 분류기 중 기대 오차율이 가장 작으므로 이 부등식은 가정 없이도 성립합니다.)

**Step 2. 한 점에서의 상한.** $c^*$가 아닌 $K-1$개 클래스의 확률에 코시-슈바르츠 부등식 $\left(\sum_{c \neq c^*} p_c \cdot 1\right)^2 \leqslant (K-1)\sum_{c \neq c^*} p_c^2$를 적용하면

$$\sum_{c \neq c^*} p_c^2 \geqslant \frac{1}{K-1}\left(\sum_{c \neq c^*} p_c\right)^2 = \frac{err^*(\boldsymbol{x})^2}{K-1}.$$

$e = err^*(\boldsymbol{x})$로 쓰면 $p^* = 1 - e$이므로

$$\sum_c p_c^2 = (p^*)^2 + \sum_{c \neq c^*} p_c^2 \geqslant (1-e)^2 + \frac{e^2}{K-1}.$$

따라서

$$
\begin{aligned}
err(\boldsymbol{x}) &\leqslant 1 - (1-e)^2 - \frac{e^2}{K-1} \\
&= 2e - e^2 - \frac{e^2}{K-1} \\
&= 2e - \frac{K}{K-1}e^2.
\end{aligned}
$$
**Step 3. 기댓값을 취합니다.** 위 식의 양변에 $\mathbb{E}_{\boldsymbol{x}}$를 취하면

$$err \leqslant 2\,\mathbb{E}[err^*(\boldsymbol{x})] - \frac{K}{K-1}\,\mathbb{E}\left[err^*(\boldsymbol{x})^2\right].$$

분산은 음수가 아니므로 $\mathbb{E}[err^*(\boldsymbol{x})^2] \geqslant \left(\mathbb{E}[err^*(\boldsymbol{x})]\right)^2 = (err^*)^2$입니다. 이 항 앞의 계수 $-\frac{K}{K-1}$가 음수이므로

$$err \leqslant 2\,err^* - \frac{K}{K-1}(err^*)^2 = err^*\left(2 - \frac{|\mathcal{Y}|}{|\mathcal{Y}|-1} \times err^*\right).$$

Step 1과 합치면 식 10.40이 성립합니다. ∎

몇 가지 덧붙입니다.

- $\frac{K}{K-1}err^* \geqslant 0$이므로 이 상한은 식 10.2의 $2 \times err^*$보다 작거나 같습니다. 즉 식 10.40은 책 본문의 "베이즈 최적 오차율의 2배를 넘지 않는다"를 다중 클래스로 정밀하게 만든 결과입니다. 이진 분류($K=2$)에서는 $err \leqslant 2\,err^*(1 - err^*)$가 됩니다.
- 항상 $p^* \geqslant \frac{1}{K}$이라 $err^* \leqslant \frac{K-1}{K}$이므로 $2 - \frac{K}{K-1}err^* \geqslant 1$이 되어, 상한이 하한보다 작아지는 일은 없습니다.
- 등호는 모든 $\boldsymbol{x}$에서 $err^*(\boldsymbol{x})$가 같은 값 $e$이고, 사후 확률이 $(1-e, \frac{e}{K-1}, \dots, \frac{e}{K-1})$처럼 나머지 클래스에 균등하게 퍼져 있을 때 성립합니다. 예를 들어 $K=4$, $e=0.3$이면 $1-\sum p_c^2 = 0.48 = 0.3 \times (2 - \frac{4}{3} \times 0.3)$입니다.
- 증명의 "$\simeq$"는 훈련 샘플 수가 무한히 많아지는 극한에서의 이야기입니다. 엄밀한 조건(사후 확률의 연속성 등)은 책 여백에 소개된 [Cover and Hart, 1967]에 있습니다.

검산 삼아 $K = 2, 3, 5, 10$에 대해 디리클레 분포로 사후 확률 벡터를 2만 개씩 뽑아 Step 1~2의 점별 부등식을 확인했고(시드 0), 위반 사례는 없었습니다.

## 문제 10.3

> 고차원 데이터 차원 축소 전에 먼저 전처리가 필요하다. 자주 보이는 방법은 공분산 행렬 $\mathbf{X}\mathbf{X}^{\mathrm{T}}$를 $\mathbf{X}\mathbf{H}\mathbf{H}^{\mathrm{T}}\mathbf{X}^{\mathrm{T}}$로 전환하는 것인데, 여기서 $\mathbf{H} = \mathbf{I} - \frac{1}{m}\mathbf{1}\mathbf{1}^{\mathrm{T}}$이다. 이에 대한 효과를 분석하라.

**풀이**

**Step 1. $\mathbf{H}$의 성질.** $\mathbf{H}$는 중심화 행렬(centering matrix)이라고 부릅니다. 대칭이고($\mathbf{H}^{\mathrm{T}} = \mathbf{H}$), $\mathbf{1}^{\mathrm{T}}\mathbf{1} = m$이므로 멱등입니다.

$$\mathbf{H}^2 = \mathbf{I} - \frac{2}{m}\mathbf{1}\mathbf{1}^{\mathrm{T}} + \frac{1}{m^2}\mathbf{1}(\mathbf{1}^{\mathrm{T}}\mathbf{1})\mathbf{1}^{\mathrm{T}} = \mathbf{I} - \frac{1}{m}\mathbf{1}\mathbf{1}^{\mathrm{T}} = \mathbf{H}.$$

또 $\mathbf{H}\mathbf{1} = \mathbf{0}$이고, $\mathbf{1}$에 수직인 벡터 $\boldsymbol{v}$는 $\mathbf{H}\boldsymbol{v} = \boldsymbol{v}$입니다. 즉 $\mathbf{H}$는 $\mathbf{1}$에 수직인 $(m-1)$차원 부분공간으로의 직교 투영 행렬이고, 고윳값은 1이 $m-1$개, 0이 1개입니다.

**Step 2. $\mathbf{X}\mathbf{H}$는 평균을 뺀 샘플 행렬입니다.** $\boldsymbol{\mu} = \frac{1}{m}\sum_i \boldsymbol{x}_i = \frac{1}{m}\mathbf{X}\mathbf{1}$로 두면

$$\mathbf{X}\mathbf{H} = \mathbf{X} - \frac{1}{m}\mathbf{X}\mathbf{1}\mathbf{1}^{\mathrm{T}} = \mathbf{X} - \boldsymbol{\mu}\mathbf{1}^{\mathrm{T}} = (\boldsymbol{x}_1 - \boldsymbol{\mu}, \dots, \boldsymbol{x}_m - \boldsymbol{\mu}).$$

따라서

$$\mathbf{X}\mathbf{H}\mathbf{H}^{\mathrm{T}}\mathbf{X}^{\mathrm{T}} = (\mathbf{X}\mathbf{H})(\mathbf{X}\mathbf{H})^{\mathrm{T}} = \sum_{i=1}^m (\boldsymbol{x}_i - \boldsymbol{\mu})(\boldsymbol{x}_i - \boldsymbol{\mu})^{\mathrm{T}}$$

로, 표본 공분산 행렬에 $m-1$(또는 $m$)을 곱한 것과 같습니다. 그림 10.5 PCA 알고리즘 1단계의 "$\boldsymbol{x}_i \leftarrow \boldsymbol{x}_i - \frac{1}{m}\sum_i \boldsymbol{x}_i$"를 행렬 하나로 쓴 것입니다.

**Step 3. 효과.**

1. **PCA 유도의 전제를 맞춰 줍니다.** 식 10.14~10.17은 $\sum_i \boldsymbol{x}_i = \mathbf{0}$을 가정해서 $\mathbf{X}\mathbf{X}^{\mathrm{T}}$를 공분산 행렬로 썼습니다. 중심화하지 않으면 $\mathbf{X}\mathbf{X}^{\mathrm{T}} = \sum_i (\boldsymbol{x}_i - \boldsymbol{\mu})(\boldsymbol{x}_i - \boldsymbol{\mu})^{\mathrm{T}} + m\boldsymbol{\mu}\boldsymbol{\mu}^{\mathrm{T}}$이 되어, 평균 방향의 항 $m\boldsymbol{\mu}\boldsymbol{\mu}^{\mathrm{T}}$이 끼어듭니다. 평균이 원점에서 멀면 첫 번째 고유 벡터가 분산이 큰 방향이 아니라 평균 벡터 방향을 가리키게 됩니다.
2. **원점 선택에 영향받지 않습니다.** 모든 샘플에 같은 벡터 $\boldsymbol{b}$를 더해도 $\mathbf{1}^{\mathrm{T}}\mathbf{H} = \mathbf{0}^{\mathrm{T}}$이므로 $(\mathbf{X} + \boldsymbol{b}\mathbf{1}^{\mathrm{T}})\mathbf{H} = \mathbf{X}\mathbf{H}$입니다. 측정 단위의 기준점(예: 섭씨와 절대온도)이 달라도 같은 주성분을 얻습니다.
3. **유효한 성분 수가 정해집니다.** $\mathbf{H}$의 계수가 $m-1$이므로 $\operatorname{rank}(\mathbf{X}\mathbf{H}) \leqslant \min(d, m-1)$입니다. $d \gg m$인 고차원 데이터에서는 0이 아닌 고윳값이 최대 $m-1$개라는 뜻이고, 문제 10.4의 실험에서 $d=3000$, $m=200$일 때 실제로 199개였습니다.
4. **새 샘플에도 같은 평균을 빼야 합니다.** 책 275쪽에서 PCA가 $\mathbf{W}^*$와 함께 평균 벡터를 보존하는 이유가 이것입니다.
5. **같은 행렬이 다른 곳에서도 쓰입니다.** MDS의 식 10.10은 행렬로 쓰면 $\mathbf{B} = -\frac{1}{2}\mathbf{H}\mathbf{D}^{(2)}\mathbf{H}$($\mathbf{D}^{(2)}$는 거리 제곱 행렬)이고, 커널 PCA에서도 특징 공간의 평균을 빼기 위해 커널 행렬을 $\mathbf{H}\mathbf{K}\mathbf{H}$로 바꿔 씁니다.

간단한 실험으로 1번 효과를 확인했습니다. 평균이 $(10, 10)$이고 분산이 가장 큰 방향이 $(1, -1)/\sqrt{2}$(그 방향 표준편차 3, 수직 방향 0.5)인 2차원 샘플 200개를 만들었습니다(시드 0).

| 사용한 행렬 | 첫 번째 고유 벡터 | 그 방향 투영의 분산 |
|-------------|-------------------|--------------------|
| $\mathbf{X}\mathbf{X}^{\mathrm{T}}$ | $(0.709, 0.705)$ | 0.262 |
| $\mathbf{X}\mathbf{H}\mathbf{H}^{\mathrm{T}}\mathbf{X}^{\mathrm{T}}$ | $(0.699, -0.715)$ | 8.316 |

중심화하지 않으면 첫 번째 성분이 평균 방향 $(1,1)/\sqrt{2}$를 가리켜 오히려 분산이 가장 작은 방향을 고르고, 중심화하면 의도한 최대 분산 방향(이론값 분산 9)을 찾습니다.

## 문제 10.4

> 실전에서 공분산 행렬 $\mathbf{X}\mathbf{X}^{\mathrm{T}}$의 특잇값 분해는 전처리 후의 샘플 행렬 $\mathbf{X}$의 특잇값 분해로 대체된다. 이 이유에 대해 설명하라.

**풀이**

**Step 1. 두 방법은 같은 답을 줍니다.** 중심화한 $\mathbf{X} \in \mathbb{R}^{d \times m}$의 특잇값 분해를 $\mathbf{X} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\mathrm{T}}$라 하면

$$\mathbf{X}\mathbf{X}^{\mathrm{T}} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\mathrm{T}}\mathbf{V}\boldsymbol{\Sigma}^{\mathrm{T}}\mathbf{U}^{\mathrm{T}} = \mathbf{U}\boldsymbol{\Sigma}\boldsymbol{\Sigma}^{\mathrm{T}}\mathbf{U}^{\mathrm{T}}$$

입니다. 그러므로 $\mathbf{X}$의 왼쪽 특이 벡터가 $\mathbf{X}\mathbf{X}^{\mathrm{T}}$의 고유 벡터이고, 고윳값은 $\lambda_i = \sigma_i^2$입니다. PCA의 해 $\mathbf{W}^*$는 $\mathbf{U}$의 앞쪽 $d'$개 열이고, 저차원 좌표도 $\mathbf{Z} = \mathbf{W}^{*\mathrm{T}}\mathbf{X} = \boldsymbol{\Sigma}_{d'}\mathbf{V}_{d'}^{\mathrm{T}}$로 분해 결과에서 바로 나옵니다. 결과가 같으니 어느 쪽이 더 정확하고 싼지가 기준이 됩니다.

**Step 2. 수치 정확도.** $\mathbf{X}\mathbf{X}^{\mathrm{T}}$를 만들면 조건수가 제곱이 됩니다($\kappa(\mathbf{X}\mathbf{X}^{\mathrm{T}}) = \kappa(\mathbf{X})^2$). 작은 특잇값 $\sigma$는 $\sigma^2$이 되어 큰 값과 더해질 때 부동소수점 반올림에 묻힐 수 있습니다. 예를 들어 $\varepsilon = 10^{-9}$일 때

$$\mathbf{X} = \begin{pmatrix} 1 & \varepsilon & 0 \\ 1 & 0 & \varepsilon \end{pmatrix}, \qquad \mathbf{X}\mathbf{X}^{\mathrm{T}} = \begin{pmatrix} 1+\varepsilon^2 & 1 \\ 1 & 1+\varepsilon^2 \end{pmatrix}
$$
이고 참 고윳값은 $2+\varepsilon^2$과 $\varepsilon^2 = 10^{-18}$입니다. 배정밀도에서 $1 + 10^{-18}$은 1로 반올림되므로, 실제로 numpy로 계산하면 $\mathbf{X}\mathbf{X}^{\mathrm{T}}$의 고윳값 분해는 $(2, 0)$을 내고, $\mathbf{X}$의 특잇값 분해는 $\sigma^2 = (2, 10^{-18})$을 정확히 냅니다.

**Step 3. 계산량과 메모리.** $\mathbf{X}\mathbf{X}^{\mathrm{T}}$는 $d \times d$ 행렬입니다. 이미지처럼 $d \gg m$이면 이 행렬을 만드는 데 $O(d^2 m)$, 저장에 $O(d^2)$, 고윳값 분해에 $O(d^3)$이 듭니다. 반면 $\mathbf{X}$의 얇은 특잇값 분해는 $O(dm^2)$이면 되고 $d \times d$ 행렬을 만들 필요가 없습니다. 같은 컴퓨터에서 재 보면 다음과 같았습니다(시간은 환경에 따라 다릅니다).

| 크기 | $\mathbf{X}\mathbf{X}^{\mathrm{T}}$ 생성 + 고윳값 분해 | $\mathbf{X}$ 얇은 SVD |
|------|------------------------------------|----------------|
| $d = 3000$, $m = 200$ | 1.53초 | 0.021초 |
| $d = 10000$, $m = 200$ | 공분산 행렬만 800MB | 0.056초 |

$d = 3000$일 때 두 방법의 상위 5개 고윳값과 첫 번째 고유 벡터(부호 제외)는 일치했습니다. 또한 실전에서는 상위 $d'$개만 필요하므로, $\mathbf{X}$에 대해 절단(truncated) SVD나 무작위(randomized) SVD를 쓰면 공분산 행렬 없이 필요한 성분만 더 빠르게 구할 수 있습니다.

정리하면, 결과는 같으면서 정확도, 시간, 메모리 모두 $\mathbf{X}$의 특잇값 분해가 유리하기 때문에 대체합니다. 책 274쪽 여백의 "실제로 $\mathbf{X}$에 대한 특잇값 분해를 진행하는 것으로 공분산 행렬의 고윳값 분해를 대체할 수 있다"는 설명이 이 내용입니다.

## 문제 10.5

> 차원 축소에서 접하는 투영 행렬은 직교를 요구한다. 직교와 비직교 투영 행렬을 차원 축소에 이용했을 때의 장단점을 서술하라.

**풀이**

투영 행렬 $\mathbf{W} \in \mathbb{R}^{d \times d'}$가 직교라는 것은 $\mathbf{W}^{\mathrm{T}}\mathbf{W} = \mathbf{I}$, 즉 기저 벡터들이 서로 수직이고 길이가 1이라는 뜻입니다(식 10.15, 10.16의 제약 조건).

| | 직교 투영 ($\mathbf{W}^{\mathrm{T}}\mathbf{W} = \mathbf{I}$) | 비직교 투영 |
|---|---|---|
| 기하 | 부분공간 안에서 거리와 각도가 보존되고, 새 좌표 사이에 중복이 없음 | 축마다 늘이고 줄이거나 비스듬해서 거리와 각도가 왜곡됨 |
| 복원 | $\hat{\boldsymbol{x}} = \mathbf{W}\mathbf{W}^{\mathrm{T}}\boldsymbol{x}$로 간단 | $\mathbf{W}(\mathbf{W}^{\mathrm{T}}\mathbf{W})^{-1}\mathbf{W}^{\mathrm{T}}\boldsymbol{x}$처럼 역행렬이 필요 |
| 최적화 | 고윳값 분해 한 번으로 닫힌 해(PCA). 제약이 척도를 고정해 목적 함수가 발산하지 않음 | 제약이 없으면 $\operatorname{tr}(\mathbf{W}^{\mathrm{T}}\mathbf{X}\mathbf{X}^{\mathrm{T}}\mathbf{W})$처럼 $\mathbf{W}$의 크기를 키우는 것만으로 목적 함수가 커지므로 다른 정규화 조건이 필요 |
| 수치 안정성 | 직교 행렬은 조건수가 1이라 안정적 | 기저가 거의 평행하면 조건수가 커져 불안정 |
| 표현력 | 기저가 반드시 서로 수직이어야 해서, 데이터가 실제로 수직이 아닌 방향으로 구조를 갖는 경우를 담지 못함 | 판별에 유리한 방향(LDA의 일반화 고윳값 문제 해), 서로 독립인 원천 신호(ICA), 부분 기반 표현(NMF)처럼 수직이 아닌 방향을 찾을 수 있음 |
| 해석 | 성분이 전체 속성의 혼합이라 의미를 붙이기 어려운 경우가 많음 | 비음수 제약 등과 결합해 해석하기 쉬운 성분을 얻을 수 있음 |
| 새 좌표 간 관계 | PCA의 경우 새 좌표끼리 상관이 0 | 새 좌표끼리 상관이 남을 수 있음 |

요약하면 직교 투영은 정보 중복이 없고 계산과 복원이 쉬우며 안정적이라는 점에서 기본 선택이 됩니다. 비직교 투영은 이 제약을 풀어 판별력, 독립성, 해석 가능성 같은 다른 목표에 맞는 방향을 찾을 수 있지만, 그 대가로 거리 왜곡과 중복이 생기고 척도를 고정할 별도의 제약이 필요합니다. 10.6절의 척도 학습에서 $\mathbf{M} = \mathbf{P}\mathbf{P}^{\mathrm{T}}$의 $\mathbf{P}$가 직교일 필요가 없는 것도 같은 맥락입니다. 축마다 다른 가중치를 주는 것 자체가 목적이기 때문입니다.

## 문제 10.6

> 매트랩(MATLAB)의 PCA 함수를 사용해서 Yale 얼굴인식 데이터를 차원 축소하라. 그리고 20개의 특성 벡터에 대응하는 이미지를 관찰해 보아라.

**풀이**

책 여백은 매트랩의 `princomp` 함수와 Yale 얼굴 데이터(인터넷 다운로드)를 안내하지만, 여기서는 매트랩 대신 numpy로 PCA를 직접 구현하고, 데이터는 인터넷 없이 쓸 수 있는 **scikit-learn 내장 손글씨 숫자 데이터**(`load_digits`, 8×8 픽셀 이미지 1,797장, $d = 64$)로 **대체**했습니다. 얼굴 대신 숫자 이미지라는 점만 다르고, "특성 벡터를 이미지로 되돌려 관찰한다"는 문제의 취지는 그대로입니다.

```python
import numpy as np
from sklearn.datasets import load_digits

D = load_digits()
X = D.data.T                          # d x m = 64 x 1797 (열이 샘플)
mu = X.mean(axis=1, keepdims=True)
Xc = X - mu                           # 그림 10.5의 1단계: 중심화
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)   # 문제 10.4: X의 SVD로 대체
lam = s**2 / (X.shape[1] - 1)         # 공분산 행렬의 고윳값
W = U[:, :20]                         # 상위 20개 특성 벡터 (64 x 20)

ratio = np.cumsum(lam) / lam.sum()
print("상위 20개 누적 분산 비율:", ratio[19].round(4))
for t in (0.8, 0.9, 0.95):            # 식 10.18
    print(f"t={t}: d' =", int(np.argmax(ratio >= t)) + 1)
X_hat = W @ (W.T @ Xc) + mu           # 20차원으로 줄였다가 복원
print("복원 RMSE:", np.sqrt(((X - X_hat)**2).mean()).round(3))

# 각 특성 벡터 W[:, j]를 8x8로 reshape하면 '고유 숫자(eigen-digit)' 이미지가 된다
eigen_images = [W[:, j].reshape(8, 8) for j in range(20)]
```

**수치 결과.**

- 상위 20개 성분이 전체 분산의 89.43%를 설명합니다. 성분별 비율은 14.89%, 13.62%, 11.79%, 8.41%, 5.78%, ... , 20번째 0.91%로 빠르게 줄어듭니다.
- 식 10.18의 임곗값 $t$에 따른 $d'$는 $t = 0.8$일 때 13, $0.9$일 때 21, $0.95$일 때 29입니다.
- 20차원으로 줄였다가 복원하면 픽셀 RMSE가 1.409(픽셀값 범위 0~16)입니다.

## 문제 10.7

> 커널 선형 차원 축소와 매니폴드 학습 사이의 관계와 장단점을 서술하라.

**풀이**

**관계.** 두 방법 모두 "어떤 $m \times m$ 행렬을 고윳값 분해해서 상위(또는 하위) 고유 벡터로 저차원 좌표를 만든다"는 같은 틀에 있습니다. 차이는 그 행렬을 어디서 가져오느냐입니다.

- 커널 PCA(KPCA)는 RBF, 다항식 같은 **미리 정한** 커널 $\kappa(\boldsymbol{x}_i, \boldsymbol{x}_j)$로 커널 행렬 $\mathbf{K}$를 만들고 식 10.24 $\mathbf{K}\boldsymbol{\alpha}^j = \lambda_j\boldsymbol{\alpha}^j$를 풉니다.
- 매니폴드 학습은 데이터에서 **이웃 그래프로 만든** 행렬을 씁니다. Isomap은 측지선 거리 행렬 $\mathbf{D}_G$로 $\mathbf{K} = -\frac{1}{2}\mathbf{H}\mathbf{D}_G^{(2)}\mathbf{H}$(식 10.10의 MDS 내적 행렬)를 만들고, LLE는 식 10.30의 $\mathbf{M}$에서 고윳값이 가장 작은 고유 벡터를 쓰는데, 이는 $\lambda_{\max}\mathbf{I} - \mathbf{M}$의 가장 큰 고유 벡터를 쓰는 것과 같습니다.

그래서 매니폴드 학습은 **데이터로부터 학습한 커널을 쓰는 KPCA**로 볼 수 있습니다. 실제로 스위스 롤(아래 실험과 같은 1,000개)에서 $k = 10$ 이웃 그래프의 측지선 거리로 $\mathbf{K} = -\frac{1}{2}\mathbf{H}\mathbf{D}_G^{(2)}\mathbf{H}$를 만들어 상위 2개 고유 벡터에 $\sqrt{\lambda}$를 곱했더니, scikit-learn `Isomap`의 결과와 부호를 맞춘 뒤 최대 차이가 $5 \times 10^{-13}$으로 일치했습니다. 다만 이 "커널"은 양의 준정부호가 아닐 수 있습니다. 같은 실험에서 1,000개 고윳값 중 470개가 음수였습니다(가장 큰 값 735,357.5, 가장 작은 값 −3,937.0). 측지선 거리 근사가 정확한 유클리드 거리 구조가 아니기 때문입니다.

**실험.** `make_swiss_roll`(1,000개, 잡음 0, `random_state=0`)로 만든 스위스 롤을 2차원으로 줄인 뒤, 임베딩 좌표로 롤의 고유 좌표(감긴 방향 $t$, 높이 $h$)를 선형 회귀했을 때의 $R^2$를 비교했습니다.

| 방법 | $R^2(t)$ | $R^2(h)$ | 임베딩 좌표와 $t$의 순위 상관 최댓값 |
|------|---------|---------|------------------------|
| PCA | 0.056 | 0.480 | 0.198 |
| KPCA, RBF $\gamma = 0.01$ | 0.019 | 0.271 | 0.137 |
| KPCA, RBF $\gamma = 0.1$ | 0.229 | 0.218 | 0.151 |
| KPCA, 3차 다항식 | 0.055 | 0.728 | 0.200 |
| Isomap, $k = 10$ | 0.984 | 0.983 | 1.000 |
| LLE, $k = 12$ | 0.984 | 0.719 | 1.000 |

일반적인 커널로는 롤을 펴지 못했고, 이웃 그래프를 쓰는 Isomap과 LLE는 감긴 방향을 거의 완벽하게 복원했습니다. 커널을 "데이터의 기하에 맞게" 고르는 것이 핵심이라는 것을 보여 줍니다.

**장단점.**

| | 커널 선형 차원 축소 (KPCA 등) | 매니폴드 학습 (Isomap, LLE 등) |
|---|---|---|
| 커널(유사도) | 사전에 고름. 데이터 구조를 모르면 맞는 커널과 파라미터를 고르기 어려움 | 이웃 그래프로 데이터에서 만듦. 저차원 매니폴드 구조를 직접 반영 |
| 비선형 구조 복원 | 커널이 맞지 않으면 실패(위 실험) | 매니폴드가 잘 샘플링되어 있으면 펼칠 수 있음 |
| 이론적 성질 | 커널이 양의 준정부호라 특징 공간의 PCA로 해석이 명확 | Isomap 커널은 양의 준정부호가 아닐 수 있어 MDS 근사가 됨 |
| 새 샘플 | 식 10.25로 바로 계산 가능 | 명시적 사상이 없어 회귀나 별도 방법이 필요(책 279쪽, 문제 10.9) |
| 파라미터 민감도 | 커널 파라미터(예: $\gamma$)에 민감 | 이웃 크기 $k$나 $\epsilon$에 민감, 단축·절단 문제(문제 10.8) |
| 잡음과 샘플링 | 전역 구조를 보므로 국소 잡음에 상대적으로 덜 민감 | 밀도 샘플링이 필요하고 잡음이 이웃 그래프를 망가뜨리기 쉬움(책 286쪽) |
| 계산 | $m \times m$ 밀집 커널 행렬, 고윳값 분해 $O(m^3)$ | Isomap은 최단 경로와 밀집 행렬로 비슷하게 큼. LLE는 희소 행렬이라 상대적으로 가벼움 |

## 문제 10.8\* (심화)

> k근접 그래프와 $\epsilon$근접 그래프는 '단축 길'과 '절단 길' 문제가 존재해 Isomap 학습을 어렵게 한다. 이에 대한 해결 방안을 논의하라.

**풀이**

**두 문제의 정의.** 책 280쪽의 설명과 연결하면 다음과 같습니다.

- **단축 길(short circuit).** 이웃 범위($k$ 또는 $\epsilon$)가 너무 크거나 잡음이 있으면, 매니폴드 위에서는 멀지만 고차원 공간에서 직선 거리가 가까운 두 점(예: 스위스 롤의 서로 다른 층)이 이웃으로 연결됩니다. 이런 간선이 하나만 있어도 많은 쌍의 최단 경로가 그 간선을 지나가면서 측지선 거리가 크게 줄어듭니다.
- **절단 길(broken path).** 이웃 범위가 너무 작거나 밀도가 고르지 않으면 그래프가 여러 연결 요소로 나뉩니다. 요소 사이의 거리는 무한대가 되어 MDS 단계를 진행할 수 없습니다.

두 문제는 $k$($\epsilon$)를 키우느냐 줄이느냐의 양쪽 끝에 있어서, 하나의 고정된 이웃 크기로 동시에 피하기 어렵습니다.

**실험으로 확인.** 잡음을 넣은 스위스 롤(`make_swiss_roll(800, noise=0.6, random_state=0)`)에서 그래프를 만들고 다음을 쟀습니다. 스위스 롤은 펼치면 직사각형이므로 참 측지선 거리를 정확히 계산할 수 있습니다(감긴 방향 좌표는 나선의 호 길이 $s(t) = \frac{1}{2}\left(t\sqrt{1+t^2} + \operatorname{arcsinh} t\right)$).

- 연결 요소 수(1이 아니면 절단 길)
- 단축 간선 수: 참 측지선 거리가 직선 거리보다 4 이상 큰 간선(층 사이 간격이 약 $2\pi$이므로 잡음 수준보다 충분히 큰 기준)
- 그래프 최단 경로 거리와 참 측지선 거리의 상관계수(연결된 쌍만 계산)

| 그래프 | 연결 요소 | 단축 간선 | 상관계수 |
|--------|----------|----------|---------|
| $k = 3$ | 4 | 0 | 0.932 |
| $k = 4$ | 1 | 0 | 0.987 |
| $k = 6$ | 1 | 0 | 0.997 |
| $k = 10$ | 1 | 3 | 0.706 |
| $k = 20$ | 1 | 155 | 0.319 |
| $k = 30$ | 1 | 732 | 0.264 |
| $\epsilon = 1.5$ | 222 | 0 | 0.916 |
| $\epsilon = 3.0$ | 2 | 0 | 0.987 |
| $\epsilon = 5.0$ | 1 | 103 | 0.307 |

$k = 10$에서 단축 간선이 3개뿐인데도 상관계수가 0.997에서 0.706으로 떨어지는 것이 단축 길의 위험을 잘 보여 줍니다. $k$가 작거나 $\epsilon$이 작으면 반대로 그래프가 끊깁니다. (끊긴 그래프의 상관계수는 연결 요소 안의 쌍만으로 계산한 값이라 높게 나오지만, 이 상태로는 Isomap을 돌릴 수 없습니다.)

**해결 방안.**

*단축 길에 대한 대책*

1. **이웃 크기를 데이터로 고릅니다.** 여러 $k$로 Isomap을 돌려 잔차 분산(측지선 거리와 임베딩 거리의 불일치)이 작은 값을 고르거나, $k$를 늘릴 때 측지선 거리가 갑자기 크게 줄어드는 지점을 단축이 생긴 신호로 봅니다.
2. **상호 k근접 그래프.** $\boldsymbol{x}_i$와 $\boldsymbol{x}_j$가 서로의 $k$근접 안에 있을 때만 연결합니다. 층 사이를 잇는 간선은 한쪽에서만 이웃인 경우가 많아 상당수 걸러집니다.
3. **접평면 검사.** 매니폴드는 국소적으로 평면에 가깝다는 성질을 이용합니다. 각 점에서 이웃으로 국소 PCA를 해 법선 방향을 구하고, 간선 방향이 접평면에서 크게 벗어나는(법선과 이루는 각의 코사인이 큰) 간선을 지웁니다. 층 사이를 잇는 간선은 대체로 법선 방향이라 잘 걸러집니다.
4. **잡음과 이상치를 먼저 처리합니다.** 평활화나 이상치 제거로 층 사이의 "다리"가 되는 점을 없앱니다. 많은 최단 경로가 몰리는(그래프 흐름이 비정상적으로 큰) 간선이나 점을 단축의 원인으로 보고 제거하는 방법도 있습니다.

*절단 길에 대한 대책*

1. **최소 신장 트리(MST)를 더합니다.** 전체 점의 MST 간선을 이웃 그래프에 합치면 항상 연결 그래프가 됩니다. MST는 가장 짧은 간선들로 요소를 잇기 때문에 단축을 거의 만들지 않습니다.
2. **적응형 이웃.** 점마다 밀도에 맞춰 $k$나 $\epsilon$을 다르게 잡아, 성긴 영역에서만 이웃을 넓힙니다. $k$근접과 $\epsilon$근접을 섞어 쓰는 것도 같은 생각입니다.
3. **연결 요소별로 처리합니다.** 요소마다 따로 임베딩한 뒤 정렬하거나, 가장 큰 요소만 임베딩하고 나머지는 새 샘플처럼 사상합니다.

실험에서 두 대책을 조합해 보았습니다. 핵심 코드는 다음과 같습니다.

```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import minimum_spanning_tree
from scipy.spatial.distance import pdist, squareform

E = squareform(pdist(X))                  # X: 800 x 3 스위스 롤 샘플

def add_mst(G):
    # 절단 길 대책: 전체 최소 신장 트리 간선을 합쳐 연결을 보장
    T = minimum_spanning_tree(csr_matrix(E))
    return G.maximum(G.T).maximum(T).maximum(T.T)

def tangent_prune(G, k_pca=10, tau=0.5):
    # 단축 길 대책: 점마다 이웃 k_pca개로 국소 PCA를 해 법선 n_i를 구하고,
    # 간선 방향과 법선의 |cos|가 tau보다 크면(접평면에서 벗어나면) 제거
    idx = np.argsort(E, axis=1)[:, 1:k_pca + 1]
    N = np.empty_like(X)
    for a in range(len(X)):
        P = X[idx[a]] - X[idx[a]].mean(0)
        N[a] = np.linalg.svd(P)[2][-1]    # 분산이 가장 작은 방향 = 법선
    G = G.maximum(G.T).tocoo()
    d = (X[G.col] - X[G.row]) / G.data[:, None]
    bad = np.maximum(abs((d * N[G.row]).sum(1)), abs((d * N[G.col]).sum(1))) > tau
    return csr_matrix((G.data[~bad], (G.row[~bad], G.col[~bad])), shape=G.shape)

# 사용 예: G = kneighbors_graph(X, 20, mode="distance"); G2 = add_mst(tangent_prune(G))
```

| 그래프 | 연결 요소 | 단축 간선 | 상관계수 |
|--------|----------|----------|---------|
| $k = 3$ + MST | 1 | 0 | 0.985 |
| $\epsilon = 1.5$ + MST | 1 | 0 | 0.907 |
| $k = 10$ 상호 kNN | 1 | 0 | 0.998 |
| $k = 20$ 상호 kNN | 1 | 1 | 0.779 |
| $k = 30$ 상호 kNN | 1 | 43 | 0.396 |
| $k = 10$ 접평면 검사 + MST | 1 | 0 | 0.998 |
| $k = 20$ 접평면 검사 + MST | 1 | 0 | 0.998 |
| $k = 30$ 접평면 검사 + MST | 1 | 2 | 0.843 |

MST를 더하면 너무 작은 $k$나 $\epsilon$에서도 그래프가 하나로 이어지고, 접평면 검사는 $k = 20$의 단축 간선 155개를 모두 걸러 상관계수를 0.319에서 0.998로 되돌렸습니다. 다만 $k = 30$처럼 이웃이 지나치게 크면 국소 평면 가정 자체가 흔들려 일부 단축이 남습니다. 결국 "넉넉한 이웃으로 연결성을 확보하고, 국소 기하로 잘못된 간선을 걸러내며, MST로 연결을 보장한다"는 조합이 실용적이고, 이웃 크기 선택은 여전히 검증이 필요합니다.

## 문제 10.9\* (심화)

> 새로운 샘플을 위해, LEE 차원 축소 후의 저차원 좌표를 찾을 수 있는 방법을 만들어 보아라.

**풀이**

문제의 "LEE"는 10.5.2절의 LLE(국소적 선형 임베딩)를 가리키는 것으로 보고 풀었습니다.

**Step 1. 식 10.28의 유도.** 새 샘플에도 같은 재구성 가중치 계산을 쓰므로, 먼저 식 10.27의 해가 식 10.28임을 보이겠습니다. 샘플 $\boldsymbol{x}_i$ 하나에 대한 문제는

$$\min_{\boldsymbol{w}_i} \left\| \boldsymbol{x}_i - \sum_{j \in Q_i} w_{ij}\boldsymbol{x}_j \right\|_2^2 \quad \text{s.t.} \quad \sum_{j \in Q_i} w_{ij} = 1$$

입니다. 제약 $\sum_j w_{ij} = 1$을 이용하면 $\boldsymbol{x}_i = \sum_j w_{ij}\boldsymbol{x}_i$이므로

$$\boldsymbol{x}_i - \sum_{j} w_{ij}\boldsymbol{x}_j = \sum_{j} w_{ij}(\boldsymbol{x}_i - \boldsymbol{x}_j).$$

따라서 목적 함수는

$$\left\| \sum_{j} w_{ij}(\boldsymbol{x}_i - \boldsymbol{x}_j) \right\|_2^2 = \sum_{j \in Q_i}\sum_{k \in Q_i} w_{ij}w_{ik}(\boldsymbol{x}_i - \boldsymbol{x}_j)^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_k) = \boldsymbol{w}_i^{\mathrm{T}}\mathbf{C}\boldsymbol{w}_i$$

이고, 여기서 $C_{jk} = (\boldsymbol{x}_i - \boldsymbol{x}_j)^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_k)$는 책의 정의와 같습니다. 라그랑주 함수를 $L = \boldsymbol{w}_i^{\mathrm{T}}\mathbf{C}\boldsymbol{w}_i - \lambda(\mathbf{1}^{\mathrm{T}}\boldsymbol{w}_i - 1)$로 두고 미분하면($\mathbf{C}$는 대칭)

$$\frac{\partial L}{\partial \boldsymbol{w}_i} = 2\mathbf{C}\boldsymbol{w}_i - \lambda\mathbf{1} = \mathbf{0} \;\Rightarrow\; \boldsymbol{w}_i = \frac{\lambda}{2}\mathbf{C}^{-1}\mathbf{1}.$$

제약에 대입하면 $\frac{\lambda}{2}\mathbf{1}^{\mathrm{T}}\mathbf{C}^{-1}\mathbf{1} = 1$이므로 $\frac{\lambda}{2} = \frac{1}{\mathbf{1}^{\mathrm{T}}\mathbf{C}^{-1}\mathbf{1}}$이고,

$$\boldsymbol{w}_i = \frac{\mathbf{C}^{-1}\mathbf{1}}{\mathbf{1}^{\mathrm{T}}\mathbf{C}^{-1}\mathbf{1}}, \qquad w_{ij} = \frac{\sum_{k \in Q_i} C^{-1}_{jk}}{\sum_{l, s \in Q_i} C^{-1}_{ls}}$$

로 식 10.28을 얻습니다($C^{-1}_{jk}$는 $\mathbf{C}^{-1}$의 $(j, k)$ 원소). $\mathbf{C}$는 벡터 $\boldsymbol{x}_i - \boldsymbol{x}_j$들의 그람 행렬이라 양의 준정부호이고, 목적 함수가 볼록하고 제약이 선형이므로 이 정류점이 최솟값입니다. 이웃 수 $k$가 차원 $d$보다 크면 $\mathbf{C}$의 계수가 $d$ 이하라서 역행렬이 없으므로, 실제로는 $\mathbf{C} + \delta\mathbf{I}$($\delta$는 $\operatorname{tr}(\mathbf{C})$에 작은 상수를 곱한 값)로 정규화합니다.

**Step 2. 새 샘플의 사상 방법.** LLE의 핵심 가정은 "고차원에서 이웃으로 자신을 재구성하는 가중치가 저차원에서도 유지된다"는 것입니다(식 10.26 아래 설명). 이를 새 샘플 $\boldsymbol{x}$에 그대로 적용합니다.

1. 훈련 샘플 중에서 $\boldsymbol{x}$의 $k$근접 이웃 집합 $Q$를 찾습니다.
2. Step 1의 식으로 $\boldsymbol{x}$를 $Q$로 재구성하는 가중치 $\boldsymbol{w}$를 구합니다. 이때 $C_{jk} = (\boldsymbol{x} - \boldsymbol{x}_j)^{\mathrm{T}}(\boldsymbol{x} - \boldsymbol{x}_k)$입니다.
3. 이미 구해 둔 훈련 샘플의 저차원 좌표로 $\boldsymbol{z} = \sum_{j \in Q} w_j\boldsymbol{z}_j$를 계산합니다.

3단계는 임의로 정한 것이 아닙니다. 훈련 샘플의 좌표 $\boldsymbol{z}_j$를 고정한 채 식 10.29에 새 샘플의 항을 더하면, 새로 정해야 하는 변수는 $\boldsymbol{z}$ 하나이고 그 항은 $\left\|\boldsymbol{z} - \sum_{j} w_j\boldsymbol{z}_j\right\|_2^2$입니다. 이 값을 최소화(0으로 만드는)하는 $\boldsymbol{z}$가 바로 $\sum_j w_j\boldsymbol{z}_j$입니다. 즉 이 방법은 "기존 임베딩은 그대로 두고 식 10.29를 새 샘플에 대해서만 푼 해"입니다. 계산량은 이웃 탐색과 $k \times k$ 선형 방정식 하나로, 전체 고윳값 분해를 다시 하지 않아도 됩니다.

**Step 3. 구현과 실험.** 그림 10.10의 LLE와 위의 사상을 numpy로 구현했습니다.

```python
import numpy as np
from sklearn.datasets import make_swiss_roll

def lle_weights(x, nbrs, reg=1e-3):
    G = x - nbrs                                   # k x d, 각 행이 x - x_j
    C = G @ G.T                                    # C_jk = (x - x_j)^T (x - x_k)
    C += np.eye(len(C)) * reg * max(np.trace(C), 1e-12)   # k > d 이면 정규화 필요
    w = np.linalg.solve(C, np.ones(len(C)))        # C^{-1} 1
    return w / w.sum()                             # 식 10.28

def knn_idx(A, B, k, skip_self=False):
    o = np.argsort(((A[:, None, :] - B[None, :, :])**2).sum(-1), axis=1)
    return o[:, 1:k+1] if skip_self else o[:, :k]

def lle_fit(X, k, d2):
    m = len(X); W = np.zeros((m, m))
    Q = knn_idx(X, X, k, skip_self=True)
    for i in range(m):
        W[i, Q[i]] = lle_weights(X[i], X[Q[i]])    # 식 10.27, 이웃이 아니면 0
    M = (np.eye(m) - W).T @ (np.eye(m) - W)        # 식 10.30
    lam, V = np.linalg.eigh(M)                     # 오름차순 고윳값
    return V[:, 1:d2 + 1]                          # 고윳값 0인 상수 벡터는 버림

def lle_transform(X_new, X, Z, k):                 # 새 샘플의 저차원 좌표
    Q = knn_idx(X_new, X, k)
    return np.array([lle_weights(x, X[q]) @ Z[q] for x, q in zip(X_new, Q)])

Xtr, ttr = make_swiss_roll(1000, random_state=0)   # 훈련 샘플
Xte, tte = make_swiss_roll(300, random_state=1)    # 새 샘플
Ztr = lle_fit(Xtr, k=12, d2=2)
Zte = lle_transform(Xte, Xtr, Ztr, k=12)
```

`lle_fit`에서 가장 작은 고윳값의 고유 벡터를 하나 버린 이유를 덧붙입니다. $\mathbf{W}$의 각 행의 합이 1이므로 $(\mathbf{I} - \mathbf{W})\mathbf{1} = \mathbf{0}$이고, 따라서 $\mathbf{M}\mathbf{1} = \mathbf{0}$입니다. 즉 상수 벡터가 항상 고윳값 0의 고유 벡터인데, 모든 샘플을 같은 좌표로 보내는 의미 없는 해라서 실제 구현에서는 두 번째부터 $d'+1$번째까지를 씁니다.

결과는 다음과 같습니다.

| 평가 | 훈련 샘플 | 새 샘플 |
|------|----------|--------|
| 임베딩으로 $t$(감긴 방향)를 선형 회귀한 $R^2$ | 0.9841 | 0.9835 |
| 임베딩으로 $h$(높이)를 선형 회귀한 $R^2$ | 0.7189 | 0.7110 |

새 샘플이 훈련 샘플과 같은 품질로 저차원 공간에 놓였습니다. 한 가지 더, 훈련 샘플과 새 샘플 1,300개를 모두 넣어 LLE를 다시 돌린 좌표를 기준으로 비교했습니다. 두 임베딩은 회전·척도 차이가 있으므로 훈련 샘플 1,000개로 아핀 변환을 맞춘 뒤 새 샘플 300개의 상대 오차를 재면 0.1585였습니다. 같은 정렬을 훈련 샘플 자신에게 적용해도 0.1565가 나오므로, 이 차이는 LLE를 다시 돌릴 때 생기는 변동 수준이고 사상 방법 자체의 오차는 거의 없다고 볼 수 있습니다. 가중치 없이 $k$개 이웃 좌표의 단순 평균을 쓰면 0.1672로 조금 나빠졌습니다. 구현 검증으로, scikit-learn `LocallyLinearEmbedding`이 학습한 좌표에 같은 사상을 적용한 결과는 그 라이브러리의 `transform` 결과와 최대 $4 \times 10^{-17}$ 차이로 일치했습니다.

**다른 방법들.** 책 279쪽이 Isomap에 대해 소개한 것처럼, 훈련 샘플의 $(\boldsymbol{x}_i, \boldsymbol{z}_i)$ 쌍으로 회귀 모델(커널 회귀, 신경망 등)을 학습해 새 샘플의 좌표를 예측할 수도 있습니다. 새 샘플이 많이 쌓이면 $\mathbf{M}$을 갱신해 고윳값 문제를 점진적으로 다시 푸는 방법도 있습니다. 위의 재구성 가중치 방법은 추가 학습 없이 LLE의 가정을 그대로 쓴다는 점에서 가장 자연스럽지만, 새 샘플의 좌표는 이웃 좌표의 아핀 결합(가중치 합 1)으로만 정해지므로, 훈련 샘플이 덮지 못한 영역으로 멀리 벗어난 샘플에 대해서는 외삽을 기대하기 어렵습니다.

## 문제 10.10

> 척도 학습이 생성한 거리가 거리척도의 네 가지 성질을 만족하게 만드는 방법을 기술하라.

**풀이**

9.3절의 네 가지 성질은 비음수성(식 9.14), 동일성(식 9.15, $\boldsymbol{x}_i = \boldsymbol{x}_j$일 때만 0), 대칭성(식 9.16), 삼각부등식(식 9.17)입니다. 10.6절의 마할라노비스 거리를 기준으로 각 성질이 언제 성립하는지 확인하고, 그에 맞는 방법을 정리하겠습니다.

**Step 1. 제곱이 아니라 제곱근을 거리로 씁니다.** 식 10.34는 $\operatorname{dist}^2_{\text{mah}}$, 즉 거리의 제곱을 정의합니다. 제곱 거리 자체는 삼각부등식을 만족하지 않습니다. 1차원에서 $\mathbf{M} = 1$, 점 0, 1, 2를 잡으면 $(2-0)^2 = 4 > 1^2 + 1^2 = 2$입니다. 실제로 무작위 3차원 점 세 개를 10만 번 뽑아 보니(시드 0), 제곱 거리는 27,797번 삼각부등식을 어겼고 제곱근 거리는 한 번도 어기지 않았습니다. 따라서 거리척도로 쓸 것은

$$\operatorname{dist}_{\mathbf{M}}(\boldsymbol{x}_i, \boldsymbol{x}_j) = \sqrt{(\boldsymbol{x}_i - \boldsymbol{x}_j)^{\mathrm{T}}\mathbf{M}(\boldsymbol{x}_i - \boldsymbol{x}_j)}$$

입니다.

**Step 2. $\mathbf{M}$이 양의 준정부호 대칭이면 세 가지 성질이 성립합니다.** $\mathbf{M} = \mathbf{P}\mathbf{P}^{\mathrm{T}}$로 쓰면

$$\operatorname{dist}_{\mathbf{M}}(\boldsymbol{x}_i, \boldsymbol{x}_j) = \sqrt{(\boldsymbol{x}_i - \boldsymbol{x}_j)^{\mathrm{T}}\mathbf{P}\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_j)} = \left\|\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_j)\right\|_2$$

로, 선형 변환 $\mathbf{P}^{\mathrm{T}}$를 한 뒤의 유클리드 거리입니다.

- 비음수성: 노름이므로 $\geqslant 0$입니다.
- 대칭성: $\|\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_j)\|_2 = \|-\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_j - \boldsymbol{x}_i)\|_2 = \|\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_j - \boldsymbol{x}_i)\|_2$입니다.
- 삼각부등식: $\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_j) = \mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_k) + \mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_k - \boldsymbol{x}_j)$이므로 유클리드 노름의 삼각부등식에서 바로 나옵니다.

$\mathbf{M}$이 대칭이 아니거나 음의 고윳값을 가지면 제곱근 안이 음수가 될 수 있어 이 성질들이 깨집니다. 책에서 $\mathbf{M}$이 "반드시 양의 준정부호 대칭 행렬"이어야 한다고 한 이유입니다.

**Step 3. 동일성에는 양의 정부호가 필요합니다.** 위 식에서 거리가 0이 되는 조건은 $\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_j) = \mathbf{0}$, 즉 $\boldsymbol{x}_i - \boldsymbol{x}_j$가 $\mathbf{M}$의 영공간에 있는 것입니다. $\mathbf{M}$이 저순위(양의 준정부호이지만 정부호가 아님)이면 서로 다른 두 점의 거리가 0이 될 수 있습니다. 계수 2인 $3 \times 3$ 행렬 $\mathbf{M}$로 확인하면, 영공간 방향으로 1만큼 떨어진 두 점의 거리가 정확히 0이었습니다. 이런 거리는 동일성만 빠진 유사 거리척도(pseudo-metric)입니다. 따라서 네 성질을 모두 만족하려면 $\mathbf{M} \succ 0$(양의 정부호)이어야 합니다.

**Step 4. 학습 과정에서 이 조건을 보장하는 방법.**

1. **분해 형태로 매개화합니다.** NCA(식 10.38)처럼 $\mathbf{M} = \mathbf{P}\mathbf{P}^{\mathrm{T}}$의 $\mathbf{P}$를 학습하면 양의 준정부호와 대칭이 자동으로 보장됩니다. 동일성까지 원하면 $\mathbf{P}$를 $d \times d$ 정방 행렬로 두고 계수가 $d$가 되게 하거나, 대각 원소가 양수인 하삼각 행렬 $\mathbf{L}$로 $\mathbf{M} = \mathbf{L}\mathbf{L}^{\mathrm{T}}$(촐레스키 형태)로 매개화합니다.
2. **양의 정부호 원뿔로 투영합니다.** 식 10.39처럼 $\mathbf{M}$을 직접 최적화할 때는 경사 하강 한 단계마다 $\mathbf{M} \leftarrow (\mathbf{M} + \mathbf{M}^{\mathrm{T}})/2$로 대칭화하고, 고윳값 분해 $\mathbf{M} = \mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{\mathrm{T}}$ 후 $\lambda_i \leftarrow \max(\lambda_i, \varepsilon)$로 잘라 다시 합칩니다. $\varepsilon = 0$이면 양의 준정부호, $\varepsilon > 0$이면 양의 정부호가 됩니다. 실험에서 고윳값이 $(-0.401, 0.533, 2.917)$인 대칭 행렬이 $\varepsilon = 10^{-3}$ 투영 후 $(0.001, 0.533, 2.917)$이 되었습니다.
3. **작은 항등 행렬을 더합니다.** 학습이 끝난 양의 준정부호 $\mathbf{M}$에 $\varepsilon\mathbf{I}$를 더하면 $\mathbf{M} + \varepsilon\mathbf{I} \succ 0$입니다. 거리로 보면 $\operatorname{dist}^2 = \|\mathbf{P}^{\mathrm{T}}(\boldsymbol{x}_i - \boldsymbol{x}_j)\|^2 + \varepsilon\|\boldsymbol{x}_i - \boldsymbol{x}_j\|^2$이라 원래 거리 구조를 거의 바꾸지 않습니다. 앞의 저순위 예에서 $\varepsilon = 0.01$을 더하자 거리가 0에서 0.1이 되었습니다.
4. **차원 축소로 해석합니다.** 저순위 $\mathbf{M}$을 일부러 쓰는 경우(책 285쪽), 원래 공간에서는 유사 거리척도지만 투영된 공간 $\boldsymbol{z} = \mathbf{P}^{\mathrm{T}}\boldsymbol{x}$에서는 유클리드 거리이므로 네 성질을 모두 만족합니다. 즉 "어느 공간의 거리척도인가"를 명확히 하면 됩니다.

**Step 5. 마할라노비스 형태가 아닌 학습된 거리라면.** 비선형 함수 $f$로 $\operatorname{dist}(\boldsymbol{x}_i, \boldsymbol{x}_j) = \|f(\boldsymbol{x}_i) - f(\boldsymbol{x}_j)\|_2$ 형태를 쓰면 Step 2와 같은 이유로 비음수성, 대칭성, 삼각부등식은 자동으로 성립하고, 동일성은 $f$가 단사일 때 성립합니다. 임의의 비유사도 행렬 $\mathbf{S}$를 학습한 경우라면 $(\mathbf{S} + \mathbf{S}^{\mathrm{T}})/2$로 대칭화하고, 음수를 0으로 자르고, 대각을 0으로 두고, 마지막으로 모든 쌍의 최단 경로 거리로 바꾸면(플로이드 알고리즘) 삼각부등식이 보장됩니다. 동일성을 위해서는 서로 다른 점 사이에 $\varepsilon\|\boldsymbol{x}_i - \boldsymbol{x}_j\|$ 같은 작은 진짜 거리척도를 더합니다. 유사 거리척도와 거리척도의 합은 거리척도이기 때문입니다.
